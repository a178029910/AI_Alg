1引言：机器学习范式概览

机器学习的学习范式（Learning Paradigm）是指模型从数据中获取知识的根本方式。不同的范式在数据标注程度、学习目标和反馈信号上存在本质差异，决定了模型的训练流程、适用场景和性能上限。

理解学习范式的核心框架可以从三个维度切入：

  • 标注信号：数据是否带有人工标注的标签（label），以及标签的完整性和准确性。
  • 学习目标：模型是学习输入到输出的映射、发现数据的内在结构，还是构建可迁移的通用表示。
  • 反馈机制：训练过程中是否有显式的奖励/惩罚信号引导模型优化。

1.2 范式之间的关系

各范式并非完全独立，而是存在递进和融合关系：

  • 有监督是最基础的范式，提供了"从标注中学习"的标准框架。
  • 无监督探索数据自身的结构，不依赖外部标签。
  • 半监督介于两者之间，用少量标注引导大量无标注数据的学习。
  • 自监督从无标注数据中自动构造监督信号（pretext task），是当前大模型预训练的核心范式。
  • 弱监督放宽了对标签质量的要求，包括不完整、不精确和不准确的标注。
范式融合趋势

当前（2024-2025）最主流的范式组合是 自监督预训练 + 少量有监督微调 + RLHF 对齐，几乎所有 SOTA 大模型（GPT-4、LLaMA、Gemini）都遵循这一路线。

2有监督学习（Supervised Learning）

2.1 定义与基本范式

有监督学习从标注数据集 $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^{N}$ 中学习一个映射函数 $f: \mathcal{X} \to \mathcal{Y}$，使得对未见输入 $\mathbf{x}$ 能预测正确的输出 $y$。训练目标是最小化经验风险：

$$\theta^* = \arg\min_{\theta} \frac{1}{N} \sum_{i=1}^{N} \mathcal{L}(f_\theta(\mathbf{x}_i), y_i) + \lambda \Omega(\theta)$$

其中 $\mathcal{L}$ 是损失函数（分类用交叉熵、回归用 MSE），$\Omega(\theta)$ 是正则化项，$\lambda$ 控制正则化强度。

2.2 两大子类

子类输出空间损失函数典型应用
分类（Classification）离散类别 $\{1, \ldots, K\}$交叉熵 $\mathcal{L} = -\sum_k y_k \log \hat{y}_k$图像分类、垃圾邮件检测
回归（Regression）连续值 $\mathbb{R}$MSE $\mathcal{L} = (f(\mathbf{x}) - y)^2$房价预测、温度预测

2.3 经典方法谱系

  • 线性模型：逻辑回归、线性回归 — 简洁、可解释、适合基线。
  • 核方法：SVM、核岭回归 — 通过核技巧处理非线性。
  • 树模型：决策树（CART、ID3、C4.5）、随机森林、GBDT — 天然处理混合类型特征。
  • 深度模型：CNN（图像）、RNN/Transformer（序列） — 端到端表征学习。

2.4 深度学习时代的有监督训练

深度学习将特征工程融入端到端训练。以图像分类为例，标准流程为：

$$\mathbf{z} = \text{CNN}(\mathbf{x}), \quad \hat{y} = \text{softmax}(\mathbf{W}\mathbf{z} + \mathbf{b}), \quad \mathcal{L} = -\log \hat{y}_{y_{\text{true}}}$$

2.5 近两年新技术（2024-2025）

大模型监督微调（SFT）

大模型时代的有监督学习核心是监督微调（Supervised Fine-Tuning, SFT）：在自监督预训练基础上，用高质量指令-响应对训练模型遵循指令。LLaMA-3、Qwen-2 等均采用 SFT 作为对齐的第一阶段。

指令微调与对话微调

指令微调（Instruction Tuning）将多任务统一为自然语言指令格式，使模型获得任务泛化能力。ChatGPT、Claude 等均通过指令微调实现多轮对话能力。2024 年的代表性工作包括FLAN-T5 升级版和NVIDIA Nemotron。

参数高效微调（PEFT）

LoRA（Low-Rank Adaptation）及其变体（QLoRA、AdaLoRA）成为大模型有监督微调的标准方法：冻结预训练权重，仅训练低秩适配矩阵，将可训练参数降至 0.1% 以下。2024-2025 年 DoRA、PiSSA 等进一步改进了 LoRA 的表达能力。

RLHF 与 RLVR

RLHF（Reinforcement Learning from Human Feedback）和 RLVR（Reinforcement Learning from Verifiable Rewards）将人类偏好或可验证奖励融入训练。OpenAI o1/o3、DeepSeek-R1 均使用大规模 RLVR 训练推理能力，代表了有监督学习向奖励驱动学习的延伸。

有监督学习的瓶颈

高质量标注数据的获取成本随任务复杂度指数增长。在医学影像、法律文本等专业领域，单条标注成本可达数百元。这是推动半监督、自监督范式发展的核心动力。

3无监督学习（Unsupervised Learning）

3.1 定义与目标

无监督学习从无标签数据 $\mathcal{D} = \{\mathbf{x}_i\}_{i=1}^{N}$ 中发现数据的内在结构、分布或关系。没有外部标签指导，模型完全依赖数据自身的统计特性进行学习。其通用目标可表述为：

$$\theta^* = \arg\min_{\theta} \frac{1}{N} \sum_{i=1}^{N} \mathcal{L}_{\text{self}}(f_\theta(\mathbf{x}_i))$$

其中 $\mathcal{L}_{\text{self}}$ 是由任务定义的自驱动损失，如重建误差、聚类紧凑度或散度最小化。

3.2 核心任务与方法

任务目标代表方法公式核心
聚类（Clustering）将相似样本归为一组K-Means、DBSCAN、层次聚类$\min \sum_k \sum_{i \in C_k} \|\mathbf{x}_i - \boldsymbol{\mu}_k\|^2$
降维（Dimensionality Reduction）压缩到低维保留信息PCA、t-SNE、UMAP$\max \text{Var}(\mathbf{X}\mathbf{w})$
密度估计（Density Estimation）估计数据分布 $p(\mathbf{x})$GMM、KDE、VAE$\max \sum_i \log p_\theta(\mathbf{x}_i)$
异常检测（Anomaly Detection）识别偏离分布的样本Isolation Forest、Autoencoder$\text{score} = \|\mathbf{x} - \hat{\mathbf{x}}\|^2$

3.3 深度无监督学习

自编码器（Autoencoder）

通过编码器-解码器结构学习压缩表示：$\mathbf{z} = E(\mathbf{x})$，$\hat{\mathbf{x}} = D(\mathbf{z})$，损失为重建误差：

$$\mathcal{L}_{\text{AE}} = \|\mathbf{x} - D(E(\mathbf{x}))\|^2$$

VAE 引入概率建模，优化 ELBO：

$$\mathcal{L}_{\text{VAE}} = \mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})}[\log p_\theta(\mathbf{x}|\mathbf{z})] - D_{\text{KL}}(q_\phi(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}))$$

生成对抗网络（GAN）

生成器 $G$ 与判别器 $D$ 博弈，目标函数为：

$$\min_G \max_D \; \mathbb{E}_{\mathbf{x} \sim p_{\text{data}}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim p_z}[\log(1 - D(G(\mathbf{z})))]$$

3.4 近两年新技术（2024-2025）

扩散模型（Diffusion Models）

扩散模型已成为无监督生成的新主流。前向过程逐步加噪 $q(\mathbf{x}_t | \mathbf{x}_{t-1})$，反向过程学习去噪 $p_\theta(\mathbf{x}_{t-1} | \mathbf{x}_t)$。DDPM 的训练目标简化为：

$$\mathcal{L}_{\text{diff}} = \mathbb{E}_{t, \mathbf{x}_0, \boldsymbol{\epsilon}} \left[ \| \boldsymbol{\epsilon} - \epsilon_\theta(\mathbf{x}_t, t) \|^2 \right]$$

2024-2025 年代表性进展：Stable Diffusion 3（改进的 Rectified Flow 采样）、Sora（视频扩散）、DiT（Diffusion Transformer 架构）。扩散模型本质上是无监督学习，从数据分布中学习生成能力。

大模型时代的无监督聚类

传统 K-Means 在高维嵌入空间中效果有限。2024 年出现了基于大模型嵌入 + 屌次聚类的新方法，如利用 BERT/CLIP 嵌入做语义聚类（SE-Clustering），在无标注场景下实现了接近有监督方法的聚类精度。

无监督表示学习新范式

2024-2025 年，掩码图像建模（MIM）和掩码语言建模（MLM）已成为无监督表示学习的主流方向。MAE 在视觉领域、BERT 在语言领域证明了：通过重建被遮盖的部分，模型能学到高质量的通用表示。

4半监督学习（Semi-Supervised Learning）

4.1 定义与问题动机

半监督学习利用少量标注数据 + 大量无标注数据联合训练。设标注集 $\mathcal{D}_L = \{(\mathbf{x}_i, y_i)\}_{i=1}^{L}$ 和无标注集 $\mathcal{D}_U = \{\mathbf{x}_j\}_{j=1}^{U}$，通常 $L \ll U$。目标是比仅用 $L$ 训练获得更好的性能。优化目标可形式化为：

$$\theta^* = \arg\min_\theta \left[ \sum_{(\mathbf{x},y) \in \mathcal{D}_L} \mathcal{L}_{\text{sup}}(f_\theta(\mathbf{x}), y) + \lambda_U \sum_{\mathbf{x} \in \mathcal{D}_U} \mathcal{L}_{\text{unsup}}(f_\theta(\mathbf{x})) \right]$$

4.2 三大假设

半监督学习依赖于以下假设才能有效利用无标注数据：

  • 平滑假设（Smoothness）：如果两个样本在输入空间中接近，它们的标签也应相同。
  • 聚类假设（Cluster）：同一聚类中的样本倾向于有相同标签。
  • 流形假设（Manifold）：高维数据集中在一个低维流形上，无标注数据有助于刻画流形结构。

4.3 经典方法

一致性正则（Consistency Regularization）

对同一输入施加不同扰动，模型应给出一致预测。代表方法 Π-Model 和 Mean Teacher：

$$\mathcal{L}_{\text{cons}} = \| f_\theta(\mathbf{x}) - f_{\theta'}(\text{aug}(\mathbf{x})) \|^2$$

Mean Teacher 用 EMA（指数移动平均）更新 $\theta'$，使教师模型更稳定。

伪标签（Pseudo-Label）

用模型对无标注数据的预测生成伪标签，再将高置信度伪标签加入训练集。FixMatch 结合一致性正则和伪标签，在极低标注量下达到全监督性能：

$$\mathcal{L}_{\text{FixMatch}} = \mathcal{L}_s + \lambda_u \cdot \mathbb{1}(\max(p) \geq \tau) \cdot \mathcal{L}_u$$

图方法（Graph-Based）

构建样本相似图，通过标签传播（Label Propagation）将标注信息扩散到无标注节点。

4.4 近两年新技术（2024-2025）

异构半监督学习（HSSL）

CVPR 2025 提出异构半监督学习（Uni-HSSL），解决了有标签和无标签数据来自不同领域的新问题设定。传统方法假设标注和无标注数据同分布，Uni-HSSL 通过统一框架连接半监督学习（SSL）和无监督域适应（UDA），在异构数据上实现知识迁移。

半监督医学图像分割

2024-2025 年半监督学习在医学图像分割取得显著进展。代表性工作 BoCLIS（TMI 2025）结合边界引导对比学习和平均教师网络，在标注量仅为 10% 时将分割精度提升 20%。关键技术包括不确定性加权、边界感知对比损失和跨切片一致性正则。

大模型辅助半监督学习

利用大语言模型（LLM）或视觉语言模型（VLM）自动生成伪标签，再结合传统半监督方法进行训练。2024 年出现了 LLM-as-annotator 范式：用 GPT-4 标注大量无标注数据，再用半监督方法训练小模型，在成本和性能间取得平衡。

半监督目标检测

在目标检测领域，SoftTeacher（2021）开创了半监督检测框架，2024-2025 年的改进包括多尺度伪标签融合和类别自适应阈值，在 COCO 上以 10% 标注达到 90% 全监督性能。

半监督学习的价值

半监督学习是在标注成本和数据规模间取得平衡的实用范式。在标注预算有限时，用少量标注+大量无标注数据往往能获得显著优于纯有监督的性能提升。

5自监督学习（Self-Supervised Learning）

5.1 定义与核心思想

自监督学习从无标注数据中自动构造监督信号（pretext task / proxy task），使模型在不依赖人工标注的情况下学习通用表示。其核心是：将数据自身的某一部分作为标签，让模型预测被隐藏或变换的部分。

$$\theta^* = \arg\min_\theta \mathbb{E}_{\mathbf{x} \sim \mathcal{D}} \left[ \mathcal{L}_{\text{pretext}}(f_\theta(\mathbf{x}), \text{target}(\mathbf{x})) \right]$$

其中 $\text{target}(\mathbf{x})$ 由数据 $\mathbf{x}$ 本身自动构造，无需人工标注。

5.2 NLP 领域：掩码语言建模

BERT 的掩码语言建模（MLM）是自监督学习的经典范例：随机遮盖 15% 的 token，让模型预测被遮盖的词。GPT 系列则使用因果语言建模（CLM）：根据上文预测下一个 token。这两种方式均无需人工标注，利用文本自身结构构造监督信号。

5.3 CV 领域：对比学习与掩码建模

对比学习（Contrastive Learning）

SimCLR、MoCo 系列通过实例判别学习表示：对同一图像的不同增强视图拉近（正样本对），对不同图像的视图推远（负样本对）。InfoNCE 损失：

$$\mathcal{L}_{\text{NCE}} = -\log \frac{\exp(\text{sim}(\mathbf{z}_i, \mathbf{z}_j^+) / \tau)}{\sum_k \exp(\text{sim}(\mathbf{z}_i, \mathbf{z}_k) / \tau)}$$

2024-2025 年对比学习在视觉自监督中的地位逐渐被掩码建模取代，但在多模态对齐（如 CLIP）中仍是核心技术。

掩码图像建模（MIM）

MAE 随机遮盖 75% 的图像 Patch，仅用可见部分重建被遮盖区域。非对称编解码器设计（轻量编码器 + 宽解码器）使预训练效率提升 3 倍以上。BEiT 系列则将遮盖 Patch 用 VQ-VAE 离散 token 替代像素重建目标。

5.4 近两年新技术（2024-2025）

掩码自编码器的全面突破

2024-2025 年，MAE 系列在视觉预训练领域占据主导地位。MAE v2 和 CAE v2 改进了重建目标和编码策略。iMAE（I-JEPA，LeCun 团队）提出了一种基于潜在空间预测的自监督方法，不再需要像素级重建，而是预测被遮盖区域的表示，在 ImageNet 线性探测和下游迁移上均超过 MAE。

多模态自监督

CLIP 开创了跨模态对比自监督范式。2024-2025 年的改进包括：SigLIP（用 sigmoid 代替 softmax 对比损失，支持大批量训练）、EVA-CLIP（扩展到 18B 参数）、OpenCLIP（开源大规模视觉-语言预训练）。这些方法本质上都是自监督学习，从海量图文对中学习跨模态表示。

自监督视频学习

VideoMAE 和 MAE-Video 将掩码建模扩展到时序维度，通过高比例时空掩码实现高效视频自监督预训练。2024 年 VideoMAE v2 在 Kinetics-400 上以 1/4 计算量达到全监督性能。

大语言模型的自监督训练

LLaMA-3、Qwen-2、DeepSeek-V3 等大语言模型的第一阶段训练（预训练）本质上就是自监督的因果语言建模：从万亿 token 的无标注文本中预测下一个 token。这是当前自监督学习规模最大的应用场景。

自监督异常检测

2024 年 Neural Networks 期刊发表的综述系统总结了自监督异常检测方法：通过变换预测、对比学习或重建误差构造异常分数。在工业质检、医学影像等领域，自监督方法已不需要异常样本即可检测异常。

自监督学习为何重要

自监督学习是当前 AI 发展的核心驱动力。它解决了有监督学习的标注瓶颈，使模型能利用互联网上的海量无标注数据（文本、图像、视频）学习通用表示。所有现代大模型的预训练阶段都是自监督学习。

6弱监督学习（Weakly Supervised Learning）

6.1 定义与分类

弱监督学习放宽了对标签完整性和准确性的要求，处理三种不完美标注场景：

类型标签特征代表场景方法
不完整标注部分样本有标签，部分无标签半监督学习、主动学习伪标签、协同训练
不精确标注标签是粗粒度的（图像级→实例级）弱监督目标检测/分割Class Activation Map (CAM)、多实例学习
不准确标注标签存在噪声众包标注、网页标签标签降噪、协同教学

6.2 关键技术

弱监督目标检测

仅有图像级标签，需定位目标。CAM（Class Activation Map）通过 GAP 层提取类别热力图，定位目标区域。2024 年改进方法引入在线分块策略和对抗擦除，逐步扩展目标区域。

弱监督语义分割

从图像级标签生成像素级分割掩码。2024-2025 年新方法结合大视觉语言模型（如 SAM、SEEM）自动生成分割伪标签，再训练分割网络。

6.3 近两年进展

2024 年中科院团队提出统一弱监督学习框架用于 LiDAR 遥感观测，将不完整、不精确、不准确标注统一建模。2026 年 arXiv 综述（Wang et al.）系统梳理了弱监督学习的新监督范式和假设松弛策略。

弱监督 vs 半监督

弱监督学习强调标签质量的问题（不精确/不准确），半监督学习强调标签数量的问题（部分有标注）。实际场景中两者常交叉出现。

7迁移学习与元学习

7.1 迁移学习（Transfer Learning）

迁移学习将源域 $\mathcal{D}_S$ 上学到的知识迁移到目标域 $\mathcal{D}_T$，核心假设是源域和目标域存在共享知识。形式化地：

$$\theta_T^* = \arg\min_\theta \mathcal{L}_T(f_\theta; \mathcal{D}_T) + \lambda \|\theta - \theta_S\|^2$$

其中 $\theta_S$ 是源域学到的参数，$\|\theta - \theta_S\|^2$ 防止偏离源域知识过远。

预训练-微调范式

当前最主流的迁移学习形式：大规模自监督预训练 + 下游有监督微调。BERT、ViT、CLIP 等模型在 ImageNet 或大规模文本上预训练，迁移到各种下游任务。

参数高效迁移

LoRA、Adapter、Prefix-Tuning 等方法使下游迁移只需训练极小参数量（<0.1%），2024-2025 年 DoRA（权重分解 LoRA）和 PiSSA（主成分 LoRA）进一步提升了参数高效微调的表达能力。

7.2 元学习（Meta-Learning）

元学习又称学会学习（Learning to Learn），目标是让模型快速适应新任务。核心思想是在大量任务上学习通用的学习策略。

MAML（Model-Agnostic Meta-Learning）

通过二阶梯度优化寻找好的初始化参数，使模型在新任务上只需少量梯度步即可收敛：

$$\theta^* = \arg\min_\theta \sum_{T_i} \mathcal{L}_{T_i}(f_{\theta - \alpha \nabla \mathcal{L}_{T_i}(\theta)})$$

近两年进展

2024-2025 年，元学习与大模型结合出现了In-Context Learning（上下文学习）范式：模型无需梯度更新，仅通过 prompt 中的示例即可学习新任务。GPT-4、Claude 等展示了强大的 ICL 能力，本质上是大规模预训练带来的隐式元学习。

8.2 RLHF / RLVR / DPO 演进

RLHF（2022-2023）通过人类偏好数据训练奖励模型，再用 PPO 优化策略。DPO（Direct Preference Optimization, 2023-2024）绕过奖励模型，直接从偏好数据优化策略，训练更简单稳定。RLVR（2024-2025）用可验证的规则（如数学答案正确性）作为奖励，OpenAI o1/o3 和 DeepSeek-R1 以此训练推理能力。2026 年 ICLR 上清华团队探索了无监督强化学习（Unsupervised RL），在无标注奖励的情况下驱动模型自我改进。

8.3 视觉自监督新进展

  • I-JEPA（Meta, 2024）：潜在空间预测式自监督，不依赖像素重建，更接近"概念级"表示学习。
  • MAE 系列成熟：MAE v2 / CAE v2 在 ImageNet 迁移和检测分割上全面超越有监督预训练。
  • 多模态对比：SigLIP 用 sigmoid 对比损失替代 InfoNCE，训练效率提升 4 倍以上。
  • 视频自监督：VideoMAE v2 将高比例掩码引入视频时序维度，实现高效视频预训练。

8.4 半监督学习新方向

  • 异构半监督（Uni-HSSL）：CVPR 2025，统一处理标注和无标注数据来自不同领域的场景。
  • 边界引导对比学习（BoCLIS）：TMI 2025，医学图像半监督分割精度大幅提升。
  • 大模型辅助标注：用 GPT-4 / VLM 生成伪标签，结合半监督方法训练小模型。
  • 半监督目标检测：多尺度伪标签融合 + 类别自适应阈值，10% 标注达 90% 性能。

8.5 弱监督学习新进展

  • 统一弱监督框架（中科院, 2024）：不完整/不精确/不准确标注的统一建模。
  • SAM 辅助弱监督：用 Segment Anything 模型自动生成分割伪标签。
  • 弱监督综述（arXiv 2026）：系统梳理新监督范式和假设松弛策略。

8.6 新兴交叉范式

具身智能中的学习范式

2025-2026 年具身智能领域出现上下文学习（In-Context Learning）新范式：机器人观看人类示范视频后直接执行任务，无需后训练阶段的数据采集和梯度更新。Skild AI 的 S1 模型将 ICL 任务长度推到 10 分钟级别。

无监督强化学习

ICLR 2026 上清华团队提出在无标注奖励的情况下驱动大模型自我改进的方法，探索了从"监督式 RL"到"无监督 RL"的新方向。

# 有监督学习：标准分类训练
def train_supervised(model, dataloader, optimizer):
    model.train()
    for x, y in dataloader:               # x: 图像, y: 标签
        pred = model(x)
        loss = cross_entropy(pred, y)     # 有标签 → 直接算损失
        optimizer.zero_grad(); loss.backward(); optimizer.step()

# 半监督学习：FixMatch（一致性正则 + 伪标签）
def train_fixmatch(model, labeled_loader, unlabeled_loader, optimizer, tau=0.95):
    model.train()
    for (x_l, y), x_u in zip(labeled_loader, unlabeled_loader):
        # 有标注部分：标准交叉熵
        loss_s = cross_entropy(model(x_l), y)
        # 无标注部分：弱增强预测伪标签 → 强增强一致性
        p_weak = model(weak_aug(x_u)).detach()
        pseudo, conf = p_weak.max(dim=1)
        mask = (conf >= tau).float()           # 仅高置信度伪标签参与
        loss_u = (cross_entropy(model(strong_aug(x_u)), pseudo, reduction='none') * mask).mean()
        loss = loss_s + 1.0 * loss_u
        optimizer.zero_grad(); loss.backward(); optimizer.step()

# 自监督学习：SimCLR 对比学习
def train_simclr(model, unlabeled_loader, optimizer, temp=0.5):
    model.train()
    for x in unlabeled_loader:             # 无标签数据
        x_i, x_j = different_aug(x), different_aug(x)  # 同一图像两种增强
        z_i, z_j = model(x_i), model(x_j)
        # InfoNCE：正样本对拉近，batch 内其余为负样本
        sim = cosine_sim(z_i, z_j) / temp
        labels = torch.arange(len(x))
        loss = cross_entropy(sim, labels)
        optimizer.zero_grad(); loss.backward(); optimizer.step()

10未来趋势与展望

10.1 自监督预训练持续主导

自监督学习已从"辅助手段"上升为 AI 训练的第一范式。随着数据规模和算力增长，自监督预训练的表示质量持续提升，与有监督方法的差距不断缩小。预计 2026-2027 年，自监督预训练在视觉领域将全面超越有监督预训练。

10.2 RLHF / RLVR 演进为"对齐范式"

RLHF 及其变体（DPO、RLVR、无监督 RL）正成为与有监督微调并列的第二大训练阶段。可验证奖励（如数学答案正确性）降低了对人类标注的依赖，使推理能力训练可规模化。清华团队的无监督强化学习探索了无需标注奖励的新方向。

10.3 范式融合：预训练 + 微调 + 对齐

当前 SOTA 模型的标准训练流程已是多范式的融合：

10.4 小模型 + 蒸馏 + 半监督

在大模型主导的同时，小模型高效训练也是重要方向：用大模型（GPT-4）作为教师蒸馏小模型，结合半监督学习利用无标注数据，在端侧部署场景中兼顾性能和成本。

10.5 具身智能与新范式

具身智能领域出现了上下文学习新范式：机器人通过观看示范视频直接执行新任务，无需后训练梯度更新。这暗示着未来可能出现"无优化器学习"的新范式。
