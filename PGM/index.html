1概率图模型概述

1.1 什么是概率图模型

概率图模型（Probabilistic Graphical Models, PGM）是用图论语言描述多元随机变量联合概率分布的框架。它将概率论（处理不确定性）与图论（描述结构关系）有机结合：图中的节点表示随机变量，边表示变量间的概率依赖关系，从而以紧凑、可解释的方式编码高维联合分布中的结构信息。

在 $n$ 个随机变量的联合分布中，完全表示需要 $O(2^n)$ 个参数。PGM 的核心价值在于利用变量间的条件独立性大幅缩减参数规模——将指数级复杂度的联合分布分解为若干局部因子的乘积，使得表示、推断和学习都变得可行。

1.2 图与概率的关系

PGM 中的图 $G = (V, E)$ 包含节点集 $V$（对应随机变量 $X_1, \dots, X_n$）和边集 $E$。图的结构编码了概率分布的因子分解性质：

  • 有向图（贝叶斯网络）：有向边 $X_i \to X_j$ 表示依赖关系——图本身只保证条件依赖，只有在引入额外因果假设的建模框架下才可解释为因果关系。分布分解为 $P(X_1, \dots, X_n) = \prod_{i=1}^{n} P(X_i \mid \mathrm{Pa}(X_i))$。
  • 无向图（马尔可夫随机场）：无向边 $X_i - X_j$ 表示对称相关性，分布分解为 $P(X_1, \dots, X_n) = \frac{1}{Z} \prod_{c} \psi_c(X_c)$。
核心思想

图的缺失边意味着对应变量之间存在条件独立性。这正是 PGM 紧凑表示的本质：我们不需要存储整张联合分布表，只需存储与图结构一致的局部因子。

2贝叶斯网络基础

2.1 有向无环图（DAG）

贝叶斯网络（Bayesian Network）用有向无环图（Directed Acyclic Graph, DAG）表示变量间的概率依赖。DAG 中每个节点对应一个随机变量，有向边 $X_i \to X_j$ 表示 $X_j$ 直接依赖于 $X_i$。无环性保证不存在循环依赖，使得联合分布可以被合法地因子分解。

对于节点 $X_i$，其所有直接前驱称为父节点集 $\mathrm{Pa}(X_i)$，所有直接后继称为子节点集 $\mathrm{Ch}(X_i)$。没有父节点的节点称为根节点。

2.2 条件概率分布（CPD）

贝叶斯网络中每个节点 $X_i$ 关联一个条件概率分布（Conditional Probability Distribution, CPD）$P(X_i \mid \mathrm{Pa}(X_i))$，描述在给定父节点取值时 $X_i$ 的分布。对于离散变量，CPD 表现为条件概率表（CPT）；对于连续变量，CPD 可用线性高斯等参数化形式。

2.3 因子分解与链式法则

给定 DAG $G$，贝叶斯网络的联合分布按链式法则因子分解为各节点 CPD 的乘积：

$$P(X_1, X_2, \ldots, X_n) = \prod_{i=1}^{n} P(X_i \mid \mathrm{Pa}(X_i))$$

这是 PGM 紧凑性的基础：若每个变量最多有 $k$ 个父节点且每个变量取 $r$ 个值，则总参数量为 $O(n \cdot r^k)$，远优于无结构联合分布的 $O(r^n)$。

2.4 局部马尔可夫性

贝叶斯网络满足局部马尔可夫性：在给定父节点的条件下，每个节点与其非后代节点条件独立：

$$X_i \perp \!\!\! \perp \mathrm{Nd}(X_i) \setminus \mathrm{Pa}(X_i) \mid \mathrm{Pa}(X_i)$$

其中 $\mathrm{Nd}(X_i)$ 表示 $X_i$ 的所有非后代节点。这一性质是因子分解（公式1）成立的充分条件——链式法则的通用分解 $P(X_1, \dots, X_n) = \prod_i P(X_i \mid X_1, \dots, X_{i-1})$ 在局部马尔可夫性下简化为 $\prod_i P(X_i \mid \mathrm{Pa}(X_i))$。

等价关系

对于 DAG $G$ 和分布 $P$：$G$ 是 $P$ 的 I-map（独立性映射） $\Leftrightarrow$ $P$ 满足局部马尔可夫性 $\Leftrightarrow$ $P$ 按 $G$ 因子分解。三者等价，是贝叶斯网络表示的理论基石。

3贝叶斯网络的独立性

3.1 d-分离

d-分离（d-separation，directional separation）是判定贝叶斯网络中条件独立性的图结构准则。对于三个节点 $X$、$Y$、$Z$ 及路径上的中间节点 $W$，路径经过 $W$ 的三种基本结构决定了信息是否"阻断"：

  • 链式结构（$X \to W \to Y$）：给定 $W$，则 $X \perp \!\!\! \perp Y \mid W$，信息被阻断。
  • 分叉结构（$X \leftarrow W \to Y$）：给定 $W$，则 $X \perp \!\!\! \perp Y \mid W$，信息被阻断。
  • 汇合结构（$X \to W \leftarrow Y$）：默认 $X \perp \!\!\! \perp Y$（信息阻断）；但给定 $W$ 或其后代时，依赖被激活，$X$ 与 $Y$ 变为相关。

3.2 贝叶斯球算法

贝叶斯球算法（Bayes Ball Algorithm）是 d-分离的可达性算法。给定观测集 $\mathbf{Z}$，从节点 $X$ 出发模拟一个"球"在图上的传播：若球无法到达 $Y$，则 $X \perp \!\!\! \perp Y \mid \mathbf{Z}$。球的传播规则依节点方向和是否被观测而定：

  • 球到达未观测的分叉/链式节点：穿过并继续传播。
  • 球到达已观测的分叉/链式节点：被阻断，停止。
  • 球到达未观测的汇合节点：被阻断（默认独立）。
  • 球到达已观测的汇合节点（或其后代被观测）：通过并继续传播。

3.3 I-map、D-map 与忠实性

概念定义含义
I-map（独立性映射）$\mathcal{I}(G) \subseteq \mathcal{I}(P)$图中所有独立性都蕴含在分布中
D-map（依赖映射）$\mathcal{I}(G) \supseteq \mathcal{I}(P)$分布中所有独立性都反映在图中
完美映射（P-map）$\mathcal{I}(G) = \mathcal{I}(P)$图与分布独立性完全一致
忠实性（Faithfulness）$\mathcal{I}(G) = \mathcal{I}(P)$分布不包含图中未编码的额外独立性

3.4 马尔可夫毯

节点 $X$ 的马尔可夫毯（Markov Blanket）是在给定该集合时 $X$ 与图中所有其他节点条件独立的最小节点集。对于贝叶斯网络：

$$\mathrm{MB}(X_i) = \mathrm{Pa}(X_i) \cup \mathrm{Ch}(X_i) \cup \bigcup_{j \in \mathrm{Ch}(X_i)} \big(\mathrm{Pa}(X_j) \setminus \{X_i\}\big)$$

即马尔可夫毯包含 $X$ 的父节点、子节点以及子节点的其他父节点（共父）。给定马尔可夫毯后，$X$ 与网络其余部分条件独立：$X_i \perp \!\!\! \perp (V \setminus (\mathrm{MB}(X_i) \cup \{X_i\})) \mid \mathrm{MB}(X_i)$。马尔可夫毯在特征选择和因果推断中具有重要应用。

4马尔可夫随机场

4.1 无向图模型

马尔可夫随机场（Markov Random Field, MRF）用无向图 $H = (V, E)$ 描述变量间的对称依赖关系。与贝叶斯网络不同，MRF 的边没有方向，不编码因果关系，而是表达变量间的相互关联——适合建模空间、图像像素、社交网络等具有对称依赖的场景。

4.2 势函数与团

MRF 中变量间的依赖通过势函数（Potential Function）$\psi_c(X_c)$ 来建模。势函数定义在团（Clique）上——团是图中任意两节点都有边相连的子集。势函数是非负函数 $\psi_c: \mathrm{Val}(X_c) \to \mathbb{R}_{\ge 0}$，它不需要归一化，也不直接对应概率值，而是编码变量子集 $X_c$ 的局部相容性。

极大团（Maximal Clique）是不能被更大团包含的团。MRF 的联合分布通过极大团上势函数的乘积来表示。

4.3 Hammersley-Clifford 定理

Hammersley-Clifford 定理建立了正概率分布与无向图因子分解的等价关系：若联合分布 $P(X) > 0$ 处处成立，则 $P$ 满足图 $H$ 上的局部马尔可夫性，当且仅当 $P$ 可以因子分解为极大团上势函数的乘积。

$$P(X_1, X_2, \ldots, X_n) = \frac{1}{Z} \prod_{c \in \mathcal{C}} \psi_c(X_c)$$

其中 $\mathcal{C}$ 为所有极大团集合，$Z$ 为配分函数（Partition Function），确保分布归一化：

$$Z = \sum_{x_1, \ldots, x_n} \prod_{c \in \mathcal{C}} \psi_c(x_c)$$
配分函数的挑战

$Z$ 的计算需要对所有变量取值求和，复杂度为 $O(r^n)$，这是 MRF 推断的核心难点。在精确推断中需要借助变量消除或信念传播；在近似推断中常通过伪似然或 MCMC 绕过直接计算。

4.4 吉布斯分布

当势函数取指数族形式 $\psi_c(X_c) = \exp\{-E_c(X_c)\}$ 时，MRF 的分布称为吉布斯分布（Gibbs Distribution），$E(X) = \sum_c E_c(X_c)$ 称为能量函数：

$$P(X) = \frac{1}{Z} \exp\left(-\sum_{c \in \mathcal{C}} E_c(X_c)\right) = \frac{1}{Z} \exp\left(-E(X)\right)$$

能量越低的配置概率越高。常见形式如玻尔兹曼机（Boltzmann Machine）和伊辛模型（Ising Model）都是吉布斯分布的特例。

5MRF的独立性

5.1 全局马尔可夫性

MRF 的全局马尔可夫性：若从 $X$ 到 $Y$ 的所有路径都经过 $\mathbf{Z}$，则 $X \perp \!\!\! \perp Y \mid \mathbf{Z}$。形式化地，若 $\mathbf{Z}$ 将图分割为若干连通分量，则不同分量中的变量条件独立：

$$\text{若 } \mathbf{Z} \text{ 分离 } X \text{ 与 } Y \text{ 在 } H \text{ 中}, \quad \text{则 } X \perp \!\!\! \perp Y \mid \mathbf{Z}$$

5.2 局部马尔可夫性

MRF 的局部马尔可夫性：给定节点的邻居集 $\mathrm{Nb}(X_i)$（与 $X_i$ 直接相连的节点），$X_i$ 与图中其余节点条件独立：

$$X_i \perp \!\!\! \perp V \setminus (\mathrm{Nb}(X_i) \cup \{X_i\}) \mid \mathrm{Nb}(X_i)$$

在 MRF 中，马尔可夫毯恰好等于邻居集 $\mathrm{MB}(X_i) = \mathrm{Nb}(X_i)$，这比贝叶斯网络（含共父）更简洁。

5.3 成对马尔可夫性

成对马尔可夫性：若两个非邻接节点 $X_i$、$X_j$ 没有边直接相连，则在给定所有其他节点时条件独立：

$$\text{若 } (X_i, X_j) \notin E, \quad \text{则 } X_i \perp \!\!\! \perp X_j \mid V \setminus \{X_i, X_j\}$$
三种马尔可夫性的等价性

对于正概率分布，全局、局部、成对马尔可夫性三者等价。Hammersley-Clifford 定理保证了：三者中任一成立 $\Leftrightarrow$ 分布可按无向图因子分解为团上势函数的乘积。

6因子图

6.1 二分图表示

因子图（Factor Graph）是统一表示 BN 和 MRF 的二分图框架。它包含两类节点：变量节点（圆圈）和因子节点（方块），边只连接变量与因子。因子图将因子分解中的每个因子显式地表示为图中的节点，使得结构更加清晰。

6.2 因子分解

因子图将联合分布显式分解为因子的乘积，每个因子节点 $f_a$ 对应一个势函数：

$$P(\mathbf{x}) = \frac{1}{Z} \prod_{a} f_a(\mathbf{x}_a), \qquad Z = \sum_{\mathbf{x}} \prod_{a} f_a(\mathbf{x}_a)$$

其中 $\mathbf{x}_a$ 是因子 $f_a$ 所连接的变量子集。这里保留 $1/Z$ 是必要的：MRF 的势函数只要求非负、不要求归一化，因此一般情形下所有因子的乘积累加并不等于 1；只有当因子本身已是归一化概率（如贝叶斯网络的 CPD）时，$Z$ 才恰好等于 1、可以省略。因子图的二分结构清晰地将"变量"与"局部函数"分离，也正是和积算法（Sum-Product）的天然载体。

6.3 从 BN / MRF 到因子图

  • BN → 因子图：每个 CPD $P(X_i \mid \mathrm{Pa}(X_i))$ 对应一个因子节点 $f_i$，连接 $X_i$ 及其所有父节点。
  • MRF → 因子图：每个极大团的势函数 $\psi_c(X_c)$ 对应一个因子节点 $f_c$，连接团中所有变量。
因子图的优势

因子图是 BN 和 MRF 的统一表示。更细粒度的因子分解（将大团分解为多个小因子）在保持分布不变的同时减少冗余计算。和积信念传播算法在因子图上的消息传递规则最自然、最简洁。

7精确推断-变量消除法

7.1 推断问题总览

推断（Inference）是在给定模型后回答概率查询的过程。本章与后续三章一共要处理三类查询，它们形式不同、用途也不同：

查询类型要算什么典型用途在哪讲
边缘后验 Marginal$P(Y \mid \mathbf{e})$：某个变量在证据下的分布置信度、软判决第 7、8 章
最大后验 MAP$\mathbf{y}^* = \arg\max_{\mathbf{y}} P(\mathbf{y} \mid \mathbf{e})$最可能的解释、解码第 8.3 节
边际似然 Evidence$P(\mathbf{e})$：证据本身出现的概率模型比较、参数学习的归一化项第 7 章、第 11 章

本章先处理最基本的边缘概率查询：给定证据 $\mathbf{e}$，求查询变量集 $\mathbf{Y}$ 的后验边缘分布：

$$P(\mathbf{Y} \mid \mathbf{e}) = \frac{P(\mathbf{Y}, \mathbf{e})}{P(\mathbf{e})} = \frac{\sum_{\mathbf{Z}} P(\mathbf{Y}, \mathbf{Z}, \mathbf{e})}{\sum_{\mathbf{Y}, \mathbf{Z}} P(\mathbf{Y}, \mathbf{Z}, \mathbf{e})}$$

其中 $\mathbf{Z}$ 是既非查询、也非证据的变量（称为需被"消除"的隐藏变量）。分子分母都要对所有隐藏变量求和——这个求和的代价，就是推断难度的来源。

为什么"难"：难度由图结构决定，而不是算法好坏

朴素地对 $\mathbf{Z}$ 求和需要枚举 $O(r^{|\mathbf{Z}|})$ 种组合，代价随隐藏变量个数指数增长。变量消除（本章）用动态规划消掉重复计算，把代价降到 $O(n \cdot r^{w+1})$，其中 $w$ 是诱导宽度——由图的连通程度决定。树状图的 $w$ 很小，精确推断线性时间可解；稠密图的 $w$ 可能很大，精确推断就成为 NP-hard。于是出现分水岭：

精确推断（第 7、8 章）适用于树与低树宽的稀疏图；近似推断（第 9 章采样、第 10 章变分）适用于高树宽的图。两者不是"好算法"与"差算法"之别，而是各自适配不同的图结构。

7.2 变量消除算法

变量消除法（Variable Elimination, VE）通过逐步消除（求和消除）隐藏变量来计算边缘分布。核心思想是利用因子分解，每次只将与当前变量相关的因子相乘并求和，生成新的中间因子，避免直接展开整张联合分布表。

VE 算法步骤如下：

  1. 初始化因子集 $\Phi = \{f_1, \dots, f_m\}$（根据证据证据化后）。
  2. 按消除顺序 $\pi$ 逐个消除变量 $Z$：
    • 收集所有包含 $Z$ 的因子 $\Phi_Z = \{\phi \in \Phi : Z \in \mathrm{Scope}(\phi)\}$。
    • 将 $\Phi_Z$ 中因子相乘：$\tau = \prod_{\phi \in \Phi_Z} \phi$。
    • 对 $Z$ 求和消除：$\tau' = \sum_Z \tau$。
    • 更新因子集：$\Phi = (\Phi \setminus \Phi_Z) \cup \{\tau'\}$。
  3. 最后 $\Phi$ 中剩余因子的乘积即为查询结果。

7.3 消除顺序与复杂度

VE 的计算复杂度高度依赖消除顺序（Elimination Ordering）。消除变量 $Z$ 时，新因子 $\tau$ 的scope是所有含 $Z$ 因子的scope之并集。该并集的大小决定计算代价。

定义诱导宽度（Induced Width）$w$：在给定消除顺序下，消除过程中产生的最大因子scope大小减 1。VE 的时间复杂度为：

$$T_{\text{VE}} = O\left(n \cdot r^{w+1}\right)$$

其中 $n$ 为变量数，$r$ 为变量取值数，$w$ 为诱导宽度。寻找最优消除顺序使 $w$ 最小化是 NP-hard 问题。启发式策略包括最小缺失宽度（Min-Fill）和最小度（Min-Degree）。

复杂度本质

精确推断在一般图上是 NP-hard。但对于树结构图（单连通图），诱导宽度 $w = 1$，VE 退化为线性复杂度 $O(n \cdot r^2)$，这正是信念传播高效的基础。

VE 算例：链式网络 $X \to Y \to Z$ 的边缘 $P(Z)$

设一个最简单的链式贝叶斯网络 $X \to Y \to Z$，三个变量均为二值（取 0/1），因子分解为：

$$P(X, Y, Z) = P(X) \cdot P(Y \mid X) \cdot P(Z \mid Y)$$

参数：$P(X) = (0.6, 0.4)$，$P(Y \mid X) = \begin{pmatrix} 0.7 & 0.3 \\ 0.4 & 0.6 \end{pmatrix}$（行 $X$、列 $Y$），$P(Z \mid Y) = \begin{pmatrix} 0.8 & 0.2 \\ 0.1 & 0.9 \end{pmatrix}$（行 $Y$、列 $Z$）。

目标：求 $P(Z) = \sum_X \sum_Y P(X) P(Y \mid X) P(Z \mid Y)$。若直接展开联合表需 $2^3 = 8$ 项，VE 只需逐步消去。

第一步：消除 $X$。收集含 $X$ 的因子 $\{P(X), P(Y \mid X)\}$，相乘后对 $X$ 求和：

$$\tau_1(Y) = \sum_{X} P(X) \cdot P(Y \mid X) = \begin{pmatrix} 0.6 \times 0.7 + 0.4 \times 0.4 \\ 0.6 \times 0.3 + 0.4 \times 0.6 \end{pmatrix} = \begin{pmatrix} 0.58 \\ 0.42 \end{pmatrix}$$

这实际上就是边缘分布 $P(Y)$——消除 $X$ 后，$Y$ 的分布已"吸收"了 $X$ 的信息。

第二步：消除 $Y$。收集含 $Y$ 的因子 $\{\tau_1(Y), P(Z \mid Y)\}$，相乘后对 $Y$ 求和：

$$P(Z) = \sum_{Y} \tau_1(Y) \cdot P(Z \mid Y) = \begin{pmatrix} 0.58 \times 0.8 + 0.42 \times 0.1 \\ 0.58 \times 0.2 + 0.42 \times 0.9 \end{pmatrix} = \begin{pmatrix} 0.506 \\ 0.494 \end{pmatrix}$$

解读：VE 的每一步只涉及两个小因子的乘积与求和，最大中间因子 scope 大小为 2（即 $w = 1$），总计算量 $O(3 \times 2^2) = 12$ 次乘法，远小于直接展开 8 项联合表再对 6 项求和。消除顺序 $X \to Y$ 比 $Y \to X$ 更优——先消叶子节点不会产生大因子。

VE 算例二：多父节点网络 $W \to R \to G \gets I$ 的边缘 $P(G)$

上一个算例是简单链式结构，本例展示更一般的情况——多父节点。设一个考试预测贝叶斯网络，4 个二值变量（取 0/1）：

  • W（天气，0=坏/1=好）：$P(W) = (0.7, 0.3)$
  • I（智商，0=低/1=高）：$P(I) = (0.8, 0.2)$
  • R（复习，0=否/1=是）：$P(R \mid W)$，天气好时更可能复习
  • G（考试分数，0=不及格/1=及格）：$P(G \mid I, R)$，受智商和复习双重影响

网络结构为 $W \to R \to G \gets I$（$G$ 有两个父节点 $I$ 和 $R$），因子分解为：

$$P(W, I, R, G) = P(W) \cdot P(I) \cdot P(R \mid W) \cdot P(G \mid I, R)$$

条件概率表：

$$P(R \mid W) = \begin{pmatrix} 0.6 & 0.4 \\ 0.1 & 0.9 \end{pmatrix} \text{（行 $W$、列 $R$）}, \qquad P(G \mid I, R) = \begin{pmatrix} 0.9 & 0.1 \\ 0.6 & 0.4 \\ 0.4 & 0.6 \\ 0.1 & 0.9 \end{pmatrix} \text{（行 $(I,R)$、列 $G$）}$$

其中 $P(G \mid I, R)$ 的四行依次对应 $(I{=}0, R{=}0)$、$(I{=}0, R{=}1)$、$(I{=}1, R{=}0)$、$(I{=}1, R{=}1)$。

目标：求 $P(G) = \sum_W \sum_I \sum_R P(W) \cdot P(I) \cdot P(R \mid W) \cdot P(G \mid I, R)$。暴力展开需 $2^4 = 16$ 项联合表。VE 按 $W \to I \to R$ 顺序消元，每步只处理小因子。

第一步：消除 $W$。收集含 $W$ 的因子 $\{P(W), P(R \mid W)\}$，相乘后对 $W$ 求和：

$$\tau_1(R) = \sum_{W} P(W) \cdot P(R \mid W) = \begin{pmatrix} 0.7 \times 0.6 + 0.3 \times 0.1 \\ 0.7 \times 0.4 + 0.3 \times 0.9 \end{pmatrix} = \begin{pmatrix} 0.45 \\ 0.55 \end{pmatrix}$$

这实际上就是边缘分布 $P(R)$——天气信息被"吸收"进 $R$ 的分布中。

第二步：消除 $I$。收集含 $I$ 的因子 $\{P(I), P(G \mid I, R)\}$，相乘后对 $I$ 求和：

$$\tau_2(G, R) = \sum_{I} P(I) \cdot P(G \mid I, R)$$
$$= \begin{pmatrix} 0.8 \times 0.9 + 0.2 \times 0.4 & 0.8 \times 0.1 + 0.2 \times 0.6 \\ 0.8 \times 0.6 + 0.2 \times 0.1 & 0.8 \times 0.4 + 0.2 \times 0.9 \end{pmatrix}_{(G,R)} = \begin{pmatrix} 0.80 & 0.20 \\ 0.50 & 0.50 \end{pmatrix}_{(G,R)}$$

此处 $\tau_2$ 的 scope 为 $\{G, R\}$（大小 2），是消元过程中产生的最大中间因子。

第三步：消除 $R$。收集含 $R$ 的因子 $\{\tau_1(R), \tau_2(G, R)\}$，相乘后对 $R$ 求和：

$$P(G) = \sum_{R} \tau_1(R) \cdot \tau_2(G, R) = \begin{pmatrix} 0.45 \times 0.80 + 0.55 \times 0.50 \\ 0.45 \times 0.20 + 0.55 \times 0.50 \end{pmatrix} = \begin{pmatrix} 0.635 \\ 0.365 \end{pmatrix}$$

学生考试及格的概率 $P(G=1) = 0.365$，即约 36.5%。

8精确推断-信念传播

8.1 和积消息传递

信念传播（Belief Propagation, BP）又称和积算法（Sum-Product Algorithm），在因子图上通过消息传递实现高效推断。每个因子节点和变量节点之间沿边交换"消息"，消息编码了从一侧子图传来的边缘概率信息。

在因子图上，变量节点 $x_i$ 向因子节点 $f_a$ 发送消息：

$$m_{i \to a}(x_i) = \prod_{b \in \mathrm{Nb}(i) \setminus a} m_{b \to i}(x_i)$$

因子节点 $f_a$ 向变量节点 $x_i$ 发送消息：

$$m_{a \to i}(x_i) = \sum_{\mathbf{x}_a \setminus x_i} f_a(\mathbf{x}_a) \prod_{j \in \mathrm{Nb}(a) \setminus i} m_{j \to a}(x_j)$$

其中 $\mathrm{Nb}(i)$ 为 $x_i$ 的邻居因子集，$\mathrm{Nb}(a)$ 为 $f_a$ 的邻居变量集。变量节点的信念（边缘概率）为所有入消息的乘积归一化：

$$b(x_i) \propto \prod_{a \in \mathrm{Nb}(i)} m_{a \to i}(x_i)$$

8.2 树结构推断

当因子图为树结构（无环连通图）时，BP 在两轮消息传递后精确收敛。第一轮从叶节点向根节点传递（收集阶段），第二轮从根节点向叶节点传递（分发阶段），每个变量节点的最终信念即为精确边缘概率。

对于含有环的图，标准 BP 不保证收敛，但实践中环状信念传播（Loopy BP）仍常被用作近似推断方法——通过迭代传递消息直至收敛或达到最大迭代次数。Loopy BP 在 LDPC 解码、图像分割等任务中取得了优异的实证效果。

BP 算例：链式因子图 $x_1 \text{—} f_a \text{—} x_2 \text{—} f_b \text{—} x_3$ 的消息传递

沿用 VE 算例的同一链式模型 $X_1 \to X_2 \to X_3$，二值变量，因子图结构为 $x_1 \text{—} f_a \text{—} x_2 \text{—} f_b \text{—} x_3$，其中：

$$f_a(x_1, x_2) = P(x_1) \cdot P(x_2 \mid x_1), \qquad f_b(x_2, x_3) = P(x_3 \mid x_2)$$

参数与 7.3 节 VE 算例完全相同（$P(x_1)=(0.6,0.4)$、$P(x_2\mid x_1)$、$P(x_3\mid x_2)$ 均沿用上表），此处不再重复。选 $x_2$ 为根节点，叶节点 $x_1, x_3$ 向根传递。

第一阶段：收集（叶 $\to$ 根）

叶节点 $x_1$ 只有一个邻居 $f_a$，发出的消息为 $m_{x_1 \to f_a} = (1, 1)$（无其他信息）。因子 $f_a$ 汇总后传给 $x_2$：

$$m_{f_a \to x_2}(x_2) = \sum_{x_1} f_a(x_1, x_2) \cdot m_{x_1 \to f_a}(x_1) = \sum_{x_1} P(x_1) \cdot P(x_2 \mid x_1)$$
$$= \begin{pmatrix} 0.6 \times 0.7 + 0.4 \times 0.4 \\ 0.6 \times 0.3 + 0.4 \times 0.6 \end{pmatrix} = \begin{pmatrix} 0.58 \\ 0.42 \end{pmatrix}$$

同理，叶节点 $x_3$ 发出 $m_{x_3 \to f_b} = (1, 1)$，因子 $f_b$ 传给 $x_2$：

$$m_{f_b \to x_2}(x_2) = \sum_{x_3} P(x_3 \mid x_2) \cdot 1 = \begin{pmatrix} 0.8 + 0.2 \\ 0.1 + 0.9 \end{pmatrix} = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$$

此时 $x_2$ 已收到两侧消息，收集阶段完成。

第二阶段：分发（根 $\to$ 叶）

$x_2$ 将"非目标方向"的入消息转发给另一侧因子。向 $f_a$ 转发 $m_{x_2 \to f_a} = m_{f_b \to x_2} = (1, 1)$，因子 $f_a$ 据此传给 $x_1$：

$$m_{f_a \to x_1}(x_1) = \sum_{x_2} f_a(x_1, x_2) \cdot m_{x_2 \to f_a}(x_2) = \sum_{x_2} P(x_1) \cdot P(x_2 \mid x_1) \cdot 1$$
$$= \begin{pmatrix} 0.6 \times (0.7 + 0.3) \\ 0.4 \times (0.4 + 0.6) \end{pmatrix} = \begin{pmatrix} 0.6 \\ 0.4 \end{pmatrix}$$

向 $f_b$ 转发 $m_{x_2 \to f_b} = m_{f_a \to x_2} = (0.58, 0.42)$，因子 $f_b$ 据此传给 $x_3$：

$$m_{f_b \to x_3}(x_3) = \sum_{x_2} P(x_3 \mid x_2) \cdot m_{x_2 \to f_b}(x_2) = \begin{pmatrix} 0.58 \times 0.8 + 0.42 \times 0.1 \\ 0.58 \times 0.2 + 0.42 \times 0.9 \end{pmatrix} = \begin{pmatrix} 0.506 \\ 0.494 \end{pmatrix}$$

最终信念（入消息乘积归一化）：

$$b(x_1) \propto m_{f_a \to x_1} = (0.6, 0.4), \quad b(x_2) \propto m_{f_a \to x_2} \cdot m_{f_b \to x_2} = (0.58, 0.42), \quad b(x_3) \propto m_{f_b \to x_3} = (0.506, 0.494)$$

与 VE 对照：$b(x_3) = P(Z) = (0.506, 0.494)$，与 7.3 节 VE 算例结果完全一致；$b(x_2) = P(Y) = (0.58, 0.42)$，与 VE 第一步的 $\tau_1(Y)$ 一致。BP 的优势在于一次运行即获得所有变量的边缘概率，而 VE 每次只能求一个目标——若需全部边缘，VE 需重复 $n$ 次，BP 仅需两轮。

BP 算例二：多父节点网络 $W \to R \to G \gets I$ 的边缘 $P(G)$

沿用 7.3 节 VE 算例二的同一考试预测模型 $W \to R \to G \gets I$（$G$ 有 $R$、$I$ 两个父节点），参数完全同前（$P(W)$、$P(I)$、$P(R \mid W)$、$P(G \mid I, R)$ 均不重复列出）。其因子图结构为 $W \text{—} f_a \text{—} R \text{—} f_b \text{—} G$，且 $f_b$ 额外连接 $I$：

$$f_a(W, R) = P(W) \cdot P(R \mid W), \qquad f_b(I, R, G) = P(I) \cdot P(G \mid I, R)$$

这是一个树结构（$W \text{—} f_a \text{—} R \text{—} f_b \text{—} G$ 为主链，$I$ 作为 $f_b$ 的叶子）。选 $R$ 为根节点（连接两个因子的枢纽），叶节点 $W, I, G$ 向根传递。

第一阶段：收集（叶 $\to$ 根 $R$）

叶节点 $W$ 发出 $m_{W \to f_a} = (1, 1)$，因子 $f_a$ 汇总后传给 $R$：

$$m_{f_a \to R}(R) = \sum_{W} f_a(W, R) \cdot m_{W \to f_a}(W) = \sum_{W} P(W) \cdot P(R \mid W)$$
$$= \begin{pmatrix} 0.7 \times 0.6 + 0.3 \times 0.1 \\ 0.7 \times 0.4 + 0.3 \times 0.9 \end{pmatrix} = \begin{pmatrix} 0.45 \\ 0.55 \end{pmatrix}$$

这恰是 $P(R)$——与 VE 算例二第一步的 $\tau_1(R)$ 相同。

叶节点 $I$ 发出 $m_{I \to f_b} = (1, 1)$，叶节点 $G$ 发出 $m_{G \to f_b} = (1, 1)$，因子 $f_b$ 对 $I, G$ 求和后传给 $R$：

$$m_{f_b \to R}(R) = \sum_{I, G} P(I) \cdot P(G \mid I, R) \cdot m_{I \to f_b}(I) \cdot m_{G \to f_b}(G) = \begin{pmatrix} \sum_I P(I) \sum_G P(G \mid I, R=0) \\ \sum_I P(I) \sum_G P(G \mid I, R=1) \end{pmatrix}$$
$$= \begin{pmatrix} (0.8+0.2) \times (0.9+0.1) \\ (0.8+0.2) \times (0.6+0.4) \end{pmatrix} = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$$

此处 $\sum_G P(G \mid I, R) = 1$ 对每个 $(I,R)$ 恒成立（概率表行和为 1），故消息为 $(1, 1)$——$f_b$ 这一侧未向 $R$ 提供信息，全部信息来自 $f_a$ 一侧。

第二阶段——分发（根 $R$ $\to$ 叶）

$R$ 向 $f_a$ 转发 $m_{R \to f_a} = m_{f_b \to R} = (1, 1)$，因子 $f_a$ 据此传给 $W$：

$$m_{f_a \to W}(W) = \sum_{R} P(W) \cdot P(R \mid W) \cdot m_{R \to f_a}(R) = \begin{pmatrix} 0.7 \times (0.6 + 0.4) \\ 0.3 \times (0.1 + 0.9) \end{pmatrix} = \begin{pmatrix} 0.7 \\ 0.3 \end{pmatrix}$$

$R$ 向 $f_b$ 转发 $m_{R \to f_b} = m_{f_a \to R} = (0.45, 0.55)$，因子 $f_b$ 据此传给 $G$——这是最关键的一步：

$$m_{f_b \to G}(G) = \sum_{I, R} P(I) \cdot P(G \mid I, R) \cdot m_{R \to f_b}(R) \cdot m_{I \to f_b}(I)$$
$$= \begin{pmatrix} 0.8 \times [0.45 \times 0.9 + 0.55 \times 0.6] + 0.2 \times [0.45 \times 0.4 + 0.55 \times 0.1] \\ 0.8 \times [0.45 \times 0.1 + 0.55 \times 0.4] + 0.2 \times [0.45 \times 0.6 + 0.55 \times 0.9] \end{pmatrix}$$
$$= \begin{pmatrix} 0.8 \times 0.735 + 0.2 \times 0.235 \\ 0.8 \times 0.265 + 0.2 \times 0.765 \end{pmatrix} = \begin{pmatrix} 0.635 \\ 0.365 \end{pmatrix}$$

最终信念：$b(G) \propto m_{f_b \to G} = (0.635, 0.365)$，即学生及格概率 $P(G{=}1) = 0.365$；其余变量信念 $b(W) = (0.7, 0.3)$、$b(I) = (0.8, 0.2)$、$b(R) = (0.45, 0.55)$ 均与先验一致（该网络无证据，边缘即先验）。

与 VE 对照：$b(G) = P(G) = (0.635, 0.365)$ 与 7.3 节 VE 算例二完全一致；$b(R) = P(R) = (0.45, 0.55)$ 与 VE 第一步 $\tau_1(R)$ 一致。本例进一步说明 BP 的多因子优势：VE 需按 $W \to I \to R$ 消元，中途产生 scope 为 2 的 $\tau_2(G, R)$；BP 则通过 $R$ 枢纽把信息拆成两路独立传播，树结构上两轮即得全部边缘，无需排序、无需维护中间因子表。

8.3 最大积信念传播

最大积 BP（Max-Product BP）将和积 BP 中的求和 $\sum$ 替换为取最大 $\max$，用于求解最大后验概率（MAP）问题——寻找最可能的变量赋值 $\mathbf{x}^* = \arg\max_{\mathbf{x}} P(\mathbf{x} \mid \mathbf{e})$：

$$m_{a \to i}(x_i) = \max_{\mathbf{x}_a \setminus x_i} f_a(\mathbf{x}_a) \prod_{j \in \mathrm{Nb}(a) \setminus i} m_{j \to a}(x_j)$$

最大积 BP 在树结构图上可在两轮消息传递中精确求解 MAP。对于一般图，可使用连接树（Junction Tree）算法：通过三角化、寻找极大团、构建连接树，将任意图转化为树结构的团图，从而实现精确推断，但代价是团的大小可能很大。

9近似推断-采样

9.1 蒙特卡洛方法

蒙特卡洛方法（Monte Carlo Methods）通过从目标分布中采样来近似计算期望、边缘概率等统计量。给定分布 $P(X)$，期望 $\mathbb{E}_{P}[f(X)]$ 可通过 $N$ 个样本 $\{x^{(s)}\}_{s=1}^{N} \sim P(X)$ 的经验平均来估计：

$$\mathbb{E}_{P}[f(X)] \approx \hat{\mu}_N = \frac{1}{N} \sum_{s=1}^{N} f(x^{(s)})$$

由大数定律（强大数定律），$\hat{\mu}_N \xrightarrow{a.s.} \mathbb{E}_{P}[f(X)]$；若 $f(X)$ 的方差有限，估计量的标准差为 $\mathrm{std}(\hat{\mu}_N) = \sigma_f / \sqrt{N}$，即均方根误差为 $O(1/\sqrt{N})$。注意这里 $O(1/\sqrt{N})$ 描述的是"误差的典型幅度"，误差本身仍是随机变量，并没有确定的阶。蒙特卡洛方法的关键优势在于这个 $1/\sqrt{N}$ 与变量维度无关——在高维空间中远优于网格数值积分（后者的误差随维度指数退化）。

9.2 吉布斯采样

吉布斯采样（Gibbs Sampling）是 MCMC 的特例，适用于可以从完整条件分布采样的场景。在每一步中，固定所有其他变量，仅从单个变量的完整条件分布中采样：

$$x_i^{(t+1)} \sim P\left(X_i \mid X_{-i}^{(t)}\right) = P\left(X_i \mid \mathrm{MB}(X_i)\right)$$

其中 $X_{-i}$ 表示除 $X_i$ 外的所有变量。关键优势：在 PGM 中，完整条件分布只依赖于马尔可夫毯，不需要计算配分函数 $Z$（在条件分布中 $Z$ 被消去）。吉布斯采样在贝叶斯网络中特别自然——每个节点的条件分布即为 CPD。

吉布斯采样算例：考试预测网络的逐变量循环采样

沿用前文的多父节点网络 $W \to R \to G \gets I$。目标：不计算任何联合分布，仅通过反复从完整条件分布采样来估计 $P(G{=}1)$。

每个变量的完整条件分布只依赖其马尔可夫毯（父 + 子 + 子父）：

$$P(W \mid R) \propto P(W) \cdot P(R \mid W), \qquad P(I \mid G, R) \propto P(I) \cdot P(G \mid I, R)$$
$$P(R \mid W, I, G) \propto P(R \mid W) \cdot P(G \mid I, R), \qquad P(G \mid I, R) = \text{CPD 表}$$

初始状态：$(W, I, R, G) = (0, 0, 0, 0)$。按顺序循环更新各变量（以当前所有其他变量为条件）：

$$P(W{=}1 \mid R{=}0) = \frac{0.3 \times 0.1}{0.7 \times 0.6 + 0.3 \times 0.1} = \frac{0.03}{0.45} \approx 0.0667$$

先验 $P(W{=}1)=0.3$，观察到 $R{=}0$ 后骤降到 6.7%——原因是"天气好时基本都会复习"（$P(R{=}0\mid W{=}1)=0.1$，远小于 $P(R{=}0\mid W{=}0)=0.6$），如今既然观察到"没复习"，天气好的可能性自然大减。采样得 $W$ 后，继续以当前值依次更新 $I, R, G$，如此循环。

一轮完整更新示例（假设采样结果）：

$$(0,0,0,0) \xrightarrow{W} (0,0,0,0) \xrightarrow{I} (0,0,0,0) \xrightarrow{R} (0,0,1,0) \xrightarrow{G} (0,0,1,0)$$

为什么成立：$P(G \mid I, R)$ 是 CPD 表，直接查表采样即可；完整条件分布中的配分函数 $Z$ 被消去——这正是不需要计算 $Z$ 的关键。当 $R$ 更新为 1 后，$G$ 的条件分布变为 $P(G \mid I{=}0, R{=}1) = (0.6, 0.4)$，采样结果进入"及格"概率 40% 的通道。

数值验证：对 $W, I, R, G$ 依次循环采样 20 万次后统计 $G$ 的频率，$P(G{=}1) \approx 0.364$，与精确值 $0.365$ 一致。完整条件分布仅涉及相邻节点，无需配分函数——这是吉布斯在 PGM 中高效的根本原因。

9.3 MCMC 与 Metropolis-Hastings

马尔可夫链蒙特卡洛（MCMC）通过构造一个以目标分布为平稳分布的马尔可夫链来采样。Metropolis-Hastings（MH）算法是最通用的 MCMC 方法：

  1. 从当前状态 $x^{(t)}$ 出发，根据提议分布 $q(x' \mid x^{(t)})$ 生成候选 $x'$。
  2. 计算接受概率： $\alpha = \min\left(1, \frac{P(x') q(x^{(t)} \mid x')}{P(x^{(t)}) q(x' \mid x^{(t)})}\right)$
  3. 以概率 $\alpha$ 接受 $x^{(t+1)} = x'$，否则拒绝 $x^{(t+1)} = x^{(t)}$。

MH 的优势在于只需要目标分布的未归一化形式（不需要 $Z$），因为 $Z$ 在接受比的分子分母中消去。这使得 MH 可直接应用于 MRF 采样。吉布斯采样可视为提议分布为完整条件分布、接受概率恒为 1 的 MH 特例。

MCMC 的关键考量

收敛诊断（Burn-in、Gelman-Rubin $\hat{R}$）、自相关（Effective Sample Size）、混合速度是 MCMC 实践的核心问题。Burn-in 期丢弃初始样本以消除初始值影响；高自相关意味着有效样本量远小于实际样本量，需要更长链或并行链来获得可靠估计。

MH 采样算例：翻转提议采样 $(W, R)$ 联合分布

目标：从 $P(W, R) = P(W) \cdot P(R \mid W)$ 采样（沿用考试模型，忽略 $I, G$），其中 $P(W) = (0.7, 0.3)$，$P(R \mid W)$ 行 $W$、列 $R$。MH 只需要未归一化的 $P(W, R)$——此处恰好归一，但对 MRF 等含 $Z$ 的分布同样适用，因为 $Z$ 在接受比中消去。

提议分布：随机选一个变量翻转（等概率选 $W$ 或 $R$ 取反）。这是对称提议（$q(x' \mid x) = q(x \mid x') = \tfrac{1}{2}$），接受概率简化为：

$$\alpha = \min\left(1, \frac{P(x')}{P(x)}\right)$$

从 $x = (W{=}0, R{=}0)$ 出发（$P = 0.7 \times 0.6 = 0.42$），随机选中翻转 $R$，提议 $x' = (0, 1)$：

$$\alpha = \min\left(1, \frac{P(W{=}0, R{=}1)}{P(W{=}0, R{=}0)}\right) = \min\left(1, \frac{0.28}{0.42}\right) = \min(1, 0.667) = 0.667$$

以 66.7% 概率接受 $x'$；若拒绝则停留在 $x$。若提议 $x' = (1, 0)$（翻转 $W$）：

$$\alpha = \min\left(1, \frac{0.3 \times 0.1}{0.42}\right) = \min(1, 0.0714) = 0.0714$$

接受率仅 7.1%——因为 $(W{=}1, R{=}0)$ 概率极低，多数此类提议被拒绝，马尔可夫链通过"拒绝"自动避免进入低概率区域。

核心思想：MH 不直接采样目标分布，而是构造一条"倾向高概率状态、偶尔接受低概率状态"的马尔可夫链。数值实验：20 万步后经验分布为 $P(W{=}0,R{=}0) \approx 0.420$、$P(W{=}1,R{=}1) \approx 0.270$，与精确值 $0.42$、$0.27$ 一致；总接受率约 61%。

10近似推断-变分推断

10.1 变分推断框架

变分推断（Variational Inference, VI）将推断问题转化为优化问题：用参数化的简单分布族 $q(Z; \phi)$ 逼近真实后验 $P(Z \mid X)$，通过最小化 KL 散度来优化变分参数 $\phi$：

$$q^*(Z) = \arg\min_{q \in \mathcal{Q}} \mathrm{KL}\left(q(Z) \,\|\, P(Z \mid X)\right)$$

由于 $P(Z \mid X)$ 未知（含配分函数），直接优化 KL 散度不可行。等价地，最大化证据下界（Evidence Lower Bound, ELBO）：

$$\log P(X) \geq \mathcal{L}(\phi) = \mathbb{E}_{q(Z;\phi)}\left[\log P(X, Z)\right] - \mathbb{E}_{q(Z;\phi)}\left[\log q(Z; \phi)\right]$$

ELBO 与 KL 散度的关系为 $\log P(X) = \mathcal{L}(\phi) + \mathrm{KL}(q \| P(Z \mid X))$。最大化 ELBO 等价于最小化 KL 散度，差值 $\log P(X) - \mathcal{L}(\phi)$ 即 KL 散度本身，恒非负。

10.2 平均场近似

平均场变分族（Mean-Field）假设各隐藏变量独立，将后验近似为各变量分布的乘积：

$$q(Z) = \prod_{i=1}^{m} q_i(Z_i)$$

这是最简单的变分族，完全忽略变量间后验依赖。在此假设下，最优各分量分布满足坐标上升更新：

$$\log q_i^*(Z_i) = \mathbb{E}_{q_{-i}}\left[\log P(X, Z)\right] + \text{const}$$

其中 $q_{-i} = \prod_{j \neq i} q_j$。各 $q_i$ 的更新依赖于其他分量的期望，需要迭代直至收敛（坐标上升法，CAVI）。

10.3 坐标上升变分推断（CAVI）

CAVI（Coordinate Ascent Variational Inference）是平均场 VI 的标准算法：

  1. 初始化各变分分量 $q_i$ 的参数。
  2. 循环直至收敛：对每个 $i$，按公式(22)更新 $q_i$（固定其他 $q_j$）。
  3. 每轮计算 ELBO，监测收敛。

CAVI 类似 EM 的交替优化：每步提升 ELBO，保证收敛到局部最优。但平均场假设可能导致低估后验不确定性——真实后验中相关的变量被强制独立。

VI 算例：Beta-Bernoulli 的变分后验

考虑最简单的贝叶斯推断问题：估计一枚硬币的正面概率 $\theta$。先验 $\theta \sim \mathrm{Beta}(2, 2)$，观测 10 次抛掷得到 7 次正面。真实后验是共轭的：

$$P(\theta \mid \text{数据}) = \mathrm{Beta}(2 + 7, 2 + 3) = \mathrm{Beta}(9, 5)$$

核心思想：VI 不求后验本身，而是选一个参数化的近似分布 $q(\theta) = \mathrm{Beta}(\alpha, \beta)$，通过最大化 ELBO 使 $q$ 逼近真实后验。由于共轭性，本例中变分族恰包含真实后验，最优解即 $\alpha^* = 9$、$\beta^* = 5$：

$$q^*(\theta) = \mathrm{Beta}(9, 5), \quad \mathbb{E}[\theta] = \frac{9}{14} \approx 0.643$$

ELBO 在该点的取值为 $-6.98$，而初始化 $\alpha = \beta = 2$ 时仅为 $-8.33$——优化过程使 ELBO 单调上升并收敛。

为什么本例不需要"迭代"：这里可观测的数据是 10 次抛掷的结果（7 正 3 反），唯一的隐变量就是参数 $\theta$ 本身，而所选变分族 $\mathrm{Beta}(\alpha, \beta)$ 恰好包含真实后验——此时 ELBO 的最大值点即解析解 $(\alpha^*, \beta^*) = (9, 5)$，坐标上升一步就能到达，所谓"迭代"退化为一次解析赋值。只有在变分族无法覆盖真实后验（例如用单峰高斯逼近多峰后验），或模型中含真正未观测的隐变量（如混合模型的分量指示变量）时，CAVI 才需要多轮迭代去逼近局部最优。

VI 的核心：把推断（积分）变成优化（求极值）。这正是它相对 MCMC 的最大优势——优化问题可以直接用梯度方法求解，从而嵌入神经网络做端到端训练（见 10.4 节）。

误差来源：平均场假设强制各分量独立，会忽略后验变量之间的相关性；本例因共轭结构而无损失，但一般模型中 $q$ 的分布族选择（如单峰高斯）会系统性低估后验方差。

10.4 随机变分推断（SVI）

随机变分推断（Stochastic Variational Inference, SVI）将自然梯度上升与随机采样结合，使用数据子集（mini-batch）估计 ELBO 梯度，适用于大规模数据集。SVI 是变分自编码器（VAE）等深度生成模型的基础——通过重参数化技巧（Reparameterization Trick）使 ELBO 梯度可通过反向传播计算。

SVI 算例：大数据场景下的随机梯度更新

将上一算例扩展到大数据：$N = 1000$ 次抛掷中 700 次正面，先验仍为与上例一致的 $\mathrm{Beta}(2, 2)$。由共轭性，真实后验为 $\mathrm{Beta}(2+700,\;2+300) = \mathrm{Beta}(702, 302)$，均值 $\approx 0.699$。若用完整 VI（CAVI），每一轮都要扫过全部 1000 个数据点计算充分统计量——成本高。

核心思想：SVI 每步只随机抽取一个小批量（mini-batch，如 $B = 100$），用批内统计量估计全数据梯度，配合衰减步长 $\rho_t = 0.1 \cdot (t+1)^{-0.6}$ 做随机梯度更新。更新式是标准的"旧值 $+$ 步长 $\times$（目标 $-$ 旧值）"形式：

$$\alpha_t = (1-\rho_t)\,\alpha_{t-1} + \rho_t\left(a_0 + \frac{N}{B} \sum_{n \in \mathcal{B}_t} x_n\right), \qquad \beta_t = (1-\rho_t)\,\beta_{t-1} + \rho_t\left(b_0 + \frac{N}{B} \sum_{n \in \mathcal{B}_t} (1 - x_n)\right)$$

其中 $\frac{N}{B}$ 把批内统计量放大到全数据规模（本例放大 10 倍），使梯度的期望等于全数据梯度。每步成本从 $O(N)$ 降到 $O(B)$。

注意 $(1-\rho_t)$ 这一项不能漏

若把更新式误写成 $\alpha_t = \rho_t(\text{目标} - \alpha_{t-1})$，等于丢掉了 $(1-\rho_t)\alpha_{t-1}$。当步长 $\rho_t$ 随迭代衰减（本例 $t=100$ 时 $\rho_t \approx 0.0063$）时，这种写法会让新值被"缩"到接近 0，而不是向目标逼近——与下面的收敛行为完全不符。正确的写法是让新值落在旧值与目标之间，权重由 $\rho_t$ 控制。

收敛行为（$B=100$，$\rho_t = 0.1(t+1)^{-0.6}$，500 轮）：$\alpha, \beta$ 从先验附近出发，前几十步迅速向 $(\approx 702, \approx 302)$ 靠拢，之后因步长衰减而缓慢逼近；均值 $\mathbb{E}[\theta] = \alpha/(\alpha+\beta)$ 是最快稳定的量，在 $t=100$ 左右就已落在 $0.699$ 附近。具体轨迹依赖随机种子与小批量抽样，但收敛目标始终是 $\mathrm{Beta}(702, 302)$——与全数据 VI 一致。

SVI 的意义正在于此：每一步只需 $O(B)$ 而非 $O(N)$，大数据集下总成本大幅下降，而收敛目标不变。

11PGM参数学习

11.1 最大似然估计（MLE）

最大似然估计选择使观测数据似然最大的参数值。给定数据集 $\mathcal{D} = \{x^{(1)}, \dots, x^{(N)}\}$，MLE 最大化对数似然：

$$\hat{\theta}_{\text{MLE}} = \arg\max_{\theta} \sum_{n=1}^{N} \log P(x^{(n)}; \theta)$$

对于贝叶斯网络，若结构已知且数据完整，各 CPD 参数可独立估计——MLE 对每个条件概率表条目退化为计数比例 $\hat\theta_{x_i \mid \mathrm{pa}} = \frac{N_{x_i, \mathrm{pa}}}{N_{\mathrm{pa}}}$，其中 $N$ 为对应取值的计数。对于 MRF，MLE 需要计算配分函数 $Z(\theta)$ 的梯度，涉及推断子例程，通常使用伪似然（Pseudo-Likelihood）替代。

MLE 算例：计数即估计

沿用第 12.1 节那个三节点网络 $D \to T \to S$（$D$ 疾病、$T$ 检查、$S$ 症状）。设 100 例完整观测数据中，$T$ 的分布统计如下：

父节点取值$T=Y$ 计数$T=N$ 计数行合计
$D=Y$9110
$D=N$98190

MLE 不做任何"拟合"，只是把计数换成比例：

$$\hat{P}(T{=}Y \mid D{=}Y) = \frac{9}{10} = 0.9, \qquad \hat{P}(T{=}Y \mid D{=}N) = \frac{9}{90} = 0.1$$

这正是 12.1 节代码里 CPT 的取值来源。结论：数据完整时，贝叶斯网络的 MLE 就是逐表计数——各 CPD 参数相互独立、可并行估计，既不需要迭代，也不需要推断。这也解释了 BN 在小数据场景下为何实用：参数估计便宜且可解释。

但数据一旦不完整就会立刻变难。若部分样本的 $T$ 观测缺失，计数就不再直接可用，必须把缺失值当作隐藏变量、用 EM（11.3 节）迭代填补；若是 MRF，因配分函数 $Z(\theta)$ 依赖参数，梯度计算必须调用推断子例程（第 7、8 章），实践中常退而使用伪似然。可见"学习为什么排在推断之后"——它为推断付账。

11.2 MAP 估计与贝叶斯学习

MAP 估计引入先验分布 $P(\theta)$，选择后验最大的参数：

$$\hat{\theta}_{\text{MAP}} = \arg\max_{\theta} \left[\sum_{n=1}^{N} \log P(x^{(n)} \mid \theta) + \log P(\theta)\right]$$

MAP 是点估计，等价于带正则化的 MLE。贝叶斯学习则更进一步——不求点估计，而是对参数做完整贝叶斯推断，计算后验分布 $P(\theta \mid \mathcal{D}) \propto P(\mathcal{D} \mid \theta) P(\theta)$，再对参数积分做预测 $P(x_{\text{new}} \mid \mathcal{D}) = \int P(x_{\text{new}} \mid \theta) P(\theta \mid \mathcal{D}) d\theta$。贝叶斯学习可量化参数不确定性，但计算复杂度更高。

11.3 EM 算法

EM 算法（Expectation-Maximization）用于含隐藏变量的参数学习，交替执行两步：

  • E 步：给定当前参数 $\theta^{(t)}$，计算隐藏变量的后验分布 $P(Z \mid X, \theta^{(t)})$，并求期望完全数据对数似然 $Q(\theta, \theta^{(t)}) = \mathbb{E}_{Z \sim P(Z \mid X, \theta^{(t)})}[\log P(X, Z \mid \theta)]$。
  • M 步：最大化 $Q$ 更新参数 $\theta^{(t+1)} = \arg\max_\theta Q(\theta, \theta^{(t)})$。

EM 保证对数似然单调递增（$\log P(X \mid \theta^{(t+1)}) \geq \log P(X \mid \theta^{(t)})$），收敛到局部最优。EM 与 VI 的区别在于：EM 的 E 步做精确推断（或近似推断），M 步做点估计；VI 则同时对参数和隐变量做变分近似。

11.4 结构学习

结构学习从数据中推断图结构本身，比参数学习复杂得多。主要方法包括：

  • 基于约束的方法（Constraint-Based）：通过条件独立性检验构建图结构。PC 算法逐步删除边，用统计检验判断独立性。
  • 基于评分的方法（Score-Based）：定义结构评分（如 BIC、BDeu），搜索最优结构。由于搜索空间为超指数，常用启发式搜索（贪心、爬山、 taboo 搜索）。
  • 混合方法：先用约束方法缩小候选集，再用评分方法精细化。
结构学习的挑战

结构学习是 NP-hard 问题。DAG 的搜索空间为超指数级 $O(n! \cdot 2^{\binom{n}{2}})$。此外，马尔可夫等价类问题（不同 DAG 可编码相同独立性）使得因果方向在某些情况下不可辨识——只有汇合结构（$v$-结构）能确定方向。

import numpy as np
from collections import defaultdict

class BayesianNetwork:
    """离散贝叶斯网络：DAG + 条件概率表"""
    def __init__(self):
        self.nodes = []
        self.parents = defaultdict(list)
        self.cpts = {}

    def add_node(self, name, parents=None, cpt=None):
        self.nodes.append(name)
        self.parents[name] = parents or []
        self.cpts[name] = cpt

    def joint_probability(self, assignment):
        """计算给定赋值的联合概率"""
        prob = 1.0
        for node in self.nodes:
            parent_vals = tuple(assignment[p] for p in self.parents[node])
            key = (assignment[node],) + parent_vals
            prob *= self.cpts[node].get(key, 0.0)
        return prob

variable_elimination.py
import numpy as np
from itertools import product

class Factor:
    """因子：变量集 + 势函数表"""
    def __init__(self, variables, table):
        self.variables = list(variables)
        self.table = np.array(table)

    def multiply(self, other):
        """两个因子相乘"""
        vars_new = self.variables + [v for v in other.variables if v not in self.variables]
        shape_new = [2] * len(vars_new)
        result = np.zeros(shape_new)
        for idx in product(*[range(2)] * len(vars_new)):
            assign = dict(zip(vars_new, idx))
            i1 = tuple(assign[v] for v in self.variables)
            i2 = tuple(assign[v] for v in other.variables)
            result[idx] = self.table[i1] * other.table[i2]
        return Factor(vars_new, result)

    def sum_out(self, var):
        """消除变量 var（求和边缘化）"""
        axis = self.variables.index(var)
        new_vars = [v for v in self.variables if v != var]
        return Factor(new_vars, np.sum(self.table, axis=axis))

def variable_elimination(factors, query, evidence, elim_order):
    """变量消除法计算 P(query | evidence)"""
    # 证据化
    for i, f in enumerate(factors):
        for var, val in evidence.items():
            if var in f.variables:
                axis = f.variables.index(var)
                factors[i] = Factor(
                    [v for v in f.variables if v != var],
                    np.take(f.table, val, axis=axis)
                )
    # 逐步消除
    for var in elim_order:
        relevant = [f for f in factors if var in f.variables]
        factors = [f for f in factors if var not in f.variables]
        if relevant:
            product_f = relevant[0]
            for f in relevant[1:]:
                product_f = product_f.multiply(f)
            factors.append(product_f.sum_out(var))
    # 剩余因子相乘
    result = factors[0]
    for f in factors[1:]:
        result = result.multiply(f)
    # 归一化
    result.table /= result.table.sum()
    return result

# 示例因子
f1 = Factor(["A"], [0.3, 0.7])
f2 = Factor(["A", "B"], [[0.1, 0.9], [0.8, 0.2]])
result = variable_elimination([f1, f2], ["B"], {}, ["A"])
print("P(B):", result.table)

import numpy as np
np.random.seed(42)

def gibbs_sampling(bn, num_samples=10000, burn_in=1000):
    """吉布斯采样：从贝叶斯网络后验中采样"""
    # 初始化：随机赋值
    assignment = {node: np.random.randint(0, 2) for node in bn.nodes}
    samples = []

    for t in range(num_samples + burn_in):
        for node in bn.nodes:
            # 计算完整条件分布 P(X_i | MB(X_i))
            probs = []
            for val in [0, 1]:
                assignment[node] = val
                p = bn.joint_probability_log(assignment)
                probs.append(p)
            # softmax 归一化
            probs = np.exp(np.array(probs) - max(probs))
            probs /= probs.sum()
            assignment[node] = np.random.choice([0, 1], p=probs)

        if t >= burn_in:
            samples.append(dict(assignment))

    return samples

class SimpleBN:
    """简单二值贝叶斯网络用于演示"""

    def joint_probability_log(self, a):

import numpy as np

def mean_field_vi(joint_log_prob, num_vars, num_iter=100):
    """平均场变分推断（CAVI）"""
    # 初始化变分参数 q_i(x_i)
    q_params = np.ones((num_vars, 2)) / 2  # 均匀分布

    elbo_history = []
    for iteration in range(num_iter):
        # 坐标上升：逐个更新 q_i
        for i in range(num_vars):
            log_q = np.zeros(2)
            for xi in range(2):
                # E_{q_{-i}}[log P(X)]
                total_logp = 0.0
                num_samples = 50
                for _ in range(num_samples):
                    sample = np.zeros(num_vars, dtype=int)
                    for j in range(num_vars):
                        if j != i:
                            sample[j] = np.random.choice(2, p=q_params[j])
                    sample[i] = xi
                    total_logp += joint_log_prob(sample)
                log_q[xi] = total_logp / num_samples

            # softmax 归一化
            log_q = log_q - log_q.max()
            q_params[i] = np.exp(log_q)
            q_params[i] /= q_params[i].sum()

        # 计算 ELBO（简化估计）
        elbo = sum(np.sum(q_params[i] * np.log(q_params[i] + 1e-10))
                   for i in range(num_vars))
        elbo_history.append(elbo)

    return q_params, elbo_history

import numpy as np
np.random.seed(42)

class IsingMRF:
    """二维 Ising 模型：图像去噪的经典 MRF"""
    def __init__(self, width, height, J=1.0):
        self.W, self.H = width, height
        self.J = J
        self.grid = np.random.choice([-1, 1], size=(height, width))

    def neighbors(self, i, j):
        """获取四邻域邻居"""
        nbrs = []
        for di, dj in [(-1,0),(1,0),(0,-1),(0,1)]:
            ni, nj = i+di, j+dj
            if 0 <= ni < self.H and 0 <= nj < self.W:
                nbrs.append((ni, nj))
        return nbrs

    def local_energy(self, i, j):
        """局部能量 E(x_i) = -J * sum(x_i * x_neighbor)"""
        e = 0
        for ni, nj in self.neighbors(i, j):
            e -= self.J * self.grid[i, j] * self.grid[ni, nj]
        return e

    def gibbs_step(self):
        """一次吉布斯扫描"""
        for i in range(self.H):
            for j in range(self.W):
                # 计算翻转前后的能量差（此时 grid 已是翻转后的状态）
                e_current = self.local_energy(i, j)
                self.grid[i, j] *= -1
                e_flipped = self.local_energy(i, j)
                # Metropolis 接受准则：能量下降必接受；能量上升以 exp(-dE) 的概率接受
                delta_e = e_flipped - e_current
                if delta_e > 0 and np.random.rand() >= np.exp(-delta_e):
                    self.grid[i, j] *= -1  # 拒绝，恢复原值
                # 否则保留翻转后的状态（接受）

    def sample(self, num_steps=100):
        """运行吉布斯采样"""
        for _ in range(num_steps):
            self.gibbs_step()
        return self.grid.copy()

import numpy as np
from itertools import product

def bic_score(data, node, parents):
    """BIC 评分：对数似然 - 惩罚项"""
    n_samples = data.shape[0]
    n_states = len(np.unique(data[:, node]))

    # 统计计数
    if not parents:
        counts = np.bincount(data[:, node], minlength=n_states)
        log_lik = np.sum(counts * np.log(counts / n_samples + 1e-10))
        n_params = n_states - 1
    else:
        parent_states = [len(np.unique(data[:, p])) for p in parents]
        n_parent_configs = int(np.prod(parent_states))
        log_lik = 0
        # 父节点的取值配置 = 各父节点取值集合的笛卡尔积
        for config in product(*[range(s) for s in parent_states]):
            mask = np.ones(n_samples, dtype=bool)
            for idx, p in enumerate(parents):
                mask &= (data[:, p] == config[idx])
            if mask.sum() > 0:
                child_counts = np.bincount(data[mask, node], minlength=n_states)
                log_lik += np.sum(child_counts * np.log(child_counts / mask.sum() + 1e-10))
        n_params = n_parent_configs * (n_states - 1)

    # BIC = log_lik - 0.5 * log(n) * n_params
    penalty = 0.5 * np.log(n_samples) * n_params
    return log_lik - penalty

def would_create_cycle(structure, child, parent):
    """若把 parent 加为 child 的父节点（新增边 parent→child），是否会成环？"""
    # 成环当且仅当 child 已是 parent 的祖先：沿 parents 链上溯就能查到
    stack, seen = [parent], set()
    while stack:
        n = stack.pop()
        if n == child:
            return True
        if n in seen:
            continue
        seen.add(n)
        stack.extend(structure.get(n, []))
    return False

def greedy_search(data, num_nodes, max_parents=3):
    """贪心搜索：逐步添加最优父节点"""
    structure = {i: [] for i in range(num_nodes)}

    for node in range(num_nodes):
        current_score = bic_score(data, node, [])
        improved = True
        while improved and len(structure[node]) < max_parents:
            improved = False
            best_parent = None
            best_score = current_score
            for candidate in range(num_nodes):
                if candidate == node or candidate in structure[node]:
                    continue
                # 无环约束：加入该父节点后不能形成环
                if would_create_cycle(structure, node, candidate):
                    continue
                new_parents = structure[node] + [candidate]
                score = bic_score(data, node, new_parents)
                if score > best_score:
                    best_score = score
                    best_parent = candidate
            if best_parent is not None:
                structure[node].append(best_parent)
                current_score = best_score
                improved = True

    return structure

# 示例数据

13.2 与深度学习的关系

PGM 与深度学习的关系是互补而非替代：

  • 可解释性：PGM 提供显式的图结构和概率语义，深度学习的端到端训练难以提供。
  • 不确定性量化：PGM 天然提供后验概率，深度学习需要额外方法（如 MC Dropout、贝叶斯神经网络）来估计不确定性。
  • 小样本学习：PGM 可融合先验知识，在小数据场景下优于纯数据驱动的深度学习。
  • 生成模型：VAE 使用变分推断框架，DDPM（扩散模型）本质是马尔可夫链上的概率推断，两者都是 PGM 思想在深度学习中的延伸。
