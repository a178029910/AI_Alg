1概率图模型概述

1.1 什么是概率图模型

概率图模型（Probabilistic Graphical Models, PGM）是用图论语言描述多元随机变量联合概率分布的框架。它将概率论（处理不确定性）与图论（描述结构关系）有机结合：图中的节点表示随机变量，边表示变量间的概率依赖关系，从而以紧凑、可解释的方式编码高维联合分布中的结构信息。

在 $n$ 个随机变量的联合分布中，完全表示需要 $O(2^n)$ 个参数。PGM 的核心价值在于利用变量间的条件独立性大幅缩减参数规模——将指数级复杂度的联合分布分解为若干局部因子的乘积，使得表示、推断和学习都变得可行。

1.2 图与概率的关系

PGM 中的图 $G = (V, E)$ 包含节点集 $V$（对应随机变量 $X_1, \dots, X_n$）和边集 $E$。图的结构编码了概率分布的因子分解性质：

  • 有向图（贝叶斯网络）：有向边 $X_i \to X_j$ 表示因果关系或时序依赖，分布分解为 $P(X_1, \dots, X_n) = \prod_{i=1}^{n} P(X_i \mid \mathrm{Pa}(X_i))$。
  • 无向图（马尔可夫随机场）：无向边 $X_i - X_j$ 表示对称相关性，分布分解为 $P(X_1, \dots, X_n) = \frac{1}{Z} \prod_{c} \psi_c(X_c)$。
核心思想

图的缺失边意味着对应变量之间存在条件独立性。这正是 PGM 紧凑表示的本质：我们不需要存储整张联合分布表，只需存储与图结构一致的局部因子。

1.3 PGM 的三大要素

要素含义核心问题
表示（Representation）如何用图结构编码联合分布有向图 vs 无向图 vs 因子图
推断（Inference）给定模型，回答概率查询精确推断（VE, BP）vs 近似推断（MCMC, VI）
学习（Learning）从数据估计模型参数与结构参数学习（MLE, MAP, EM）vs 结构学习

这三大要素构成 PGM 理论的完整框架。表示定义模型族，推断在给定模型上进行概率计算，学习则从数据中获取模型。三者环环相扣：学习需要推断作为子例程，推断依赖表示给出的因子分解。

2贝叶斯网络基础

2.1 有向无环图（DAG）

贝叶斯网络（Bayesian Network）用有向无环图（Directed Acyclic Graph, DAG）表示变量间的概率依赖。DAG 中每个节点对应一个随机变量，有向边 $X_i \to X_j$ 表示 $X_j$ 直接依赖于 $X_i$。无环性保证不存在循环依赖，使得联合分布可以被合法地因子分解。

对于节点 $X_i$，其所有直接前驱称为父节点集 $\mathrm{Pa}(X_i)$，所有直接后继称为子节点集 $\mathrm{Ch}(X_i)$。没有父节点的节点称为根节点。

2.2 条件概率分布（CPD）

贝叶斯网络中每个节点 $X_i$ 关联一个条件概率分布（Conditional Probability Distribution, CPD）$P(X_i \mid \mathrm{Pa}(X_i))$，描述在给定父节点取值时 $X_i$ 的分布。对于离散变量，CPD 表现为条件概率表（CPT）；对于连续变量，CPD 可用线性高斯等参数化形式。

2.3 因子分解与链式法则

给定 DAG $G$，贝叶斯网络的联合分布按链式法则因子分解为各节点 CPD 的乘积：

$$P(X_1, X_2, \ldots, X_n) = \prod_{i=1}^{n} P(X_i \mid \mathrm{Pa}(X_i))$$

这是 PGM 紧凑性的基础：若每个变量最多有 $k$ 个父节点且每个变量取 $r$ 个值，则总参数量为 $O(n \cdot r^k)$，远优于无结构联合分布的 $O(r^n)$。

2.4 局部马尔可夫性

贝叶斯网络满足局部马尔可夫性：在给定父节点的条件下，每个节点与其非后代节点条件独立：

$$X_i \perp \!\!\! \perp \mathrm{Nd}(X_i) \setminus \mathrm{Pa}(X_i) \mid \mathrm{Pa}(X_i)$$

其中 $\mathrm{Nd}(X_i)$ 表示 $X_i$ 的所有非后代节点。这一性质是因子分解（公式1）成立的充分条件——链式法则的通用分解 $P(X_1, \dots, X_n) = \prod_i P(X_i \mid X_1, \dots, X_{i-1})$ 在局部马尔可夫性下简化为 $\prod_i P(X_i \mid \mathrm{Pa}(X_i))$。

等价关系

对于 DAG $G$ 和分布 $P$：$G$ 是 $P$ 的 I-map（独立性映射） $\Leftrightarrow$ $P$ 满足局部马尔可夫性 $\Leftrightarrow$ $P$ 按 $G$ 因子分解。三者等价，是贝叶斯网络表示的理论基石。

3贝叶斯网络的独立性

3.1 d-分离

d-分离（d-separation，directional separation）是判定贝叶斯网络中条件独立性的图结构准则。对于三个节点 $X$、$Y$、$Z$ 及路径上的中间节点 $W$，路径经过 $W$ 的三种基本结构决定了信息是否"阻断"：

  • 链式结构（$X \to W \to Y$）：给定 $W$，则 $X \perp \!\!\! \perp Y \mid W$，信息被阻断。
  • 分叉结构（$X \leftarrow W \to Y$）：给定 $W$，则 $X \perp \!\!\! \perp Y \mid W$，信息被阻断。
  • 汇合结构（$X \to W \leftarrow Y$）：默认 $X \perp \!\!\! \perp Y$（信息阻断）；但给定 $W$ 或其后代时，依赖被激活，$X$ 与 $Y$ 变为相关。

3.2 贝叶斯球算法

贝叶斯球算法（Bayes Ball Algorithm）是 d-分离的可达性算法。给定观测集 $\mathbf{Z}$，从节点 $X$ 出发模拟一个"球"在图上的传播：若球无法到达 $Y$，则 $X \perp \!\!\! \perp Y \mid \mathbf{Z}$。球的传播规则依节点方向和是否被观测而定：

  • 球到达未观测的分叉/链式节点：穿过并继续传播。
  • 球到达已观测的分叉/链式节点：被阻断，停止。
  • 球到达未观测的汇合节点：被阻断（默认独立）。
  • 球到达已观测的汇合节点（或其后代被观测）：通过并继续传播。

3.3 I-map、D-map 与忠实性

概念定义含义
I-map（独立性映射）$\mathcal{I}(G) \subseteq \mathcal{I}(P)$图中所有独立性都蕴含在分布中
D-map（依赖映射）$\mathcal{I}(G) \supseteq \mathcal{I}(P)$分布中所有独立性都反映在图中
完美映射（P-map）$\mathcal{I}(G) = \mathcal{I}(P)$图与分布独立性完全一致
忠实性（Faithfulness）$\mathcal{I}(G) = \mathcal{I}(P)$分布不包含图中未编码的额外独立性

3.4 马尔可夫毯

节点 $X$ 的马尔可夫毯（Markov Blanket）是在给定该集合时 $X$ 与图中所有其他节点条件独立的最小节点集。对于贝叶斯网络：

$$\mathrm{MB}(X_i) = \mathrm{Pa}(X_i) \cup \mathrm{Ch}(X_i) \cup \bigcup_{j \in \mathrm{Ch}(X_i)} \mathrm{Pa}(X_j) \setminus \{X_i\}$$

即马尔可夫毯包含 $X$ 的父节点、子节点以及子节点的其他父节点（共父）。给定马尔可夫毯后，$X$ 与网络其余部分条件独立：$X_i \perp \!\!\! \perp (V \setminus (\mathrm{MB}(X_i) \cup \{X_i\})) \mid \mathrm{MB}(X_i)$。马尔可夫毯在特征选择和因果推断中具有重要应用。

4马尔可夫随机场

4.1 无向图模型

马尔可夫随机场（Markov Random Field, MRF）用无向图 $H = (V, E)$ 描述变量间的对称依赖关系。与贝叶斯网络不同，MRF 的边没有方向，不编码因果关系，而是表达变量间的相互关联——适合建模空间、图像像素、社交网络等具有对称依赖的场景。

4.2 势函数与团

MRF 中变量间的依赖通过势函数（Potential Function）$\psi_c(X_c)$ 来建模。势函数定义在团（Clique）上——团是图中任意两节点都有边相连的子集。非负函数 $\psi_c: \mathrm{Val}(X_c) \to \mathbb{R}^+$，不需要归一化，也不直接对应概率值，而是编码变量子集 $X_c$ 的局部相容性。

极大团（Maximal Clique）是不能被更大团包含的团。MRF 的联合分布通过极大团上势函数的乘积来表示。

4.3 Hammersley-Clifford 定理

Hammersley-Clifford 定理建立了正概率分布与无向图因子分解的等价关系：若联合分布 $P(X) > 0$ 处处成立，则 $P$ 满足图 $H$ 上的局部马尔可夫性，当且仅当 $P$ 可以因子分解为极大团上势函数的乘积。

$$P(X_1, X_2, \ldots, X_n) = \frac{1}{Z} \prod_{c \in \mathcal{C}} \psi_c(X_c)$$

其中 $\mathcal{C}$ 为所有极大团集合，$Z$ 为配分函数（Partition Function），确保分布归一化：

$$Z = \sum_{x_1, \ldots, x_n} \prod_{c \in \mathcal{C}} \psi_c(x_c)$$
配分函数的挑战

$Z$ 的计算需要对所有变量取值求和，复杂度为 $O(r^n)$，这是 MRF 推断的核心难点。在精确推断中需要借助变量消除或信念传播；在近似推断中常通过伪似然或 MCMC 绕过直接计算。

4.4 吉布斯分布

当势函数取指数族形式 $\psi_c(X_c) = \exp\{-E_c(X_c)\}$ 时，MRF 的分布称为吉布斯分布（Gibbs Distribution），$E(X) = \sum_c E_c(X_c)$ 称为能量函数：

$$P(X) = \frac{1}{Z} \exp\left(-\sum_{c \in \mathcal{C}} E_c(X_c)\right) = \frac{1}{Z} \exp\left(-E(X)\right)$$

能量越低的配置概率越高。常见形式如玻尔兹曼机（Boltzmann Machine）和伊辛模型（Ising Model）都是吉布斯分布的特例。

5MRF的独立性

5.1 全局马尔可夫性

MRF 的全局马尔可夫性：若从 $X$ 到 $Y$ 的所有路径都经过 $\mathbf{Z}$，则 $X \perp \!\!\! \perp Y \mid \mathbf{Z}$。形式化地，若 $\mathbf{Z}$ 将图分割为若干连通分量，则不同分量中的变量条件独立：

$$\text{若 } \mathbf{Z} \text{ 分离 } X \text{ 与 } Y \text{ 在 } H \text{ 中}, \quad \text{则 } X \perp \!\!\! \perp Y \mid \mathbf{Z}$$

5.2 局部马尔可夫性

MRF 的局部马尔可夫性：给定节点的邻居集 $\mathrm{Nb}(X_i)$（与 $X_i$ 直接相连的节点），$X_i$ 与图中其余节点条件独立：

$$X_i \perp \!\!\! \perp V \setminus (\mathrm{Nb}(X_i) \cup \{X_i\}) \mid \mathrm{Nb}(X_i)$$

在 MRF 中，马尔可夫毯恰好等于邻居集 $\mathrm{MB}(X_i) = \mathrm{Nb}(X_i)$，这比贝叶斯网络（含共父）更简洁。

5.3 成对马尔可夫性

成对马尔可夫性：若两个非邻接节点 $X_i$、$X_j$ 没有边直接相连，则在给定所有其他节点时条件独立：

$$\text{若 } (X_i, X_j) \notin E, \quad \text{则 } X_i \perp \!\!\! \perp X_j \mid V \setminus \{X_i, X_j\}$$
三种马尔可夫性的等价性

对于正概率分布，全局、局部、成对马尔可夫性三者等价。Hammersley-Clifford 定理保证了：三者中任一成立 $\Leftrightarrow$ 分布可按无向图因子分解为团上势函数的乘积。

5.4 BN 与 MRF 对比

6因子图

6.1 二分图表示

因子图（Factor Graph）是统一表示 BN 和 MRF 的二分图框架。它包含两类节点：变量节点（圆圈）和因子节点（方块），边只连接变量与因子。因子图将因子分解中的每个因子显式地表示为图中的节点，使得结构更加清晰。

6.2 因子分解

因子图将联合分布显式分解为因子的乘积，每个因子节点 $f_a$ 对应一个势函数：

$$P(\mathbf{x}) = \prod_{a} f_a(\mathbf{x}_a)$$

其中 $\mathbf{x}_a$ 是因子 $f_a$ 所连接的变量子集。因子图的二分结构清晰地将"变量"与"局部函数"分离，是和积算法（Sum-Product）的天然载体。

6.3 从 BN / MRF 到因子图

  • BN → 因子图：每个 CPD $P(X_i \mid \mathrm{Pa}(X_i))$ 对应一个因子节点 $f_i$，连接 $X_i$ 及其所有父节点。
  • MRF → 因子图：每个极大团的势函数 $\psi_c(X_c)$ 对应一个因子节点 $f_c$，连接团中所有变量。
因子图的优势

因子图是 BN 和 MRF 的统一表示。更细粒度的因子分解（将大团分解为多个小因子）在保持分布不变的同时减少冗余计算。和积信念传播算法在因子图上的消息传递规则最自然、最简洁。

7精确推断-变量消除法

7.1 推断问题

推断（Inference）是在给定 PGM 后计算概率查询的过程。最基本的形式是边缘概率查询：给定证据 $\mathbf{e}$，查询变量集 $\mathbf{Y}$ 的后验边缘分布：

$$P(\mathbf{Y} \mid \mathbf{e}) = \frac{P(\mathbf{Y}, \mathbf{e})}{P(\mathbf{e})} = \frac{\sum_{\mathbf{Z}} P(\mathbf{Y}, \mathbf{Z}, \mathbf{e})}{\sum_{\mathbf{Y}, \mathbf{Z}} P(\mathbf{Y}, \mathbf{Z}, \mathbf{e})}$$

其中 $\mathbf{Z}$ 为非查询非证据变量（需被消除的"隐藏变量"）。分子分母都需要对所有隐藏变量求和，这是推断复杂度的来源。

7.2 变量消除算法

变量消除法（Variable Elimination, VE）通过逐步消除（求和消除）隐藏变量来计算边缘分布。核心思想是利用因子分解，每次只将与当前变量相关的因子相乘并求和，生成新的中间因子，避免直接展开整张联合分布表。

VE 算法步骤如下：

  1. 初始化因子集 $\Phi = \{f_1, \dots, f_m\}$（根据证据证据化后）。
  2. 按消除顺序 $\pi$ 逐个消除变量 $Z$：
    • 收集所有包含 $Z$ 的因子 $\Phi_Z = \{\phi \in \Phi : Z \in \mathrm{Scope}(\phi)\}$。
    • 将 $\Phi_Z$ 中因子相乘：$\tau = \prod_{\phi \in \Phi_Z} \phi$。
    • 对 $Z$ 求和消除：$\tau' = \sum_Z \tau$。
    • 更新因子集：$\Phi = (\Phi \setminus \Phi_Z) \cup \{\tau'\}$。
  3. 最后 $\Phi$ 中剩余因子的乘积即为查询结果。

7.3 消除顺序与复杂度

VE 的计算复杂度高度依赖消除顺序（Elimination Ordering）。消除变量 $Z$ 时，新因子 $\tau$ 的scope是所有含 $Z$ 因子的scope之并集。该并集的大小决定计算代价。

定义诱导宽度（Induced Width）$w$：在给定消除顺序下，消除过程中产生的最大因子scope大小减 1。VE 的时间复杂度为：

$$T_{\text{VE}} = O\left(n \cdot r^{w+1}\right)$$

其中 $n$ 为变量数，$r$ 为变量取值数，$w$ 为诱导宽度。寻找最优消除顺序使 $w$ 最小化是 NP-hard 问题。启发式策略包括最小缺失宽度（Min-Fill）和最小度（Min-Degree）。

复杂度本质

精确推断在一般图上是 NP-hard。但对于树结构图（单连通图），诱导宽度 $w = 1$，VE 退化为线性复杂度 $O(n \cdot r^2)$，这正是信念传播高效的基础。

8精确推断-信念传播

8.1 和积消息传递

信念传播（Belief Propagation, BP）又称和积算法（Sum-Product Algorithm），在因子图上通过消息传递实现高效推断。每个因子节点和变量节点之间沿边交换"消息"，消息编码了从一侧子图传来的边缘概率信息。

在因子图上，变量节点 $x_i$ 向因子节点 $f_a$ 发送消息：

$$m_{i \to a}(x_i) = \prod_{b \in \mathrm{Nb}(i) \setminus a} m_{b \to i}(x_i)$$

因子节点 $f_a$ 向变量节点 $x_i$ 发送消息：

$$m_{a \to i}(x_i) = \sum_{\mathbf{x}_a \setminus x_i} f_a(\mathbf{x}_a) \prod_{j \in \mathrm{Nb}(a) \setminus i} m_{j \to a}(x_j)$$

其中 $\mathrm{Nb}(i)$ 为 $x_i$ 的邻居因子集，$\mathrm{Nb}(a)$ 为 $f_a$ 的邻居变量集。变量节点的信念（边缘概率）为所有入消息的乘积归一化：

$$b(x_i) \propto \prod_{a \in \mathrm{Nb}(i)} m_{a \to i}(x_i)$$

8.2 树结构推断

当因子图为树结构（无环连通图）时，BP 在两轮消息传递后精确收敛。第一轮从叶节点向根节点传递（收集阶段），第二轮从根节点向叶节点传递（分发阶段），每个变量节点的最终信念即为精确边缘概率。

对于含有环的图，标准 BP 不保证收敛，但实践中环状信念传播（Loopy BP）仍常被用作近似推断方法——通过迭代传递消息直至收敛或达到最大迭代次数。Loopy BP 在 LDPC 解码、图像分割等任务中取得了优异的实证效果。

8.3 最大积信念传播

最大积 BP（Max-Product BP）将和积 BP 中的求和 $\sum$ 替换为取最大 $\max$，用于求解最大后验概率（MAP）问题——寻找最可能的变量赋值 $\mathbf{x}^* = \arg\max_{\mathbf{x}} P(\mathbf{x} \mid \mathbf{e})$：

$$m_{a \to i}(x_i) = \max_{\mathbf{x}_a \setminus x_i} f_a(\mathbf{x}_a) \prod_{j \in \mathrm{Nb}(a) \setminus i} m_{j \to a}(x_j)$$

最大积 BP 在树结构图上可在两轮消息传递中精确求解 MAP。对于一般图，可使用连接树（Junction Tree）算法：通过三角化、寻找极大团、构建连接树，将任意图转化为树结构的团图，从而实现精确推断，但代价是团的大小可能很大。

9近似推断-采样

9.1 蒙特卡洛方法

蒙特卡洛方法（Monte Carlo Methods）通过从目标分布中采样来近似计算期望、边缘概率等统计量。给定分布 $P(X)$，期望 $\mathbb{E}_{P}[f(X)]$ 可通过 $N$ 个样本 $\{x^{(s)}\}_{s=1}^{N} \sim P(X)$ 的经验平均来估计：

$$\mathbb{E}_{P}[f(X)] \approx \hat{\mu}_N = \frac{1}{N} \sum_{s=1}^{N} f(x^{(s)})$$

由大数定律，$\hat{\mu}_N \xrightarrow{a.s.} \mathbb{E}_{P}[f(X)]$，收敛速度为 $O(1/\sqrt{N})$。蒙特卡洛方法的优势在于估计精度与变量维度无关——在高维空间中比数值积分远为高效。

9.2 吉布斯采样

吉布斯采样（Gibbs Sampling）是 MCMC 的特例，适用于可以从完整条件分布采样的场景。在每一步中，固定所有其他变量，仅从单个变量的完整条件分布中采样：

$$x_i^{(t+1)} \sim P\left(X_i \mid X_{-i}^{(t)}\right) = P\left(X_i \mid \mathrm{MB}(X_i)\right)$$

其中 $X_{-i}$ 表示除 $X_i$ 外的所有变量。关键优势：在 PGM 中，完整条件分布只依赖于马尔可夫毯，不需要计算配分函数 $Z$（在条件分布中 $Z$ 被消去）。吉布斯采样在贝叶斯网络中特别自然——每个节点的条件分布即为 CPD。

9.3 MCMC 与 Metropolis-Hastings

马尔可夫链蒙特卡洛（MCMC）通过构造一个以目标分布为平稳分布的马尔可夫链来采样。Metropolis-Hastings（MH）算法是最通用的 MCMC 方法：

  1. 从当前状态 $x^{(t)}$ 出发，根据提议分布 $q(x' \mid x^{(t)})$ 生成候选 $x'$。
  2. 计算接受概率： $\alpha = \min\left(1, \frac{P(x') q(x^{(t)} \mid x')}{P(x^{(t)}) q(x' \mid x^{(t)})}\right)$
  3. 以概率 $\alpha$ 接受 $x^{(t+1)} = x'$，否则拒绝 $x^{(t+1)} = x^{(t)}$。

MH 的优势在于只需要目标分布的未归一化形式（不需要 $Z$），因为 $Z$ 在接受比的分子分母中消去。这使得 MH 可直接应用于 MRF 采样。吉布斯采样可视为提议分布为完整条件分布、接受概率恒为 1 的 MH 特例。

MCMC 的关键考量

收敛诊断（Burn-in、Gelman-Rubin $\hat{R}$）、自相关（Effective Sample Size）、混合速度是 MCMC 实践的核心问题。Burn-in 期丢弃初始样本以消除初始值影响；高自相关意味着有效样本量远小于实际样本量，需要更长链或并行链来获得可靠估计。

10近似推断-变分推断

10.1 变分推断框架

变分推断（Variational Inference, VI）将推断问题转化为优化问题：用参数化的简单分布族 $q(Z; \phi)$ 逼近真实后验 $P(Z \mid X)$，通过最小化 KL 散度来优化变分参数 $\phi$：

$$q^*(Z) = \arg\min_{q \in \mathcal{Q}} \mathrm{KL}\left(q(Z) \,\|\, P(Z \mid X)\right)$$

由于 $P(Z \mid X)$ 未知（含配分函数），直接优化 KL 散度不可行。等价地，最大化证据下界（Evidence Lower Bound, ELBO）：

$$\log P(X) \geq \mathcal{L}(\phi) = \mathbb{E}_{q(Z;\phi)}\left[\log P(X, Z)\right] - \mathbb{E}_{q(Z;\phi)}\left[\log q(Z; \phi)\right]$$

ELBO 与 KL 散度的关系为 $\log P(X) = \mathcal{L}(\phi) + \mathrm{KL}(q \| P(Z \mid X))$。最大化 ELBO 等价于最小化 KL 散度，差值 $\log P(X) - \mathcal{L}(\phi)$ 即 KL 散度本身，恒非负。

10.2 平均场近似

平均场变分族（Mean-Field）假设各隐藏变量独立，将后验近似为各变量分布的乘积：

$$q(Z) = \prod_{i=1}^{m} q_i(Z_i)$$

这是最简单的变分族，完全忽略变量间后验依赖。在此假设下，最优各分量分布满足坐标上升更新：

$$\log q_i^*(Z_i) = \mathbb{E}_{q_{-i}}\left[\log P(X, Z)\right] + \text{const}$$

其中 $q_{-i} = \prod_{j \neq i} q_j$。各 $q_i$ 的更新依赖于其他分量的期望，需要迭代直至收敛（坐标上升法，CAVI）。

10.3 坐标上升变分推断（CAVI）

CAVI（Coordinate Ascent Variational Inference）是平均场 VI 的标准算法：

  1. 初始化各变分分量 $q_i$ 的参数。
  2. 循环直至收敛：对每个 $i$，按公式(22)更新 $q_i$（固定其他 $q_j$）。
  3. 每轮计算 ELBO，监测收敛。

CAVI 类似 EM 的交替优化：每步提升 ELBO，保证收敛到局部最优。但平均场假设可能导致低估后验不确定性——真实后验中相关的变量被强制独立。

10.4 随机变分推断（SVI）

随机变分推断（Stochastic Variational Inference, SVI）将自然梯度上升与随机采样结合，使用数据子集（mini-batch）估计 ELBO 梯度，适用于大规模数据集。SVI 是变分自编码器（VAE）等深度生成模型的基础——通过重参数化技巧（Reparameterization Trick）使 ELBO 梯度可通过反向传播计算。

11PGM参数学习

11.1 最大似然估计（MLE）

最大似然估计选择使观测数据似然最大的参数值。给定数据集 $\mathcal{D} = \{x^{(1)}, \dots, x^{(N)}\}$，MLE 最大化对数似然：

$$\hat{\theta}_{\text{MLE}} = \arg\max_{\theta} \sum_{n=1}^{N} \log P(x^{(n)}; \theta)$$

对于贝叶斯网络，若结构已知且数据完整，各 CPD 参数可独立估计——MLE 对每个条件概率表条目退化为计数比例 $\hat\theta_{x_i \mid \mathrm{pa}} = \frac{N_{x_i, \mathrm{pa}}}{N_{\mathrm{pa}}}$，其中 $N$ 为对应取值的计数。对于 MRF，MLE 需要计算配分函数 $Z(\theta)$ 的梯度，涉及推断子例程，通常使用伪似然（Pseudo-Likelihood）替代。

11.2 MAP 估计与贝叶斯学习

MAP 估计引入先验分布 $P(\theta)$，选择后验最大的参数：

$$\hat{\theta}_{\text{MAP}} = \arg\max_{\theta} \left[\sum_{n=1}^{N} \log P(x^{(n)} \mid \theta) + \log P(\theta)\right]$$

MAP 是点估计，等价于带正则化的 MLE。贝叶斯学习则更进一步——不求点估计，而是对参数做完整贝叶斯推断，计算后验分布 $P(\theta \mid \mathcal{D}) \propto P(\mathcal{D} \mid \theta) P(\theta)$，再对参数积分做预测 $P(x_{\text{new}} \mid \mathcal{D}) = \int P(x_{\text{new}} \mid \theta) P(\theta \mid \mathcal{D}) d\theta$。贝叶斯学习可量化参数不确定性，但计算复杂度更高。

11.3 EM 算法

EM 算法（Expectation-Maximization）用于含隐藏变量的参数学习，交替执行两步：

  • E 步：给定当前参数 $\theta^{(t)}$，计算隐藏变量的后验分布 $P(Z \mid X, \theta^{(t)})$，并求期望完全数据对数似然 $Q(\theta, \theta^{(t)}) = \mathbb{E}_{Z \sim P(Z \mid X, \theta^{(t)})}[\log P(X, Z \mid \theta)]$。
  • M 步：最大化 $Q$ 更新参数 $\theta^{(t+1)} = \arg\max_\theta Q(\theta, \theta^{(t)})$。

EM 保证对数似然单调递增（$\log P(X \mid \theta^{(t+1)}) \geq \log P(X \mid \theta^{(t)})$），收敛到局部最优。EM 与 VI 的区别在于：EM 的 E 步做精确推断（或近似推断），M 步做点估计；VI 则同时对参数和隐变量做变分近似。

11.4 结构学习

结构学习从数据中推断图结构本身，比参数学习复杂得多。主要方法包括：

  • 基于约束的方法（Constraint-Based）：通过条件独立性检验构建图结构。PC 算法逐步删除边，用统计检验判断独立性。
  • 基于评分的方法（Score-Based）：定义结构评分（如 BIC、BDeu），搜索最优结构。由于搜索空间为超指数，常用启发式搜索（贪心、爬山、 taboo 搜索）。
  • 混合方法：先用约束方法缩小候选集，再用评分方法精细化。
结构学习的挑战

结构学习是 NP-hard 问题。DAG 的搜索空间为超指数级 $O(n! \cdot 2^{\binom{n}{2}})$。此外，马尔可夫等价类问题（不同 DAG 可编码相同独立性）使得因果方向在某些情况下不可辨识——只有汇合结构（$v$-结构）能确定方向。

import numpy as np
from collections import defaultdict

class BayesianNetwork:
    """离散贝叶斯网络：DAG + 条件概率表"""
    def __init__(self):
        self.nodes = []
        self.parents = defaultdict(list)
        self.cpts = {}

    def add_node(self, name, parents=None, cpt=None):
        self.nodes.append(name)
        self.parents[name] = parents or []
        self.cpts[name] = cpt

    def joint_probability(self, assignment):
        """计算给定赋值的联合概率"""
        prob = 1.0
        for node in self.nodes:
            parent_vals = tuple(assignment[p] for p in self.parents[node])
            key = (assignment[node],) + parent_vals
            prob *= self.cpts[node].get(key, 0.0)
        return prob

# 示例：D → T → S 简单链式网络

})

variable_elimination.py
import numpy as np
from itertools import product

class Factor:
    """因子：变量集 + 势函数表"""
    def __init__(self, variables, table):
        self.variables = list(variables)
        self.table = np.array(table)

    def multiply(self, other):
        """两个因子相乘"""
        vars_new = self.variables + [v for v in other.variables if v not in self.variables]
        shape_new = [2] * len(vars_new)
        result = np.zeros(shape_new)
        for idx in product(*[range(2)] * len(vars_new)):
            assign = dict(zip(vars_new, idx))
            i1 = tuple(assign[v] for v in self.variables)
            i2 = tuple(assign[v] for v in other.variables)
            result[idx] = self.table[i1] * other.table[i2]
        return Factor(vars_new, result)

    def sum_out(self, var):
        """消除变量 var（求和边缘化）"""
        axis = self.variables.index(var)
        new_vars = [v for v in self.variables if v != var]
        return Factor(new_vars, np.sum(self.table, axis=axis))

def variable_elimination(factors, query, evidence, elim_order):
    """变量消除法计算 P(query | evidence)"""
    # 证据化
    for i, f in enumerate(factors):
        for var, val in evidence.items():
            if var in f.variables:
                axis = f.variables.index(var)
                factors[i] = Factor(
                    [v for v in f.variables if v != var],
                    np.take(f.table, val, axis=axis)
                )
    # 逐步消除
    for var in elim_order:
        relevant = [f for f in factors if var in f.variables]
        factors = [f for f in factors if var not in f.variables]
        if relevant:
            product_f = relevant[0]
            for f in relevant[1:]:
                product_f = product_f.multiply(f)
            factors.append(product_f.sum_out(var))
    # 剩余因子相乘
    result = factors[0]
    for f in factors[1:]:
        result = result.multiply(f)
    # 归一化
    result.table /= result.table.sum()
    return result

# 示例因子
f1 = Factor(["A"], [0.3, 0.7])
f2 = Factor(["A", "B"], [[0.1, 0.9], [0.8, 0.2]])
result = variable_elimination([f1, f2], ["B"], {}, ["A"])
print("P(B):", result.table)

import numpy as np
np.random.seed(42)

def gibbs_sampling(bn, num_samples=10000, burn_in=1000):
    """吉布斯采样：从贝叶斯网络后验中采样"""
    # 初始化：随机赋值
    assignment = {node: np.random.randint(0, 2) for node in bn.nodes}
    samples = []

    for t in range(num_samples + burn_in):
        for node in bn.nodes:
            # 计算完整条件分布 P(X_i | MB(X_i))
            probs = []
            for val in [0, 1]:
                assignment[node] = val
                p = bn.joint_probability_log(assignment)
                probs.append(p)
            # softmax 归一化
            probs = np.exp(np.array(probs) - max(probs))
            probs /= probs.sum()
            assignment[node] = np.random.choice([0, 1], p=probs)

        if t >= burn_in:
            samples.append(dict(assignment))

    return samples

class SimpleBN:
    """简单二值贝叶斯网络用于演示"""

        # P(X), P(Y|X)
        self.px = [0.4, 0.6]
        self.py_given_x = [[0.3, 0.7], [0.8, 0.2]]

    def joint_probability_log(self, a):
        lp = np.log(self.px[a["X"]])
        lp += np.log(self.py_given_x[a["X"]][a["Y"]])
        return lp

import numpy as np

def mean_field_vi(joint_log_prob, num_vars, num_iter=100):
    """平均场变分推断（CAVI）"""
    # 初始化变分参数 q_i(x_i)
    q_params = np.ones((num_vars, 2)) / 2  # 均匀分布

    elbo_history = []
    for iteration in range(num_iter):
        # 坐标上升：逐个更新 q_i
        for i in range(num_vars):
            log_q = np.zeros(2)
            for xi in range(2):
                # E_{q_{-i}}[log P(X)]
                total_logp = 0.0
                num_samples = 50
                for _ in range(num_samples):
                    sample = np.zeros(num_vars, dtype=int)
                    for j in range(num_vars):
                        if j != i:
                            sample[j] = np.random.choice(2, p=q_params[j])
                    sample[i] = xi
                    total_logp += joint_log_prob(sample)
                log_q[xi] = total_logp / num_samples

            # softmax 归一化
            log_q = log_q - log_q.max()
            q_params[i] = np.exp(log_q)
            q_params[i] /= q_params[i].sum()

        # 计算 ELBO（简化估计）
        elbo = sum(np.sum(q_params[i] * np.log(q_params[i] + 1e-10))
                   for i in range(num_vars))
        elbo_history.append(elbo)

    return q_params, elbo_history

# 示例：2变量 Ising 模型
def ising_log_prob(x, J=1.0, h=0.1):
    """Ising 模型 log P(x) = J*x1*x2 + h*(x1+x2)"""
    return J * x[0] * x[1] + h * (x[0] + x[1])

q_params, elbo_hist = mean_field_vi(ising_log_prob, num_vars=2, num_iter=20)

import numpy as np
np.random.seed(42)

class IsingMRF:
    """二维 Ising 模型：图像去噪的经典 MRF"""
    def __init__(self, width, height, J=1.0):
        self.W, self.H = width, height
        self.J = J
        self.grid = np.random.choice([-1, 1], size=(height, width))

    def neighbors(self, i, j):
        """获取四邻域邻居"""
        nbrs = []
        for di, dj in [(-1,0),(1,0),(0,-1),(0,1)]:
            ni, nj = i+di, j+dj
            if 0 <= ni < self.H and 0 <= nj < self.W:
                nbrs.append((ni, nj))
        return nbrs

    def local_energy(self, i, j):
        """局部能量 E(x_i) = -J * sum(x_i * x_neighbor)"""
        e = 0
        for ni, nj in self.neighbors(i, j):
            e -= self.J * self.grid[i, j] * self.grid[ni, nj]
        return e

    def gibbs_step(self):
        """一次吉布斯扫描"""
        for i in range(self.H):
            for j in range(self.W):
                # 计算翻转前后的能量差
                e_current = self.local_energy(i, j)
                self.grid[i, j] *= -1
                e_flipped = self.local_energy(i, j)
                # Metropolis 接受准则
                delta_e = e_flipped - e_current
                if delta_e > 0:
                    self.grid[i, j] *= -1  # 拒绝，恢复
                else:
                    if np.random.rand() > np.exp(-delta_e):
                        self.grid[i, j] *= -1  # 拒绝

    def sample(self, num_steps=100):
        """运行吉布斯采样"""
        for _ in range(num_steps):
            self.gibbs_step()
        return self.grid.copy()

# 运行 8x8 Ising 模型
ising = IsingMRF(8, 8, J=1.0)

import numpy as np
from itertools import combinations

def bic_score(data, node, parents):
    """BIC 评分：对数似然 - 惩罚项"""
    n_samples = data.shape[0]
    n_states = len(np.unique(data[:, node]))

    # 统计计数
    if not parents:
        counts = np.bincount(data[:, node], minlength=n_states)
        log_lik = np.sum(counts * np.log(counts / n_samples + 1e-10))
        n_params = n_states - 1
    else:
        parent_states = [len(np.unique(data[:, p])) for p in parents]
        n_parent_configs = int(np.prod(parent_states))
        log_lik = 0
        for config in combinations(range(n_parent_configs), len(parents)):
            mask = np.ones(n_samples, dtype=bool)
            for idx, p in enumerate(parents):
                mask &= (data[:, p] == config[idx])
            if mask.sum() > 0:
                child_counts = np.bincount(data[mask, node], minlength=n_states)
                log_lik += np.sum(child_counts * np.log(child_counts / mask.sum() + 1e-10))
        n_params = n_parent_configs * (n_states - 1)

    # BIC = log_lik - 0.5 * log(n) * n_params
    penalty = 0.5 * np.log(n_samples) * n_params
    return log_lik - penalty

def greedy_search(data, num_nodes, max_parents=3):
    """贪心搜索：逐步添加最优父节点"""
    structure = {i: [] for i in range(num_nodes)}

    for node in range(num_nodes):
        current_score = bic_score(data, node, [])
        improved = True
        while improved and len(structure[node]) < max_parents:
            improved = False
            best_parent = None
            best_score = current_score
            for candidate in range(num_nodes):
                if candidate == node or candidate in structure[node]:
                    continue
                # 检查无环约束（简化：跳过已在node后代的节点）
                new_parents = structure[node] + [candidate]
                score = bic_score(data, node, new_parents)
                if score > best_score:
                    best_score = score
                    best_parent = candidate
            if best_parent is not None:
                structure[node].append(best_parent)
                current_score = best_score
                improved = True

    return structure

# 示例数据
np.random.seed(42)
data = np.random.randint(0, 2, size=(200, 4))
structure = greedy_search(data, num_nodes=4)
print("学到的结构（节点 → 父节点）:")
for node, parents in structure.items():
    print(f"  X{node} ← {['X'+str(p) for p in parents] if parents else '无'}")

13.2 与深度学习的关系

PGM 与深度学习的关系是互补而非替代：

  • 可解释性：PGM 提供显式的图结构和概率语义，深度学习的端到端训练难以提供。
  • 不确定性量化：PGM 天然提供后验概率，深度学习需要额外方法（如 MC Dropout、贝叶斯神经网络）来估计不确定性。
  • 小样本学习：PGM 可融合先验知识，在小数据场景下优于纯数据驱动的深度学习。
  • 生成模型：VAE 使用变分推断框架，DDPM（扩散模型）本质是马尔可夫链上的概率推断，两者都是 PGM 思想在深度学习中的延伸。

一句话总结

表示用图编码结构（BN 有向 / MRF 无向 / 因子图统一），推断在图上计算概率（VE / BP 精确，MCMC / VI 近似），学习从数据获取模型（MLE / EM 参数，评分搜索结构）。三者交汇，构成了不确定性建模的完整框架，并与深度学习深度融合于现代 AI。
