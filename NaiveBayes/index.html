1贝叶斯定理与直觉

1.1 逆概率问题

18 世纪英国牧师 Thomas Bayes 解决了一个根本性的问题：已知结果，如何推断原因？这就是"逆概率"——从观察到的证据反推隐藏的原因。频率学派只关注"已知原因求结果的概率"（正向概率），而贝叶斯学派开创性地回答了反方向的问题。

经典直觉示例

医学检测问题：某种疾病患病率为 $1\%$。检测仪器的灵敏度为 $99\%$（患病者阳性概率），特异度为 $95\%$（健康者阴性概率）。如果一个人检测阳性，真正患病的概率是多少？直觉上可能是 $99\%$，但用贝叶斯定理计算后只有 $16.7\%$。这就是基础概率忽视（Base Rate Neglect）。

1.2 贝叶斯定理

贝叶斯定理描述了在观察到证据 $E$ 后，如何更新假设 $H$ 的概率：

$$P(H \mid E) = \frac{P(E \mid H) \cdot P(H)}{P(E)}$$
术语符号含义
先验概率$P(H)$观察到证据前对假设的信念
似然$P(E \mid H)$假设为真时观察到证据的概率
后验概率$P(H \mid E)$观察到证据后对假设的更新信念
证据$P(E)$归一化常数，确保概率和为 1

对于分类问题，我们将假设 $H$ 替换为类别 $y$，证据 $E$ 替换为特征向量 $\mathbf{x}$：

$$P(y \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid y) \cdot P(y)}{P(\mathbf{x})}$$

由于 $P(\mathbf{x})$ 对所有类别相同，分类决策只需最大化分子：

$$\hat{y} = \arg\max_y \; P(y) \cdot P(\mathbf{x} \mid y)$$

2"朴素"假设与条件独立

2.1 指数级概率难题

直接使用贝叶斯定理进行分类有一个致命问题：计算 $P(\mathbf{x} \mid y)$ 需要估计特征向量的联合概率分布。如果 $\mathbf{x} = (x_1, x_2, \ldots, x_d)$ 有 $d$ 个特征，每个特征有 $k$ 个取值，则需要估计 $k^d$ 个参数——这随特征维度指数增长，在数据和计算上都不可行。

2.2 条件独立假设

朴素贝叶斯做出了一个大胆的"朴素"假设：在给定类别 $y$ 的条件下，各特征之间相互独立。即：

$$P(\mathbf{x} \mid y) = P(x_1, x_2, \ldots, x_d \mid y) = \prod_{i=1}^{d} P(x_i \mid y)$$

这个假设将联合概率分解为 $d$ 个独立的一维条件概率的乘积，参数量从 $k^d$ 降为 $d \times k$，是线性增长而非指数增长。

"朴素"在哪里？

这个假设在现实中几乎从不严格成立。例如在垃圾邮件分类中，"免费"和"优惠"这两个词的出现显然不独立——它们经常一起出现。但令人惊讶的是，即使条件独立假设不成立，朴素贝叶斯的分类性能依然出色——因为它只需要排序正确，不需要概率估计精确。

2.3 朴素贝叶斯分类器

结合公式 (3) 和 (4)，朴素贝叶斯分类器为：

$$\hat{y} = \arg\max_y \; P(y) \prod_{i=1}^{d} P(x_i \mid y)$$

2.4 对数概率与数值稳定性

当特征维度 $d$ 很大时，$\prod_i P(x_i \mid y)$ 的乘积可能下溢为 0。实践中取对数将乘法变为加法：

$$\hat{y} = \arg\max_y \; \left[ \log P(y) + \sum_{i=1}^{d} \log P(x_i \mid y) \right]$$

取对数不改变 $\arg\max$ 结果，但避免了数值下溢问题，且加法计算比乘法更高效。

3三种经典模型

朴素贝叶斯的核心是估计 $P(x_i \mid y)$，而特征的类型决定了使用哪种分布模型。三种最经典的变体对应不同的数据类型。

3.1 高斯朴素贝叶斯（连续特征）

当特征为连续值时，假设在给定类别下特征服从高斯分布：

$$P(x_i \mid y) = \frac{1}{\sqrt{2\pi\sigma_{y,i}^2}} \exp\left(-\frac{(x_i - \mu_{y,i})^2}{2\sigma_{y,i}^2}\right)$$

参数 $\mu_{y,i}$ 和 $\sigma_{y,i}^2$ 分别为类别 $y$ 下特征 $x_i$ 的均值和方差，通过训练数据的极大似然估计获得。

3.2 多项式朴素贝叶斯（计数特征）

当特征为计数/频率时（如文本中词频），假设特征服从多项式分布：

$$P(\mathbf{x} \mid y) \propto \prod_{i=1}^{d} \theta_{y,i}^{x_i}$$

其中 $\theta_{y,i} = P(x_i \mid y)$ 是类别 $y$ 下特征 $i$ 出现的概率，$\sum_i \theta_{y,i} = 1$。这是文本分类最常用的模型。

3.3 伯努利朴素贝叶斯（二值特征）

当特征为0/1 二值时（如词是否出现），假设特征服从伯努利分布：

$$P(\mathbf{x} \mid y) = \prod_{i=1}^{d} \theta_{y,i}^{x_i} (1-\theta_{y,i})^{1-x_i}$$

与多项式模型不同，伯努利模型考虑了词不出现的概率，适合短文本或特征稀疏的场景。

4参数估计与拉普拉斯平滑

4.1 极大似然估计

朴素贝叶斯的参数通过极大似然估计（MLE）从训练数据中学习：

类别先验：

$$\hat{P}(y) = \frac{N_y}{N}$$

条件概率（离散特征）：

$$\hat{P}(x_i = v \mid y) = \frac{N_{y, x_i=v}}{N_y}$$

其中 $N_y$ 是类别 $y$ 的样本数，$N_{y, x_i=v}$ 是类别 $y$ 中特征 $x_i$ 取值 $v$ 的样本数。

4.2 零概率问题

致命问题

如果某个特征值 $v$ 在类别 $y$ 的训练数据中从未出现，则 $\hat{P}(x_i=v \mid y) = 0$。由于各特征概率相乘，一个零值会导致整个后验为零——即使其他特征强烈支持类别 $y$，分类器也会完全忽略它。这就是"零概率问题"。

4.3 拉普拉斯平滑

解决方案是拉普拉斯平滑（又称加一平滑）：

$$\hat{P}(x_i = v \mid y) = \frac{N_{y, x_i=v} + \alpha}{N_y + \alpha |V_i|}$$

其中 $\alpha > 0$ 是平滑参数（$\alpha=1$ 为标准拉普拉斯平滑），$|V_i|$ 是特征 $x_i$ 的取值数。平滑确保了所有概率为正，且满足 $\sum_v \hat{P}(x_i=v \mid y) = 1$。

$\alpha$ 值效果适用场景
$\alpha = 0$无平滑，MLE不推荐（零概率风险）
$\alpha = 1$标准拉普拉斯平滑默认选择
$0 < \alpha < 1$弱平滑（Lidstone 平滑）大数据集、避免过度平滑
$\alpha > 1$强平滑小数据集、高稀疏特征

4.4 多项式模型的平滑

对于多项式朴素贝叶斯（文本分类），平滑后的参数为：

$$\hat{\theta}_{y,i} = \frac{N_{y,i} + \alpha}{N_y + \alpha d}$$

其中 $N_{y,i}$ 是类别 $y$ 中词 $i$ 的总出现次数，$N_y = \sum_i N_{y,i}$ 是类别 $y$ 的总词数，$d$ 是词表大小。

4.5 朴素贝叶斯完整算法流程

至此，我们已经掌握了朴素贝叶斯的全部核心组件——贝叶斯定理、条件独立假设、三种概率模型、参数估计与拉普拉斯平滑。下面将它们串联为一个完整的通用算法流程，适用于任意数据类型。

训练阶段

  1. 统计类别先验：计算每个类别 $y$ 的先验概率 $\hat{P}(y) = N_y / N$，其中 $N_y$ 是类别 $y$ 的样本数，$N$ 是总样本数。
  2. 估计条件概率：根据数据类型选择模型，估计每个特征在每个类别下的条件概率 $\hat{P}(x_i \mid y)$：
    • 连续特征 → 高斯模型，估计均值 $\mu_{y,i}$ 和方差 $\sigma_{y,i}^2$
    • 计数特征 → 多项式模型，估计 $\theta_{y,i} = N_{y,i} / N_y$
    • 二值特征 → 伯努利模型，估计 $\theta_{y,i} = N_{y,i} / N_y$
  3. 拉普拉斯平滑：对离散特征施加平滑 $\hat{P}(x_i = v \mid y) = (N_{y, x_i=v} + \alpha) / (N_y + \alpha |V_i|)$，避免零概率（见 4.3 节）。
  4. 取对数存储：将所有概率取对数存储为 $\log \hat{P}(y)$ 和 $\log \hat{P}(x_i \mid y)$，避免预测时连乘下溢（见 2.4 节）。

预测阶段

  1. 提取特征：对新样本 $\mathbf{x} = (x_1, x_2, \ldots, x_d)$ 提取特征向量（与训练阶段使用相同的特征空间）。
  2. 计算各类别得分：对每个候选类别 $y$，利用条件独立假设计算对数后验得分： $$\text{score}(y) = \log \hat{P}(y) + \sum_{i=1}^{d} \log \hat{P}(x_i \mid y)$$
  3. 输出预测：取得分最高的类别作为预测结果 $\hat{y} = \arg\max_y \, \text{score}(y)$。
流程特点

整个训练过程只需一次遍历训练数据即可完成所有统计，时间复杂度 $O(nd)$；预测时对每个类别做一次求和，复杂度 $O(dK)$（$K$ 为类别数）。无需迭代优化，这是朴素贝叶斯在大规模场景下依然广泛使用的核心优势。

5文本分类

5.1 文本表示：从文档到特征向量

文本分类的第一步是将文档转化为数值特征向量。常用的表示方法有：

方法描述配合模型
词袋模型（BoW）统计每个词的出现次数多项式 NB
TF-IDF词频 × 逆文档频率多项式 / 伯努利 NB
二值化只记录词是否出现（0/1）伯努利 NB

5.2 TF-IDF 加权

TF-IDF 衡量词对文档的重要性：

$$\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \log\frac{N}{\text{DF}(t) + 1}$$

其中 TF 是词频，DF 是包含词 $t$ 的文档数，$N$ 是总文档数。高频通用词（"的"、"是"）的 IDF 低，稀有词的 IDF 高。

5.3 文本分类流程

文本分类的完整流程分为训练阶段与预测阶段两部分，每部分又分若干步骤：

训练阶段（离线）

  1. 文本预处理：对原始文档进行分词（中文按词切分，英文按空格/标点切分），去除停用词（"的"、"是"、"了"等高频无意义词）与噪声符号（HTML 标签、URL、表情）。
  2. 特征提取：将清洗后的词序列转化为数值向量。可选词袋（BoW）统计词频，或进一步做 TF-IDF 加权（见 5.2 节），得到特征向量 $\mathbf{x}$。
  3. 参数估计：统计每个类别的先验 $\hat{P}(y)$ 与条件概率 $\hat{P}(x_i \mid y)$，并施加拉普拉斯平滑（见 4.3 节）避免零概率。训练整体复杂度为 $O(nd)$，$n$ 为文档数，$d$ 为词表大小。

预测阶段（在线）

  1. 预处理与特征提取：对新文档执行与训练阶段相同的分词、清洗与特征转换，保证特征空间一致。
  2. 计算得分：对每个候选类别 $y$，计算对数后验得分 $\log P(y) + \sum_i \log P(x_i \mid y)$（见 2.4 节，取对数避免下溢）。
  3. 输出决策：取得分最大的类别 $\hat{y} = \arg\max_y \left[\log P(y) + \sum_i \log P(x_i \mid y)\right]$，即最终分类结果。
为什么这套流程这么快？

训练阶段只需一次扫描统计词频与类别计数；预测阶段对每个类别做一次求和即可，复杂度 $O(dK)$（$K$ 为类别数）。相比 SVM、深度学习等方法，无需迭代优化，因此特别适合大规模文本分类场景，如新闻分类、垃圾邮件过滤。

6垃圾邮件过滤

6.1 问题设定

垃圾邮件过滤是朴素贝叶斯最经典的应用之一。给定一封邮件，判断它是"垃圾邮件"（spam）还是"正常邮件"（ham）。这是一个二分类问题，$y \in \{\text{spam}, \text{ham}\}$。

6.2 多项式 NB 垃圾过滤流程

假设邮件包含 $n$ 个词 $\mathbf{x} = (w_1, w_2, \ldots, w_n)$，用多项式 NB：

$$P(\text{spam} \mid \mathbf{x}) \propto P(\text{spam}) \prod_{i=1}^{n} P(w_i \mid \text{spam})$$

预测规则：

$$\text{预测} = \begin{cases} \text{spam} & \text{if } \frac{P(\text{spam} \mid \mathbf{x})}{P(\text{ham} \mid \mathbf{x})} > \tau \\ \text{ham} & \text{otherwise} \end{cases}$$

其中 $\tau$ 是决策阈值。$\tau > 1$ 时更保守（需更强证据才判 spam），$\tau < 1$ 时更激进。

实际工程中的改进
  • 停用词过滤：去除"的、是、在"等高频无信息词
  • n-gram 特征：使用二元组（如"免费"+"领取"→"免费领取"）捕捉词序信息
  • 阈值调优：设置 $\tau = 999$（强保守），避免误删正常邮件
  • 增量学习：用户标记的新spam邮件可在线更新模型参数

7半监督与在线学习变体

7.1 EM 半监督朴素贝叶斯

在标注数据稀缺时，可以用EM 算法（Expectation-Maximization）结合未标注数据训练朴素贝叶斯：

  1. E 步：用当前模型对未标注数据预测 $P(y \mid \mathbf{x})$（软标签）
  2. M 步：用标注数据 + 软标签数据重新估计参数 $P(y)$ 和 $P(x_i \mid y)$
  3. 重复 E、M 步直到收敛

7.2 在线学习

朴素贝叶斯天然支持在线更新：当新样本到来时，只需更新计数器（$N_y$ 和 $N_{y,x_i}$），无需重新训练。这使它在流式数据场景中极其高效。

$$\hat{P}(x_i \mid y)^{(t+1)} = \frac{N_{y,x_i}^{(t)} + \mathbb{I}(x_i^{(t)}, y^{(t)}) + \alpha}{N_y^{(t)} + \mathbb{I}(y^{(t)}) + \alpha|V_i|}$$

其中上标 $(t)$ 表示时刻，$\mathbb{I}$ 是指示函数。

7.3 补充朴素贝叶斯

当数据类别极度不平衡时，标准朴素贝叶斯的先验会偏向多数类。补充朴素贝叶斯（Complement NB）不直接计算每类的概率，而是计算不属于该类的概率，然后选择补集概率最小的类：

$$\hat{y} = \arg\min_y \; \sum_{i} x_i \log\frac{N_{\bar{y},i} + \alpha}{N_{\bar{y}} + \alpha d}$$

其中 $\bar{y}$ 表示除 $y$ 以外的所有类别。Complement NB 在文本分类的不平衡数据集上表现优于标准多项式 NB。

9.1 高斯朴素贝叶斯（纯 NumPy）

gaussian_nb.py
import numpy as np

class GaussianNB:
    """高斯朴素贝叶斯：连续特征"""
    def __init__(self, var_smoothing=1e-9):
        self.var_smoothing = var_smoothing

    def fit(self, X, y):
        self.classes_ = np.unique(y)
        n_features = X.shape[1]
        self.mean_ = np.zeros((len(self.classes_), n_features))
        self.var_ = np.zeros((len(self.classes_), n_features))
        self.priors_ = np.zeros(len(self.classes_))
        for idx, c in enumerate(self.classes_):
            X_c = X[y == c]
            self.mean_[idx] = X_c.mean(axis=0)
            self.var_[idx] = X_c.var(axis=0) + self.var_smoothing
            self.priors_[idx] = len(X_c) / len(y)
        return self

    def _log_likelihood(self, X, cls_idx):
        mean = self.mean_[cls_idx]
        var = self.var_[cls_idx]
        log_prob = -0.5 * np.sum(np.log(2 * np.pi * var))
        log_prob -= 0.5 * np.sum((X - mean) ** 2 / var, axis=1)
        return log_prob

    def predict_log_proba(self, X):
        log_probs = np.zeros((len(X), len(self.classes_)))
        for idx, c in enumerate(self.classes_):
            log_probs[:, idx] = self._log_likelihood(X, idx) + np.log(self.priors_[idx])
        return log_probs

    def predict(self, X):
        log_probs = self.predict_log_proba(X)
        return self.classes_[np.argmax(log_probs, axis=1)]

9.2 多项式朴素贝叶斯（文本分类）

multinomial_nb.py
import numpy as np

class MultinomialNB:
    """多项式朴素贝叶斯：计数/频率特征"""
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def fit(self, X, y):
        self.classes_ = np.unique(y)
        n_classes = len(self.classes_)
        n_features = X.shape[1]
        self.feature_log_prob_ = np.zeros((n_classes, n_features))
        self.class_log_prior_ = np.zeros(n_classes)
        for idx, c in enumerate(self.classes_):
            X_c = X[y == c]
            # 拉普拉斯平滑后的条件概率
            count = X_c.sum(axis=0) + self.alpha
            total = count.sum()
            self.feature_log_prob_[idx] = np.log(count) - np.log(total)
            # 类先验
            self.class_log_prior_[idx] = np.log(X_c.shape[0] / X.shape[0])
        return self

    def predict(self, X):
        log_probs = X @ self.feature_log_prob_.T + self.class_log_prior_
        return self.classes_[np.argmax(log_probs, axis=1)]

9.3 伯努利朴素贝叶斯

bernoulli_nb.py
import numpy as np

class BernoulliNB:
    """伯努利朴素贝叶斯：二值特征"""
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def fit(self, X, y):
        self.classes_ = np.unique(y)
        n_classes = len(self.classes_)
        n_features = X.shape[1]
        self.feature_prob_ = np.zeros((n_classes, n_features))
        self.class_log_prior_ = np.zeros(n_classes)
        for idx, c in enumerate(self.classes_):
            X_c = X[y == c]
            # P(x_i=1 | y) 拉普拉斯平滑
            self.feature_prob_[idx] = (X_c.sum(axis=0) + self.alpha) / (X_c.shape[0] + 2 * self.alpha)
            self.class_log_prior_[idx] = np.log(X_c.shape[0] / X.shape[0])
        return self

    def predict(self, X):
        log_probs = np.zeros((len(X), len(self.classes_)))
        for idx in range(len(self.classes_)):
            p = self.feature_prob_[idx]
            log_prob = X @ np.log(p) + (1 - X) @ np.log(1 - p)
            log_probs[:, idx] = log_prob + self.class_log_prior_[idx]
        return self.classes_[np.argmax(log_probs, axis=1)]

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline
from sklearn.model_selection import cross_val_score

def build_nb_pipeline(alpha=1.0, max_features=10000):
    """构建文本分类 Pipeline"""
    return Pipeline([
        ('tfidf', TfidfVectorizer(max_features=max_features, stop_words='english')),
        ('nb', MultinomialNB(alpha=alpha))
    ])

# 使用示例
texts = ["免费领取优惠券", "会议纪要请查收", "点击链接赢大奖", "项目进度报告"]
labels = ["spam", "ham", "spam", "ham"]

pipeline = build_nb_pipeline(alpha=0.5)
scores = cross_val_score(pipeline, texts, labels, cv=3, scoring='f1_macro')
print(f"5-Fold F1: {scores.mean():.4f} +/- {scores.std():.4f}")

pipeline.fit(texts, labels)
test = ["免费的报告请查收"]
print(f"预测: {pipeline.predict(test)}")

9.5 补充朴素贝叶斯（Complement NB）

complement_nb.py
import numpy as np

class ComplementNB:
    """补充朴素贝叶斯：适合不平衡数据"""
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def fit(self, X, y):
        self.classes_ = np.unique(y)
        n_classes = len(self.classes_)
        n_features = X.shape[1]
        # 计算每个类的补集统计
        self.complement_log_prob_ = np.zeros((n_classes, n_features))
        self.class_log_prior_ = np.zeros(n_classes)
        for idx, c in enumerate(self.classes_):
            X_not_c = X[y != c]  # 补集数据
            count = X_not_c.sum(axis=0) + self.alpha
            total = count.sum()
            self.complement_log_prob_[idx] = np.log(count) - np.log(total)
            self.class_log_prior_[idx] = np.log(np.sum(y != c) / len(y))
        # 权重归一化（帮助不平衡数据）
        w = np.exp(self.complement_log_prob_)
        self.complement_log_prob_ = np.log(w / w.sum(axis=1, keepdims=True))
        return self

    def predict(self, X):
        # 选择补集得分最小的类
        scores = X @ self.complement_log_prob_.T
        return self.classes_[np.argmin(scores, axis=1)]

9.6 在线学习朴素贝叶斯

online_nb.py
import numpy as np
from collections import defaultdict

class OnlineBernoulliNB:
    """在线学习伯努利朴素贝叶斯"""
    def __init__(self, alpha=1.0):
        self.alpha = alpha
        self.class_counts_ = defaultdict(int)
        self.feature_counts_ = defaultdict(lambda: defaultdict(int))
        self.n_features = 0

    def partial_fit(self, X, y, classes=None):
        if classes is not None and not self.class_counts_:
            for c in classes:
                self.class_counts_[c] = 0
        for xi, yi in zip(X, y):
            self.class_counts_[yi] += 1
            self.n_features = max(self.n_features, len(xi))
            for j, val in enumerate(xi):
                if val == 1:
                    self.feature_counts_[yi][j] += 1
        return self

    def predict_one(self, x):
        best_class, best_score = None, -np.inf
        total = sum(self.class_counts_.values())
        for c in self.class_counts_:
            log_prob = np.log(self.class_counts_[c] / total)
            n_c = self.class_counts_[c]
            for j, val in enumerate(x):
                p = (self.feature_counts_[c][j] + self.alpha) / (n_c + 2 * self.alpha)
                if val == 1:
                    log_prob += np.log(p)
                else:
                    log_prob += np.log(1 - p)
            if log_prob > best_score:
                best_score = log_prob
                best_class = c
        return best_class

    def predict(self, X):
        return np.array([self.predict_one(x) for x in X])

10优缺点与适用场景

10.1 优势

  • 训练极快：只需统计频率，$O(nd)$ 复杂度，无迭代优化
  • 预测极快：$O(dK)$ 矩阵乘法
  • 天然多分类：无需 OvR/OvO 分解
  • 天然概率输出：直接给出后验概率
  • 在线学习：增量更新，天然支持流式数据
  • 小样本鲁棒：参数少（$O(dK)$），不易过拟合
  • 高维友好：特征独立假设使高维空间可行

10.2 劣势

  • 条件独立假设过强：特征相关时性能下降
  • 概率估计不准：虽然分类准确，但输出概率往往过自信（接近 0 或 1）
  • 零概率问题：需要平滑处理
  • 决策边界简单：线性边界，无法捕捉复杂模式
  • 对特征缩放敏感（高斯 NB）：需要标准化

10.3 适用场景

场景推荐模型理由
文本分类多项式 / 补充 NB高维稀疏 + 快速训练
垃圾邮件过滤伯努利 NB二值特征 + 在线更新
情感分析多项式 NB词频特征 + 快速基线
医疗诊断辅助高斯 NB连续生理指标 + 概率输出

12贝叶斯网络：从朴素到一般化

12.1 朴素假设的局限

朴素贝叶斯假设所有特征条件独立，相当于一个星形贝叶斯网络：类别节点指向所有特征节点，特征节点之间无连接。当特征之间存在强依赖时，这一假设过于简化。

12.2 贝叶斯网络

贝叶斯网络（Bayesian Network）是朴素贝叶斯的推广：一个有向无环图（DAG），节点表示随机变量，边表示直接依赖关系。每对父子节点之间对应一个条件概率 $P(\text{子} \mid \text{父})$。联合分布分解为：

$$P(X_1, X_2, \ldots, X_n) = \prod_{i=1}^{n} P(X_i \mid \text{Pa}(X_i))$$

其中 $\text{Pa}(X_i)$ 是 $X_i$ 的父节点集合。

12.3 从朴素贝叶斯到贝叶斯网络的谱系

模型结构假设表达能力推理复杂度
朴素贝叶斯星形，全条件独立弱$O(dK)$
树增强 NB (TAN)类别 + 特征间树形依赖中$O(d^2 K)$
半朴素贝叶斯 (AODE)每个特征依赖一个父特征中$O(d^2 K)$
一般贝叶斯网络任意 DAG强NP-hard（最坏情况）
实践建议

朴素贝叶斯是贝叶斯网络的最简特例。当特征独立假设严重不满足时，可以尝试TAN（Tree Augmented Naive Bayes）：允许特征之间形成一棵依赖树，在实践中往往比纯朴素贝叶斯有明显提升，且推理仍然高效。

13演进时间线与总结

1763
Bayes 定理发表
Thomas Bayes 去世后两年，其论文被 Royal Society 发表，奠定贝叶斯推断基础
1812
Laplace 独立重新发现贝叶斯定理
Laplace 将贝叶斯定理系统化，并提出了拉普拉斯平滑
1960s
朴素贝叶斯在信息检索中应用
Maron 和 Kuhns 将贝叶斯方法用于文档自动分类
1996
Joachims 提出文本分类中的 NB 方法
系统验证朴素贝叶斯在文本分类中的有效性
1998
Sahami 将朴素贝叶斯应用于垃圾邮件过滤
开创了 NB 垃圾过滤的工程实践范式
2001
McCallum 提出 TAN 和补充朴素贝叶斯
通过树增强和补集方法改进朴素贝叶斯的性能
2003
Rennie 等提出 Complement NB 优化不平衡文本
解决类别不平衡导致的偏差问题
2007
scikit-learn 集成朴素贝叶斯
NB 成为工业界文本分类的标准基线
2014
分布式 NB 框架用于大规模文本
Spark MLlib / Mahout 等框架支持亿级文本分类
2020+
深度学习时代 NB 仍作为强基线
在快速原型开发和资源受限场景中，NB 仍是首选基线之一
总结

朴素贝叶斯以其极简的设计——一个条件独立假设加上贝叶斯定理——实现了惊人的分类效果。它的价值不在于追求极致精度，而在于速度、简单和鲁棒性的完美平衡：训练只需一次数据扫描，预测只需矩阵乘法，天然支持多分类和在线学习，在文本分类领域仍是不可替代的强基线。理解朴素贝叶斯，就是理解贝叶斯思维的精髓——用先验知识和观测数据，理性更新信念。
