1算法介绍

1.1 问题设定与符号

18 世纪英国牧师 Thomas Bayes 解决了一个根本性的问题：已知结果，如何推断原因？这就是"逆概率"——从观察到的证据反推隐藏的原因。频率学派只关注"已知原因求结果的概率"（正向概率），而贝叶斯学派开创性地回答了反方向的问题。

经典直觉示例

医学检测问题：某种疾病患病率为 $1\%$。检测仪器的灵敏度为 $99\%$（患病者阳性概率），特异度为 $95\%$（健康者阴性概率）。如果一个人检测阳性，真正患病的概率是多少？直觉上可能是 $99\%$，但用贝叶斯定理计算后只有 $16.7\%$。这就是基础概率忽视（Base Rate Neglect）。

本模块组织方式如下：先固定问题设定与记号，再定义概率模型，随后给出参数估计方法，最后导出预测规则、算法伪代码与复杂度。

设输入空间为 $\mathcal{X} \subseteq \mathbb{R}^d$，类别集合为 $\mathcal{Y} = \{1, 2, \ldots, K\}$，训练集 $\mathcal{D} = \{(\mathbf{x}_n, y_n)\}_{n=1}^{N}$ 由某未知联合分布 $P(\mathbf{X}, Y)$ 独立同分布采样得到。分类任务的目标是学得映射 $h: \mathcal{X} \to \mathcal{Y}$，使 0-1 风险 $R(h) = \mathbb{E}[\mathbb{I}(h(\mathbf{X}) \neq Y)]$ 最小。

朴素贝叶斯的求解策略不是直接拟合 $h$，而是先估计后验概率 $P(Y \mid \mathbf{X})$，再据此做决策——对 0-1 风险而言，最优决策恰是取后验最大的类别（MAP 决策）。因此算法分为两个阶段：学习阶段由 $\mathcal{D}$ 估计先验 $P(y)$ 与条件概率 $P(\mathbf{x} \mid y)$；推断阶段对新样本计算各类得分并取最大值。下面约定全文符号：

符号含义
$\mathcal{D}$，$N$训练集及其样本数
$d$特征维度（特征个数）
$\mathcal{Y}$，$K$类别集合与类别数
$\mathbf{x} = (x_1, \ldots, x_d)$一个样本的特征向量
$x_i$第 $i$ 个特征（标量）
$N_y$类别 $y$ 的样本数，$\sum_y N_y = N$
$N_{y,i}$类别 $y$ 中特征 $i$ 的取值总和（多项式模型）
$\theta_{y,i}$类别 $y$ 下特征 $i$ 的条件概率 $P(x_i \mid y)$
$\mu_{y,i}$，$\sigma_{y,i}^2$高斯模型下类别 $y$ 中特征 $i$ 的均值与方差
$\alpha$拉普拉斯平滑系数
$|V_i|$（文本中即词表大小 $d$）特征 $i$ 的取值个数

1.2 概率模型：贝叶斯定理

贝叶斯定理描述了在观察到证据 $E$ 后，如何更新假设 $H$ 的概率：

$$P(H \mid E) = \frac{P(E \mid H) \cdot P(H)}{P(E)}$$
术语符号含义
先验概率$P(H)$观察到证据前对假设的信念
似然$P(E \mid H)$假设为真时观察到证据的概率
后验概率$P(H \mid E)$观察到证据后对假设的更新信念
证据$P(E)$归一化常数，确保概率和为 1

对于分类问题，我们将假设 $H$ 替换为类别 $y$，证据 $E$ 替换为特征向量 $\mathbf{x}$：

$$P(y \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid y) \cdot P(y)}{P(\mathbf{x})}$$

由于 $P(\mathbf{x})$ 对所有类别相同，分类决策只需最大化分子：

$$\hat{y} = \arg\max_y \; P(y) \cdot P(\mathbf{x} \mid y)$$

1.3 条件独立假设

指数级概率难题

直接使用贝叶斯定理进行分类有一个致命问题：计算 $P(\mathbf{x} \mid y)$ 需要估计特征向量的联合概率分布。如果 $\mathbf{x} = (x_1, x_2, \ldots, x_d)$ 有 $d$ 个特征，每个特征有 $k$ 个取值，则单个类别的联合分布就需要估计 $k^d - 1$ 个参数——这随特征维度指数增长，在数据和计算上都不可行。

条件独立性假设

朴素贝叶斯做出了一个大胆的"朴素"假设：在给定类别 $y$ 的条件下，各特征之间相互独立。即：

$$P(\mathbf{x} \mid y) = P(x_1, x_2, \ldots, x_d \mid y) = \prod_{i=1}^{d} P(x_i \mid y)$$

这个假设将联合概率分解为 $d$ 个独立的一维条件概率的乘积，参数量从每类 $k^d$ 量级降为每类 $d(k-1)$ 量级（自由参数），是线性增长而非指数增长。

"朴素"在哪里？

这个假设在现实中几乎从不严格成立。例如在垃圾邮件分类中，"免费"和"优惠"这两个词的出现显然不独立——它们经常一起出现。但令人惊讶的是，即使条件独立假设不成立，朴素贝叶斯的分类性能依然出色——因为它只需要排序正确，不需要概率估计精确。

朴素贝叶斯分类器

结合公式 (3) 和 (4)，朴素贝叶斯分类器为：

$$\hat{y} = \arg\max_y \; P(y) \prod_{i=1}^{d} P(x_i \mid y)$$

1.4 参数估计与平滑

极大似然估计

朴素贝叶斯的参数通过极大似然估计（MLE）从训练数据中学习：

类别先验：

$$\hat{P}(y) = \frac{N_y}{N}$$

条件概率（离散特征）：

$$\hat{P}(x_i = v \mid y) = \frac{N_{y, x_i=v}}{N_y}$$

其中 $N_y$ 是类别 $y$ 的样本数，$N_{y, x_i=v}$ 是类别 $y$ 中特征 $x_i$ 取值 $v$ 的样本数。

零概率问题

致命问题

如果某个特征值 $v$ 在类别 $y$ 的训练数据中从未出现，则 $\hat{P}(x_i=v \mid y) = 0$。由于各特征概率相乘，一个零值会导致整个后验为零——即使其他特征强烈支持类别 $y$，分类器也会完全忽略它。这就是"零概率问题"。

拉普拉斯平滑

解决方案是拉普拉斯平滑（又称加一平滑）：

$$\hat{P}(x_i = v \mid y) = \frac{N_{y, x_i=v} + \alpha}{N_y + \alpha |V_i|}$$

其中 $\alpha > 0$ 是平滑参数（$\alpha=1$ 为标准拉普拉斯平滑），$|V_i|$ 是特征 $x_i$ 的取值数。平滑确保了所有概率为正，且满足 $\sum_v \hat{P}(x_i=v \mid y) = 1$。

$\alpha$ 值效果适用场景
$\alpha = 0$无平滑，MLE不推荐（零概率风险）
$\alpha = 1$标准拉普拉斯平滑默认选择
$0 < \alpha < 1$弱平滑（Lidstone 平滑）大数据集、避免过度平滑
$\alpha > 1$强平滑小数据集、高稀疏特征

多项式模型的平滑

对于多项式朴素贝叶斯（文本分类），平滑后的参数为：

$$\hat{\theta}_{y,i} = \frac{N_{y,i} + \alpha}{N_y + \alpha d}$$

其中 $N_{y,i}$ 是类别 $y$ 中词 $i$ 的总出现次数，$N_y = \sum_i N_{y,i}$ 是类别 $y$ 的总词数（注意：多项式模型在此处将 $N_y$ 重定义为词数而非符号表中的样本数），$d$ 是词表大小。

1.5 预测规则：对数空间 MAP

当特征维度 $d$ 很大时，$\prod_i P(x_i \mid y)$ 的乘积可能下溢为 0。实践中取对数将乘法变为加法：

$$\hat{y} = \arg\max_y \; \left[ \log P(y) + \sum_{i=1}^{d} \log P(x_i \mid y) \right]$$

取对数不改变 $\arg\max$ 结果，但避免了数值下溢问题，且加法计算比乘法更高效。

1.6 算法伪代码

综合前述模型、估计方法与决策规则，朴素贝叶斯的完整训练与预测流程如下。其中 $M$ 为所选的概率模型族（高斯 / 多项式 / 伯努利），$\hat{\theta}$ 统指各模型的参数估计结果。

算法 1：朴素贝叶斯分类器（训练与预测）

输入：标注数据集 $\mathcal{D} = \{(\mathbf{x}_n, y_n)\}_{n=1}^{N}$、平滑系数 $\alpha$、模型族 $M$（高斯 / 多项式 / 伯努利）。

输出：后验得分函数 $\mathrm{score}(\cdot)$ 与分类器 $\hat{y}(\cdot)$。

训练阶段

  1. 统计类别先验：对每个类别 $y \in \mathcal{Y}$ 统计样本数 $N_y$，得 $\hat{P}(y) = N_y / N$（式 (6)）。
  2. 估计条件概率：对每个类别 $y$ 与每个特征 $i \in \{1, \ldots, d\}$，按模型族 $M$ 分三种情况处理：
    • 高斯模型（连续特征）：由该类样本估计均值 $\hat{\mu}_{y,i}$ 与方差 $\hat{\sigma}_{y,i}^{2}$，代入式 (11) 的高斯密度。
    • 多项式模型（计数特征）：统计特征的总出现次数 $N_{y,i}$，按式 (9) 平滑估计条件概率 $\hat{\theta}_{y,i}$。
    • 伯努利模型（二值特征）：统计 $x_i = 1$ 的样本数 $N_{y,i}$，按式 (8) 平滑估计 $\hat{\theta}_{y,i}$，其中取值数 $|V_i| = 2$。

预测阶段

  1. 计算各类得分：给定新样本 $\mathbf{x} = (x_1, \ldots, x_d)$，对每个类别 $y \in \mathcal{Y}$ 计算对数后验得分 $\mathrm{score}(y)$（式 (10)）。
  2. 输出决策：返回得分最大的类别 $\hat{y}(\mathbf{x}) = \arg\max_{y \in \mathcal{Y}} \mathrm{score}(y)$。

1.7 复杂度分析

朴素贝叶斯的开销集中在统计量上，训练与预测都不含迭代优化：

阶段时间复杂度空间复杂度说明
训练（离散特征）$O(nd)$$O(dK)$一次扫描即可完成全部计数，可并行、可流式
训练（高斯特征）$O(nd)$$O(dK)$用在线公式增量累加均值与平方和，同样单遍
预测$O(dK)$$O(1)$对每个类别做一次 $d$ 项求和后取最大
在线更新$O(d)$$O(1)$只需更新计数器 $N_y$、$N_{y,i}$（见 4.2 节）

与逻辑回归（$O(ndT)$，需多轮迭代）、SVM（$O(n^2 \sim n^3)$）相比，朴素贝叶斯的训练是单遍、可并行、可流式的。代价是条件独立假设引入的建模偏差——但它并不追求后验概率的精确数值，只要各类得分的相对排序正确即可做出正确决策，这正是它在高维稀疏文本上依然强健的原因。

2三种经典模型

朴素贝叶斯的核心是估计 $P(x_i \mid y)$，而特征的类型决定了使用哪种分布模型。三种最经典的变体对应不同的数据类型。

2.1 高斯朴素贝叶斯（连续特征）

当特征为连续值时，假设在给定类别下特征服从高斯分布：

$$P(x_i \mid y) = \frac{1}{\sqrt{2\pi\sigma_{y,i}^2}} \exp\left(-\frac{(x_i - \mu_{y,i})^2}{2\sigma_{y,i}^2}\right)$$

参数 $\mu_{y,i}$ 和 $\sigma_{y,i}^2$ 分别为类别 $y$ 下特征 $x_i$ 的均值和方差，通过训练数据的极大似然估计获得。

生活化示例：水果识别（含完整计算过程）

假设要根据重量（克）和甜度（%）两个连续指标判断一个水果是苹果还是橙子。已有 10 个苹果和 10 个橙子的标记数据作为预训练集（训练样本举例：苹果 140g/10%、150g/12%、160g/14%；橙子 190g/7%、200g/9%、210g/11%……每类各 10 个）。

第一步：预训练（MLE 估计参数）。对每类的每个特征，用训练数据计算均值 $\mu$ 和方差 $\sigma^2$，同时由公式 (6) 估出类别先验 $\hat{P}(y) = N_y / N$。由于训练集苹果和橙子各 10 个、共 20 个，先验为 $P(\text{apple}) = P(\text{orange}) = 10/20 = 0.5$。参数汇总如下：

类别样本数先验重量 $\mu$（g）重量 $\sigma^2$甜度 $\mu$（%）甜度 $\sigma^2$
苹果100.515050122
橙子100.52005092

接下来来了三个待测水果：

  • 样本 A：重量 170g、甜度 10.5%
  • 样本 B：重量 190g、甜度 8.5%
  • 样本 C：重量 155g、甜度 11.5%

第二步：预测。把每个样本代入公式 (11) 的高斯曲线。先看样本 A（170g, 10.5%）：

苹果类：$P(170 \mid \text{apple}) = \frac{1}{\sqrt{2\pi \cdot 50}} e^{-\frac{(170-150)^2}{2\cdot 50}} \approx 0.00103$，$P(10.5\% \mid \text{apple}) = \frac{1}{\sqrt{2\pi \cdot 2}} e^{-\frac{(10.5-12)^2}{2\cdot 2}} \approx 0.1607$。

橙子类：$P(170 \mid \text{orange}) = \frac{1}{\sqrt{2\pi \cdot 50}} e^{-\frac{(170-200)^2}{2\cdot 50}} \approx 6.96\times10^{-6}$，$P(10.5\% \mid \text{orange}) = \frac{1}{\sqrt{2\pi \cdot 2}} e^{-\frac{(10.5-9)^2}{2\cdot 2}} \approx 0.1607$。

乘以先验（均 0.5）：苹果后验 $\propto 0.5 \times 0.00103 \times 0.1607 \approx 8.30\times10^{-5}$，橙子后验 $\propto 0.5 \times 6.96\times10^{-6} \times 0.1607 \approx 5.60\times10^{-7}$。苹果后验约是橙子的 148 倍，判为苹果。

样本 B（190g, 8.5%）：苹果后验 $\propto 0.5 \times 6.35\times10^{-9} \times 0.0132 \approx 4.19\times10^{-11}$，橙子后验 $\propto 0.5 \times 0.0208 \times 0.265 \approx 2.75\times10^{-3}$。橙子后验远大于苹果，判为橙子。

样本 C（155g, 11.5%）：苹果后验 $\propto 0.5 \times 0.0439 \times 0.265 \approx 5.82\times10^{-3}$，橙子后验 $\propto 0.5 \times 9.06\times10^{-11} \times 0.0591 \approx 2.68\times10^{-12}$。判为苹果。

第三步：增量更新模型。把预测结果带回训练集——样本 A 确认为苹果、样本 B 确认为橙子（本例 C 暂不加入），重新估计参数：

类别更新前加入新样本更新后
苹果（11 个）$\mu_{\text{w}}=150,\ \sigma^2_{\text{w}}=50$；$\mu_{\text{s}}=12,\ \sigma^2_{\text{s}}=2$170g, 10.5%$\mu_{\text{w}}\approx 151.8,\ \sigma^2_{\text{w}}\approx 78.5$；$\mu_{\text{s}}\approx 11.9,\ \sigma^2_{\text{s}}\approx 2.0$
橙子（11 个）$\mu_{\text{w}}=200,\ \sigma^2_{\text{w}}=50$；$\mu_{\text{s}}=9,\ \sigma^2_{\text{s}}=2$190g, 8.5%$\mu_{\text{w}}\approx 199.1,\ \sigma^2_{\text{w}}\approx 53.7$；$\mu_{\text{s}}\approx 9.0,\ \sigma^2_{\text{s}}\approx 1.8$

更新后的 $\mu$ 和 $\sigma^2$ 用于后续样本的预测，模型随着新数据持续进化，这就是朴素贝叶斯能够做在线学习的原因。

直观理解：A 的甜度 10.5% 正好卡在两类中间，但重量 170g 离苹果均值 150g 更近（差 20）而离橙子均值 200g 更远（差 30），高斯密度差异让苹果胜出。特征越接近某类的均值，该类得分越高。

2.2 多项式朴素贝叶斯（计数特征）

当特征为计数/频率时（如文本中词频），假设特征服从多项式分布：

$$P(\mathbf{x} \mid y) \propto \prod_{i=1}^{d} \theta_{y,i}^{x_i}$$

其中 $\theta_{y,i} = P(x_i \mid y)$ 是类别 $y$ 下特征 $i$ 出现的概率，$\sum_i \theta_{y,i} = 1$。这是文本分类最常用的模型。

生活化示例：新闻分类（含完整计算过程）

词频表随新文章滚动累加，模型不断吸收新知识。

直观理解：词出现得越多，对所属类别的影响越大。D1 里"进球"出现 3 次，哪怕有一个"算法"词，整体仍更可能判为体育。

2.3 伯努利朴素贝叶斯（二值特征）

当特征为0/1 二值时（如词是否出现），假设特征服从伯努利分布：

$$P(\mathbf{x} \mid y) = \prod_{i=1}^{d} \theta_{y,i}^{x_i} (1-\theta_{y,i})^{1-x_i}$$

与多项式模型不同，伯努利模型考虑了词不出现的概率，适合短文本或特征稀疏的场景。

生活化示例：垃圾短信识别（含完整计算过程）

特征只记录短信里关键词是否出现（出现记 1，不出现记 0），不管出现几次。我们跟踪两个词：「中奖」和「免费」。预训练集共 20 条短信（垃圾 10 条、正常 10 条），统计每个词在各类中出现的频次：

类别中奖 = 1 的条数免费 = 1 的条数总条数
垃圾（10 条）8710
正常（10 条）1210

第一步：预训练（MLE 估计参数）。直接用频次除以总条数：$\theta_{\text{spam,prize}} = 8/10 = 0.8$，$\theta_{\text{spam,free}} = 7/10 = 0.7$；$\theta_{\text{ham,prize}} = 1/10 = 0.1$，$\theta_{\text{ham,free}} = 2/10 = 0.2$。先验 $P(\text{spam}) = P(\text{ham}) = 0.5$。

第二步：预测。来了三条新短信：

  • S1：「恭喜您中奖了，点击链接免费领取」→ 中奖 = 1、免费 = 1
  • S2：「您中奖了，请到柜台领取」→ 中奖 = 1、免费 = 0
  • S3：「明天下午开会，请准时参加」→ 中奖 = 0、免费 = 0

代入公式 (13)（注意 $x_i=0$ 时用 $1-\theta_{y,i}$ 项）：

S1：$P \propto 0.5 \times 0.8^1 \times 0.7^1 = 0.280$（垃圾）；$P \propto 0.5 \times 0.1^1 \times 0.2^1 = 0.010$（正常）。比值 28:1，判为垃圾短信。

S2：$P \propto 0.5 \times 0.8 \times (1-0.7) = 0.120$（垃圾）；$P \propto 0.5 \times 0.1 \times (1-0.2) = 0.040$（正常）。比值 3:1，判为垃圾短信。

S3：$P \propto 0.5 \times (1-0.8) \times (1-0.7) = 0.030$（垃圾）；$P \propto 0.5 \times (1-0.1) \times (1-0.2) = 0.360$（正常）。比值 0.083，判为正常短信。

第三步：增量更新模型。S1、S2 判为垃圾，S3 判为正常，加入训练集后用拉普拉斯平滑（$\alpha=1$，$|V|=2$）重估参数：

类别更新前加入新样本更新后（$\alpha=1, |V|=2$）
垃圾（12 条）中奖 8、免费 7S1（1,1）+ S2（1,0）$\theta_{\text{prize}} = \frac{8+2+1}{12+2} = 0.786$；$\theta_{\text{free}} = \frac{7+1+1}{12+2} = 0.643$
正常（11 条）中奖 1、免费 2S3（0,0）$\theta_{\text{prize}} = \frac{1+0+1}{11+2} = 0.154$；$\theta_{\text{free}} = \frac{2+0+1}{11+2} = 0.231$

关键差异：伯努利模型对"某词没出现"也计概率（$1-\theta$ 项）。S3 中"中奖"和"免费"都没出现，$0.2 \times 0.3 = 0.06$（垃圾类）远小于 $0.9 \times 0.8 = 0.72$（正常类），模型正确识别为正常——这种敏感性对短文本非常有用。

3文本分类与垃圾邮件过滤

3.1 文本表示：从文档到特征向量

文本分类的第一步是将文档转化为数值特征向量。常用的表示方法有：

方法描述配合模型
词袋模型（BoW）统计每个词的出现次数多项式 NB
TF-IDF词频 × 逆文档频率多项式 / 伯努利 NB
二值化只记录词是否出现（0/1）伯努利 NB

3.2 TF-IDF 加权

TF-IDF 衡量词对文档的重要性：

$$\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \log\frac{N}{\text{DF}(t) + 1}$$

其中 TF 是词频，DF 是包含词 $t$ 的文档数，$N$ 是总文档数。高频通用词（"的"、"是"）的 IDF 低，稀有词的 IDF 高。

3.3 文本分类流程

文本分类的完整流程分为训练阶段与预测阶段两部分，每部分又分若干步骤：

训练阶段（离线）

  1. 文本预处理：对原始文档进行分词（中文按词切分，英文按空格/标点切分），去除停用词（"的"、"是"、"了"等高频无意义词）与噪声符号（HTML 标签、URL、表情）。
  2. 特征提取：将清洗后的词序列转化为数值向量。可选词袋（BoW）统计词频，或进一步做 TF-IDF 加权（见 3.2 节），得到特征向量 $\mathbf{x}$。
  3. 参数估计：统计每个类别的先验 $\hat{P}(y)$ 与条件概率 $\hat{P}(x_i \mid y)$，并施加拉普拉斯平滑（见 1.4 节）避免零概率。训练整体复杂度为 $O(nd)$，$n$ 为文档数，$d$ 为词表大小。

预测阶段（在线）

  1. 预处理与特征提取：对新文档执行与训练阶段相同的分词、清洗与特征转换，保证特征空间一致。
  2. 计算得分：对每个候选类别 $y$，计算对数后验得分 $\log P(y) + \sum_i \log P(x_i \mid y)$（见 1.5 节，取对数避免下溢）。
  3. 输出决策：取得分最大的类别 $\hat{y} = \arg\max_y \left[\log P(y) + \sum_i \log P(x_i \mid y)\right]$，即最终分类结果。
为什么这套流程这么快？

训练阶段只需一次扫描统计词频与类别计数；预测阶段对每个类别做一次求和即可，复杂度 $O(dK)$（$K$ 为类别数）。相比 SVM、深度学习等方法，无需迭代优化，因此特别适合大规模文本分类场景，如新闻分类、垃圾邮件过滤。

3.5 垃圾邮件过滤（实例）

问题设定

垃圾邮件过滤是朴素贝叶斯最经典的应用之一。给定一封邮件，判断它是"垃圾邮件"（spam）还是"正常邮件"（ham）。这是一个二分类问题，$y \in \{\text{spam}, \text{ham}\}$。

过滤流程

假设邮件包含 $n$ 个词 $\mathbf{x} = (w_1, w_2, \ldots, w_n)$，用多项式 NB：

$$P(\text{spam} \mid \mathbf{x}) \propto P(\text{spam}) \prod_{i=1}^{n} P(w_i \mid \text{spam})$$

预测规则：

$$\text{预测} = \begin{cases} \text{spam} & \text{if } \frac{P(\text{spam} \mid \mathbf{x})}{P(\text{ham} \mid \mathbf{x})} > \tau \\ \text{ham} & \text{otherwise} \end{cases}$$

其中 $\tau$ 是决策阈值。$\tau > 1$ 时更保守（需更强证据才判 spam），$\tau < 1$ 时更激进。

词频表示例

词$P(w \mid \text{spam})$$P(w \mid \text{ham})$倾向
"免费"0.0800.005spam
"点击"0.0500.010spam
"会议"0.0020.030ham
"附件"0.0100.040ham
"的"0.1500.140中性
实际工程中的改进
  • 停用词过滤：去除"的、是、在"等高频无信息词
  • n-gram 特征：使用二元组（如"免费"+"领取"→"免费领取"）捕捉词序信息
  • 阈值调优：设置 $\tau = 999$（强保守），避免误删正常邮件
  • 增量学习：用户标记的新 spam 邮件可在线更新模型参数

4变体与推广

4.1 EM 半监督朴素贝叶斯

在标注数据稀缺时，可以用EM 算法（Expectation-Maximization）结合未标注数据训练朴素贝叶斯：

  1. E 步：用当前模型对未标注数据预测 $P(y \mid \mathbf{x})$（软标签）
  2. M 步：用标注数据 + 软标签数据重新估计参数 $P(y)$ 和 $P(x_i \mid y)$
  3. 重复 E、M 步直到收敛

4.2 在线学习与增量更新

朴素贝叶斯天然支持在线更新：当新样本到来时，只需更新计数器（$N_y$ 和 $N_{y,x_i}$），无需重新训练。这使它在流式数据场景中极其高效。

$$\hat{P}(x_i \mid y)^{(t+1)} = \frac{N_{y,x_i}^{(t)} + \mathbb{I}(y^{(t)} = y,\; x_i^{(t)} = x_i) + \alpha}{N_y^{(t)} + \mathbb{I}(y^{(t)} = y) + \alpha|V_i|}$$

其中上标 $(t)$ 表示时刻，$\mathbb{I}$ 是指示函数：当新样本 $\mathbf{x}^{(t)}$ 的类别 $y^{(t)}$ 等于 $y$ 时，分母 $N_y$ 加 $1$；若同时其特征 $i$ 取值为 $x_i$，则分子 $N_{y,x_i}$ 再加 $1$。新样本不属于类别 $y$ 时分子分母均不变。

4.3 补充朴素贝叶斯（Complement NB）

当数据类别极度不平衡时，标准朴素贝叶斯的先验会偏向多数类。补充朴素贝叶斯（Complement NB）不直接计算每类的概率，而是计算不属于该类的概率——其中 $\bar{y}$ 表示除 $y$ 以外的所有类别（补集），$N_{\bar{y},i}$ 为补集中特征 $i$ 的计数、$N_{\bar{y}}$ 为补集总词数——然后选择补集概率最小的类：

$$\hat{y} = \arg\min_y \; \sum_{i} x_i \log\frac{N_{\bar{y},i} + \alpha}{N_{\bar{y}} + \alpha d}$$

Complement NB 在文本分类的不平衡数据集上表现优于标准多项式 NB。

4.4 从朴素贝叶斯到贝叶斯网络

朴素假设的局限

朴素贝叶斯假设所有特征条件独立，相当于一个星形贝叶斯网络：类别节点指向所有特征节点，特征节点之间无连接。当特征之间存在强依赖时，这一假设过于简化。

贝叶斯网络

贝叶斯网络（Bayesian Network）是朴素贝叶斯的推广：一个有向无环图（DAG），节点表示随机变量，边表示直接依赖关系。每对父子节点之间对应一个条件概率 $P(\text{子} \mid \text{父})$。联合分布分解为：

$$P(X_1, X_2, \ldots, X_n) = \prod_{i=1}^{n} P(X_i \mid \text{Pa}(X_i))$$

其中 $\text{Pa}(X_i)$ 是 $X_i$ 的父节点集合。

从朴素贝叶斯到贝叶斯网络的谱系

模型结构假设表达能力推理复杂度
朴素贝叶斯星形，全条件独立弱$O(dK)$
树增强 NB (TAN)类别 + 特征间树形依赖中$O(d^2 K)$
半朴素贝叶斯 (AODE)每个特征依赖一个父特征中$O(d^2 K)$
一般贝叶斯网络任意 DAG强NP-hard（最坏情况）
实践建议

朴素贝叶斯是贝叶斯网络的最简特例。当特征独立假设严重不满足时，可以尝试TAN（Tree Augmented Naive Bayes）：允许特征之间形成一棵依赖树，在实践中往往比纯朴素贝叶斯有明显提升，且推理仍然高效。

6.1 高斯朴素贝叶斯（纯 NumPy）

gaussian_nb.py
import numpy as np

class GaussianNB:
    """高斯朴素贝叶斯：连续特征"""
    def __init__(self, var_smoothing=1e-9):
        self.var_smoothing = var_smoothing

    def fit(self, X, y):
        self.classes_ = np.unique(y)
        n_features = X.shape[1]
        self.mean_ = np.zeros((len(self.classes_), n_features))
        self.var_ = np.zeros((len(self.classes_), n_features))
        self.priors_ = np.zeros(len(self.classes_))
        for idx, c in enumerate(self.classes_):
            X_c = X[y == c]
            self.mean_[idx] = X_c.mean(axis=0)
            self.var_[idx] = X_c.var(axis=0) + self.var_smoothing
            self.priors_[idx] = len(X_c) / len(y)
        return self

    def _log_likelihood(self, X, cls_idx):
        mean = self.mean_[cls_idx]
        var = self.var_[cls_idx]
        log_prob = -0.5 * np.sum(np.log(2 * np.pi * var))
        log_prob -= 0.5 * np.sum((X - mean) ** 2 / var, axis=1)
        return log_prob

    def predict_log_proba(self, X):
        log_probs = np.zeros((len(X), len(self.classes_)))
        for idx, c in enumerate(self.classes_):
            log_probs[:, idx] = self._log_likelihood(X, idx) + np.log(self.priors_[idx])
        return log_probs

    def predict(self, X):
        log_probs = self.predict_log_proba(X)
        return self.classes_[np.argmax(log_probs, axis=1)]

6.2 多项式朴素贝叶斯（文本分类）

multinomial_nb.py
import numpy as np

class MultinomialNB:
    """多项式朴素贝叶斯：计数/频率特征"""
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def fit(self, X, y):
        self.classes_ = np.unique(y)
        n_classes = len(self.classes_)
        n_features = X.shape[1]
        self.feature_log_prob_ = np.zeros((n_classes, n_features))
        self.class_log_prior_ = np.zeros(n_classes)
        for idx, c in enumerate(self.classes_):
            X_c = X[y == c]
            # 拉普拉斯平滑后的条件概率
            count = X_c.sum(axis=0) + self.alpha
            total = count.sum()
            self.feature_log_prob_[idx] = np.log(count) - np.log(total)
            # 类先验
            self.class_log_prior_[idx] = np.log(X_c.shape[0] / X.shape[0])
        return self

    def predict(self, X):
        log_probs = X @ self.feature_log_prob_.T + self.class_log_prior_
        return self.classes_[np.argmax(log_probs, axis=1)]

6.3 伯努利朴素贝叶斯

bernoulli_nb.py
import numpy as np

class BernoulliNB:
    """伯努利朴素贝叶斯：二值特征"""
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def fit(self, X, y):
        self.classes_ = np.unique(y)
        n_classes = len(self.classes_)
        n_features = X.shape[1]
        self.feature_prob_ = np.zeros((n_classes, n_features))
        self.class_log_prior_ = np.zeros(n_classes)
        for idx, c in enumerate(self.classes_):
            X_c = X[y == c]
            # P(x_i=1 | y) 拉普拉斯平滑
            self.feature_prob_[idx] = (X_c.sum(axis=0) + self.alpha) / (X_c.shape[0] + 2 * self.alpha)
            self.class_log_prior_[idx] = np.log(X_c.shape[0] / X.shape[0])
        return self

    def predict(self, X):
        log_probs = np.zeros((len(X), len(self.classes_)))
        for idx in range(len(self.classes_)):
            p = self.feature_prob_[idx]
            log_prob = X @ np.log(p) + (1 - X) @ np.log(1 - p)
            log_probs[:, idx] = log_prob + self.class_log_prior_[idx]
        return self.classes_[np.argmax(log_probs, axis=1)]

6.4 文本分类完整 Pipeline

text_classification.py
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline
from sklearn.model_selection import cross_val_score

def build_nb_pipeline(alpha=1.0, max_features=10000):
    """构建文本分类 Pipeline"""
    return Pipeline([
        ('tfidf', TfidfVectorizer(max_features=max_features, stop_words='english')),
        ('nb', MultinomialNB(alpha=alpha))
    ])

# 使用示例
texts = ["免费领取优惠券", "会议纪要请查收", "点击链接赢大奖", "项目进度报告"]
labels = ["spam", "ham", "spam", "ham"]

pipeline = build_nb_pipeline(alpha=0.5)
scores = cross_val_score(pipeline, texts, labels, cv=3, scoring='f1_macro')
print(f"3-Fold F1: {scores.mean():.4f} +/- {scores.std():.4f}")

pipeline.fit(texts, labels)
test = ["免费的报告请查收"]
print(f"预测: {pipeline.predict(test)}")

6.5 补充朴素贝叶斯（Complement NB）

complement_nb.py
import numpy as np

class ComplementNB:
    """补充朴素贝叶斯：适合不平衡数据"""
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def fit(self, X, y):
        self.classes_ = np.unique(y)
        n_classes = len(self.classes_)
        n_features = X.shape[1]
        # 计算每个类的补集统计
        self.complement_log_prob_ = np.zeros((n_classes, n_features))
        self.class_log_prior_ = np.zeros(n_classes)
        for idx, c in enumerate(self.classes_):
            X_not_c = X[y != c]  # 补集数据
            count = X_not_c.sum(axis=0) + self.alpha
            total = count.sum()
            self.complement_log_prob_[idx] = np.log(count) - np.log(total)
            self.class_log_prior_[idx] = np.log(np.sum(y != c) / len(y))
        # 权重归一化（帮助不平衡数据）
        w = np.exp(self.complement_log_prob_)
        self.complement_log_prob_ = np.log(w / w.sum(axis=1, keepdims=True))
        return self

    def predict(self, X):
        # 选择补集得分最小的类
        scores = X @ self.complement_log_prob_.T
        return self.classes_[np.argmin(scores, axis=1)]

6.6 在线学习朴素贝叶斯

online_nb.py
import numpy as np
from collections import defaultdict

class OnlineBernoulliNB:
    """在线学习伯努利朴素贝叶斯"""
    def __init__(self, alpha=1.0):
        self.alpha = alpha
        self.class_counts_ = defaultdict(int)
        self.feature_counts_ = defaultdict(lambda: defaultdict(int))
        self.n_features = 0

    def partial_fit(self, X, y, classes=None):
        if classes is not None and not self.class_counts_:
            for c in classes:
                self.class_counts_[c] = 0
        for xi, yi in zip(X, y):
            self.class_counts_[yi] += 1
            self.n_features = max(self.n_features, len(xi))
            for j, val in enumerate(xi):
                if val == 1:
                    self.feature_counts_[yi][j] += 1
        return self

    def predict_one(self, x):
        best_class, best_score = None, -np.inf
        total = sum(self.class_counts_.values())
        for c in self.class_counts_:
            log_prob = np.log(self.class_counts_[c] / total)
            n_c = self.class_counts_[c]
            for j, val in enumerate(x):
                p = (self.feature_counts_[c][j] + self.alpha) / (n_c + 2 * self.alpha)
                if val == 1:
                    log_prob += np.log(p)
                else:
                    log_prob += np.log(1 - p)
            if log_prob > best_score:
                best_score = log_prob
                best_class = c
        return best_class

    def predict(self, X):
        return np.array([self.predict_one(x) for x in X])

7演进时间线与总结

1763
Bayes 定理发表
Thomas Bayes 去世后两年，其论文被 Royal Society 发表，奠定贝叶斯推断基础
1812
Laplace 系统化贝叶斯定理
Laplace 独立推导逆概率法则并在《概率分析理论》中系统化，同时提出拉普拉斯平滑
1960s
朴素贝叶斯在信息检索中应用
Maron 提出基于贝叶斯概率的文档自动索引方法
1997
Joachims 从概率角度分析 TF-IDF 文本分类
解释 TF-IDF 加权的概率性，推动文本分类的向量化方法发展
1998
Sahami 将朴素贝叶斯应用于垃圾邮件过滤
开创了 NB 垃圾过滤的工程实践范式
2002
Ng & Jordan 系统比较生成式与判别式分类器
理论分析朴素贝叶斯（生成式）与逻辑回归（判别式）在小样本与大数据场景下的差异
2003
Rennie 等提出 Complement NB 优化不平衡文本
解决类别不平衡导致的偏差问题
2007
scikit-learn 集成朴素贝叶斯
NB 成为工业界文本分类的标准基线
2014
分布式 NB 框架用于大规模文本
Spark MLlib / Mahout 等框架支持亿级文本分类
2020+
深度学习时代 NB 仍作为强基线
在快速原型开发和资源受限场景中，NB 仍是首选基线之一
总结

朴素贝叶斯以其极简的设计——一个条件独立假设加上贝叶斯定理——实现了惊人的分类效果。它的价值不在于追求极致精度，而在于速度、简单和鲁棒性的完美平衡：训练只需一次数据扫描，预测只需矩阵乘法，天然支持多分类和在线学习，在文本分类领域仍是不可替代的强基线。理解朴素贝叶斯，就是理解贝叶斯思维的精髓——用先验知识和观测数据，理性更新信念。
