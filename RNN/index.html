1序列数据与建模动机

1.1 什么是序列数据

在现实世界中，大量数据具有时序结构——数据点之间存在先后顺序，且当前数据与历史数据相关。这类数据统称为序列数据。常见的序列数据类型包括：

文本序列

自然语言是典型的离散序列。句子"深度学习改变了人工智能"由 8 个汉字按特定顺序排列组成。改变顺序（如"人工智能改变了深度学习"）虽然语法正确，但语义已完全不同。文本序列的特点是：

  • 长度可变：句子可以是几个词，也可以是几百个词
  • 存在长距离依赖：句首的"主语"可能影响句尾的"谓语"
  • 上下文敏感：同一个词在不同上下文中含义不同

时间序列

股票价格、天气数据、传感器读数等连续型时序数据。例如，某股票连续 5 天的收盘价为 [100.2, 101.5, 99.8, 102.3, 103.1]，每一天的价格都与前几天存在相关性。

音频序列

语音信号以 16kHz 采样，一段 10 秒的语音就是 160000 个时间步的序列。语音识别需要将这段长序列映射为文字序列。

视频序列

视频由帧序列组成，30fps 视频每秒 30 帧，帧间存在时序关联。

生物序列

DNA 序列由 A、T、C、G 四种碱基按特定顺序排列，蛋白质序列由 20 种氨基酸组成。

1.2 前馈网络的局限

传统前馈神经网络（MLP、CNN）在处理序列数据时面临根本性困难：

局限说明示例
输入长度固定MLP 输入层维度固定，无法直接处理变长序列最大长度 100 → 短序列需补齐、长序列需截断
缺乏时序记忆MLP 对每个输入独立处理，无法利用历史信息温度预测：7 天温度拼接为向量，丢失时间顺序
参数不共享不同时间步由不同权重处理，无法识别跨位置模式"连续上涨回调"无论出现在第几天含义相同

1.3 RNN 的核心思想

RNN 的设计灵感来源于人类阅读文本的方式：逐词阅读，每读一个词，大脑就在之前理解的基础上更新对当前句子的认识。RNN 模拟了这一过程：

核心机制
在每个时间步 $t$，RNN 接收当前输入 $x_t$ 和上一时刻的隐藏状态 $h_{t-1}$，计算得到新的隐藏状态 $h_t$。隐藏状态 $h_t$ 编码了从序列开始到当前时刻的所有信息，同时可以生成输出 $y_t$。

2RNN 的数学基础

2.1 基本定义与符号

给定长度为 $T$ 的输入序列 $X = (x_1, x_2, \ldots, x_T)$，其中每个 $x_t \in \mathbb{R}^d$。RNN 维护隐藏状态序列 $H = (h_1, h_2, \ldots, h_T)$，其中 $h_t \in \mathbb{R}^h$。

符号维度含义
$W_{hx}$$h \times d$输入到隐藏层的权重矩阵
$W_{hh}$$h \times h$隐藏层到隐藏层的循环权重
$W_{hy}$$o \times h$隐藏层到输出层的权重矩阵
$b_h$$h$隐藏层偏置
$b_y$$o$输出层偏置
$h_0$$h$初始隐藏状态（通常为零向量）

2.2 前向传播公式

$$h_t = \tanh(W_{hx} x_t + W_{hh} h_{t-1} + b_h)$$
$$y_t = W_{hy} h_t + b_y \quad | \quad \hat{y}_t = \text{softmax}(y_t)$$
图 3：单个 RNN 单元的内部计算流程 — 展示矩阵乘法、加法、tanh 激活和循环连接

2.3 计算过程实例

让我们用一个具体的数值例子来演示 RNN 的前向传播过程。假设输入维度 $d=2$，隐藏维度 $h=2$：

参数值
输入序列$x_1 = [1, 0]$，$x_2 = [0, 1]$
$W_{hx}$$[[0.5, 0.1], [0.2, 0.3]]$
$W_{hh}$$[[0.4, 0.1], [0.3, 0.2]]$
$W_{hy}$$[[1.0, 0.0], [0.0, 1.0]]$
$h_0$$[0, 0]$

时间步 $t=1$

$$a_1 = W_{hx} \cdot x_1 + W_{hh} \cdot h_0 = [0.5,\; 0.2]$$ $$h_1 = \tanh(a_1) \approx [0.462,\; 0.197]$$ $$y_1 = W_{hy} \cdot h_1 \approx [0.462,\; 0.197]$$

时间步 $t=2$

$$a_2 = W_{hx} \cdot x_2 + W_{hh} \cdot h_1 = [0.1,\; 0.3] + [0.205,\; 0.178] = [0.305,\; 0.478]$$ $$h_2 = \tanh(a_2) \approx [0.296,\; 0.444]$$ $$y_2 = W_{hy} \cdot h_2 \approx [0.296,\; 0.444]$$
观察
$y_2$ 不仅反映了 $x_2$ 的信息，还融合了 $x_1$ 通过 $h_1$ 传递的信息。这就是 RNN 的"记忆"效果——但由于经过了 $\tanh$ 非线性变换，$x_1$ 的信息已有一定程度的衰减。

2.4 不同的 RNN 定义形式

类型公式特点
Elman 网络$h_t = f(W_{hx} \cdot x_t + W_{hh} \cdot h_{t-1} + b)$最常用，使用隐藏状态反馈
Jordan 网络$h_t = f(W_{hx} \cdot x_t + W_{hy} \cdot y_{t-1} + b)$使用输出反馈，较少使用
多层 RNN$h_t^{(l)} = f(W^{(l)} \cdot h_t^{(l-1)} + W_{hh}^{(l)} \cdot h_{t-1}^{(l)} + b)$低层输出作高层输入

3RNN 的训练算法

3.1 损失函数

RNN 的总损失通常是各时间步损失之和：

$$L = \sum_t L_t \quad | \quad L_t = -\sum_i y_{t,i} \log \hat{y}_{t,i} \quad \text{（交叉熵）}$$

3.2 BPTT：沿时间反向传播

BPTT（Backpropagation Through Time）将展开的 RNN 视为一个深度为 $T$ 的前馈网络，然后应用反向传播。

图 4：BPTT 沿时间反向传播 — 前向传播（蓝色）计算隐藏状态和损失，反向传播（红色）将梯度从后向前传递

3.3 梯度消失与梯度爆炸

梯度传播中的连乘项是梯度消失和爆炸的根源：

$$\frac{\partial h_t}{\partial h_k} = \prod_{i=k+1}^{t} \text{diag}(\sigma'(a_i)) \cdot W_{hh}$$
图 5：梯度消失与梯度爆炸 — 上方箭头递减表示梯度随时间步衰减；下方箭头递增表示梯度指数增长
数值示例
假设 $W_{hh} = 0.9$，$\sigma'(a) = 0.5$，序列长度 $T=10$。则从第 1 步到第 10 步的梯度传播系数为 $(0.45)^9 \approx 7.5 \times 10^{-4}$ —— 第 1 步的梯度信号衰减到原来的万分之七点五。

3.4 截断 BPTT

对于长序列，完整 BPTT 内存和计算开销巨大。截断 BPTT 将长序列切分为长度为 $k$ 的片段，在每个片段内独立进行 BPTT。例如序列长度 $T=100$，截断长度 $k=20$，则分 5 次处理。虽然跨片段的梯度传播被切断，但实践中效果良好。

3.5 数值稳定性技巧

技巧方法作用
梯度裁剪if $\|\nabla\| > \text{threshold}$: $\nabla = \frac{\text{threshold}}{\|\nabla\|} \cdot \nabla$防止梯度爆炸
正交初始化将 $W_{hh}$ 初始化为正交矩阵特征值模为1，减少衰减/爆炸
Layer Normalization每个时间步对隐藏状态归一化稳定激活值尺度
使用 ReLU正区间导数恒为1缓解梯度消失（需配合其他技巧）
Python — 梯度裁剪
# PyTorch 中梯度裁剪的标准做法
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=5.0)

# 正交初始化
for name, param in model.named_parameters():
    if 'weight_hh' in name:
        nn.init.orthogonal_(param)

4LSTM：长短期记忆网络

4.1 设计动机

标准 RNN 的隐藏状态 $h_t$ 需要同时承担两个职责：(1) 存储历史信息 (2) 生成当前输出。这两个职责之间存在冲突。LSTM 的核心创新是分离记忆与计算：引入独立的"细胞状态" $C_t$ 专门存储信息，通过"门控"机制精确控制信息的流入、保留和输出。

4.2 LSTM 结构详解

LSTM 在每个时间步接收三个输入：当前输入 $x_t$、上一时刻隐藏状态 $h_{t-1}$ 和细胞状态 $C_{t-1}$，输出新的 $h_t$ 和 $C_t$。

图 6：LSTM 单元完整结构 — 遗忘门（橙色）、输入门（绿色）、输出门（紫色）、候选值（蓝色）及细胞状态更新路径

遗忘门（Forget Gate）

$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$$

$f_t$ 的每个元素在 $[0, 1]$ 之间，1 表示完全保留，0 表示完全遗忘。

输入门（Input Gate）

$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$$

候选值（Candidate Value）

$$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$$

细胞状态更新

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$

旧记忆 $C_{t-1}$ 按遗忘门 $f_t$ 缩放，新信息 $\tilde{C}_t$ 按输入门 $i_t$ 缩放，两者相加。

输出门与隐藏状态

$$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o) \quad | \quad h_t = o_t \odot \tanh(C_t)$$

4.3 LSTM 缓解梯度消失的原理

标准 RNN 中梯度消失的原因是 $h_t$ 到 $h_{t-1}$ 的路径包含矩阵连乘 $\prod W_{hh}$。而 LSTM 的细胞状态更新中：

$$\frac{\partial C_t}{\partial C_{t-1}} = f_t$$

当遗忘门 $f_t \approx 1$ 时，梯度可以几乎无损地从 $C_t$ 传到 $C_{t-1}$。这意味着梯度可以沿细胞状态路径传播很远而不衰减。

直觉理解
LSTM 可以类比为一个带笔记本的人进行会议记录：细胞状态 $C_t$ = 笔记本（长期记忆）；遗忘门 $f_t$ = 划掉旧条目；输入门 $i_t$ = 决定是否写入新内容；候选值 $\tilde{C}_t$ = 新内容草稿；输出门 $o_t$ = 决定提取哪些内容回答问题；隐藏状态 $h_t$ = 当前可用于回答的信息。

4.4 LSTM 计算实例

假设输入维度 $d=2$，隐藏维度 $h=1$，输入 $x_t = [0.5, 0.3]$，$h_{t-1} = [0.1]$，$C_{t-1} = [0.2]$：

门计算结果
遗忘门 $f_t$$\sigma(0.01 + 0.10 + 0.09) = \sigma(0.20)$$\approx 0.550$
输入门 $i_t$$\sigma(0.04 + 0.05 + 0.06) = \sigma(0.15)$$\approx 0.537$
候选值 $\tilde{C}_t$$\tanh(0.02 + 0.15 + 0.03) = \tanh(0.20)$$\approx 0.197$
细胞状态 $C_t$$0.550 \times 0.2 + 0.537 \times 0.197$$\approx 0.216$
输出门 $o_t$$\sigma(0.01 + 0.10 + 0.12) = \sigma(0.23)$$\approx 0.557$
隐藏状态 $h_t$$0.557 \times \tanh(0.216) = 0.557 \times 0.213$$\approx 0.119$

4.5 LSTM 的变体

带窥孔连接的 LSTM（Peephole LSTM）

让门控信号直接从细胞状态获取：

$$f_t = \sigma(W_f \cdot [C_{t-1}, h_{t-1}, x_t] + b_f)$$

耦合遗忘-输入门

将遗忘门和输入门合并为一个门：

$$i_t = 1 - f_t \quad | \quad C_t = f_t \odot C_{t-1} + (1 - f_t) \odot \tilde{C}_t$$

遗忘多少就写入多少，简化了模型。

5GRU：门控循环单元

5.1 设计思想

GRU（Gated Recurrent Unit）由 Cho 等人于 2014 年提出，是 LSTM 的简化版本：(1) 合并细胞状态和隐藏状态，只用 $h_t$ (2) 将三个门简化为两个门：更新门和重置门。

图 7：GRU 单元结构 — 更新门（绿色）控制新旧信息比例，重置门（橙色）控制候选状态计算

5.2 GRU 的公式

$$z_t = \sigma(W_z \cdot [h_{t-1}, x_t] + b_z)$$ 更新门 $$r_t = \sigma(W_r \cdot [h_{t-1}, x_t] + b_r)$$ 重置门 $$\tilde{h}_t = \tanh(W_h \cdot [r_t \odot h_{t-1}, x_t] + b_h)$$ 候选状态 $$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$ 状态更新

5.3 GRU vs LSTM 对比

特性LSTMGRU
门数量3（遗忘、输入、输出）2（更新、重置）
状态数量2（细胞状态 + 隐藏状态）1（隐藏状态）
参数量$\approx 12h(h+d)$$\approx 9h(h+d)$（减少约 25%）
计算速度较慢较快
长距离依赖较强相近
表达能力较强略弱但相当

5.4 GRU 计算实例

门计算结果
更新门 $z_t$$\sigma(0.03 + 0.20 + 0.06) = \sigma(0.29)$$\approx 0.572$
重置门 $r_t$$\sigma(0.01 + 0.10 + 0.09) = \sigma(0.20)$$\approx 0.550$
候选状态 $\tilde{h}_t$$\tanh(0.011 + 0.15 + 0.03) = \tanh(0.191)$$\approx 0.189$
隐藏状态 $h_t$$0.428 \times 0.1 + 0.572 \times 0.189$$\approx 0.151$

5.5 何时选择 GRU vs LSTM

  • 数据量较大时：LSTM 通常表现更好，更强的表达能力可以充分利用更多数据
  • 数据量较小时：GRU 参数更少，不易过拟合，常优于 LSTM
  • 追求效率时：GRU 计算更快、内存占用更少，更适合资源受限的场景
  • 长序列依赖：LSTM 的独立细胞状态在极长序列上可能略有优势

6双向 RNN

6.1 动机

标准 RNN 只能利用当前时刻之前的信息。但在许多任务中，当前时刻的判断依赖于未来信息。例如命名实体识别："我 去 了 苹果 发布会"中的"苹果"是公司名还是水果？只看到"我 去 了 苹果"无法确定，但看到后面的"发布会"就可以确定是公司名。

双向 RNN（BiRNN）由 Schuster 和 Paliwal 于 1997 年提出，通过同时从前向后和从后向前处理序列，使每个时间步的输出都融合了全局上下文信息。

图 8：双向 RNN 结构 — 前向层（蓝色）从左到右，反向层（绿色）从右到左，输出拼接两层隐藏状态

6.2 计算公式

$$\overrightarrow{h}_t = \tanh(W^{(f)} x_t + W^{(f)} \overrightarrow{h}_{t-1} + b^{(f)})$$ $$\overleftarrow{h}_t = \tanh(W^{(b)} x_t + W^{(b)} \overleftarrow{h}_{t+1} + b^{(b)})$$ $$y_t = W_{hy} [\overrightarrow{h}_t;\; \overleftarrow{h}_t] + b_y$$

6.3 适用场景

适用（完整序列可见）不适用（实时/流式）
文本分类、命名实体识别实时语音识别、实时股票预测
离线语音识别、翻译编码器在线翻译、流式生成

7深层（堆叠）RNN

7.1 动机

单层 RNN 表达能力受限于隐藏维度。深层 RNN 通过堆叠多层增加深度，低层输出作高层输入，每层学习不同抽象层次的特征。

图 9：深层堆叠 RNN — 3 层 RNN，每层 4 个时间步，低层输出作高层输入

7.2 层数选择与残差连接

  • 1-2 层：适合简单任务（情感分析、短文本分类）
  • 2-4 层：适合中等复杂度任务（机器翻译编码器/解码器）
  • 4 层以上：可引入残差连接 $h_t^{(l)} = h_t^{(l-1)} + \text{RNN}^{(l)}(\ldots)$ 缓解梯度消失

8Seq2Seq 架构

8.1 编码器-解码器框架

Seq2Seq 模型由 Sutskever 等人于 2014 年提出，用于输入输出长度不同的序列映射。编码器将完整序列压缩为上下文向量 $c$，解码器从 $c$ 出发逐步生成输出序列。

图 10：Seq2Seq 编码器-解码器架构 — 编码器压缩输入为上下文向量，解码器逐步生成输出

8.2 注意力增强 Seq2Seq

基础 Seq2Seq 的瓶颈是：整个输入序列被压缩为一个固定长度的上下文向量。Bahdanau 注意力机制让解码器在每步动态关注编码器的不同位置：

$$e_{t,i} = \text{score}(s_{t-1}, h_i^{\text{enc}}) \;\rightarrow\; \alpha_{t,i} = \text{softmax}(e_{t,i}) \;\rightarrow\; c_t = \sum_i \alpha_{t,i} \cdot h_i^{\text{enc}}$$

9其他重要变体

9.1 Minimal Gated Unit (MGU)

进一步简化 GRU，只保留一个门，参数量约为 GRU 的 2/3：

$$h_t = (1 - f_t) \odot h_{t-1} + f_t \odot \tanh(W \cdot [f_t \odot h_{t-1}, x_t])$$

9.2 回声状态网络 (ESN)

储备池——随机初始化且不训练的递归层，只训练输出层线性权重。训练极快但表达能力有限。

9.3 神经图灵机 (NTM)

将 RNN 与外部记忆矩阵结合，RNN 作为控制器通过读写头与外部记忆交互，能执行复制、排序等算法任务。

9.4 Independently RNN (IndRNN)

将神经元连接解耦，每个神经元独立处理自己的序列，可堆叠到 21 层而标准 RNN 通常只能少数几层。

11.1 基础 RNN 从零实现

Python — SimpleRNN
class SimpleRNN(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super().__init__()
        self.hidden_size = hidden_size
        self.W_hx = nn.Parameter(torch.randn(hidden_size, input_size) * 0.01)
        self.W_hh = nn.Parameter(torch.randn(hidden_size, hidden_size) * 0.01)
        self.W_hy = nn.Parameter(torch.randn(output_size, hidden_size) * 0.01)
        self.b_h = nn.Parameter(torch.zeros(hidden_size))
        self.b_y = nn.Parameter(torch.zeros(output_size))

    def forward(self, x):
        seq_len, batch_size, _ = x.shape
        h = torch.zeros(batch_size, self.hidden_size)
        outputs = []
        for t in range(seq_len):
            # 核心: h_t = tanh(W_hx * x_t + W_hh * h_{t-1} + b_h)
            h = torch.tanh(x[t] @ self.W_hx.T + h @ self.W_hh.T + self.b_h)
            y = h @ self.W_hy.T + self.b_y
            outputs.append(y)
        return torch.stack(outputs), h

class RNNLanguageModel(nn.Module):
    def __init__(self, vocab_size, embed_size, hidden_size, num_layers=1):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.rnn = nn.RNN(embed_size, hidden_size, num_layers,
                         batch_first=True, dropout=0.1)
        self.fc = nn.Linear(hidden_size, vocab_size)

    def forward(self, x, hidden=None):
        embedded = self.embedding(x)
        output, hidden = self.rnn(embedded, hidden)
        logits = self.fc(output)
        return logits, hidden

11.3 LSTM 分类模型

Python — BiLSTM Classifier
class LSTMModel(nn.Module):
    def __init__(self, vocab_size, embed_size, hidden_size,
                 num_classes, num_layers=2, bidirectional=True):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.lstm = nn.LSTM(embed_size, hidden_size, num_layers,
                           batch_first=True,
                           bidirectional=bidirectional, dropout=0.3)
        self.num_directions = 2 if bidirectional else 1
        self.fc = nn.Linear(hidden_size * self.num_directions, num_classes)

    def forward(self, x):
        embedded = self.embedding(x)
        output, (h_n, c_n) = self.lstm(embedded)
        if self.lstm.bidirectional:
            hidden = torch.cat([h_n[-2], h_n[-1]], dim=1)
        else:
            hidden = h_n[-1]
        return self.fc(hidden)

        super().__init__()
        self.gru = nn.GRU(input_size, hidden_size, num_layers,
                         batch_first=True, dropout=0.2)

    def forward(self, x):
        output, h_n = self.gru(x)
        return self.fc(h_n[-1])

11.5 Seq2Seq 实现

Python — Encoder-Decoder
class Encoder(nn.Module):
    def __init__(self, vocab_size, embed_size, hidden_size):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.lstm = nn.LSTM(embed_size, hidden_size, batch_first=True)
    def forward(self, x):
        embedded = self.embedding(x)
        return self.lstm(embedded)

class Decoder(nn.Module):
    def __init__(self, vocab_size, embed_size, hidden_size):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.lstm = nn.LSTM(embed_size, hidden_size, batch_first=True)
        self.fc = nn.Linear(hidden_size, vocab_size)
    def forward(self, x, hidden):
        output, hidden = self.lstm(self.embedding(x), hidden)
        return self.fc(output.squeeze(1)), hidden

class Seq2Seq(nn.Module):
    def __init__(self, encoder, decoder):
        super().__init__()
        self.encoder = encoder
        self.decoder = decoder
    def forward(self, src, trg, teacher_forcing_ratio=0.5):
        batch_size, trg_len = trg.shape
        outputs = torch.zeros(batch_size, trg_len,
                             self.decoder.fc.out_features)
        _, hidden = self.encoder(src)
        dec_input = torch.zeros(batch_size, 1, dtype=torch.long)
        for t in range(trg_len):
            output, hidden = self.decoder(dec_input, hidden)
            outputs[:, t] = output
            dec_input = trg[:, t:t+1] if torch.rand(1).item() < teacher_forcing_ratio \
                        else output.argmax(1, keepdim=True)
        return outputs

VOCAB_SIZE = 10000; EMBED_SIZE = 128; HIDDEN_SIZE = 256
NUM_LAYERS = 2; CLIP = 5.0; LR = 0.001

for epoch in range(NUM_EPOCHS):
    model.train()
    for batch_x, batch_y in train_loader:
        optimizer.zero_grad()
        logits = model(batch_x)
        loss = criterion(logits, batch_y)
        loss.backward()

        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=CLIP)
        optimizer.step()

11.7 手动实现 LSTM 单元

Python — LSTM Cell from Scratch
class LSTMCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.hidden_size = hidden_size
        # 4个门合并为一个大矩阵
        self.W_x = nn.Parameter(torch.randn(4*hidden_size, input_size) * 0.01)
        self.W_h = nn.Parameter(torch.randn(4*hidden_size, hidden_size) * 0.01)
        self.b = nn.Parameter(torch.zeros(4*hidden_size))

    def forward(self, x, state):
        h_prev, c_prev = state
        for t in range(x.shape[0]):
            gates = x[t] @ self.W_x.T + h_prev @ self.W_h.T + self.b
            f, i, g, o = gates.chunk(4, dim=-1)
            c_prev = torch.sigmoid(f) * c_prev + torch.sigmoid(i) * torch.tanh(g)
            h_prev = torch.sigmoid(o) * torch.tanh(c_prev)
        return h_prev, (h_prev, c_prev)

12局限与 Transformer 替代

12.1 RNN 的根本局限

局限说明
顺序计算瓶颈必须逐步处理，$T$ 步计算无法并行化，训练时间与序列长度成正比
长距离依赖有限即使 LSTM/GRU，数百步以上的长距离依赖仍然困难
隐藏状态瓶颈所有历史信息压缩到固定维度向量中，信息容量有限
无法并行训练与 GPU/TPU 大规模并行计算能力不匹配

12.2 Transformer 的替代

2017 年 Transformer 通过自注意力机制彻底解决了 RNN 的顺序计算瓶颈：

维度RNN/LSTMTransformer
训练并行度低（顺序计算）高（全并行）
推理速度（逐 token）快（$O(1)$ 每步）慢（$O(n^2)$ 注意力）
内存占用低（固定隐藏状态）高（KV 缓存增长）
流式处理天然支持需要特殊设计
边缘设备部署适合较难

12.3 RNN 在大模型时代的复兴

2023-2024 RNN 复兴

RWKV（2023）：将注意力优势融入 RNN 框架，训练可并行、推理保持线性复杂度。

Mamba（2024）：状态空间模型，结合 RNN 递归计算和注意力选择性，在大规模语言建模上展现竞争力。

这些工作表明，RNN 的核心思想——递归状态更新——仍然具有强大生命力。
