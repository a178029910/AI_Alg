一 起源与直觉

1.1 什么是强化学习

强化学习（Reinforcement Learning, RL） 是机器学习三大范式之一：智能体（Agent）在与环境（Environment）的反复交互中，通过试错（trial-and-error）积累经验，以最大化长期累积奖励为目标，逐步学会最优决策策略。与监督学习直接给定答案不同，强化学习只给出奖励信号（reward），智能体必须自己判断"哪些行为带来了好结果"。

核心直觉

想象训练一只小狗：做了正确动作就奖励零食（正奖励），做了错误动作就轻轻呵斥（负奖励）。小狗并不理解"奖励"背后的数学公式，但它能通过无数次试错逐渐学会：什么动作在什么状态下最有利。强化学习的本质，就是把这一过程用数学语言形式化。

与监督学习、无监督学习的对比

维度监督学习无监督学习强化学习
数据来源带标签样本 $(x, y)$无标签数据 $x$交互产生的经验 $(s, a, r, s')$
学习信号明确的误差数据内在结构延迟的稀疏奖励
目标拟合映射 $f: x \to y$发现隐藏结构最大化累积奖励
探索不需要不需要核心要素（探索 vs 利用）
典型场景图像分类、翻译聚类、降维游戏、机器人、推荐

强化学习面临独特的信用分配问题（Credit Assignment Problem）：一步动作的后果可能要在许多步之后才显现。例如棋局中某一步看似无用的棋，几十步之后才决定胜负——算法必须能判断"功劳"和"过错"究竟应归因于哪一步。这正是价值函数（value function）与折扣回报（discounted return）要解决的问题。

1.2 强化学习的经典应用

  • AlphaGo 系列：2016 年战胜李世石，利用策略网络 + 价值网络 + 蒙特卡洛树搜索，是 RL 最出圈的里程碑。
  • 机器人控制：机械臂抓取、四足机器人行走、无人机编队，通过真实或仿真环境学习连续动作策略。
  • 推荐系统：把"给用户推荐什么"建模为序贯决策，以点击率、停留时长、长期留存作为奖励。
  • 电信网络优化：基站资源分配、网络切片调度、5G/6G 频谱管理，把时变网络状态当作环境状态。
  • RLHF（基于人类反馈的强化学习）：ChatGPT 等大模型用人类偏好训练奖励模型，再以 PPO 微调语言模型以对齐人类价值观。

二 马尔可夫决策过程

马尔可夫决策过程（Markov Decision Process, MDP）是强化学习的标准数学框架，几乎所有经典 RL 算法都建立在 MDP 之上。

2.1 MDP 五元组

元素符号含义
状态集合$S$环境所有可能的状态，如棋盘局面、传感器读数
动作集合$A$智能体可执行的动作，如落子、前进、推荐
状态转移概率$P(s' \mid s, a)$在状态 $s$ 执行动作 $a$ 后转移到 $s'$ 的概率
奖励函数$R(s, a, s')$转移发生时环境返回的即时奖励
折扣因子$\gamma \in [0, 1]$权衡即时奖励与未来奖励的权重

一个 MDP 可记为五元组 $M = \langle S, A, P, R, \gamma \rangle$。当 $\gamma = 0$ 时智能体只看眼前利益；$\gamma$ 越接近 1，越有"长远眼光"。

2.2 马尔可夫性质与轨迹

马尔可夫性质：未来的状态只与当前状态有关，与更早的历史无关，即"无记忆性"。

$$P(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \dots) = P(s_{t+1} \mid s_t, a_t)$$

智能体与环境交互产生一条轨迹（trajectory）：状态、动作、奖励的交替序列。

$$\tau = s_0, a_0, r_1, s_1, a_1, r_2, s_2, a_2, \dots$$

2.3 策略与折扣回报

策略（policy） $\pi(a \mid s)$ 定义了智能体在每个状态下选择动作的概率分布。给定一条轨迹，其折扣回报（discounted return）为未来奖励的加权和：

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

折扣因子 $\gamma$ 有三个作用：① 数学上保证无限步求和收敛；② 反映"近期奖励比远期更重要"；③ 在实际工程中可以限制回报的视界长度。

2.4 价值函数

状态价值函数 $V^{\pi}(s)$ 表示从状态 $s$ 出发、遵循策略 $\pi$ 所能获得的期望回报：

$$V^{\pi}(s) = \mathbb{E}_{\pi}\left[ G_t \mid S_t = s \right]$$

动作价值函数 $Q^{\pi}(s, a)$ 表示在状态 $s$ 先执行动作 $a$、之后遵循策略 $\pi$ 的期望回报：

$$Q^{\pi}(s, a) = \mathbb{E}_{\pi}\left[ G_t \mid S_t = s, A_t = a \right]$$

两者关系：$V^{\pi}(s) = \sum_a \pi(a \mid s) \, Q^{\pi}(s, a)$，即状态价值是动作价值按策略概率的加权平均。

2.5 最优价值函数与最优策略

在有限 MDP 中，一定存在一个（或多个）最优策略 $\pi^*$，其价值不低于任何其他策略。最优价值函数定义为：

$$V^*(s) = \max_{\pi} V^{\pi}(s), \qquad Q^*(s, a) = \max_{\pi} Q^{\pi}(s, a)$$

最优策略即为在每个状态下贪心地选取最优动作价值对应的动作：

$$\pi^*(a \mid s) = \begin{cases} 1 & \text{if } a = \arg\max_{a'} Q^*(s, a') \\ 0 & \text{otherwise} \end{cases}$$

2.6 贝尔曼方程

贝尔曼方程（Bellman Equation）是价值函数与自举（bootstrap）思想的数学表达：当前状态的价值 = 即时奖励 + 下一状态的（折扣）期望价值。这一递归关系是所有价值类强化学习算法的基石。

贝尔曼期望方程（Bellman Expectation Equation）

把式 (4) 按"状态 → 动作 → 下一状态"两步展开：

$$V^{\pi}(s) = \sum_{a} \pi(a \mid s) \sum_{s'} P(s' \mid s, a)\left[ R(s, a, s') + \gamma V^{\pi}(s') \right]$$
$$Q^{\pi}(s, a) = \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma \sum_{a'} \pi(a' \mid s') Q^{\pi}(s', a') \right]$$

贝尔曼最优方程（Bellman Optimality Equation）

把式 (6)、(7) 代入期望方程，把"对策略求期望"替换为"对动作取最大值"：

$$V^*(s) = \max_{a} \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V^*(s') \right]$$
$$Q^*(s, a) = \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma \max_{a'} Q^*(s', a') \right]$$
贝尔曼方程的作用

贝尔曼方程把"评估一整条轨迹"的难题，转化为"评估当前一步 + 下一步"的递归问题。后面的动态规划、时序差分、DQN，本质上都是在用不同方式求解（或逼近）这组方程。

三 动态规划：策略与价值迭代

动态规划（Dynamic Programming, DP）是求解 MDP 的第一类系统性方法，其前提是已知完整的环境模型（状态转移概率 $P$ 与奖励函数 $R$）。DP 通过"自举"（用后继状态的估计值更新当前状态）迭代求解贝尔曼方程。

3.1 策略评估（Policy Evaluation）

给定一个策略 $\pi$，策略评估迭代地计算其状态价值函数。利用贝尔曼期望方程 (8) 构造迭代公式：第 $k+1$ 轮的新估值，由第 $k$ 轮的旧估值代入方程右端得到。

$$V_{k+1}(s) = \sum_{a} \pi(a \mid s) \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V_k(s') \right]$$

当 $k \to \infty$ 时，$V_k \to V^{\pi}$。实际中通常在两次迭代差值小于阈值时提前停止。

3.2 策略改进（Policy Improvement）

有了 $V^{\pi}$ 之后，就可以"贪心"地改进策略：在每个状态下选择能使 $Q$ 值最大的动作：

$$\pi'(s) = \arg\max_{a} \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V^{\pi}(s') \right]$$

策略改进定理保证：只要 $\pi'$ 至少在一个状态下严格优于 $\pi$，那么 $V^{\pi'}(s) \geq V^{\pi}(s)$ 对所有状态成立。评估 → 改进 → 再评估 → 再改进……最终收敛到最优策略。

3.3 策略迭代与价值迭代

策略迭代（Policy Iteration）：交替执行完整的策略评估与策略改进，直到策略不再变化。每轮评估需要多次扫描整个状态空间，收敛缓慢但保证单调。

价值迭代（Value Iteration）：把策略改进"折叠"进评估过程，每一步直接取最大值，即把贝尔曼最优方程 (10) 变为迭代公式：

$$V_{k+1}(s) = \max_{a} \sum_{s'} P(s' \mid s, a) \left[ R(s, a, s') + \gamma V_k(s') \right]$$
DP 方法的两大局限
  • 需要完美模型：真实环境中 $P$ 与 $R$ 往往未知或难以精确估计。
  • 状态空间爆炸（curse of dimensionality）：状态每增加一个维度，数量就指数增长，全量扫描不可行。

这两大局限促使强化学习走向无模型（model-free）方法：不假设转移概率已知，直接从经验中学习——这就是蒙特卡洛与时序差分方法。

四 蒙特卡洛方法

蒙特卡洛（Monte Carlo, MC）方法不再假设已知环境模型，而是用完整经验轨迹的实际回报来估计价值。它只从真实（或采样）的轨迹中学习。

4.1 First-Visit 与 Every-Visit MC

  • First-visit MC：对于每条轨迹，只在状态 $s$ 第一次被访问时，才用该次轨迹的回报 $G_t$ 更新 $V(s)$ 的均值估计。理论性质更好（无偏、依概率收敛）。
  • Every-visit MC：状态 $s$ 每次被访问都参与回报均值更新。方差可能略大，但实践中同样常用。
MC 策略评估

核心更新式：$V(s) \leftarrow V(s) + \alpha\left[ G_t - V(s) \right]$，其中 $G_t$ 是整条轨迹的实际折扣回报，$\alpha$ 是学习率。注意：MC 依赖实际经历的完整轨迹，是无偏估计，且不使用自举（不利用其他状态的估计值）。

4.2 MC 控制：探索与 epsilon-greedy

MC 控制的目标是同时逼近最优价值与最优策略。核心难点是探索（exploration）：如果始终贪心选择当前最优动作，就永远发现不了更优动作。解决办法是 $\epsilon$-greedy：以概率 $1 - \epsilon$ 选择贪心动作，以概率 $\epsilon$ 随机探索，并让 $\epsilon$ 随训练衰减，使策略最终收敛。

4.3 MC 与 DP、TD 的关系

MC 代表"纯经验"路线：用样本均值估计价值；DP 代表"纯模型"路线：用模型推导价值；时序差分（TD）介于两者之间——既用经验，又用自举。三者的关系见下图：

五 时序差分与 Q-Learning

时序差分（Temporal Difference, TD）方法结合了 MC 的"经验采样"与 DP 的"自举"：每走一步就立即更新，不必等轨迹结束。这使得 TD 可用于非终止型任务，且方差远小于 MC。

5.1 TD(0)：一步自举

TD(0) 用"当前奖励 + 下一状态的估计价值"作为更新目标，取代 MC 中的完整回报 $G_t$，从而把等待时间从"轨迹结束"缩短到"一步之后"：

$$V(s) \leftarrow V(s) + \alpha \left[ R + \gamma V(s') - V(s) \right]$$

方括号中的 $R + \gamma V(s') - V(s)$ 称为TD 误差（TD error）。与 MC 相比：TD 偏差更大但方差小得多；两者充分学习后都会收敛到真实价值函数。

5.2 SARSA：同策略控制

SARSA 的名字来自其更新元组 $(s, a, r, s', a')$。它每一步用一个五元组做自举更新，且用来采样的策略与要学习的策略是同一个（on-policy）：

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma Q(s', a') - Q(s, a) \right]$$

SARSA 的探索机制（如 $\epsilon$-greedy）会影响它最终学到的策略，因此对探索参数比较敏感。

5.3 Q-Learning：off-policy 控制

Q-Learning 是强化学习中最经典的算法。其更新不再使用"实际执行的 $a'$"，而是取下一状态所有动作的最大值 $\max_{a'} Q(s', a')$。即使当前行为策略在探索，学习目标始终指向最优策略，因此是 off-policy：

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

Q-Learning 的收敛性有严格理论保证：只要每个状态-动作对被无限次探索，且学习率满足 Robbins-Monro 条件，$Q$ 将以概率 1 收敛到 $Q^*$。

5.3 epsilon-greedy 探索

$\epsilon$-greedy 是权衡"探索 vs 利用"的最简单策略：以大概率选择当前最优动作，以小概率随机探索：

$$\pi(a \mid s) = \begin{cases} 1 - \epsilon + \frac{\epsilon}{|A|} & \text{if } a = \arg\max_{a'} Q(s, a') \\ \frac{\epsilon}{|A|} & \text{otherwise} \end{cases}$$

5.4 On-policy vs Off-policy 对比

维度On-policy（如 SARSA）Off-policy（如 Q-Learning）
行为策略即目标策略本身可与目标策略不同（如引入经验回放）
学到的策略包含探索在内的策略始终指向贪心最优策略
样本效率较低，探索轨迹被"浪费"较高，可复用历史经验
风险更保守，适合带风险场景有过估计风险，需额外处理
典型算法SARSA、A2C 等Q-Learning、DQN、DDPG、TD3、SAC

六 深度 Q 网络（DQN）

经典 Q-Learning 用表格存储 $Q(s, a)$，当状态空间巨大（如 Atari 游戏的像素画面）时表格必然爆炸。深度 Q 网络（Deep Q-Network, DQN）用神经网络 $Q_\theta(s, a)$ 近似 Q 函数，并借助两项关键技巧让深度 Q-learning 稳定训练。

6.1 DQN 核心思想

DQN 的网络输入是状态 $s$（如图像），输出是每个动作的 Q 值向量。训练目标是最小化预测与贝尔曼最优目标之间的均方误差：

$$\mathcal{L}(\theta) = \mathbb{E}_{(s, a, r, s') \sim \mathcal{D}}\left[ \left( r + \gamma \max_{a'} Q_{\theta^-}(s', a') - Q_\theta(s, a) \right)^2 \right]$$

6.2 经验回放（Experience Replay）

智能体把经历的四元组 $(s, a, r, s')$ 存入回放缓冲区 $\mathcal{D}$，训练时随机采样小批量。这样带来三大好处：① 打破样本时间相关性，稳定梯度；② 提高样本复用率；③ 平滑训练分布，减少灾难性遗忘。

6.3 目标网络（Target Network）

如果更新时用同一个网络既算目标又算预测，目标会随参数变化而"移动"，导致训练震荡。DQN 维护一个延迟更新的目标网络 $Q_{\theta^-}$（每 $C$ 步从在线网络拷贝一次权重），使目标相对稳定，如式 (18) 所示。

6.4 Double DQN：缓解过估计

标准 DQN 的 $\max_{a'} Q(s', a')$ 会系统性高估价值。Double DQN 用在线网络选动作、目标网络估值，把"选择"与"评估"解耦，显著降低过估计：

$$y = r + \gamma Q_{\theta^-}\left(s', \arg\max_{a'} Q_\theta(s', a')\right)$$

6.5 Dueling DQN：分离优势与状态价值

Dueling 架构把 Q 值拆成两部分：状态价值 $V(s)$ 与动作优势 $A(s, a)$（该动作相对平均水平的优势）。当某些状态下动作选择并不重要时，网络只需学准确的 $V$ 即可：

$$Q(s, a) = V(s) + A(s, a) - \max_{a'} A(s, a')$$

下图展示了 DQN 的完整数据流：状态输入网络，输出各动作 Q 值，经 argmax 选动作与环境交互，经验存入回放池，再抽样训练两个网络。

七 策略梯度与 REINFORCE

价值方法（Q-Learning、DQN 等）先学价值函数，再隐式导出策略；策略梯度方法则直接参数化策略 $\pi_\theta(a \mid s)$，并通过梯度上升直接优化目标。

7.1 策略梯度定理

策略目标函数 $J(\theta) = \mathbb{E}_{s_0 \sim \rho_0}\left[ V^{\pi_\theta}(s_0) \right]$ 对参数的梯度可由下式给出（策略梯度定理，Policy Gradient Theorem）：

$$\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\left[ \nabla_\theta \log \pi_\theta(a \mid s) \, Q^{\pi_\theta}(s, a) \right]$$

注意：该梯度 不包含对状态分布 $\rho^\pi$ 的导数，因此可以直接用采样轨迹估计梯度，无需环境模型。

7.2 REINFORCE 算法

REINFORCE 是最简单的策略梯度算法：用蒙特卡洛采样的完整回报 $G_t$ 代替 $Q^{\pi_\theta}(s, a)$，对每条轨迹做一次梯度上升更新：

$$\theta \leftarrow \theta + \alpha \sum_{t} \nabla_\theta \log \pi_\theta(a_t \mid s_t) \, G_t$$
REINFORCE 的局限

用完整回报 $G_t$ 作为权重意味着方差极大：同一轨迹的随机性会导致梯度剧烈波动。因此 REINFORCE 收敛缓慢，常配合基线（baseline）使用。

7.3 基线（Baseline）降低方差

从回报中减去一个只与状态有关的基线 $b(s)$（如状态价值 $V(s)$），梯度的期望不变，但方差显著下降：

$$\nabla_\theta J(\theta) = \mathbb{E}_{\tau}\left[ \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t) \left( G_t - b(s_t) \right) \right]$$

最常用的基线是状态价值函数 $V(s)$，而 $G_t - V(s_t)$ 就是优势（advantage）的概念雏形——这自然引出了下一章的 Actor-Critic 架构。

八 Actor-Critic 与 A3C

Actor-Critic（演员-评论家）架构把"策略"与"价值"两个角色分开：Actor 负责决策（策略网络），Critic 负责评价（价值网络）。Critic 提供低方差的估计，引导 Actor 更新；Actor 的更新又反过来提升 Critic 的评价精度。

8.1 架构分工

模块角色输入输出更新方向
Actor（策略网络）决定"做什么"状态 $s$动作分布 $\pi_\theta(a \mid s)$梯度上升（提升优势）
Critic（价值网络）评价"做得好不好"状态 $s$价值 $V_\phi(s)$TD 误差最小化

8.2 优势函数（Advantage）

优势函数衡量"在状态 $s$ 采取动作 $a$ 相比平均水平好多少"：

$$A^{\pi}(s, a) = Q^{\pi}(s, a) - V^{\pi}(s)$$

Actor 的梯度目标改为最大化优势：$\nabla_\theta J = \mathbb{E}\left[ \nabla_\theta \log \pi_\theta(a \mid s) \, A(s, a) \right]$。Critic 提供的优势估计 $A \approx r + \gamma V(s') - V(s)$（即 TD 误差）方差远小于 MC 回报，训练更稳定。

8.3 A3C：异步并行采集

A3C（Asynchronous Advantage Actor-Critic）的思想：启动多个并行 worker，每个 worker 有独立的环境副本，各自异步采集经验、计算梯度，并定期把梯度同步到共享的全局参数。并行带来的"异步性"本身就起到了类似经验回放的去相关作用，因此 A3C 不再依赖经验回放。

九 PPO：近端策略优化

PPO（Proximal Policy Optimization）是 OpenAI 在 2017 年提出的算法，也是当今 RLHF 与大模型对齐的事实标准。它解决的是策略更新步子过大导致训练崩溃的问题。

9.1 TRPO 的思路

TRPO（Trust Region Policy Optimization）通过信赖域约束（trust region）限制每次更新的步长，要求新旧策略的 KL 散度不超过阈值，从而保证更新单调不减。但其共轭梯度求解复杂、实现繁琐。

9.2 PPO Clip 目标函数

PPO 用一阶近似的 Clip 约束替代 TRPO 的二次约束：定义新旧策略的比率 $r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{old}}(a_t \mid s_t)}$，目标函数为：

$$\mathcal{L}^{CLIP}(\theta) = \mathbb{E}_t\left[ \min\left( r_t(\theta) A_t, \; \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) A_t \right) \right]$$

当优势 $A_t > 0$ 时，目标希望增大动作概率；但当概率比超过 $1 + \epsilon$ 时，收益被截断——防止一步更新过大。当 $A_t < 0$ 时同理。由此，PPO 在保持训练稳定的同时只需要一阶梯度，实现非常简单。

9.3 PPO 完整流程

PPO 单次迭代
  1. 用当前策略与环境交互，收集一批轨迹（若干 step 或若干 episode）。
  2. 计算每个时间步的优势估计 $A_t$（常用 GAE，广义优势估计）。
  3. 保存数据，用旧策略计算概率比 $r_t(\theta)$。
  4. 对新策略做多次 mini-batch 梯度上升，目标为 Clip 目标 (24)。
  5. 可加入熵正则项鼓励探索，循环往复。

十 连续控制：DDPG 与 TD3

前文的 Q-Learning、DQN、策略梯度都默认离散动作。但机械臂力矩、自动驾驶方向盘角度等是连续动作——需要新一代方法：DDPG 与 TD3。

10.1 DDPG：确定性策略梯度

DDPG（Deep Deterministic Policy Gradient）把 Actor-Critic 应用于连续空间：Actor 网络直接输出一个确定性动作 $a = \mu_\theta(s)$（而不是动作概率分布），Critic 用 DQN 式的经验回放与目标网络训练 Q 值。DDPG 是 DPG + DQN 的深度化结合，适合动作空间连续的机器人控制。

DDPG 的训练目标：Critic 最小化 $L = \mathbb{E}\left[ \left( r + \gamma Q_{\theta^-}(s', \mu_{\phi^-}(s')) - Q_\theta(s, a) \right)^2 \right]$；Actor 的梯度为 $\nabla_\theta J \approx \mathbb{E}\left[ \nabla_a Q_\theta(s, a) \big|_{a=\mu(s)} \nabla_\theta \mu_\theta(s) \right]$。探索通过在动作上叠加高斯噪声 $a = \mu(s) + \mathcal{N}(0, \sigma^2)$ 实现。

10.2 TD3：三个关键改进

TD3（Twin Delayed DDPG）针对 DDPG 的三个弱点分别提出改进：

  1. Clipped Double-Q：训练两个 Critic，目标用两者的较小值，缓解过估计。
  2. 延迟策略更新（Delayed Policy Updates）：策略网络比价值网络更新更慢（如每 2 步策略更新 1 次），让 Critic 先收敛得更稳。
  3. 目标策略平滑（Target Policy Smoothing）：目标动作加入噪声，使 Q 对动作的"尖峰"不敏感，增加鲁棒性。

10.3 算法对比表

算法动作空间核心技巧适用场景局限性
DDPG连续确定性 Actor + 经验回放中低维连续控制超参数敏感、易过估计
TD3连续Double-Q + 延迟更新 + 平滑更高稳定性连续控制训练较慢、实现复杂
PPO（连续版）离散或连续Clip 稳定更新、随机策略通用、稳健样本效率一般
SAC连续最大熵 + 随机策略高样本效率连续控制调参敏感

11.1 Q-Learning 表格法（GridWorld）

在一个 4x4 网格世界中，智能体从左上角出发，走到右下角（目标）获得奖励，撞墙则原地不动并受小惩罚。表格法直接维护 Q 表：

q_learning.py
import torch

# GridWorld: 4x4 网格, 0 = 起点, 15 = 终点, 撞墙则停留
N = 4
GOAL = 15
WALLS = {5, 7, 11}
ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]  # 上 下 左 右
GAMMA = 0.95
ALPHA = 0.1
EPS = 0.3
EPISODES = 3000


def to_state(r, c):
    return r * N + c


def step(state, a_idx):
    r, c = divmod(state, N)
    dr, dc = ACTIONS[a_idx]
    nr, nc = r + dr, c + dc
    if 0 <= nr < N and 0 <= nc < N and to_state(nr, nc) not in WALLS:
        nxt = to_state(nr, nc)
    else:
        nxt = state
    if nxt == GOAL:
        return nxt, 10.0, True
    return nxt, -0.1, False


def eps_greedy(Q, s, eps):
    if torch.rand(1).item() < eps:
        return torch.randint(len(ACTIONS), (1,)).item()
    return max(range(len(ACTIONS)), key=lambda a: Q[s][a])


def main():
    Q = [[0.0] * len(ACTIONS) for _ in range(N * N)]
    for _ in range(EPISODES):
        s = 0
        done = False
        while not done:
            a = eps_greedy(Q, s, EPS)
            s2, r, done = step(s, a)
            best = max(Q[s2])
            Q[s][a] += ALPHA * (r + GAMMA * best - Q[s][a])
            s = s2
    path = [0]
    s = 0
    while s != GOAL:
        a = max(range(len(ACTIONS)), key=lambda x: Q[s][x])
        s = step(s, a)[0]
        path.append(s)
    print("Q-Learning path:", " -> ".join(str(p) for p in path))


if __name__ == "__main__":
    main()

11.2 DQN（经验回放 + 目标网络）

在简易 CartPole 式环境中，用神经网络近似 Q 值，配合经验回放与目标网络稳定训练：

dqn.py
import torch
import torch.nn as nn
import torch.optim as optim

# 简易 CartPole 环境: 状态 4 维, 动作 2 个 (左/右)
STATE_DIM = 4
ACTION_DIM = 2


class MiniCartPole:
    def __init__(self):
        self.x, self.xd, self.theta, self.td = 0.0, 0.0, 0.0, 0.0
        self.steps = 0

    def reset(self):
        self.x, self.xd, self.theta, self.td = 0.0, 0.0, 0.0, 0.0
        self.steps = 0
        return [self.x, self.xd, self.theta, self.td]

    def step(self, a):
        force = 10.0 if a == 1 else -10.0
        # 简化物理模型
        self.xd += force * 0.02
        self.x += self.xd * 0.02
        self.td += -self.theta * 0.1 + self.xd * 0.05
        self.theta += self.td * 0.02
        self.steps += 1
        done = abs(self.theta) > 0.3 or abs(self.x) > 2.4
        r = 1.0 if not done else -1.0
        return [self.x, self.xd, self.theta, self.td], r, done


class QNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Sequential(nn.Linear(STATE_DIM, 32), nn.ReLU(),
                                nn.Linear(32, 32), nn.ReLU(),
                                nn.Linear(32, ACTION_DIM))

    def forward(self, x):
        return self.fc(x)


def main():
    net = QNet()
    tnet = QNet()
    opt = optim.Adam(net.parameters(), lr=1e-3)
    buf = []
    env = MiniCartPole()
    BATCH = 64
    GAMMA = 0.99
    for ep in range(400):
        s = env.reset()
        done = False
        total = 0.0
        while not done:
            eps = max(0.05, 1.0 - ep / 200.0)
            q = net(torch.tensor(s, dtype=torch.float32))
            a = q.argmax().item() if torch.rand(1).item() > eps else torch.randint(ACTION_DIM, (1,)).item()
            s2, r, done = env.step(a)
            buf = buf + [(s, a, r, s2, done)]
            if len(buf) > 5000:
                buf = buf[-5000:]
            if len(buf) >= 256:
                bs = 64
                idx = torch.randint(len(buf), (bs,))
                batch = [buf[i] for i in idx.tolist()]
                st = torch.tensor([b[0] for b in batch], dtype=torch.float32)
                ac = torch.tensor([b[1] for b in batch], dtype=torch.long)
                rw = torch.tensor([b[2] for b in batch], dtype=torch.float32)
                sn = torch.tensor([b[3] for b in batch], dtype=torch.float32)
                dn = torch.tensor([b[4] for b in batch], dtype=torch.float32)
                qv = net(st).gather(1, ac.unsqueeze(1)).squeeze(1)
                with torch.no_grad():
                    tgt = rw + GAMMA * (1 - dn) * tnet(sn).max(1).values
                loss = nn.functional.mse_loss(qv, tgt)
                opt.zero_grad()
                loss.backward()
                opt.step()
            if ep % 20 == 0:
                tnet.load_state_dict(net.state_dict())
            s = s2
            total += r
        if ep % 50 == 0:
            print("episode", ep, "reward", total)


if __name__ == "__main__":
    main()

11.3 REINFORCE（蒙特卡洛策略梯度）

直接参数化策略，用完整回报 $G_t$ 作为更新权重，配合基线归一化降低方差：

policy_gradient.py
import torch
import torch.nn as nn
import torch.optim as optim

# REINFORCE: 用完整回报 G 作为权重, 蒙特卡洛策略梯度
STATE_DIM = 4
ACTION_DIM = 2


class MiniEnv:
    """极简环境: 状态 4 维, 动作 2 个。右动作偏向更好结果。"""
    def reset(self):
        return [0.0, 0.0, 0.0, 0.0]

    def step(self, a):
        s = [0.0, 0.0, 0.0, 0.0]
        r = 1.0 if a == 1 else -0.5
        done = True  # 单步回合
        return s, r, done


class PolicyNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Sequential(nn.Linear(STATE_DIM, 32), nn.ReLU(),
                                nn.Linear(32, ACTION_DIM))

    def forward(self, x):
        return self.fc(x)


def main():
    net = PolicyNet()
    opt = optim.Adam(net.parameters(), lr=1e-2)
    env = MiniEnv()
    GAMMA = 0.99
    for ep in range(1000):
        s = env.reset()
        done = False
        log_probs = []
        rewards = []
        while not done:
            s_t = torch.tensor(s, dtype=torch.float32)
            logits = net(s_t)
            dist = torch.distributions.Categorical(logits=logits)
            a = dist.sample()
            log_probs.append(dist.log_prob(a))
            s, r, done = env.step(a.item())
            rewards.append(r)
        G = 0.0
        returns = []
        for r in reversed(rewards):
            G = r + GAMMA * G
            returns.insert(0, G)
        returns = torch.tensor(returns, dtype=torch.float32)
        returns = (returns - returns.mean()) / (returns.std() + 1e-8)
        loss = 0.0
        for lp, Gt in zip(log_probs, returns):
            loss = loss - lp * Gt
        opt.zero_grad()
        loss.backward()
        opt.step()
        if ep % 100 == 0:
            print("episode", ep, "reward", sum(rewards))


if __name__ == "__main__":
    main()

11.4 Actor-Critic

Actor 负责选动作，Critic 用 TD 误差评估优劣，两者交替更新：

actor_critic.py
import torch
import torch.nn as nn
import torch.optim as optim

# Actor-Critic: Actor 学策略, Critic 学价值, 优势驱动更新
STATE_DIM = 4
ACTION_DIM = 2


class MiniWalk:
    # 简易环境: 步数越多奖励越高, 鼓励长轨迹
    def __init__(self):
        self.t = 0

    def reset(self):
        self.t = 0
        return [0.0, 0.0, 0.0, 0.0]

    def step(self, a):
        self.t += 1
        s = [float(self.t)] * STATE_DIM
        done = self.t >= 20
        r = 1.0 if not done else 5.0
        return s, r, done


class ActorCritic(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Sequential(nn.Linear(STATE_DIM, 32), nn.ReLU(),
                                nn.Linear(32, 32), nn.ReLU())
        self.actor = nn.Linear(32, ACTION_DIM)
        self.critic = nn.Linear(32, 1)

    def forward(self, x):
        h = self.fc(x)
        return self.actor(h), self.critic(h)


def main():
    net = ActorCritic()
    opt = optim.Adam(net.parameters(), lr=1e-3)
    env = MiniWalk()
    GAMMA = 0.99
    for ep in range(500):
        s = env.reset()
        done = False
        while not done:
            s_t = torch.tensor(s, dtype=torch.float32)
            logits, val = net(s_t)
            dist = torch.distributions.Categorical(logits=logits)
            a = dist.sample()
            s2, r, done = env.step(a.item())
            s2_t = torch.tensor(s2, dtype=torch.float32)
            _, val2 = net(s2_t)
            td = r + GAMMA * val2 * (0.0 if done else 1.0) - val
            pg = -dist.log_prob(a) * td.detach()
            loss = pg + td.pow(2) * 0.5
            opt.zero_grad()
            loss.backward()
            opt.step()
            s = s2
        if ep % 100 == 0:
            print("episode", ep, "done")
    print("Actor-Critic training finished")


if __name__ == "__main__":
    main()

11.5 PPO（Clip 目标）

用新旧策略比率加上 Clip 截断，在保持训练稳定的前提下多轮更新：

ppo.py
import torch
import torch.nn as nn
import torch.optim as optim

# PPO: Clip 目标函数, 一阶近似信赖域
STATE_DIM = 4
ACTION_DIM = 2


class MiniCart:
    # 简化 CartPole: 回合内步数越多奖励越高
    def __init__(self):
        self.t = 0

    def reset(self):
        self.t = 0
        return [0.0, 0.0, 0.0, 0.0]

    def step(self, a):
        self.t += 1
        s = [0.0, 0.0, float(self.t), 0.0]
        done = self.t >= 50
        r = 1.0
        return s, r, done


class ACNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Sequential(nn.Linear(STATE_DIM, 32), nn.ReLU(),
                                nn.Linear(32, 32), nn.ReLU())
        self.actor = nn.Linear(32, ACTION_DIM)
        self.critic = nn.Linear(32, 1)

    def forward(self, x):
        h = self.fc(x)
        return self.actor(h), self.critic(h)


def main():
    net = ACNet()
    opt = optim.Adam(net.parameters(), lr=1e-3)
    env = MiniCart()
    GAMMA = 0.99
    EPS_CLIP = 0.2
    for ep in range(300):
        # 采集一批轨迹
        states, actions, rewards, logps, dones = [], [], [], [], []
        s = env.reset()
        done = False
        while not done:
            s_t = torch.tensor(s, dtype=torch.float32)
            logits, val = net(s_t)
            dist = torch.distributions.Categorical(logits=logits)
            a = dist.sample()
            states.append(s)
            actions.append(a.item())
            logps.append(dist.log_prob(a).item())
            s, r, done = env.step(a.item())
            rewards.append(r)
            dones.append(done)
        # 计算回报与优势（简易 GAE）
        returns = []
        G = 0.0
        for r in reversed(rewards):
            G = r + GAMMA * G
            returns.insert(0, G)
        st_t = torch.tensor(states, dtype=torch.float32)
        ac_t = torch.tensor(actions, dtype=torch.long)
        rt_t = torch.tensor(returns, dtype=torch.float32)
        with torch.no_grad():
            _, vals = net(st_t)
        adv = rt_t - vals.squeeze(1)
        adv = (adv - adv.mean()) / (adv.std() + 1e-8)
        # 多次 mini-batch 更新
        for _ in range(4):
            logits, _ = net(st_t)
            dist = torch.distributions.Categorical(logits=logits)
            new_lp = dist.log_prob(ac_t)
            old_lp = torch.tensor(logps, dtype=torch.float32)
            ratio = torch.exp(new_lp - old_lp)
            surr1 = ratio * adv
            surr2 = torch.clamp(ratio, 1 - EPS_CLIP, 1 + EPS_CLIP) * adv
            pg_loss = -torch.min(surr1, surr2).mean()
            v_loss = nn.functional.mse_loss(dist.logits.new_zeros(dist.logits.size(0)), rt_t)
            loss = pg_loss + 0.5 * v_loss
            opt.zero_grad()
            loss.backward()
            opt.step()
        if ep % 50 == 0:
            print("episode", ep, "reward", sum(rewards))


if __name__ == "__main__":
    main()

11.6 DDPG（连续控制）

确定性 Actor + 经验回放 + 目标网络软更新，直接输出连续动作：

ddpg.py
import torch
import torch.nn as nn
import torch.optim as optim

# DDPG: 确定性策略梯度, 用于连续动作空间
STATE_DIM = 2
ACTION_DIM = 1
ACTION_BOUND = 1.0


class MiniPendulum:
    # 极简摆锤: 状态 2 维, 动作 1 维连续
    def reset(self):
        return [0.1, 0.0]

    def step(self, a):
        th = self.angle()
        r = -th * th - 0.1 * a * a
        self.theta += a * 0.1
        self.omega = a
        done = False
        return [self.theta, self.omega], r, done

    def angle(self):
        return self.theta % (2 * 3.14159) - 3.14159


class Actor(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Sequential(nn.Linear(STATE_DIM, 64), nn.ReLU(),
                                nn.Linear(64, 64), nn.ReLU(),
                                nn.Linear(64, ACTION_DIM), nn.Tanh())

    def forward(self, x):
        return self.fc(x) * ACTION_BOUND


class Critic(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Sequential(nn.Linear(STATE_DIM + ACTION_DIM, 64), nn.ReLU(),
                                nn.Linear(64, 64), nn.ReLU(),
                                nn.Linear(64, 1))

    def forward(self, x, a):
        return self.fc(torch.cat([x, a], dim=1))


def main():
    actor = Actor()
    critic = Critic()
    tactor = Actor()
    tcritic = Critic()
    tactor.load_state_dict(actor.state_dict())
    tcritic.load_state_dict(critic.state_dict())
    a_opt = optim.Adam(actor.parameters(), lr=1e-3)
    c_opt = optim.Adam(critic.parameters(), lr=1e-3)
    env = MiniPendulum()
    buf = []
    GAMMA = 0.99
    TAU = 0.005
    for ep in range(300):
        s = env.reset()
        done = False
        total = 0.0
        while not done:
            s_t = torch.tensor(s, dtype=torch.float32).unsqueeze(0)
            a = actor(s_t).detach().squeeze(0) + 0.1 * torch.randn(ACTION_DIM)
            a = torch.clamp(a, -ACTION_BOUND, ACTION_BOUND)
            s2, r, done = env.step(a.tolist())
            buf = buf + [(s, a.tolist(), r, s2, done)]
            if len(buf) > 10000:
                buf = buf[-10000:]
            if len(buf) >= 128:
                bs = 128
                idx = torch.randint(len(buf), (bs,))
                batch = [buf[i] for i in idx.tolist()]
                st = torch.tensor([b[0] for b in batch], dtype=torch.float32)
                ac = torch.tensor([b[1] for b in batch], dtype=torch.float32)
                rw = torch.tensor([b[2] for b in batch], dtype=torch.float32)
                sn = torch.tensor([b[3] for b in batch], dtype=torch.float32)
                dn = torch.tensor([b[4] for b in batch], dtype=torch.float32)
                with torch.no_grad():
                    a_next = tactor(sn)
                    target = rw + GAMMA * (1 - dn) * tcritic(sn, a_next).squeeze(1)
                qv = critic(st, ac).squeeze(1)
                c_loss = nn.functional.mse_loss(qv, target)
                c_opt.zero_grad()
                c_loss.backward()
                c_opt.step()
                a_loss = -critic(st, actor(st)).mean()
                a_opt.zero_grad()
                a_loss.backward()
                a_opt.step()
                # 软更新目标网络
                for p, tp in zip(actor.parameters(), tactor.parameters()):
                    tp.data.copy_(TAU * p.data + (1 - TAU) * tp.data)
                for p, tp in zip(critic.parameters(), tcritic.parameters()):
                    tp.data.copy_(TAU * p.data + (1 - TAU) * tp.data)
            s = s2
            total += r
        if ep % 50 == 0:
            print("episode", ep, "reward", round(total, 2))


if __name__ == "__main__":
    main()

十二 算法对比与工程选型

12.1 主流算法对比表

算法类型on/off-policy动作空间优点缺点
Q-Learning价值off-policy离散简单、理论完备、表格法只能处理小状态空间
DQN价值off-policy离散深度网络泛化、经验回放过估计、样本效率一般
Double DQN价值off-policy离散缓解过估计仍需目标网络调参
Dueling DQN价值off-policy离散优势与价值分离、更稳网络结构略复杂
REINFORCE策略on-policy离散/连续简单、可处理连续动作方差大、收敛慢
Actor-Critic策略+价值on-policy离散/连续低方差、通用单步偏差、双网络协调
A3C策略+价值on-policy离散/连续异步并行、去相关多进程实现复杂
PPO策略+价值on-policy离散/连续稳定、实现简单、工业标准样本效率中等
DDPG策略+价值off-policy连续样本效率较高超参数敏感、易过估计
TD3策略+价值off-policy连续稳定、鲁棒、缓解过估计实现复杂

12.2 工程选型建议

  • 动作空间离散且规模小：优先 Q-Learning / DQN 家族（如棋盘、卡片、Atari）。
  • 动作空间离散但状态巨大：DQN / Double DQN / Dueling DQN，搭配经验回放与目标网络。
  • 连续控制（机器人、自动驾驶）：优先 TD3 / SAC（样本效率与稳定性俱佳），DDPG 可作基线。
  • 追求通用、稳健、易部署：PPO 是最稳妥的默认选择，也是 RLHF 的事实标准。
  • 需要多智能体或大规模并行：A3C / PPO（分布式版）适合多 worker 扩展。
样本效率 vs 稳定性权衡

Off-policy 方法（DQN、DDPG、TD3、SAC）通常样本效率更高，但超参数敏感、训练不稳定；on-policy 方法（PPO、A3C）更稳健，但需要更多环境交互。工程上常采用"先 PPO 验证可行性，再 SAC 提效率"的路线。

12.3 超参数调优建议

超参数常见范围影响调优建议
学习率1e-5 ~ 1e-3过大会发散，过小收敛慢从 3e-4 起，按量级网格搜索
折扣因子0.9 ~ 0.999越大越"长远"长序任务取 0.99+，短回合取 0.9
探索 epsilon0.01 ~ 0.3探索与利用平衡初始高，随训练指数衰减
回放缓冲区1e4 ~ 1e6越大样本越多样根据显存与内存折中
批量大小32 ~ 512梯度稳定性PPO 常用 256，DQN 常用 64
目标网络更新软更新 TAU 0.005训练稳定性DQN 用硬拷贝每 C 步；AC 系用软更新

十三 演进时间线与总结

13.1 发展时间线

从行为主义心理学到 RLHF，强化学习走过了约 70 年。下图给出关键里程碑的总览：

1950s
操作性条件反射：行为主义心理学
Skinner 的强化理论为"试错学习"奠定思想基础。
1957
Bellman 动态规划 / MDP 框架
贝尔曼方程奠定了序贯决策的理论基础。
1989
Q-Learning 提出（Watkins）
off-policy 时序差分控制的经典算法。
1992
TD-Gammon 击败人类
Tesauro 用 TD 方法训练西洋双陆棋程序。
2013
DQN 发布（Mnih 等）
深度网络 + 经验回放，Atari 上超越人类。
2015
Nature DQN：深度强化学习起点
目标网络与 49 个 Atari 游戏的里程碑成果。
2016
AlphaGo 击败李世石
策略网络 + 价值网络 + MCTS，RL 最出圈时刻。
2017
PPO 与 A3C 提出
PPO 成为稳定通用基线；A3C 推动异步训练。
2018
TD3 / SAC / DDPG 成熟
连续控制算法体系走向成熟。
2022
RLHF 引爆大模型对齐
ChatGPT 用 PPO + 人类反馈训练奖励模型。

13.2 发展脉络总结

强化学习的两条主线——价值方法与策略方法——从 1989 年 Q-Learning 开始并不断融合：

维度价值方法策略方法
代表Q-Learning → DQN → Double/DuelingREINFORCE → Actor-Critic → PPO
学什么先学 Q/V 函数，再导出策略直接学策略参数
优点样本效率高、理论成熟可处理连续动作、随机策略
缺点难以处理连续动作、过估计方差大、样本效率低
融合产物Actor-Critic、DDPG、TD3、SAC、PPO（策略+价值混合）
未来趋势

多智能体强化学习（MARL）、离线强化学习（Offline RL）、基于模型的 RL（MBRL）、RLHF 与多模态对齐，是当前最重要的演进方向。无论哪个方向，贝尔曼方程、策略梯度定理与探索-利用权衡这三块基石都不会过时。
