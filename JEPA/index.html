1动机：为什么"预测像素"是错的

1.1 重建路线的信息论代价

第 2 个模块讲过，MAE 与 SimMIM 能让编码器学到很强的表征。但它们的训练目标里含有一个隐含的浪费：模型必须重建被遮像素的每一个细节，包括光照、纹理、噪声。这些细节对理解画面毫无帮助，却占掉了损失函数里很大一部分。

LeCun 在 2022 年的立场论文里把这个观点推到了极致：他认为生成式建模（预测每一个像素）是一条方向错误的路——现实世界的信息量太大，而且大部分是不可预测的随机细节，模型不应该把容量花在还原它们上。

一个演示这个问题的经典例子

假设一段视频里有一片树叶在随风抖动。要"预测下一帧的像素"，模型必须精确还原每一片叶子的位置——但这些位置本质上是混沌、不可预测的。如果强迫模型去预测，它只会在大量样本上学会输出一个模糊的平均值。而如果只预测表征（"这里是一片树冠"），不可预测的细节就被自然地过滤掉了。

1.2 核心主张：在表征空间做预测

JEPA（Joint-Embedding Predictive Architecture，联合嵌入预测架构）的全部主张可以浓缩成一句话：

不要预测"会变成什么像素"，而是预测"会变成什么概念"

把输入和输出都先映射到同一个表征空间，然后在这个空间里做预测。这样一来：低层的、不可预测的细节在编码阶段就被丢弃；需要预测的部分只剩下语义级的状态变化——而这恰恰是可预测、也值得预测的。

1.3 三条路线的定位

把自监督学习的三条主流路线放在一起，它们的差异集中在同一个问题上：预测发生在哪个空间？

对比学习只需要"判像不像"，重建要求"画出一模一样"，JEPA 则要求"说对是什么"。越靠下，损失越聚焦在语义层，模型越不必为无关细节浪费容量。

1.4 与模块 2 的衔接

回到模块 2 的公式 (1)——掩码建模的统一骨架。JEPA 复用了这个骨架的全部前半段（分块、掩码、只编码可见部分），只把最后一步换掉：

MAE / SimMIMJEPA
掩码与可见块相同相同
编码器只看可见块相同（MAE）相同
被遮位置的目标原始像素由另一个编码器（EMA）算出的表征
解码器必需（浅层或线性）不需要——预测器在表征空间工作
损失空间像素空间表征空间

这个改动看起来很小，却带来一个全新的问题：如果目标和预测都在同一个表征空间里，模型可以把所有输入都映射成同一个向量来"作弊"。这就是第 2 章要讲的坍缩问题，也是 JEPA 系列十余篇论文真正在解决的核心矛盾。

2JEPA 的基本架构与它的软肋

2.1 三件套与一个隐变量

JEPA 的形式化定义包含三个组件，外加一个常被忽略的隐变量：

组件作用
上下文编码器 $E_\theta$把可见部分 $x$ 编码成表征 $s_x = E_\theta(x)$
目标编码器 $E_{\bar\theta}$把完整输入 $y$ 编码成目标表征 $s_y = E_{\bar\theta}(y)$，参数由 $\theta$ 做指数滑动平均（EMA）得到
预测器 $P_\phi$给定 $s_x$ 与目标的位置信息 $z$，预测 $\hat{s}_y = P_\phi(s_x, z)$
隐变量 $z$表示"当前观测不到、但会影响未来走向"的潜在因素
$$\mathcal{L}_{\text{JEPA}} = \Big\| P_\phi\big(E_\theta(x),\, z\big) \;-\; \operatorname{sg}\big(E_{\bar\theta}(y)\big) \Big\|$$

其中 $\operatorname{sg}(\cdot)$ 表示 stop-gradient——目标分支不接收梯度。

2.2 隐变量 $z$ 为什么必需

这一点经常被跳过，但它是 JEPA 与 BYOL 这类"预测自己"的方法的本质区别。设想用 JEPA 预测视频的下一帧：即使看完了前面所有帧，未来仍然有多种可能（球可能被接住，也可能落地）。如果只有一个确定性预测器，模型只能输出这些可能性的平均值——而平均出来的东西既不是接住也不是落地，是毫无意义的。

隐变量 $z$ 的作用就是把这部分固有的不可预测性显式地表示出来：给定不同的 $z$，预测器可以给出不同的合理未来。训练时 $z$ 通常从一个先验分布采样（或由目标编码器提供），模型因此学会"在不确定性下输出多个合理的预测"，而不是一个模糊的平均。

这也是 JEPA 与 MAE 在世界观上的差别

MAE 隐含假设"缺失部分可以被唯一确定"，所以用回归损失逼模型给出一个答案；JEPA 承认"缺失部分可能本就不可唯一确定"，所以用隐变量承载这部分不确定性。前者在图像上还勉强成立（纹理可猜），到了视频与规划场景就完全站不住。

2.3 软肋：表征坍缩

把公式 (1) 的损失展开看，它只做了一件事：让预测的输出接近目标输出的表征。这里存在一个平凡的解法：

如果所有输入都映射成同一个常量向量，损失就是 0

令 $E_\theta(x) = E_{\bar\theta}(y) = c$（常量），则预测器只需输出 $c$，损失恒为 0。此时模型什么都没学到，但优化目标"完美达成"。这就是表征坍缩（representation collapse）。更隐蔽的形式是维度坍缩——所有嵌入落在一个低维子空间上（比如一条直线），虽然不完全是常量，但可用信息量极少。

BYOL、SimSiam、DINO、以及 JEPA 家族都在解决同一个问题。历史上出现过三类解法：

解法做法代表代价
非对称结构预测器分支加 stop-gradient，配合 EMA 目标BYOL / SimSiam / I-JEPA / V-JEPA为什么有效缺少严格解释，超参敏感
隐式对比用居中、锐化等方式间接制造排斥力DINO / DINOv2需要调温度、中心动量等多个超参
显式分布约束直接要求嵌入服从某个分布LeJEPA（SIGReg）需要设计可微且可扩展的分布检验

第 5 章的 LeJEPA 正是沿第三条路走到底的结果。它把"如何防止坍缩"从一个工程技巧问题，变成了一个统计学问题。

2.4 为什么目标编码器要用 EMA 而不是直接复制

一个自然的问题是：为什么目标编码器不直接用 $E_\theta$ 本身，或者每隔几步同步一次参数？

  • 直接共用参数：目标和预测都来自同一个编码器，梯度会同时把两者推向同一个"塌缩点"，坍缩会迅速发生。
  • 周期性硬同步：目标表征在同步点前后会发生突变，训练过程出现周期性震荡。
  • EMA（指数滑动平均）：目标编码器成为 $\theta$ 的历史轨迹的平滑版本，既提供了"稍微落后但更稳定"的目标，又不会突变。这也是 JEPA 系列从 I-JEPA 起就固定使用的做法。

3I-JEPA：把 JEPA 落到图像上

3.1 三件套的具体形态

I-JEPA（Assran et al., 2023）是 JEPA 从"概念蓝图"变成"可运行系统"的第一个节点。它沿用 ViT 骨干，把第 2 章的三件套具体化为：

注意红色虚线：它是整张图的关键。目标表征前向传播，但梯度不回传——这让目标成为"固定靶"，而不是和预测器一起"互相追着跑"。

3.2 目标：$L_2$ 回归到目标表征

$$\mathcal{L}_{\text{I-JEPA}} = \frac{1}{|\mathcal{B}|}\sum_{b \in \mathcal{B}} \Big\| P_\phi\big(E_\theta(x_{\text{ctx}}),\, \text{pos}(b)\big) - \operatorname{sg}\big(E_{\bar\theta}(y)\big)\big|_{b} \Big\|_2^{2}$$

其中 $\mathcal{B}$ 是目标块集合，$\text{pos}(b)$ 是目标块的位置编码。注意损失是对每个目标块分别算的，而不是全局平均——这样不同位置的目标块获得同等权重的监督。

$$\bar\theta \leftarrow m\,\bar\theta + (1 - m)\,\theta, \qquad m \approx 0.996$$

EMA 的动量 $m$ 通常取 0.996 附近，意味着目标编码器大约每 250 步"走完"跟随 $\theta$ 的 63%。

3.3 掩码策略：4 个大块 + 1 个上下文块

I-JEPA 的掩码设计与 MAE 有本质区别：它不是逐 patch 随机遮挡，而是采样若干个"块"。

与 MAE 的"逐 patch 均匀随机"不同，I-JEPA 用少量大尺度块同时充当目标与上下文。这个改动把"补纹理"变成了"推语义"，也让它不需要任何数据增强。

为什么必须是"大块"

如果按 MAE 的方式逐 patch 随机遮挡，模型可以通过局部插值完成预测——它甚至不需要理解画面内容。I-JEPA 用大尺度目标块把这个捷径堵死：一个占 15%–20% 面积的块，其内部远离任何可见像素，模型只能依赖对全局语义的理解。这与模块 2 中 SimMIM 的 AvgDist 洞察是同一个道理，只是 I-JEPA 换了个维度来实现它。

3.4 一个结构性优势：不需要数据增强

这是 I-JEPA 相对对比学习最重要的差异点。对比学习（SimCLR、MoCo）高度依赖"什么算同一张图的两个视图"——裁剪、颜色抖动、翻转。这些增强策略本身携带了很强的归纳偏置，而且换到医学影像、遥感等领域往往需要重新设计。

I-JEPA 不使用任何数据增强（只做最基本的 resize 与归一化），因为它的监督信号不来自"两个视图之间的一致性"，而来自"从上下文块预测目标块"。这消除了对增强策略的依赖，也让迁移到新领域时少了一个需要重调的环节。

4V-JEPA 与 V-JEPA 2：走向视频与世界模型

4.1 为什么视频更适合表征预测

把 JEPA 搬到视频上不是"顺手的扩展"，而是这条路线的天然领域。原因在于：视频里的不可预测部分远多于图像。

图像视频
缺失部分的可确定性纹理有一定规律，多数场合可合理猜测运动与未来发展本质上是多可能的
像素级重建的代价可接受时空维度叠加，计算量急剧上升
模式层面的可预测性静态语义物体如何运动、状态如何演化——这些是真正值得学的

用 LeCun 的说法：视频里真正有价值的监督信号是"世界如何变化"，而不是"下一个像素是什么颜色"。这正好是表征预测擅长的。

4.2 V-JEPA：$L_1$ 损失与三维掩码

V-JEPA（Bardes et al., 2024）在 I-JEPA 基础上做了三处关键改动：

  1. 时空 token。视频被切成 $2 \times 16 \times 16$ 的 tubelet（2 帧 × 16×16 像素），直接形成三维 token 序列。
  2. 损失从 $L_2$ 改为 $L_1$。论文指出在视频任务中 $L_1$ 回归更稳定。
  3. 掩码率提高到 90%，并采用管状掩码，机制与 VideoMAE 相同——这是视频掩码的通用要求。
$$\mathcal{L}_{\text{V-JEPA}} = \frac{1}{|\mathcal{M}|}\sum_{i \in \mathcal{M}} \big\| \hat{s}_i - \operatorname{sg}(s_i) \big\|_1$$

V-JEPA 的掩码采样混合了两种尺度：短程掩码（8 个小块，各占约 15% 面积）与长程掩码（2 个大块，各占约 70% 面积）。混合的目的是让模型同时面对"局部细节要补"与"大范围结构要推"两类任务——单一尺度会让模型只擅长其中一种。

预训练数据Kinetics-400 等VideoMix2M（约 200 万段视频）

损失MSE（像素）$L_1$（表征空间）

在冻结骨干的评估协议下，V-JEPA 在 Something-Something v2（71.2%）这类高度依赖动作理解的任务上明显超过此前的视频掩码模型，也拉开了与 DINOv2 这类图像基础模型的距离——后者缺乏时序建模能力。

4.4 V-JEPA 2-AC：动作条件的潜在世界模型

V-JEPA 2 最重要的贡献不是刷榜，而是把同一个表征空间从"理解"扩展到了"行动"。做法是：冻结预训练好的 V-JEPA 2 编码器，只训练一个新的、动作条件的预测器。

$$\hat{z}_{t+1} = P_\psi\big(z_t,\ a_t,\ q_t\big), \qquad \mathcal{L}_{\text{AC}} = \big\| \hat{z}_{t+1} - \operatorname{sg}\big(E(z_{t+1})\big) \big\|_1$$

其中 $z_t$ 是当前帧表征，$a_t$ 是机器人动作，$q_t$ 是末端执行器的位姿状态。注意它预测的仍然是表征，不是 RGB 像素。

训练上用了两种损失配合：teacher forcing（每步都喂入真实的上一帧表征）稳定但存在分布偏移；rollout loss（把模型自己的预测再喂回去）用于训练多步预测，减少误差累积。预测器使用 time-causal 注意力——每个时间步只能看到当前与过去。

规划时不需要生成任何视频，而是在表征空间里比较距离：

$$a_{1:T}^{*} = \arg\min_{a_{1:T}} \big\| \hat{z}_T\big(a_{1:T}\big) - E(x_{\text{goal}}) \big\|_1$$

用交叉熵方法（CEM）搜索动作序列：采样多条动作轨迹、保留表现最好的若干条、更新高斯分布、重复若干轮，最后只执行第一个动作再重新规划（滚动时域控制）。

这条结果的意义

V-JEPA 2-AC 只用了约 62 小时无标注机器人视频（Droid 数据集），就能在未见过的环境中完成抓取与放置，零样本成功率约 65%–80%。没有奖励工程、没有动作标注、没有仿真到真实的迁移。它证明了：一个纯靠"看视频"学到的表征空间，本身就包含了可用来规划的动作后果信息。

4.5 一个中间结论

从 I-JEPA 到 V-JEPA 2，路线是清晰的：先把"在表征空间预测"这件事在图像上验证（I-JEPA），再扩展到时空（V-JEPA），最后接上动作变量变成世界模型（V-JEPA 2）。但这条路上始终悬着一个问题——所有防坍缩的手段都是启发式的：EMA、stop-gradient、预测器要浅、掩码块要大。为什么是这些？能不能换成别的方法？

第 5 章的 LeJEPA 正面回答了这个问题。

5LeJEPA：把启发式全部删掉

5.1 问题的重新表述

LeJEPA（Balestriero & LeCun, 2025）换了个提问方式。之前的工作都在问"怎么防止坍缩"，答案是一堆技巧。LeJEPA 问的是：

如果坍缩的反面不是"不坍缩"，而是"服从某个特定分布"呢？

坍缩的本质是"嵌入分布的形态退化"——所有点挤在一个点上，或挤在一条线上。既然如此，与其用一堆技巧去间接阻止它，不如直接指定嵌入应该服从的目标分布，然后把这个分布匹配写进损失函数。

接下来的问题是：哪个分布才是"好的"？ LeJEPA 给出了一个可证明的答案——各向同性高斯分布（isotropic Gaussian）。

5.2 为什么是各向同性高斯

论文从下游预测风险出发推导：在冻结编码器上用线性探针或核方法评估时，若要让任意下游任务的预测风险最小，嵌入应当服从均值任意、协方差为单位矩阵的高斯分布。

$$p(z) = \frac{1}{(2\pi)^{d/2}} \exp\!\left(-\frac{1}{2}\|z - \mu\|_2^{2}\right), \qquad \Sigma = I_d$$

直观理解这个结论：

  • 协方差为单位矩阵意味着每个维度有相同的方差、且维度之间不相关 → 没有冗余维度，也没有被压扁的维度。这正好排除了"维度坍缩"。
  • 高斯分布的各向同性意味着嵌入在球面上均匀铺开，任意方向的信息量对等 → 下游客任务无论从哪个方向读取，都不会因为该方向被压缩而吃亏。
  • 这也是信息论意义上"给定方差约束下熵最大"的分布——在容量约束内保留最多的信息。
为什么各向异性会出问题

如果嵌入分布是各向异性的（比如在一个方向上摊得很开、另一个方向压得很扁），那么下游线性探针在"压扁"的方向上做判断时，方差估计的波动会大得多。论文用二分类任务做了模拟：各向异性嵌入下的决策边界在不同采样上的抖动明显更大——泛化更差。

5.3 SIGReg：把分布匹配写成一个损失

知道了目标分布，还要有一个能用的正则项。直接去估计高维分布的密度是不可能的（维度灾难），所以论文把分布匹配重新表述为一个统计假设检验：

零假设 $H_0$：嵌入的分布 $P_\theta$ 等于目标分布 $Q$（各向同性高斯）

于是问题变成"构造一个检验统计量，它在 $P_\theta = Q$ 时取值小、偏离时取值大"。SIGReg（Sketched Isotropic Gaussian Regularization）选取的是 Epps–Pulley 检验——它比较两个分布的特征函数，通过随机投影（sketching）把高维问题降成一维问题逐个处理，从而避开维度灾难。

$$\text{SIGReg}(Z) = \frac{1}{M}\sum_{m=1}^{M} T\Big(\big\langle Z,\, u_m \big\rangle,\; \mathcal{N}(0,1)\Big), \qquad u_m \sim \mathcal{S}^{d-1}$$

其中 $u_m$ 是从单位球面随机采样的投影方向，$T(\cdot, \mathcal{N}(0,1))$ 是"把一维投影样本与标准正态做 Epps–Pulley 检验"得到的统计量。若嵌入在每一个随机方向上的投影都接近标准正态，那么原分布就接近各向同性高斯——这就是把高维分布匹配分解为一维检验的巧妙之处。

这个设计带来几个论文强调的性质：

性质意义
可微梯度与曲率有界，能直接反传
线性时间与内存与批量大小线性相关，不是平方
可扩展天然支持多 GPU 分布式，随机投影方向可以各卡独立采样
避开维度灾难把 $d$ 维问题拆成 $M$ 个一维检验，$M$ 与 $d$ 无关

5.4 最终的损失：只有一个超参数

$$\mathcal{L}_{\text{LeJEPA}} = \underbrace{\big\| P_\phi\big(E_\theta(x),\, z\big) - \operatorname{sg}(E_{\bar\theta}(y)) \big\|^{2}}_{\text{JEPA 预测损失}} \;+\; \lambda \cdot \underbrace{\text{SIGReg}\big(Z\big)}_{\text{分布匹配}}$$

整个方法只有 $\lambda$ 一个需要调的超参数。而被删掉的启发式包括：

被删掉的机制为什么不再需要
stop-gradient坍缩由分布约束直接阻止，不需要靠阻断梯度来间接防
teacher–student / EMA 目标编码器目标不再需要一个"滞后的版本"来提供稳定性
超参数调度器（学习率、动量预热等）论文报告在不同超参与架构间表现稳定
非对称结构设计架构可以自由选择，ResNet / ViT / ConvNet 都能直接套

左边是坍缩的样子，右边是理想形态。LeJEPA 的贡献在于给出了"理想形态"的可证明答案（各向同性高斯），并把它变成一个可微、可扩展、只有一个超参数的损失项。

需要看清的一点

论文报告的实现约 50 行代码、跨 60 多种架构稳定，这些是可验证的工程结论。但"各向同性高斯是最优分布"这个核心命题的推导依赖于一组关于嵌入空间与损失形式的假设——这是该方法最需要被后续工作检验的地方。把它当作"已被完全证明"来引用是不准确的。

6.4 三个仍未解决的问题

① 目标分布的选择是否唯一

LeJEPA 论证了各向同性高斯在给定假设下最优。但这些假设（嵌入空间的形式、评估方式、损失类型）在更一般的情形下是否成立，仍待检验。若假设松动，最优分布可能不同。

② 隐变量的训练信号从哪里来

隐变量 $z$ 理论上承载"不可预测的因素"，但在实际实现中，$z$ 往往只是从先验里采样或干脆省略（例如 I-JEPA 的图像版本）。如何让 $z$ 真正学到有意义的结构，仍是一个开放问题。

③ 与语言的对齐

JEPA 目前是纯视觉（或多模态感知）的路线，与语言模型几乎没有交集。而当前主流的多模态系统几乎都是"视觉编码器 + 语言模型"的组合。JEPA 的表征空间如何与语言空间对接——既是一个工程问题，也可能暴露"纯预测式表征"在语义标注上的短板。

7工程实现与知识体系总结

7.1 JEPA 的核心前向与损失

jepa_core.py — 三件套、EMA 与表征空间损失
import copy
import torch
import torch.nn as nn


class JEPA(nn.Module):
    """最小可运行的 JEPA：上下文编码器 + EMA 目标编码器 + 预测器"""
    def __init__(self, encoder, predictor, ema_momentum=0.996):
        super().__init__()
        self.context_encoder = encoder
        self.target_encoder = copy.deepcopy(encoder)   # 目标编码器的初始参数与上下文一致
        self.predictor = predictor
        self.m = ema_momentum

        for p in self.target_encoder.parameters():
            p.requires_grad = False                       # 关键：目标分支不接收梯度

    def forward(self, x_context, x_full, target_pos):
        s_x = self.context_encoder(x_context)         # 只编码可见块
        with torch.no_grad():                          # 目标表征：前向但不建图
            s_y = self.target_encoder(x_full)
        s_hat = self.predictor(s_x, target_pos)         # 在表征空间做预测
        return (s_hat - s_y).pow(2).mean()                # 回归到目标表征，不是像素

    @torch.no_grad()
    def update_target(self):
        """EMA：目标编码器缓慢跟随上下文编码器"""
        for p_c, p_t in zip(self.context_encoder.parameters(),
                              self.target_encoder.parameters()):
            p_t.mul_(self.m).add_(p_c, alpha=1 - self.m)
三处细节决定成败

① requires_grad = False 必须设，且前向要包在 torch.no_grad() 里，否则显存会被白白占用；② EMA 更新必须用 @torch.no_grad() 装饰，否则会污染计算图；③ 损失是表征之间的均方误差，不是像素误差——这是整个 JEPA 与 MAE 的分界线。

7.2 I-JEPA 的多块掩码采样

block_masking.py — 采样大块目标块与一个上下文块
import numpy as np


def sample_block(H, W, scale, aspect_ratio):
    """采样一个面积占比在 scale 区间、长宽比在 aspect_ratio 区间的块"""
    area = H * W * np.random.uniform(*scale)
    log_r = np.random.uniform(*np.log(aspect_ratio))
    h = int(round(np.sqrt(area / np.exp(log_r))))
    w = int(round(np.sqrt(area * np.exp(log_r))))
    top  = np.random.randint(0, H - h)
    left = np.random.randint(0, W - w)
    return top, left, h, w


def ijepa_masks(H, W, n_target=4):
    """4 个目标块（各 15%-20% 面积，随机长宽比）+ 1 个上下文块（85%-100%，比例方正）"""
    targets = [sample_block(H, W, (0.15, 0.20), (0.75, 1.5))
               for _ in range(n_target)]
    ctx = sample_block(H, W, (0.85, 1.00), (1.0, 1.0))

    # 关键：从上下文块中剔除与任何目标块重叠的部分（"挖洞"）
    mask_ctx = np.zeros((H, W), dtype=bool)
    t, l, h, w = ctx
    mask_ctx[t:t + h, l:l + w] = True
    for t, l, h, w in targets:
        mask_ctx[t:t + h, l:l + w] = False          # 挖掉重叠区域
    return mask_ctx, targets

最后那三行是 I-JEPA 与"简单掩码"的分界：上下文块不是一个完整矩形，而是被目标块"挖了洞"的形状。若不剔除重叠，预测任务会因为上下文里已含答案而失效。

7.3 SIGReg 的随机投影检验

sigreg.py — 把高维分布匹配拆成一维投影上的正态检验
import torch


def sigreg(embeddings, n_projections=256, n_points=17):
    """SIGReg 的骨架：随机方向投影 + 与标准正态做特征函数距离比较

    embeddings: (N, d) 的嵌入；返回一个标量正则项
    """
    N, d = embeddings.shape

    # 1) 在单位球面上采样 M 个随机投影方向
    u = torch.randn(d, n_projections, device=embeddings.device)
    u = u / u.norm(dim=0, keepdim=True)

    # 2) 投影到一维：(N, M)
    proj = embeddings @ u

    # 3) 与标准正态做 Epps-Pulley 特征函数距离（这里给出结构骨架）
    t = torch.linspace(0.2, 2.0, n_points, device=embeddings.device)
    emp_cos = torch.cos(proj.unsqueeze(1) * t).mean(dim=0)   # 经验特征函数
    emp_sin = torch.sin(proj.unsqueeze(1) * t).mean(dim=0)
    ref_cos = torch.exp(-0.5 * t ** 2)                       # 标准正态的特征函数
    ref_sin = torch.zeros_like(t)                            # 标准正态为偶函数，sin 项为 0

    diff = (emp_cos - ref_cos) ** 2 + (emp_sin - ref_sin) ** 2
    return diff.mean()                                        # 越小 = 越接近各向同性高斯

核心思想就一句话：如果嵌入在每一个随机方向上的投影都是标准正态，那它就是各向同性高斯。于是 $d$ 维分布匹配被拆成 $M$ 个一维检验，既避开了维度灾难，也天然可并行。
