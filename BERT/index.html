1BERT 的诞生与动机

1.1 预训练时代的背景

2018 年之前，NLP 领域的主流范式是特征工程 + 浅层模型。词向量（Word2Vec、GloVe）将词映射为静态向量，但无法处理一词多义和上下文依赖。ELMo 通过双向 LSTM 提取上下文特征，缓解了这一问题，但 LSTM 的顺序计算限制了并行效率和模型规模。

与此同时，Transformer 架构（2017）凭借自注意力机制实现了完全并行的序列建模。OpenAI 的 GPT（2018）验证了"预训练 + 微调"范式在 NLP 中的潜力，但 GPT 使用单向语言模型（仅从左到右预测），无法利用右侧上下文信息。

模型年份架构预训练任务方向性
Word2Vec2013浅层 CBOW/Skip-gram无（静态词向量）无上下文
ELMo2018双向 LSTM双向语言模型双向（但拼接）
GPT2018Transformer Decoder单向语言模型单向（左→右）
BERT2018Transformer EncoderMLM + NSP双向（真正）
核心动机

BERT 的核心动机是：语言理解需要双向上下文。"The man went to the ___ to buy milk" 中，填空不仅需要左侧的 "went to"，还需要右侧的 "to buy milk" 来推断答案是 "store" 而非 "bank"。GPT 的单向语言模型无法做到这一点——BERT 通过掩码语言模型（MLM）任务实现了真正的双向编码。

1.2 BERT 的诞生

2018 年 10 月，Google AI 团队在论文 "BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding" 中提出了 BERT。BERT 在 11 项 NLP 基准测试中刷新了 SOTA：

  • GLUE 基准：$80.5$ 分（此前 SOTA 为 $72.8$），提升 $7.7$ 分
  • SQuAD v1.1 问答：$F1 = 93.2$（超越人类 $91.2$）
  • SWAG 推理：$86.5$%（此前 SOTA 为 $76.0$%）

2整体架构：双向 Transformer 编码器

2.1 架构概述

BERT 的核心架构是一个多层双向 Transformer 编码器。与原始 Transformer（编码器+解码器）不同，BERT 只使用编码器部分，因为它的目标是理解语言而非生成语言。编码器的双向自注意力允许每个 Token 同时关注序列中的所有其他 Token，实现真正的双向上下文建模。

配置BERT-BaseBERT-Large
编码器层数 $L$$12$$24$
隐藏维度 $H$$768$$1024$
注意力头数 $A$$12$$16$
FFN 中间维度$3072$$4096$
参数量$110$M$340$M
最大序列长度$512$$512$
词表大小$30{,}522$$30{,}522$

2.2 Transformer 编码器层

每一层 Transformer 编码器由两个子层组成：多头自注意力（Multi-Head Self-Attention）和前馈网络（Feed-Forward Network）。每个子层后接残差连接和 LayerNorm：

$$\text{output} = \text{LayerNorm}(x + \text{Sublayer}(x))$$

其中 $x$ 为子层输入，$\text{Sublayer}$ 为自注意力或 FFN。残差连接缓解了深层网络的梯度消失问题，LayerNorm 稳定了训练过程。

2.3 为什么只用编码器

BERT 选择只用编码器而非完整的 Transformer（编码器+解码器）或只用解码器（如 GPT），是由其任务目标决定的：

架构选择代表模型方向性适合任务
编码器（Encoder）BERT双向理解类（分类、问答、NER）
解码器（Decoder）GPT单向（左→右）生成类（文本生成）
编码器+解码器T5、BART编码器双向，解码器单向序列到序列（翻译、摘要）
双向编码的力量

BERT 的编码器中，每个 Token 的表示同时融合了左侧和右侧上下文信息。这种真正的双向性使得 BERT 在理解类任务上大幅超越单向的 GPT。代价是 BERT 不适合自回归生成——它需要完整的输入序列才能工作。

3输入表示：Token、Segment、Position

3.1 三种嵌入的相加

BERT 的输入表示是三种嵌入的逐元素相加：Token Embedding、Segment Embedding 和 Position Embedding。这三种嵌入的维度相同（$H$），相加后形成每个 Token 的最终输入向量。

$$E_{\text{input}} = E_{\text{token}} + E_{\text{segment}} + E_{\text{position}}$$

3.2 WordPiece 分词

BERT 使用 WordPiece 子词分词器，词表大小为 $30{,}522$。WordPiece 将罕见词拆分为子词单元，例如 "playing" → "play" + "##ing"，"unaffordable" → "un" + "##aff" + "##ord" + "##able"。这一策略解决了未登录词（OOV）问题，同时控制了词表规模。

3.3 特殊 Token

Token含义用途
[CLS]分类标记置于序列首位，其最终隐藏状态用于分类任务
[SEP]分隔标记分隔两个句子，或标记序列结束
[MASK]掩码标记预训练 MLM 任务中替换被遮蔽的 Token
[PAD]填充标记将短序列填充到统一长度
[UNK]未知标记WordPiece 无法拆分的字符

3.4 位置编码：学习式 vs 正弦式

与原始 Transformer 使用固定的正弦/余弦位置编码不同，BERT 使用可学习的位置编码——位置嵌入是一个 $512 \times H$ 的可训练参数矩阵。学习式位置编码更灵活，但限制了最大序列长度（BERT 为 $512$）。

4核心机制：自注意力与多头注意力

4.1 缩放点积注意力

自注意力是 Transformer 的核心。给定输入序列的 Query $Q$、Key $K$、Value $V$，注意力计算为：

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中 $d_k$ 为 Key 的维度，$\sqrt{d_k}$ 是缩放因子，防止点积过大导致 softmax 梯度消失。$QK^T$ 计算每对 Token 之间的相似度，softmax 归一化后作为权重对 $V$ 加权求和。

4.2 多头注意力

多头注意力将 $Q$、$K$、$V$ 分别投影到 $h$ 个不同的子空间，各自计算注意力后拼接：

$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)W^O$$
$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

其中 $W_i^Q \in \mathbb{R}^{d_{\text{model}} \times d_k}$，$W_i^K \in \mathbb{R}^{d_{\text{model}} \times d_k}$，$W_i^V \in \mathbb{R}^{d_{\text{model}} \times d_v}$，$W^O \in \mathbb{R}^{hd_v \times d_{\text{model}}}$。BERT-Base 使用 $h = 12$ 个头，每个头的维度 $d_k = d_v = 768/12 = 64$。

4.3 前馈网络

每个编码器层的第二个子层是前馈网络（FFN），由两个线性变换和 GELU 激活函数组成：

$$\text{FFN}(x) = \text{GELU}(xW_1 + b_1)W_2 + b_2$$

FFN 的中间维度通常是隐藏维度的 $4$ 倍（BERT-Base: $768 \times 4 = 3072$）。GELU 激活函数是 ReLU 的平滑近似，在 NLP 任务中表现更好。

$$\text{GELU}(x) = x \cdot \Phi(x) = x \cdot \frac{1}{2}\!\left[1 + \text{erf}\!\left(\frac{x}{\sqrt{2}}\right)\right]$$

4.4 注意力的直觉理解

多头注意力让 BERT 同时关注不同维度的语言特征。研究发现，不同注意力头确实学到了不同的模式：

注意力头类型关注模式示例
语法头关注句法依赖动词 → 主语/宾语
共指头关注代词指代"he" → 上文的 "John"
语义头关注语义相关词"bank" → "money" / "river"
位置头关注相邻 Token关注前一个/后一个词
分隔头关注句子边界关注 [SEP] Token

5预训练任务一：掩码语言模型（MLM）

5.1 MLM 任务定义

掩码语言模型（Masked Language Model, MLM）是 BERT 的核心预训练任务。给定输入序列，随机选择 $15$% 的 Token 进行处理：

  • $80$% 替换为 [MASK]
  • $10$% 替换为词表中的随机 Token
  • $10$% 保持原 Token 不变

模型需要预测被选中的 $15$% Token 的原始内容。这一设计迫使模型利用双向上下文来推断被遮蔽的 Token。

$$\mathcal{L}_{\text{MLM}} = -\frac{1}{|\mathcal{M}|}\sum_{i \in \mathcal{M}} \log P(x_i \mid x_{\setminus \mathcal{M}}; \theta)$$

其中 $\mathcal{M}$ 为被掩码 Token 的索引集合，$x_{\setminus \mathcal{M}}$ 为未被掩码的 Token。模型对每个掩码位置输出词表上的 softmax 概率分布，损失为交叉熵。

5.2 为什么不是 100% [MASK]

如果所有被选中的 Token 都替换为 [MASK]，会产生两个问题：

策略比例目的
替换为 [MASK]$80$%主要任务：模型学会从上下文推断缺失内容
替换为随机 Token$10$%迫使模型判断 Token 是否被篡改，增强鲁棒性
保持不变$10$%让模型也学习未修改 Token 的表示，保持信息流
微调时的分布偏移

预训练时 [MASK] 占输入的 $15\% \times 80\% = 12\%$，但微调时输入中没有 [MASK]。这是 BERT 的一个已知问题——预训练与微调存在分布偏移。后续的 RoBERTa 和 SpanBERT 对此进行了改进。

5.3 MLM 的双向优势

与 GPT 的单向语言模型相比，MLM 的关键优势在于双向性。在 GPT 中，Token $x_t$ 只能依赖 $x_{t}$。这使得 BERT 的表示更加丰富，特别是在需要全局上下文的任务上。

5.4 15% 掩码比例的选择

BERT 选择 $15$% 的掩码比例，而非更高的比例。这是因为 NLP 的信息密度远高于图像——每个词都承载独特语义，掩码太多会导致任务不可完成，掩码太少则学习信号不足。实验表明 $15$% 是 NLP 掩码预训练的甜蜜点。

6预训练任务二：下一句预测（NSP）

6.1 NSP 任务定义

下一句预测（Next Sentence Prediction, NSP）是 BERT 的第二个预训练任务，旨在学习句间关系。给定句子对 $(A, B)$，模型需要判断 $B$ 是否是 $A$ 的下一句：

  • 正样本（$50$%）：$B$ 确实是 $A$ 的下一句
  • 负样本（$50$%）：$B$ 从语料库中随机采样

模型使用 [CLS] Token 的最终隐藏状态进行二分类：

$$\mathcal{L}_{\text{NSP}} = -\log P(\text{IsNext} \mid \text{[CLS]}; \theta)$$

6.2 联合预训练损失

BERT 的总预训练损失是 MLM 和 NSP 的平均：

$$\mathcal{L}_{\text{BERT}} = \mathcal{L}_{\text{MLM}} + \mathcal{L}_{\text{NSP}}$$

两个任务共享 Transformer 编码器参数，但使用不同的输出头。MLM 使用所有掩码位置的输出，NSP 只使用 [CLS] 的输出。

6.3 NSP 的争议

NSP 任务的有效性后来受到质疑。RoBERTa 的研究发现，移除 NSP 任务后性能反而更好。原因是 NSP 任务太简单——模型只需判断主题是否一致，而非真正的句间逻辑关系。ALBERT 将 NSP 改进为句子顺序预测（SOP），要求模型判断两个句子的先后顺序，这一任务更难也更有效。

模型NSP 策略效果
BERT原始 NSP（正/负采样）有效但偏简单
RoBERTa移除 NSP性能提升
ALBERTSOP（句子顺序预测）更难且更有效
SpanBERT移除 NSP，改进 MLM性能提升

7微调范式：下游任务适配

7.1 微调的核心思想

BERT 的微调范式极其简洁：保留预训练的编码器参数，在顶部添加任务特定的输出层，用少量标注数据端到端微调。所有 BERT 参数在微调过程中都会更新，使得通用语言表示适配特定任务。

7.2 四类下游任务

任务类型输入输出层示例
单句分类单句 + [CLS][CLS] → Linear → Softmax情感分析、文本分类
句对分类句A [SEP] 句B[CLS] → Linear → SoftmaxNLI、问答匹配
问答抽取问题 [SEP] 段落每个Token → Start/End概率SQuAD 阅读理解
序列标注单句每个Token → Linear → CRFNER、POS标注

7.3 单句分类的数学描述

对于单句分类任务，取 [CLS] 的最终表示 $C \in \mathbb{R}^H$，通过线性层输出类别概率：

$$P(y \mid x) = \text{softmax}(CW_{\text{cls}} + b_{\text{cls}})$$

其中 $W_{\text{cls}} \in \mathbb{R}^{H \times K}$，$K$ 为类别数。微调时优化交叉熵损失：

$$\mathcal{L}_{\text{fine-tune}} = -\sum_{(x,y)} \log P(y \mid x; \theta, W_{\text{cls}}, b_{\text{cls}})$$

7.4 问答抽取

对于 SQuAD 式的抽取式问答，BERT 输入为 "问题 [SEP] 段落"，对段落中每个 Token 输出两个概率：起始位置 $P_{\text{start}}$ 和结束位置 $P_{\text{end}}$：

$$P_{\text{start}}(i) = \frac{e^{S \cdot T_i}}{\sum_j e^{S \cdot T_j}}, \quad P_{\text{end}}(i) = \frac{e{E \cdot T_i}}{\sum_j e^{E \cdot T_j}}$$

其中 $S, E \in \mathbb{R}^H$ 为可训练的起始/结束向量，$T_i$ 为第 $i$ 个 Token 的表示。答案为 $P_{\text{start}} \times P_{\text{end}}$ 最大的连续片段。

微调的通用性

BERT 的微调范式之所以强大，是因为预训练学到的通用语言表示只需少量任务适配即可迁移到各种任务。通常只需 $3$-$5$ 个 epoch 的微调即可达到 SOTA，而预训练需要数十天的计算。这一"预训练一次、微调多次"的范式大幅降低了 NLP 任务的开发成本。

8BERT 的数学描述

8.1 完整前向传播

给定输入序列 $X = [x_1, x_2, \ldots, x_N]$，BERT 的完整前向传播如下：

步骤 1：输入嵌入。三种嵌入相加：

$$H^{(0)} = E_{\text{token}}(X) + E_{\text{segment}}(S) + E_{\text{position}}(P)$$

步骤 2：逐层编码。第 $l$ 层的输出为：

$$H^{(l)} = \text{TransformerLayer}(H^{(l-1)}), \quad l = 1, \ldots, L$$

步骤 3：输出。第 $L$ 层输出 $H^{(L)} \in \mathbb{R}^{N \times H}$ 即为每个 Token 的最终表示。

8.2 单层 Transformer 的展开

$$\tilde{H}^{(l)} = \text{LayerNorm}\!\left(H^{(l-1)} + \text{MultiHead}\!\left(H^{(l-1)}\right)\right)$$
$$H^{(l)} = \text{LayerNorm}\!\left(\tilde{H}^{(l)} + \text{FFN}\!\left(\tilde{H}^{(l)}\right)\right)$$

8.4 计算复杂度

自注意力的计算复杂度为 $O(N^2 \cdot H)$（$N$ 为序列长度），FFN 为 $O(N \cdot H^2)$。对于 BERT-Base，$N = 512$，$H = 768$：

$$\text{FLOPs per layer} \approx 2N^2H + 2NH \cdot 4H = 2 \times 512^2 \times 768 + 2 \times 512 \times 768 \times 3072$$

9.1 架构对比

9.2 注意力掩码对比

BERT 和 GPT 的核心差异在于注意力掩码。BERT 使用全可见掩码（每个 Token 可见所有 Token），GPT 使用因果掩码（每个 Token 只可见自身及之前的 Token）：

$$M_{\text{BERT}}(i,j) = 1 \quad \forall i,j \qquad M_{\text{GPT}}(i,j) = \begin{cases} 1 & \text{if } j \le i \\ 0 & \text{if } j > i \end{cases}$$

9.3 表示能力对比

BERT 的双向编码在理解类任务上天然优于 GPT 的单向编码。但 BERT 无法直接用于自回归生成——生成时需要逐 Token 预测，而 BERT 的输入需要完整序列。后续的 BART 和 T5 使用编码器+解码器架构，兼顾理解和生成。

    def __init__(self, vocab_size=30522, hidden_size=768,
                 max_position_embeddings=512, type_vocab_size=2,
                 dropout=0.1, layer_norm_eps=1e-12):
        super().__init__()
        self.word_embeddings = nn.Embedding(vocab_size, hidden_size)
        self.position_embeddings = nn.Embedding(max_position_embeddings, hidden_size)
        self.token_type_embeddings = nn.Embedding(type_vocab_size, hidden_size)
        self.LayerNorm = nn.LayerNorm(hidden_size, eps=layer_norm_eps)
        self.dropout = nn.Dropout(dropout)
        # 位置 ID 缓冲区
        self.register_buffer("position_ids",
            torch.arange(max_position_embeddings).unsqueeze(0))

    def forward(self, input_ids, token_type_ids=None):
        seq_length = input_ids.size(1)
        if token_type_ids is None:
            token_type_ids = torch.zeros_like(input_ids)
        position_ids = self.position_ids[:, :seq_length]

        embeddings = (self.word_embeddings(input_ids)
                      + self.position_embeddings(position_ids)
                      + self.token_type_embeddings(token_type_ids))
        embeddings = self.LayerNorm(embeddings)
        embeddings = self.dropout(embeddings)
        return embeddings

11.2 多头注意力

multi_head_attention.py
class MultiHeadAttention(nn.Module):
    """多头自注意力机制"""
    def __init__(self, hidden_size=768, num_heads=12, dropout=0.1):
        super().__init__()
        assert hidden_size % num_heads == 0
        self.num_heads = num_heads
        self.head_dim = hidden_size // num_heads
        self.scaling = self.head_dim ** -0.5

        self.query = nn.Linear(hidden_size, hidden_size)
        self.key = nn.Linear(hidden_size, hidden_size)
        self.value = nn.Linear(hidden_size, hidden_size)
        self.attn_dropout = nn.Dropout(dropout)
        self.out_proj = nn.Linear(hidden_size, hidden_size)

    def transpose_for_scores(self, x):
        # (B, N, H) -> (B, num_heads, N, head_dim)
        new_shape = x.size()[:-1] + (self.num_heads, self.head_dim)
        x = x.view(*new_shape)
        return x.permute(0, 2, 1, 3)

    def forward(self, hidden_states, attention_mask=None):
        Q = self.transpose_for_scores(self.query(hidden_states))
        K = self.transpose_for_scores(self.key(hidden_states))
        V = self.transpose_for_scores(self.value(hidden_states))

        # 注意力分数: (B, num_heads, N, N)
        attn_scores = torch.matmul(Q, K.transpose(-1, -2)) * self.scaling
        if attention_mask is not None:
            attn_scores = attn_scores + attention_mask

        attn_probs = torch.softmax(attn_scores, dim=-1)
        attn_probs = self.attn_dropout(attn_probs)

        # 加权求和: (B, num_heads, N, head_dim)
        context = torch.matmul(attn_probs, V)
        context = context.permute(0, 2, 1, 3).contiguous()
        new_shape = context.size()[:-2] + (self.num_heads * self.head_dim,)
        context = context.view(*new_shape)

        return self.out_proj(context)

11.3 Transformer 编码器层

transformer_encoder.py
class BertSelfOutput(nn.Module):
    """自注意力后的残差 + LayerNorm"""
    def __init__(self, hidden_size=768, dropout=0.1, eps=1e-12):
        super().__init__()
        self.dense = nn.Linear(hidden_size, hidden_size)
        self.LayerNorm = nn.LayerNorm(hidden_size, eps=eps)
        self.dropout = nn.Dropout(dropout)

    def forward(self, hidden_states, input_tensor):
        hidden_states = self.dense(hidden_states)
        hidden_states = self.dropout(hidden_states)
        return self.LayerNorm(input_tensor + hidden_states)

class BertLayer(nn.Module):
    """单层 Transformer 编码器"""
    def __init__(self, hidden_size=768, num_heads=12,
                 intermediate_size=3072, dropout=0.1, eps=1e-12):
        super().__init__()
        self.attention = MultiHeadAttention(hidden_size, num_heads, dropout)
        self.attention_output = BertSelfOutput(hidden_size, dropout, eps)
        self.intermediate = nn.Sequential(
            nn.Linear(hidden_size, intermediate_size),
            nn.GELU()
        )
        self.output = nn.Sequential(
            nn.Linear(intermediate_size, hidden_size),
        )
        self.output_layer_norm = nn.LayerNorm(hidden_size, eps=eps)
        self.output_dropout = nn.Dropout(dropout)

    def forward(self, hidden_states, attention_mask=None):
        # 自注意力子层
        attn_output = self.attention(hidden_states, attention_mask)
        attn_output = self.attention_output(attn_output, hidden_states)

        # 前馈网络子层
        intermediate_output = self.intermediate(attn_output)
        layer_output = self.output(intermediate_output)
        layer_output = self.output_dropout(layer_output)
        layer_output = self.output_layer_norm(attn_output + layer_output)
        return layer_output

11.4 完整 BERT 模型

bert_model.py
class BertModel(nn.Module):
    """完整 BERT 模型"""
    def __init__(self, vocab_size=30522, hidden_size=768,
                 num_layers=12, num_heads=12,
                 intermediate_size=3072, max_position=512,
                 type_vocab_size=2, dropout=0.1, eps=1e-12):
        super().__init__()
        self.embeddings = BertEmbeddings(
            vocab_size, hidden_size, max_position,
            type_vocab_size, dropout, eps
        )
        self.layers = nn.ModuleList([
            BertLayer(hidden_size, num_heads, intermediate_size, dropout, eps)
            for _ in range(num_layers)
        ])
        self.pooler = nn.Sequential(
            nn.Linear(hidden_size, hidden_size),
            nn.Tanh()
        )

    def forward(self, input_ids, attention_mask=None, token_type_ids=None):
        # 构建注意力掩码: (B, 1, 1, N)
        if attention_mask is not None:
            ext_mask = attention_mask[:, None, None, :].float()
            ext_mask = (1.0 - ext_mask) * -10000.0

        # 输入嵌入
        hidden_states = self.embeddings(input_ids, token_type_ids)

        # 逐层编码
        for layer in self.layers:
            hidden_states = layer(hidden_states, ext_mask)

        # [CLS] 池化输出
        pooled = self.pooler(hidden_states[:, 0])
        return hidden_states, pooled

11.5 预训练任务

pretraining_tasks.py
class BertForPreTraining(nn.Module):
    """BERT 预训练：MLM + NSP"""
    def __init__(self, bert_config):
        super().__init__()
        self.bert = BertModel(**bert_config)
        H = bert_config["hidden_size"]
        V = bert_config["vocab_size"]

        # MLM 输出头
        self.cls = nn.Sequential(
            nn.Linear(H, H),
            nn.GELU(),
            nn.LayerNorm(H)
        )
        self.mlm_decoder = nn.Linear(H, V, bias=False)
        self.mlm_bias = nn.Parameter(torch.zeros(V))

        # NSP 输出头
        self.nsp_classifier = nn.Linear(H, 2)

    def forward(self, input_ids, attention_mask, token_type_ids,
                masked_positions=None, masked_labels=None, nsp_label=None):
        sequence_output, pooled_output = self.bert(
            input_ids, attention_mask, token_type_ids
        )

        # MLM: 仅预测被掩码的位置
        if masked_positions is not None:
            # 收集被掩码位置的隐藏状态
            B, N, H = sequence_output.shape
            flat_indices = masked_positions.reshape(-1)
            batch_indices = torch.arange(B).repeat_interleave(
                masked_positions.size(1)
            )
            hidden = sequence_output[batch_indices, flat_indices]
            hidden = hidden.reshape(B, -1, H)

            hidden = self.cls(hidden)
            logits = self.mlm_decoder(hidden) + self.mlm_bias
            mlm_loss = nn.CrossEntropyLoss()(
                logits.view(-1, logits.size(-1)),
                masked_labels.view(-1)
            )
        else:
            mlm_loss = torch.tensor(0.0)

        # NSP: 使用 [CLS] 池化输出
        nsp_logits = self.nsp_classifier(pooled_output)
        nsp_loss = nn.CrossEntropyLoss()(nsp_logits, nsp_label)

        total_loss = mlm_loss + nsp_loss
        return total_loss, mlm_loss, nsp_loss

11.6 微调分类

class BertForSequenceClassification(nn.Module):
    """BERT 微调：单句/句对分类"""
    def __init__(self, bert_config, num_classes=2, dropout=0.1):
        super().__init__()
        self.bert = BertModel(**bert_config)
        H = bert_config["hidden_size"]
        self.dropout = nn.Dropout(dropout)
        self.classifier = nn.Linear(H, num_classes)

    def forward(self, input_ids, attention_mask=None, token_type_ids=None):
        _, pooled_output = self.bert(input_ids, attention_mask, token_type_ids)
        pooled_output = self.dropout(pooled_output)
        logits = self.classifier(pooled_output)
        return logits


def finetune_bert(model, dataloader, num_classes, epochs=3, lr=2e-5):
    """微调 BERT 分类模型"""
    optimizer = torch.optim.AdamW(model.parameters(), lr=lr, weight_decay=0.01)
    scheduler = torch.optim.lr_scheduler.LinearLR(
        optimizer, start_factor=0.1, total_iters=len(dataloader) * epochs
    )
    criterion = nn.CrossEntropyLoss()
    model.train()

    for epoch in range(epochs):
        total_loss = 0
        for batch in dataloader:
            input_ids, masks, labels = batch
            logits = model(input_ids, attention_mask=masks)
            loss = criterion(logits, labels)
            optimizer.zero_grad()
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            optimizer.step()
            scheduler.step()
            total_loss += loss.item()
        print(f"Epoch {epoch+1}, Loss: {total_loss/len(dataloader):.4f}")

12BERT 的扩展与变体

12.1 BERT 家族

模型年份核心改进解决的问题
BERT2018双向 MLM + NSP 预训练NLP 预训练范式
RoBERTa2019移除 NSP，动态掩码，更大 batch/数据NSP 无效 + 训练不充分
ALBERT2020参数共享 + 因子分解嵌入 + SOP参数量过大 + NSP 偏简单
DeBERTa2021解耦注意力 + 增强掩码解码器位置与内容编码耦合
SpanBERT2020连续 Span 掩码 + 边界表示MLM 掩码太碎片化
ELECTRA2020替换 Token 检测（RTD）MLM 计算效率低
DistilBERT2020知识蒸馏压缩模型过大部署困难
CamemBERT2020法语 BERT多语言适配

12.2 RoBERTa 的关键改进

RoBERTa（Robustly Optimized BERT Pretraining Approach）通过更好的训练策略而非架构改变显著提升了性能：

  • 移除 NSP：实验证明 NSP 任务不仅无益甚至有害
  • 动态掩码：每个 epoch 重新生成掩码模式（BERT 的掩码在预处理时固定）
  • 更大 batch：从 $256$ 增到 $8{,}192$，配合更大学习率
  • 更多数据：从 $16$GB 增到 $160$GB（CC-News、OpenWebText、Stories）
  • 更长训练：从 $100$K 步增到 $500$K 步
  • 字节对编码（BPE）：取代 WordPiece，词表 $50{,}265$

12.3 ALBERT 的参数压缩

ALBERT 通过两个技术大幅减少参数量：

因子分解嵌入参数化：将 $V \times H$ 的大嵌入矩阵分解为 $V \times E$ + $E \times H$，其中 $E \ll H$：

$$E = E_{\text{vocab}}(V \times E) \times E_{\text{project}}(E \times H)$$

跨层参数共享：所有 Transformer 层共享同一组参数，将 $L$ 层的参数从 $L \times \theta_{\text{layer}}$ 减少到 $\theta_{\text{layer}}$。ALBERT-Base 参数量仅 $12$M（BERT-Base 的 $1/9$），但性能接近。

12.4 ELECTRA 的效率改进

ELECTRA 使用替换 Token 检测（Replaced Token Detection）取代 MLM。一个小型生成器将部分 Token 替换为看似合理但不正确的 Token，判别器（主模型）判断每个 Token 是否被替换：

$$\mathcal{L}_{\text{RTD}} = -\sum_{i=1}^{N} \log P(\text{original/replaced} \mid x_i)$$

与 MLM 只在 $15$% 位置计算损失不同，RTD 在所有位置计算损失，训练效率提升 $4\times$。

12.5 知识蒸馏：DistilBERT

DistilBERT 通过知识蒸馏将 BERT 压缩到 $66$M 参数（原始 $1/2$），保留 $95$% 的性能：

$$\mathcal{L}_{\text{distill}} = \alpha \cdot \text{CE}(y_s, y_t) + (1-\alpha) \cdot \text{KL}(p_s \| p_t)$$

其中 $y_s, y_t$ 为学生/教师模型的 logits，$p_s, p_t$ 为 softmax 概率，$\alpha$ 为权重。学生模型学习教师模型的软标签（soft labels），获得更丰富的训练信号。

2017.06

总结

BERT 的核心贡献可以归纳为一句话：真正的双向编码是语言理解的关键。通过掩码语言模型任务，BERT 让 Transformer 编码器同时利用左侧和右侧上下文，在理解类 NLP 任务上实现了突破性进展。尽管后续 RoBERTa 改进了训练策略、ALBERT 压缩了参数、ELECTRA 提升了效率，但 BERT 确立的"双向预训练 + 微调"范式依然是 NLP 的标准做法。BERT 的影响远超 NLP——其掩码预训练思想启发了视觉领域的 MAE、BeiT 等方法，成为自监督学习跨模态的通用范式。
