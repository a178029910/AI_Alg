1Flamingo 的诞生与动机

1.1 视觉-语言模型的挑战

2022 年之前，视觉-语言模型（VLM）面临一个根本性矛盾：大语言模型（LLM）已具备强大的少样本推理能力，但视觉模块的接入方式破坏了这一能力。早期方法要么将视觉特征简单地拼接到文本前面（破坏了 LLM 的上下文学习），要么从头训练整个模型（计算成本极高且难以扩展）。

更深层的问题是：多模态训练数据存在尺度不平衡。纯文本数据量远超图文对数据——互联网上有万亿 Token 的文本，但高质量的图文对仅有数亿。如何在保持 LLM 强大推理能力的同时，高效注入视觉理解能力，是 Flamingo 要解决的核心问题。

方法范式视觉接入方式少样本能力训练成本
从头联合训练端到端学习需大量图文对极高
视觉特征拼接拼接在文本前破坏 LLM 上下文中
线性投影（如 CLIP）投影到文本空间有限低
Flamingo交叉注意力桥接保持 LLM 少样本能力高效（冻结主体）
核心动机

Flamingo 的核心动机是：保留预训练 LLM 的强大推理能力，通过最小化可训练参数将视觉信息"注入"语言模型。关键创新在于使用 Gated Cross-Attention 机制将视觉特征桥接到冻结的 LLM 中，既不破坏 LLM 的文本推理能力，又能高效融合多模态信息。

1.2 Flamingo 的诞生

2022 年 4 月，DeepMind 在论文 "Flamingo: a Visual Language Model for Few-Shot Learning" 中提出了 Flamingo。Flamingo 利用预训练的 NFNet 视觉编码器和 Chinchilla 语言模型，通过感知器重采样和 Gated Cross-Attention 将两者桥接，仅需训练少量新增参数即可实现强大的少样本视觉-语言推理。

Flamingo 在 6 个经典视觉-语言基准上仅用 32 个示例就超越了 fine-tuned 的 SOTA 模型，标志着多模态少样本学习的重要突破。

1.3 Flamingo 的关键创新

Flamingo 与传统视觉-语言模型相比，有四个关键创新：

创新点传统 VLMFlamingo
视觉接入特征拼接或端到端Gated Cross-Attention 桥接
LLM 参数全部微调冻结，仅训练新增层
视觉特征压缩无（直接使用）Perceiver Resampler 压缩
少样本能力需 fine-tuneIn-context few-shot
多图像支持单图像交错多图像/视频
Flamingo 的定位

Flamingo 是第一个在少样本设定下超越 fine-tuned SOTA 的视觉-语言模型。它证明了：通过巧妙的架构设计，可以在不微调 LLM 的情况下注入视觉能力，保留 LLM 的推理优势。这一思路深刻影响了后续的 BLIP-2、LLaVA 等视觉-语言模型。

2整体架构：感知器重采样

2.1 架构总览

Flamingo 的架构由四个核心组件构成，数据流从图像输入到文本输出依次为：

  1. 视觉编码器（NFNet）：从图像/视频提取特征图（冻结）
  2. 感知器重采样（Perceiver Resampler）：将变长特征图压缩为固定数量的 latent tokens（可训练）
  3. Gated Cross-Attention：将视觉 latent tokens 注入冻结的 LLM 层中（可训练）
  4. 语言模型（Chinchilla）：处理文本生成（冻结）

2.2 组件参数量对比

Flamingo 的设计哲学是最大化复用预训练模型，最小化新增可训练参数。下表展示了各组件的参数量与训练状态：

组件参数量训练状态功能
NFNet-F6 视觉编码器~195M冻结提取图像/视频特征
Perceiver Resampler~30M可训练压缩视觉特征为固定 tokens
Gated X-Attention~1B（总）可训练视觉信息注入 LLM
Chinchilla LLM70B冻结文本理解与生成
总可训练参数~1.03B可训练仅占总量 1.5%
设计哲学

80B 参数的模型中，仅约 1B 参数可训练（1.5%）。这种"冻结主体 + 训练桥接"的设计使得 Flamingo 在保持强大推理能力的同时，训练效率和稳定性远优于全参数微调。

3视觉编码器：NFNet 与 Patch 提取

3.1 NFNet：Normalizer-Free 架构

Flamingo 的视觉编码器使用 NFNet-F6（Normalizer-Free Network），这是一类不使用 Batch Normalization 的卷积网络架构。NFNet 的优势在于训练稳定性和特征质量，尤其在大批量训练时表现出色。

NFNet 的核心设计要点：

  • 无归一化层：使用 Adaptive Gradient Clipping（AGC）替代 BN，避免 BN 引入的噪声和训练-推理不一致
  • ResNet 风格残差块：使用 Bottleneck 结构，包含 $3 \times 3$ 和 $1 \times 1$ 卷积
  • SE 模块：Squeeze-and-Excitation 通道注意力增强特征表达
  • 特征金字塔：多个 stage 产生不同分辨率的特征图

3.2 特征提取与 Patch 化

NFNet-F6 在输入分辨率为 $320 \times 320$ 的图像上，最终阶段输出 $H \times W = 10 \times 10$ 的特征图，每个位置是 $D = 2048$ 维向量。对于视频输入，Flamingo 每秒采样 1 帧，每帧独立通过 NFNet 提取特征。

$$\mathbf{X}_{\text{visual}} = \text{NFNet}(\mathbf{I}) \in \mathbb{R}^{H \times W \times D}$$

其中 $\mathbf{I}$ 是输入图像（或视频帧），$H \times W$ 是空间分辨率，$D$ 是特征维度。由于 $H \times W$ 随输入分辨率变化，这产生了变长序列问题——后续的 Perceiver Resampler 正是为此设计。

视频处理

对于包含 $T$ 帧的视频输入，每帧独立提取特征后得到 $T \times H \times W \times D$ 的特征。Flamingo 将所有帧的空间位置展平为 $(T \cdot H \cdot W) \times D$，作为一个统一序列送入 Perceiver Resampler。

4感知器重采样：压缩视觉特征

4.1 为什么需要重采样

NFNet 输出的特征图展平后是一个变长序列。对于 $320 \times 320$ 输入，产生 $100$ 个 tokens（$10 \times 10$）；但对于更大分辨率或视频，token 数量会急剧增长。直接将这些 tokens 送入 LLM 会产生两个问题：

  1. 计算成本：Cross-Attention 的复杂度与视觉 token 数量成正比
  2. 变长处理：LLM 的位置编码和 KV 缓存需要固定长度输入

Perceiver Resampler 通过一组可学习的查询向量，将变长的视觉特征压缩为固定数量的 latent tokens。

4.2 Perceiver Resampler 架构

Perceiver Resampler 包含 $L$ 层，每层执行以下操作：

$$\mathbf{Z}_\ell = \text{Attention}\!\left(\mathbf{Q} = \mathbf{Z}_{\ell-1},\ \mathbf{K} = \mathbf{X}_\text{visual},\ \mathbf{V} = \mathbf{X}_\text{visual}\right) + \mathbf{Z}_{\ell-1}$$

其中 $\mathbf{Z}_{\ell-1} \in \mathbb{R}^{N \times D}$ 是上一层的 latent（$N$ 个查询，$D$ 维），$\mathbf{X}_\text{visual} \in \mathbb{R}^{M \times D}$ 是视觉特征（$M$ 个，可变长）。注意这里 Q 来自 latent（固定 $N$），K/V 来自视觉特征（变长 $M$），因此输出固定为 $N \times D$。

完整的单层 Perceiver Resampler 包含：

  1. 多头交叉注意力（Latent → Visual）
  2. 残差连接 + LayerNorm
  3. 前馈网络（FFN）
  4. 残差连接 + LayerNorm
$$\mathbf{Z}'_\ell = \text{LN}_1\!\left(\mathbf{Z}_{\ell-1} + \text{MHCA}(\mathbf{Z}_{\ell-1}, \mathbf{X}_\text{visual})\right)$$
$$\mathbf{Z}_\ell = \text{LN}_2\!\left(\mathbf{Z}'_\ell + \text{FFN}(\mathbf{Z}'_\ell)\right)$$

初始 latent $\mathbf{Z}_0$ 由 $N$ 个可学习的查询向量组成。Flamingo 使用 $N = 64$ 个 latent tokens，每层 $D = 2048$ 维，$L = 6$ 层。

4.3 多图像/视频处理

Flamingo 的一个重要特性是支持交错多图像输入。当输入包含多张图像/视频时，每张图像独立通过 NFNet + Perceiver Resampler，产生各自独立的 $N$ 个 latent tokens。这些 latent tokens 在文本序列中对应各自的图像位置标记。

$$\mathbf{Z}^{(k)} = \text{PerceiverResampler}\!\left(\text{NFNet}(\mathbf{I}_k)\right) \in \mathbb{R}^{N \times D}, \quad k = 1, \ldots, K$$

其中 $K$ 是输入中的图像/视频数量。每个图像产生 $N$ 个 latent tokens，它们在序列中占据 $N$ 个位置，与文本 tokens 交错排列。

4.4 Perceiver Resampler 的优势

优势说明
固定长度输出无论输入分辨率如何，输出始终是 N 个 tokens
计算效率将 M 个视觉 tokens 压缩为 N 个（N $\ll$ M），大幅降低后续 Cross-Attention 成本

5语言模型：Chinchilla 与 Gated Cross-Attention

5.1 Chinchilla：计算最优的语言模型

Flamingo 的语言模型基于 Chinchilla，这是 DeepMind 提出的 70B 参数语言模型。Chinchilla 的关键贡献在于发现了"计算最优训练"定律：在固定计算预算下，模型大小和训练数据量应按比例增长。Chinchilla 在 1.4 万亿 tokens 上训练，证明了对于 70B 参数模型，需要约 1.4T tokens 才能达到计算最优。

属性ChinchillaGPT-3（对比）
参数量70B175B
训练数据1.4T tokens0.3T tokens
计算量~相同~相同
性能优于 GPT-3基准
训练效率计算最优欠训练

5.2 LLM 冻结策略

Flamingo 完全冻结 Chinchilla 的所有参数，不进行任何微调。这一决策基于以下理由：

  • 保留推理能力：LLM 的少样本推理能力来自大规模预训练，微调可能破坏
  • 训练效率：冻结 LLM 意味着不需要为 70B 参数计算梯度或维护优化器状态
  • 模块化：可以随时替换为更好的 LLM，只需重训桥接层
  • 防止灾难遗忘：避免在多模态数据上微调导致文本能力退化

5.3 Gated Cross-Attention 的位置

Flamingo 在 Chinchilla 的 Transformer 层之间插入新的 Gated Cross-Attention 层。具体来说，在每个 Transformer Block 的自注意力层和 FFN 层之间（或之后），插入一个 Cross-Attention 层，该层的 K/V 来自视觉 latent tokens，Q 来自文本 hidden states。

5.4 从文本到多模态

通过 Gated Cross-Attention，文本的 hidden states 可以"查询"视觉 latent tokens 中的信息。这意味着 LLM 在处理文本时，可以动态地获取与当前文本相关的视觉信息。例如，当文本中出现"图中的物体是什么颜色"时，LLM 的注意力机制可以引导查询从视觉 latent 中提取颜色信息。

$$\mathbf{h}' = \mathbf{h} + \tanh(\alpha) \cdot \text{CrossAttn}(\mathbf{h}, \mathbf{Z}_\text{visual})$$

其中 $\mathbf{h}$ 是文本 hidden states，$\mathbf{Z}_\text{visual}$ 是 Perceiver Resampler 输出的 latent tokens，$\alpha$ 是可学习的门控参数（初始化为 $0$），$\tanh(\alpha)$ 控制视觉信息的注入强度。

6Gated Cross-Attention 详解

6.1 交叉注意力机制

Gated Cross-Attention 的核心是标准的多头交叉注意力，但有两个关键设计：门控机制和零初始化。

标准交叉注意力计算如下：

$$\text{Attn}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\!\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}$$

在 Flamingo 的 Gated Cross-Attention 中：

  • $\mathbf{Q} = \mathbf{h} \mathbf{W}_Q$：来自文本 hidden states（当前 LLM 层的输出）
  • $\mathbf{K} = \mathbf{Z}_\text{visual} \mathbf{W}_K$：来自视觉 latent tokens（Perceiver Resampler 输出）
  • $\mathbf{V} = \mathbf{Z}_\text{visual} \mathbf{W}_V$：来自视觉 latent tokens
$$\text{CrossAttn}(\mathbf{h}, \mathbf{Z}_\text{visual}) = \text{softmax}\!\left(\frac{(\mathbf{h}\mathbf{W}_Q)(\mathbf{Z}_\text{visual}\mathbf{W}_K)^\top}{\sqrt{d_k}}\right)(\mathbf{Z}_\text{visual}\mathbf{W}_V)$$

6.2 门控机制

门控是 Flamingo 的核心创新之一。在交叉注意力的输出上加一个可学习的标量门，通过 $\tanh$ 激活函数控制视觉信息的注入比例：

$$\mathbf{h}' = \mathbf{h} + \tanh(\alpha) \cdot \text{CrossAttn}(\mathbf{h}, \mathbf{Z}_\text{visual})$$

其中 $\alpha$ 是一个可学习的标量参数，初始化为 $0$。这意味着训练开始时 $\tanh(0) = 0$，视觉信息完全不注入——LLM 的行为与原始模型完全一致。随着训练进行，$\alpha$ 逐渐增大，视觉信息开始融入。

零初始化的智慧

零初始化确保了训练初始时 Flamingo 的行为等同于原始 LLM，不会因为随机初始化的交叉注意力层而破坏 LLM 的文本推理能力。这种设计类似于 ControlNet 中的"零卷积"思想——新模块初始时不影响原模型，随着训练逐步学习如何注入新信息。

6.3 梯门机制

除了输入门控 $\tanh(\alpha)$，Flamingo 还在 FFN 层使用梯度门控，控制梯度从新增的 Cross-Attention 层回传到冻结 LLM 的强度：

$$\mathbf{h}'' = \mathbf{h}' + \text{FFN}_{\text{LLM}}(\mathbf{h}') \cdot \beta$$

其中 $\beta$ 控制梯度流经 FFN 的比例。在训练初期 $\beta$ 较小，保护 LLM 不受梯度干扰；随训练推进 $\beta$ 逐渐增大。注意 LLM 参数始终冻结，这里的梯度门控影响的是信号流（前向/反向），不是参数更新。

6.4 完整 Gated X-Attention 层

一个完整的 Flamingo Transformer Block 包含三部分：

$$\mathbf{h}_1 = \text{LN}_\text{SA}\!\left(\mathbf{h} + \text{SelfAttn}_{\text{frozen}}(\mathbf{h})\right)$$
$$\mathbf{h}_2 = \text{LN}_\text{XA}\!\left(\mathbf{h}_1 + \tanh(\alpha) \cdot \text{CrossAttn}_{\text{trainable}}(\mathbf{h}_1, \mathbf{Z}_\text{visual})\right)$$
$$\mathbf{h}_3 = \text{LN}_\text{FFN}\!\left(\mathbf{h}_2 + \text{FFN}_{\text{frozen}}(\mathbf{h}_2)\right)$$

其中 $\text{LN}$ 是 LayerNorm，$\text{SelfAttn}$ 和 $\text{FFN}$ 来自冻结的 LLM，$\text{CrossAttn}$ 是新增的可训练层。$\alpha$ 是可学习门控参数（初始化为 $0$）。

7训练策略：冻结 + 梯门 + 零初始化

7.1 冻结预训练骨干

Flamingo 的训练策略是其成功的核心因素之一。与从头训练或全量微调不同，Flamingo 采用了冻结预训练骨干的策略：

组件来源训练状态参数量
视觉编码器（NFNet）预训练 ImageNet 分类模型冻结$\sim 1$B
语言模型（Chinchilla）预训练 LLM冻结$70$B
Perceiver Resampler随机初始化可训练$\sim 200$M
Gated Cross-Attention随机初始化（零初始化门控）可训练$\sim 1$B
为什么冻结骨干？

冻结预训练骨干有两个核心优势：(1) 保留知识——NFNet 保留了强大的视觉特征提取能力，Chinchilla 保留了文本理解与生成能力，避免了灾难性遗忘；(2) 降低成本——只有 $\sim 1.2$B 参数需要训练，而 $71$B 参数被冻结，训练显存和计算量大幅降低。

7.2 零初始化门控

如第 6 章所述，Gated Cross-Attention 的门控参数 $\alpha$ 初始化为 $0$，使得 $\tanh(0) = 0$。这意味着在训练开始时：

$$\mathbf{h}' = \mathbf{h} + \underbrace{\tanh(0)}_{=0} \cdot \text{CrossAttn}(\mathbf{h}, \mathbf{Z}_\text{visual}) = \mathbf{h}$$

即 Flamingo 的初始行为与原始 Chinchilla 完全一致——视觉信息完全不注入。随着训练进行，$\alpha$ 通过梯度逐渐学习到合适的值，视觉信息开始融入文本推理过程。这种"渐进式融合"避免了随机初始化的 Cross-Attention 破坏 LLM 的语言能力。

7.3 梯度门控（Gradient Gating）

除了输入端的 $\tanh(\alpha)$ 门控，Flamingo 还在 FFN 层引入了梯度门控 $\beta$，控制梯度回传的强度：

$$\mathbf{h}_3 = \text{LN}\!\left(\mathbf{h}_2 + \beta \cdot \text{FFN}(\mathbf{h}_2)\right)$$

其中 $\beta$ 是可学习参数，同样初始化为较小值。梯度门控的主要作用是保护冻结的 LLM 参数不受新增层梯度的干扰——虽然 LLM 参数本身不更新，但梯度仍需流经 LLM 层以更新上游的可训练参数（如 Perceiver Resampler）。

8Few-Shot 学习与 In-Context Learning

8.1 In-Context Learning 范式

Flamingo 的核心卖点之一是In-Context Learning（上下文学习）——通过在推理时提供少量示例（demonstrations），模型无需任何参数更新即可适配新任务。这与 GPT-3 的 Few-Shot 范式一脉相承，但 Flamingo 将其扩展到了多模态场景。

给定一个任务（如图像描述、视觉问答），Few-Shot 推理的输入格式为：

$$\text{Prompt} = \underbrace{(I_1, Q_1, A_1), \ldots, (I_n, Q_n, A_n)}_{\text{n 个示例}} ,\underbrace{(I_{\text{test}}, Q_{\text{test}})}_{\text{测试样本}}$$

模型自回归地生成 $A_{\text{test}}$，将前面的示例作为上下文"学习"任务模式。

8.2 Few-Shot vs Zero-Shot vs Fine-Tuning

9多图像推理与 Flamingo-Mini

9.1 多图像推理

Flamingo 的一个独特能力是多图像推理——在单个 prompt 中包含多张图像，模型可以综合多张图像的信息进行推理。这是通过在文本序列中插入特殊图像占位符 `` 实现的：

$$\text{Input} = \text{""}\;\text{img}_1\;\text{""}\;\text{img}_2\;\ldots\;\text{""}\;\text{img}_K\;\text{Question?}$$

多图像推理能力的关键在于训练数据。Flamingo 使用了 M3W（Multi-modal Massive Web）数据集，其中包含大量交错图文内容——网页中文字和图片交替出现。这种数据格式使模型自然地学会在图文混合序列中推理。

10.1 Perceiver Resampler

perceiver_resampler.py
import torch
import torch.nn as nn
import torch.nn.functional as F

class PerceiverResampler(nn.Module):
    """Perceiver Resampler：将变长视觉特征压缩为固定数量 latent tokens"""
    def __init__(self, vision_dim, latent_dim=1024, num_latents=64,
                 num_heads=8, num_layers=4):
        super().__init__()
        self.latents = nn.Parameter(
            torch.randn(num_latents, latent_dim))
        self.input_proj = nn.Linear(vision_dim, latent_dim)
        self.layers = nn.ModuleList([
            CrossAttentionLayer(latent_dim, num_heads)
            for _ in range(num_layers)
        ])
        self.ln = nn.LayerNorm(latent_dim)

    def forward(self, vision_features):
        # vision_features: (B, M, vision_dim) -- M = (H/P)*(W/P) + 1
        B = vision_features.size(0)
        x = self.input_proj(vision_features)  # (B, M, latent_dim)
        latents = self.latents.unsqueeze(0).expand(B, -1, -1)
        for layer in self.layers:
            latents = layer(latents, x)
        return self.ln(latents)  # (B, num_latents, latent_dim)


class CrossAttentionLayer(nn.Module):
    def __init__(self, dim, num_heads):
        super().__init__()
        self.norm_q = nn.LayerNorm(dim)
        self.norm_kv = nn.LayerNorm(dim)
        self.attn = nn.MultiheadAttention(
            dim, num_heads, batch_first=True)
        self.norm_ff = nn.LayerNorm(dim)
        self.ff = nn.Sequential(
            nn.Linear(dim, dim * 4),
            nn.GELU(),
            nn.Linear(dim * 4, dim)
        )

    def forward(self, q, kv):
        q_norm = self.norm_q(q)
        kv_norm = self.norm_kv(kv)
        attn_out, _ = self.attn(q_norm, kv_norm, kv_norm)
        q = q + attn_out
        q = q + self.ff(self.norm_ff(q))
        return q

10.2 Gated Cross-Attention 层

gated_cross_attention.py
class GatedCrossAttention(nn.Module):
    """Gated Cross-Attention：门控交叉注意力层"""
    def __init__(self, text_dim, visual_dim, num_heads=8):
        super().__init__()
        self.norm_q = nn.LayerNorm(text_dim)
        self.norm_kv = nn.LayerNorm(visual_dim)
        self.cross_attn = nn.MultiheadAttention(
            text_dim, num_heads, kdim=visual_dim,
            vdim=visual_dim, batch_first=True)
        # 零初始化门控参数
        self.gate = nn.Parameter(torch.zeros(1))
        # FFN 梯度门控
        self.ff_gate = nn.Parameter(torch.zeros(1))

    def forward(self, text_hidden, visual_latent):
        # text_hidden: (B, L, text_dim) -- 文本 hidden states
        # visual_latent: (B, K, visual_dim) -- 视觉 latent tokens
        q = self.norm_q(text_hidden)
        kv = self.norm_kv(visual_latent)
        attn_out, _ = self.cross_attn(q, kv, kv)
        # 门控注入：tanh(alpha) * CrossAttn
        text_hidden = text_hidden + torch.tanh(self.gate) * attn_out
        return text_hidden

10.3 Flamingo Transformer Block

flamingo_block.py
class FlamingoBlock(nn.Module):
    """Flamingo Transformer Block = 冻结 LLM Block + 可训练 Gated X-Attn"""
    def __init__(self, frozen_llm_block, text_dim, visual_dim, num_heads=8):
        super().__init__()
        self.frozen_block = frozen_llm_block  # 冻结的 LLM 层
        self.gated_xattn = GatedCrossAttention(
            text_dim, visual_dim, num_heads)
        # 冻结 LLM 参数
        for p in self.frozen_block.parameters():
            p.requires_grad = False

    def forward(self, text_hidden, visual_latent):
        # 1. 先经过 Gated Cross-Attention
        text_hidden = self.gated_xattn(text_hidden, visual_latent)
        # 2. 再经过冻结的 LLM Block (Self-Attn + FFN)
        text_hidden = self.frozen_block(text_hidden)
        return text_hidden

10.4 完整 Flamingo 模型

flamingo_model.py
class Flamingo(nn.Module):
    """完整 Flamingo 模型"""
    def __init__(self, vision_encoder, perceiver_resampler,
                 frozen_llm, flamingo_blocks, tokenizer):
        super().__init__()
        self.vision_encoder = vision_encoder      # 冻结的 NFNet
        self.perceiver = perceiver_resampler       # 可训练
        self.llm = frozen_llm                      # 冻结的 Chinchilla
        self.blocks = flamingo_blocks              # 可训练 Gated X-Attn
        self.tokenizer = tokenizer
        # 冻结视觉编码器
        for p in self.vision_encoder.parameters():
            p.requires_grad = False
        for p in self.llm.parameters():
            p.requires_grad = False

    def encode_images(self, images):
        """提取图像的视觉 latent tokens"""
        with torch.no_grad():
            features = self.vision_encoder(images)  # (B, M, D_v)
        latents = self.perceiver(features)           # (B, K, D_l)
        return latents

    def forward(self, images, text_tokens):
        # 1. 视觉编码
        visual_latent = self.encode_images(images)
        # 2. 文本嵌入
        text_hidden = self.llm.embed_tokens(text_tokens)
        # 3. 逐层经过 Flamingo Block
        for block in self.blocks:
            text_hidden = block(text_hidden, visual_latent)
        # 4. LM Head 预测 logits
        logits = self.llm.lm_head(text_hidden)
        return logits

10.5 Few-Shot 推理

few_shot_inference.py
def few_shot_inference(model, examples, test_image, test_question, tokenizer, device):
    """Flamingo Few-Shot 推理"""
    model.eval()
    # 构建 prompt：n 个示例 + 1 个测试样本
    prompt_tokens = []
    for img, question, answer in examples:
        prompt_tokens.append(tokenizer.encode("<image>"))
        prompt_tokens.append(tokenizer.encode(question))
        prompt_tokens.append(tokenizer.encode(answer))
    prompt_tokens.append(tokenizer.encode("<image>"))
    prompt_tokens.append(tokenizer.encode(test_question))

    # 拼接 token
    input_ids = torch.cat([torch.tensor(t) for t in prompt_tokens])
    input_ids = input_ids.unsqueeze(0).to(device)

    # 收集所有图像
    all_images = [img for img, _, _ in examples] + [test_image]
    images = torch.stack(all_images).to(device)

    with torch.no_grad():
        # 逐 token 生成
        generated = input_ids
        for _ in range(50):  # 最多生成 50 个 token
            logits = model(images, generated)
            next_token = logits[:, -1, :].argmax(dim=-1, keepdim=True)
            generated = torch.cat([generated, next_token], dim=1)
            if next_token.item() == tokenizer.eos_token_id:
                break

    # 解码生成的回答
    answer_tokens = generated[0, input_ids.size(1):]
    answer = tokenizer.decode(answer_tokens)
    return answer

10.6 训练循环

train_flamingo.py
def train_flamingo(model, dataloader, epochs=10, lr=1e-4, device="cuda"):
    """Flamingo 训练循环"""
    model = model.to(device)
    # 只收集可训练参数（Perceiver + Gated X-Attn）
    trainable_params = [p for p in model.parameters() if p.requires_grad]
    optimizer = torch.optim.AdamW(trainable_params, lr=lr, weight_decay=0.1)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
        optimizer, T_max=epochs * len(dataloader))
    scaler = torch.cuda.amp.GradScaler()

    for epoch in range(epochs):
        model.train()
        total_loss = 0
        for batch in dataloader:
            images, text_tokens, labels = batch
            images = images.to(device)
            text_tokens = text_tokens.to(device)
            labels = labels.to(device)

            with torch.cuda.amp.autocast():
                logits = model(images, text_tokens)
                # 只计算文本部分的交叉熵损失
                loss = F.cross_entropy(
                    logits.view(-1, logits.size(-1)),
                    labels.view(-1),
                    ignore_index=-100
                )

            optimizer.zero_grad()
            scaler.scale(loss).backward()
            scaler.unscale_(optimizer)
            torch.nn.utils.clip_grad_norm_(trainable_params, max_norm=1.0)
            scaler.step(optimizer)
            scaler.update()
            scheduler.step()
            total_loss += loss.item()

        avg_loss = total_loss / len(dataloader)
        print(f"Epoch {epoch+1}/{epochs}, Loss: {avg_loss:.4f}, "
              f"LR: {scheduler.get_last_lr()[0]:.2e}")

12.1 视觉-语言模型谱系

12.2 BLIP-2：Q-Former 替代 Perceiver

BLIP-2 用 Q-Former（Querying Transformer）替代了 Flamingo 的 Perceiver Resampler。Q-Former 同样使用可学习的 query tokens 从视觉特征中提取信息，但引入了两阶段预训练：第一阶段做图文对比 + 图文匹配（冻结视觉编码器和 LLM），第二阶段做生成任务。BLIP-2 的 Q-Former 比 Perceiver Resampler 参数更少，训练更高效。

12.3 LLaVA：MLP 投影的简洁方案

LLaVA 采用了极其简洁的方案——直接用两层 MLP将 CLIP 视觉编码器的输出投影到 LLM 的嵌入空间，不使用 Cross-Attention 机制。LLaVA 通过指令微调（Instruction Tuning）获得了强大的多模态对话能力。虽然 LLaVA 不支持 Few-Shot In-Context Learning，但其简洁性和开源特性使其成为最受欢迎的 VLM 之一。

12.4 IDEFICS：Flamingo 的开源复现

Flamingo 本身未开源，Hugging Face 的 IDEFICS 项目复现了 Flamingo 的架构（Perceiver Resampler + Gated Cross-Attention），并使用公开数据训练。IDEFICS 验证了 Flamingo 架构的可复现性，为社区提供了开源的 Flamingo 模型。

12.5 Flamingo 的设计启示

Flamingo 的设计理念影响了后续所有 VLM：

  • 冻结 LLM：BLIP-2、LLaVA 等均采用冻结 LLM 策略
  • 可训练的连接层：Q-Former、MLP 投影等都是 Flamingo Perceiver Resampler 的变体
  • 门控机制：零初始化门控的思想被广泛应用于多模态融合
  • In-Context Learning：Few-Shot 多模态推理成为 VLM 的重要评估范式

总结

Flamingo 的核心贡献可以归纳为三点：(1) 门控 Cross-Attention——通过零初始化门控实现安全的视觉-语言融合，不破坏 LLM 的文本能力；(2) Perceiver Resampler——将变长视觉特征压缩为固定数量的 latent tokens，解决序列长度问题；(3) 多模态 Few-Shot Learning——将 GPT-3 的 In-Context Learning 范式扩展到视觉-语言领域，在 $6$ 个基准上以 $32$ 示例超过微调模型。Flamingo 证明了：强大的预训练骨干 + 灵活的连接层 + 门控融合，是多模态学习的关键公式。这一设计理念深刻影响了 BLIP-2、LLaVA、IDEFICS 等后续所有视觉-语言模型的架构设计。
