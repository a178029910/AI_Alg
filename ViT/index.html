1ViT 的诞生与动机

1.1 从 NLP 到 CV：Transformer 的跨界

2017 年 Transformer 在 NLP 领域取得革命性成功后，研究者一直在探索将其应用于计算机视觉。早期尝试如 Vision Transformer 的非正式版本需要 CNN 特征提取器作为前端，并非真正的"纯 Transformer 视觉模型"。2020 年，Google Research 的 Dosovitskiy 等人在论文 "An Image is Worth 16×16 Words" 中提出了真正的纯 Transformer 视觉架构——ViT，彻底抛弃卷积，仅用标准 Transformer Encoder 处理图像。

1.2 核心思想：图像即序列

ViT 的核心洞察极其简洁：将图像切割为固定大小的图块（patch），将每个图块视为一个"视觉单词"，然后直接送入标准 Transformer。这一思路将图像分类转化为与 NLP 完全相同的序列分类问题：

  • NLP：句子 → 分词（Token）→ Transformer → 分类
  • ViT：图像 → 分块（Patch）→ Transformer → 分类
直觉理解

CNN 的卷积核扫描图像，像是一个拿着放大镜的侦探——从局部细节到全局结构逐层抽象。ViT 则像是一个快速浏览全局的观察者——第一层就能看到整幅图像（全局感受野），让注意力机制决定哪些区域相互关联。CNN 走的是"局部到全局"的路线，ViT 一上来就是"全局视野"。

1.3 为什么纯 Transformer 之前不成功

在 ViT 之前，将 Transformer 直接用于图像面临两大挑战：

挑战说明ViT 的解决方案
序列长度爆炸$224 \times 224$ 图像展平为 $50176$ 个像素，自注意力复杂度 $O(N^2)$ 无法承受切成 $16 \times 16$ 图块，序列长度降至 $196$
缺乏归纳偏置CNN 自带局部性和平移不变性先验，Transformer 无先验需大量数据学习在大数据集（JFT-300M）上预训练

2图像分块与线性嵌入

2.1 分块操作

ViT 的第一步是将输入图像 $\mathbf{x} \in \mathbb{R}^{H \times W \times C}$ 切分为 $N$ 个不重叠的图块。设定图块大小为 $P \times P$，则图块数量为：

$$N = \frac{H \times W}{P^2}$$

对于标准 ImageNet 输入 $H = W = 224$，图块大小 $P = 16$，则 $N = 196$。每个图块展平后得到维度 $P^2 \cdot C = 16 \times 16 \times 3 = 768$ 的向量。

2.2 线性投影嵌入

展平后的图块向量通过一个可训练的线性投影映射到 $D$ 维嵌入空间（$D$ 即 Transformer 的隐藏维度，通常 $D = 768$）：

$$\mathbf{z}_i = \mathbf{x}_i^{(p)} \mathbf{E} + \mathbf{e}_{pos}^i, \quad i = 1, \ldots, N$$

其中 $\mathbf{E} \in \mathbb{R}^{(P^2 C) \times D}$ 为投影矩阵（等价于一个 $P \times P$ 卷积核的卷积层），$\mathbf{e}_{pos}^i \in \mathbb{R}^D$ 为位置编码。

分块投影 = 卷积

将 $P \times P$ 的分块展平后做线性投影，在数学上等价于用 stride $= P$、kernel size $= P$ 的卷积层处理原图。PyTorch 实现中通常直接用 nn.Conv2d(C, D, kernel_size=P, stride=P) 一步完成分块+投影。

2.3 CLS Token

ViT 借鉴 BERT 的做法，在序列开头插入一个可学习的特殊 Token $\mathbf{x}_{class}$（CLS Token）。它的初始值是随机初始化的参数，通过 Transformer 后其最终状态 $\mathbf{z}_L^0$ 被用作分类特征：

$$\mathbf{Z}_0 = [\mathbf{x}_{class}; \mathbf{z}_1; \mathbf{z}_2; \cdots; \mathbf{z}_N] + \mathbf{E}_{pos}$$

其中 $\mathbf{Z}_0 \in \mathbb{R}^{(N+1) \times D}$，$\mathbf{E}_{pos} \in \mathbb{R}^{(N+1) \times D}$ 为位置编码矩阵。CLS Token 的优势在于让网络自主学习最优的全局表示，而非依赖固定位置的池化操作。

3位置编码

3.1 为什么需要位置编码

Transformer 的自注意力机制本身是排列等变的——打乱输入顺序不会改变输出（只是重排输出）。这意味着没有位置编码的 ViT 会将"猫在左、狗在右"和"狗在左、猫在右"视为完全相同的输入。位置编码为每个图块注入位置信息，使模型能够区分空间布局。

3.2 可学习 vs 正弦余弦编码

ViT 原论文使用可学习的 1D 位置编码 $\mathbf{E}_{pos} \in \mathbb{R}^{(N+1) \times D}$，每个位置一个 $D$ 维向量作为参数训练。这与原始 Transformer 的正弦-余弦编码不同：

$$\text{SinPos}(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/D}}\right), \quad \text{SinPos}(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/D}}\right)$$

实验表明，可学习编码和正弦-余弦编码在 ViT 上效果差异不大，可学习编码略好。DeiT 等后续工作沿用了可学习编码。

3.3 2D 位置编码

1D 编码直接按图块的线性序号编码位置，忽略了图块的 2D 空间结构。一种改进方案是2D 位置编码，将行和列的位置分开编码：

$$\mathbf{e}_{pos}^{i,j} = [\mathbf{e}_r^i; \mathbf{e}_c^j], \quad i \in [0, \sqrt{N}), \quad j \in [0, \sqrt{N})$$

其中 $\mathbf{e}_r^i \in \mathbb{R}^{D/2}$ 为行编码，$\mathbf{e}_c^j \in \mathbb{R}^{D/2}$ 为列编码。但实验表明 1D 可学习编码已足够捕捉空间信息，2D 编码的提升很小。

3.4 相对位置编码

Swin Transformer 使用相对位置偏置（Relative Position Bias），注意力分数不仅取决于内容还取决于图块间的相对距离：

$$\text{Attn}(Q, K) = \text{Softmax}\left(\frac{Q K^\top}{\sqrt{d_k}} + B\right) V$$

其中 $B$ 为相对位置偏置矩阵，取决于 Query 和 Key 的相对位置 $(i-j)$。相对位置编码在密集预测任务（检测、分割）中表现更好。

4多头自注意力

4.1 自注意力机制

自注意力（Self-Attention）是 Transformer 的核心。对于输入序列 $\mathbf{Z} \in \mathbb{R}^{N \times D}$，通过三个权重矩阵将其映射为 Query、Key、Value：

$$Q = \mathbf{Z}\mathbf{W}^Q, \quad K = \mathbf{Z}\mathbf{W}^K, \quad V = \mathbf{Z}\mathbf{W}^V$$

其中 $\mathbf{W}^Q, \mathbf{W}^K \in \mathbb{R}^{D \times d_k}$，$\mathbf{W}^V \in \mathbb{R}^{D \times d_v}$。注意力计算为：

$$\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V$$

其中 $\sqrt{d_k}$ 为缩放因子，防止点积过大导致 Softmax 饱和。$Q K^\top \in \mathbb{R}^{N \times N}$ 为注意力矩阵，表示每个图块对所有图块的关注程度。

全局感受野

与 CNN 的局部卷积不同，自注意力的 $Q K^\top$ 计算让每个图块能直接与所有其他图块交互——第一层就是全局感受野。这是 ViT 和 CNN 的本质区别：CNN 通过逐层堆叠逐步扩大感受野，ViT 从一开始就拥有全局视野。

4.2 多头注意力

多头注意力（Multi-Head Attention, MHA）将注意力 computation 分配到 $h$ 个头并行计算，每个头关注不同的表示子空间：

$$\text{head}_j = \text{Attention}(Q \mathbf{W}_j^Q, K \mathbf{W}_j^K, V \mathbf{W}_j^V), \quad j = 1, \ldots, h$$
$$\text{MHA}(\mathbf{Z}) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) \mathbf{W}^O$$

其中每个头的维度 $d_k = d_v = D / h$。ViT-Base 使用 $h = 12$ 头，$D = 768$，每个头维度 $64$。

4.3 注意力矩阵可视化

注意力矩阵 $A = \text{Softmax}(QK^\top / \sqrt{d_k}) \in \mathbb{R}^{N \times N}$ 的每一行表示一个图块对所有图块的关注分布。ViT 的注意力呈现以下特点：

  • 浅层：注意力集中在局部邻域，类似 CNN 的局部卷积
  • 深层：注意力扩散到全局，捕捉长距离语义依赖
  • CLS Token：深层注意力覆盖整幅图像，形成全局表示
图 3：多头自注意力 — 输入映射为 Q/K/V 后分成多头并行计算注意力，拼接后线性投影输出

4.4 计算复杂度分析

自注意力的计算复杂度为 $O(N^2 \cdot D)$，其中 $N$ 为序列长度。对于 ViT-Base 的 $N = 197$（含 CLS Token）和 $D = 768$，计算量完全可控。但如果直接用像素级序列（$N = 50176$），复杂度将爆炸。这就是分块策略是 ViT 成功的关键前提。

5Transformer Encoder

ViT 的主体由 $L$ 个 Transformer Encoder 层堆叠而成。每层包含两个子层：多头自注意力（MSA）和前馈网络（FFN），都带有残差连接和 LayerNorm。

5.1 单层结构

$$\mathbf{Z}'_\ell = \text{MSA}(\text{LN}(\mathbf{Z}_{\ell-1})) + \mathbf{Z}_{\ell-1}$$
$$\mathbf{Z}_\ell = \text{FFN}(\text{LN}(\mathbf{Z}'_\ell)) + \mathbf{Z}'_\ell$$

其中 $\text{LN}(\cdot)$ 为 Layer Normalization，$\text{MSA}(\cdot)$ 为多头自注意力，$\text{FFN}(\cdot)$ 为前馈网络。注意 ViT 使用 Pre-LN 结构（LayerNorm 在子层之前），比原始 Transformer 的 Post-LN 更稳定。

5.2 前馈网络（FFN）

FFN 是一个两层 MLP，对每个位置独立施加非线性变换：

$$\text{FFN}(\mathbf{x}) = \text{GELU}(\mathbf{x}\mathbf{W}_1 + \mathbf{b}_1)\mathbf{W}_2 + \mathbf{b}_2$$

其中 $\mathbf{W}_1 \in \mathbb{R}^{D \times D_{ff}}$，$\mathbf{W}_2 \in \mathbb{R}^{D_{ff} \times D}$。ViT 中 $D_{ff} = 4D$（如 $D = 768$ 时 $D_{ff} = 3072$）。FFN 是 ViT 参数量的主要来源——约占总参数的 $2/3$。

5.3 LayerNorm vs BatchNorm

ViT 使用 LayerNorm 而非 BatchNorm。LayerNorm 对每个样本独立归一化，不依赖批次统计量，因此在批次大小较小时更稳定。LayerNorm 也更适合变长序列和自回归推理。

$$\text{LN}(\mathbf{x}) = \gamma \cdot \frac{\mathbf{x} - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta$$

其中 $\mu, \sigma^2$ 在特征维度上计算，$\gamma, \beta$ 为可学习参数。

5.4 残差连接

每个子层都有一条残差连接（skip connection），将输入直接加到输出上。残差连接对深层 Transformer 的训练至关重要——它提供了梯度直接传播的路径，防止梯度消失。

6分类头与训练策略

6.1 CLS Token 分类

ViT 取 Transformer Encoder 最后一层输出的 CLS Token 状态 $\mathbf{z}_L^0$ 作为全局图像表示，通过一个线性分类头输出类别 logits：

$$\hat{y} = \text{Softmax}(\text{LN}(\mathbf{z}_L^0) \cdot \mathbf{W}_{cls})$$

其中 $\mathbf{W}_{cls} \in \mathbb{R}^{D \times K}$，$K$ 为类别数。在预训练阶段，分类头通过 MLP 实现；微调时替换为线性层。

6.2 全局平均池化替代方案

除了 CLS Token，也可以使用全局平均池化（GAP）——对所有图块 Token 的最终表示取平均作为全局特征。实验表明，两者效果差异很小。GAP 无需额外 Token，但 CLS Token 的优势在于可学习的自适应聚合权重。

6.3 预训练-微调范式

ViT 的训练采用大规模预训练 + 下游微调的两阶段范式：

  • 预训练：在大数据集（JFT-300M / ImageNet-21k）上训练分类任务，学习通用视觉表示
  • 微调：在目标数据集（如 ImageNet-1K）上微调，移除预训练分类头，添加新的线性分类头
数据饥饿

ViT 没有卷积的归纳偏置（局部性、平移不变性），因此需要更多数据来学习这些先验。在 ImageNet-1K（1.2M 图像）上从头训练，ViT 不如 ResNet。但在 JFT-300M（300M 图像）上预训练后，ViT 全面超越 CNN。这就是 ViT "大数据吃一切"的特性。

6.4 高分辨率微调

ViT 预训练通常在 $224 \times 224$ 分辨率上进行。微调时可以使用更高分辨率（如 $384 \times 384$ 或 $512 \times 512$）以提升性能。由于图块大小 $P$ 固定，更高分辨率意味着更多图块（更长的序列），但位置编码需要插值：

$$\mathbf{E}_{pos}^{new} = \text{Interpolate}(\mathbf{E}_{pos}^{old}, N_{new})$$

通常使用双线性插值将 $197 \times D$ 的位置编码插值到 $(N_{new}+1) \times D$。这种插值是有效的，因为可学习位置编码具有平滑的 2D 结构。

7ViT 的数学描述

7.1 完整前向传播

将 ViT 的全部组件串联起来，完整前向传播如下：

$$\mathbf{Z}_0 = [\mathbf{x}_{class}; \mathbf{x}_1^{(p)}\mathbf{E}; \cdots; \mathbf{x}_N^{(p)}\mathbf{E}] + \mathbf{E}_{pos}$$
$$\mathbf{Z}'_\ell = \text{MSA}(\text{LN}(\mathbf{Z}_{\ell-1})) + \mathbf{Z}_{\ell-1}, \quad \ell = 1, \ldots, L$$
$$\mathbf{Z}_\ell = \text{FFN}(\text{LN}(\mathbf{Z}'_\ell)) + \mathbf{Z}'_\ell, \quad \ell = 1, \ldots, L$$
$$\hat{y} = \text{Softmax}(\text{LN}(\mathbf{z}_L^0)\mathbf{W}_{cls})$$

7.2 参数量分析

ViT 的参数量约 $2/3$ 来自 FFN，$1/3$ 来自 MSA。这与 NLP Transformer 的分布一致。FFN 的作用是在注意力聚合后进行非线性变换——它存储了模型的"知识"。

7.3 计算量分析

单层 Encoder 的 FLOPs（$N$ 为序列长度，$D$ 为隐藏维度）：

$$\text{FLOPs}_{\text{MSA}} = 4ND^2 + 2N^2D, \quad \text{FLOPs}_{\text{FFN}} = 8ND^2$$

当 $N = 197, D = 768$ 时：MSA 约 $0.59$G FLOPs，FFN 约 $1.18$G FLOPs（不含 LN 和残差）。FFN 的计算量是 MSA 的约 $2$ 倍。

8ViT vs CNN：归纳偏置之争

ViT 与 CNN 的核心争论聚焦于一个概念：归纳偏置（Inductive Bias）——模型架构中内嵌的先验假设。CNN 自带两种强归纳偏置：局部性（每个神经元只看局部区域）和平移等变性（特征不随位置改变）。ViT 几乎完全抛弃了这些先验，让模型从数据中自行学习空间关系。

8.1 归纳偏置对比

维度CNNViT

平移等变性强：权值共享保证平移不变弱：需通过数据增强学习
层级结构显式：池化层逐级下采样隐式：所有层在同一分辨率
感受野局部 → 全局（逐层扩大）全局（第一层即全局）

8.2 数据量是关键变量

ViT 论文中一个关键发现：在 ImageNet-1K（130万张）上从头训练时，ViT-Base 不如 ResNet；但在 JFT-300M（3 亿张）上预训练后，ViT-Base 超越所有 CNN。这说明：

  • 小数据：CNN 的归纳偏置是优势——先验帮助泛化，防止过拟合
  • 大数据：归纳偏置变为瓶颈——先验限制了模型容量，数据足以学习更优模式
直觉类比

CNN 像一个受过专业训练的侦探——自带一套方法论（局部先验），在小案件（小数据）中高效破案。ViT 像一个白纸天才——没有方法论，但看过海量案例（大数据）后能发现侦探看不到的规律。案件少时侦探赢，案件多时天才赢。

8.3 注意力距离的演化

ViT 论文分析了不同层中注意力所覆盖的空间距离。发现一个有趣的规律：

层位置注意力模式类比
浅层（1-5 层）主要 attend 局部邻域，部分 attend 全局像 CNN 的低层特征
中层（6-9 层）混合局部与全局注意力多尺度特征融合
深层（10-12 层）全局注意力占主导语义级全局推理

这表明 ViT 虽然"第一层即全局"，但模型自行学习出了类似 CNN 的"局部→全局"层级结构——归纳偏置是涌现的，而非强制的。

10.1 ViT 家族主要变体

ViT 发布后衍生出大量改进变体，以下是最具影响力的：

10.2 DeiT：让 ViT 摆脱大数据依赖

DeiT（Data-efficient Image Transformers）解决了 ViT 最大的痛点——需要 JFT-300M 级别数据。其核心策略：

  • 强数据增强：RandAugment + Mixup + CutMix + Random Erasing
  • 知识蒸馏：用 RegNet 作为教师网络，向 ViT 传递 CNN 的局部先验
  • 硬蒸馏：直接使用教师的硬标签（而非软标签），效果更好

结果：DeiT-Base 仅用 ImageNet-1K 就达到了 81.8% top-1，与 JFT-300M 预训练的 ViT-Base 持平。

DeiT 的启示

DeiT 证明：通过知识蒸馏，可以将 CNN 的归纳偏置"注入"ViT，从而在小数据上获得 ViT 的架构优势 + CNN 的数据效率。这一思路开创了"CNN 教师 + Transformer 学生"的范式。

10.3 MAE：自监督预训练新范式

MAE（Masked Autoencoder）将 BERT 式掩码预训练引入视觉：

  • 高掩码比例：随机遮挡 75% 的图块（BERT 只遮 15%）
  • 非对称架构：编码器只处理可见图块（25%），解码器处理全部
  • 重建目标：预测被遮挡图块的原始像素值
$$\mathcal{L}_{\text{MAE}} = \frac{1}{|\mathcal{M}|} \sum_{i \in \mathcal{M}} \| \hat{\mathbf{x}}_i - \mathbf{x}_i \|^2$$

其中 $\mathcal{M}$ 为被遮挡图块集合，$\hat{\mathbf{x}}_i$ 为重建预测。MAE 预训练的 ViT-Base 在 ImageNet 上达到 83.6% top-1，远超有监督预训练的 82.3%。

11.1 Patch Embedding

分块嵌入的核心是利用卷积一步完成分块 + 线性投影：

vit_code.py
import torch
import torch.nn as nn

class PatchEmbedding(nn.Module):
    """将图像分割为图块并线性投影到 D 维"""
    def __init__(self, img_size=224, patch_size=16, in_channels=3, embed_dim=768):
        super().__init__()
        self.num_patches = (img_size // patch_size) ** 2  # 196
        # 卷积分块等价于展平+线性投影
        self.proj = nn.Conv2d(
            in_channels, embed_dim,
            kernel_size=patch_size, stride=patch_size
        )

    def forward(self, x):
        # x: (B, C, H, W) -> (B, num_patches, embed_dim)
        x = self.proj(x)               # (B, D, H/P, W/P)
        x = x.flatten(2)               # (B, D, num_patches)
        x = x.transpose(1, 2)          # (B, num_patches, D)
        return x

11.2 多头自注意力

vit_code.py
class MultiHeadSelfAttention(nn.Module):
    """标准多头自注意力"""
    def __init__(self, dim=768, num_heads=12, qkv_bias=True, attn_drop=0., proj_drop=0.):
        super().__init__()
        assert dim % num_heads == 0
        self.num_heads = num_heads
        self.head_dim = dim // num_heads
        self.scale = self.head_dim ** -0.5

        # QKV 合并为一个线性层（高效实现）
        self.qkv = nn.Linear(dim, dim * 3, bias=qkv_bias)
        self.attn_drop = nn.Dropout(attn_drop)
        self.proj = nn.Linear(dim, dim)
        self.proj_drop = nn.Dropout(proj_drop)

    def forward(self, x):
        B, N, D = x.shape
        # (B, N, D) -> (B, N, 3D) -> (B, N, 3, h, d) -> (3, B, h, N, d)
        qkv = self.qkv(x).reshape(B, N, 3, self.num_heads, self.head_dim)
        qkv = qkv.permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]

        # 注意力: (B, h, N, d) @ (B, h, d, N) -> (B, h, N, N)
        attn = (q @ k.transpose(-2, -1)) * self.scale
        attn = attn.softmax(dim=-1)
        attn = self.attn_drop(attn)

        # (B, h, N, N) @ (B, h, N, d) -> (B, h, N, d) -> (B, N, D)
        x = (attn @ v).transpose(1, 2).reshape(B, N, D)
        x = self.proj_drop(self.proj(x))
        return x

11.3 Transformer Encoder Block

vit_code.py
class TransformerBlock(nn.Module):
    """Pre-LN Transformer Encoder Block"""
    def __init__(self, dim=768, num_heads=12, mlp_ratio=4.0, drop=0.):
        super().__init__()
        self.norm1 = nn.LayerNorm(dim)
        self.attn = MultiHeadSelfAttention(dim, num_heads, attn_drop=drop, proj_drop=drop)
        self.norm2 = nn.LayerNorm(dim)
        self.mlp = nn.Sequential(
            nn.Linear(dim, int(dim * mlp_ratio)),
            nn.GELU(),
            nn.Dropout(drop),
            nn.Linear(int(dim * mlp_ratio), dim),
            nn.Dropout(drop),
        )

    def forward(self, x):
        # Pre-LN: LN -> Attn -> Add
        x = x + self.attn(self.norm1(x))
        # Pre-LN: LN -> FFN -> Add
        x = x + self.mlp(self.norm2(x))
        return x

11.4 完整 ViT 模型

vit_code.py
class VisionTransformer(nn.Module):
    """完整 ViT 分类模型"""
    def __init__(self, img_size=224, patch_size=16, in_ch=3,
                 num_classes=1000, embed_dim=768, depth=12,
                 num_heads=12, mlp_ratio=4.0, drop=0.):
        super().__init__()
        self.patch_embed = PatchEmbedding(img_size, patch_size, in_ch, embed_dim)
        num_patches = self.patch_embed.num_patches

        # CLS Token (可学习参数)
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        # 位置编码 (可学习参数)
        self.pos_embed = nn.Parameter(torch.zeros(1, num_patches + 1, embed_dim))
        self.pos_drop = nn.Dropout(drop)

        # Transformer Encoder: 堆叠 L 层
        self.blocks = nn.ModuleList([
            TransformerBlock(embed_dim, num_heads, mlp_ratio, drop)
            for _ in range(depth)
        ])
        self.norm = nn.LayerNorm(embed_dim)

        # 分类头
        self.head = nn.Linear(embed_dim, num_classes)

        # 初始化
        nn.init.trunc_normal_(self.pos_embed, std=0.02)
        nn.init.trunc_normal_(self.cls_token, std=0.02)

    def forward(self, x):
        B = x.shape[0]

        # 1. 分块嵌入: (B, C, H, W) -> (B, N, D)
        x = self.patch_embed(x)

        # 2. 插入 CLS Token
        cls = self.cls_token.expand(B, -1, -1)  # (B, 1, D)
        x = torch.cat([cls, x], dim=1)           # (B, N+1, D)

        # 3. 加位置编码
        x = self.pos_drop(x + self.pos_embed)

        # 4. Transformer Encoder
        for blk in self.blocks:
            x = blk(x)
        x = self.norm(x)

        # 5. CLS Token -> 分类
        cls_out = x[:, 0]           # (B, D)
        return self.head(cls_out)   # (B, num_classes)

11.6 训练循环

vit_code.py
def train_vit(model, train_loader, epochs=300, lr=1e-4, weight_decay=0.3):
    """ViT 训练循环 (DeiT 风格超参)"""
    optimizer = torch.optim.AdamW(
        model.parameters(), lr=lr, weight_decay=weight_decay
    )
    # 余弦退火 + 线性 warmup
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
        optimizer, T_max=epochs, eta_min=1e-6
    )
    criterion = nn.CrossEntropyLoss()

    model.train()
    for epoch in range(epochs):
        for images, labels in train_loader:
            # Mixup 数据增强
            lam = np.random.beta(0.2, 0.2)
            idx = torch.randperm(images.size(0))
            mixed_x = lam * images + (1 - lam) * images[idx]
            labels_a, labels_b = labels, labels[idx]

            logits = model(mixed_x)
            loss = lam * criterion(logits, labels_a) + (1 - lam) * criterion(logits, labels_b)

            optimizer.zero_grad()
            loss.backward()
            # 梯度裁剪 (ViT 训练稳定性)
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            optimizer.step()

        scheduler.step()
        print(f"Epoch {epoch+1}/{epochs}, Loss: {loss.item():.4f}")

12Swin Transformer 与窗口注意力

12.1 标准 ViT 的复杂度困境

标准 ViT 的自注意力复杂度为 $O(N^2)$。当图像分辨率增大或图块变小时，序列长度 $N$ 急剧增长：

$$\text{FLOPs}_{\text{MSA}} = 4ND^2 + 2N^2D$$

当 $N = 196$（$224 \times 224$）时尚可接受，但若做密集预测（目标检测、分割）需要更高分辨率特征图（如 $224 \times 224$ 时 $N = 196$，$448 \times 448$ 时 $N = 784$），$N^2$ 项成为瓶颈。

12.2 Swin 的核心创新：窗口注意力

Swin Transformer（ICCV 2021 最佳论文）通过两个关键设计将复杂度降为线性：

设计说明效果
窗口注意力 (W-MSA)在局部 $M \times M$ 窗口内计算注意力$O(N \cdot M^2)$，线性于 $N$
移位窗口 (SW-MSA)相邻层窗口偏移半个窗口跨窗口信息流动
层级结构逐阶段合并 $2 \times 2$ 相邻图块多尺度特征（类似 CNN 金字塔）
$$\text{FLOPs}_{\text{W-MSA}} = 4M^2 D^2 + 2M^4 D, \quad \text{FLOPs}_{\text{SW-MSA}} = O(N \cdot M^2 D)$$

其中 $M$ 为窗口大小（通常 $M = 7$），$N$ 为总图块数。窗口注意力使复杂度从 $O(N^2)$ 降为 $O(N)$。

Swin 的定位

Swin Transformer 是 ViT 与 CNN 的折中——保留 Transformer 的全局建模能力，同时引入窗口局部性和层级结构，使其既能高效处理高分辨率图像，又能生成多尺度特征图。这使得 Transformer 首次在目标检测和语义分割任务上超越 CNN。
