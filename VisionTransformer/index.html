1引言：视觉 Transformer 要解决什么问题

1.1 卷积时代的"归纳偏置红利"

2020 年之前，视觉骨干网络几乎被卷积神经网络（CNN）垄断：AlexNet（2012）→ VGG（2014）→ ResNet（2015）→ EfficientNet（2019）。CNN 的优势不只来自算力与数据，更来自它内置的归纳偏置（inductive bias）：局部性假设相邻像素高度相关，因此卷积核只看小邻域；平移等变假设同一模式出现在图像任何位置都应当被同等识别，因此权重在所有空间位置共享。

这两条假设与自然图像的统计规律高度吻合，带来两个直接好处：参数极少（卷积核与图像尺寸无关），且在小数据上也能有效学习。代价是模型被"锁"在局部、平移等变的框架里——长距离依赖需要靠堆层数逐级扩大感受野，而"把整张图当作一个整体来推理"这类需求表达起来很别扭。

1.2 Transformer 跨界的两个具体障碍

Transformer 在 NLP 上取代 RNN 之后，一个自然的问题浮现：去掉卷积、只用注意力，能否做视觉？ 直接移植会撞上两个障碍，它们决定了后续所有工作的技术路线。

  • 序列长度带来的二次复杂度：自注意力的计算量是 $O(n^2)$（$n$ 为 token 数）。NLP 中一句话不过数百 token；若按像素建模，$224 \times 224$ 的图像就是 50176 个 token，注意力矩阵元素数达 $2.5\times 10^9$，显存与算力都无法承受。因此如何把图像"变短"成为第一个核心问题。
  • 缺少空间先验，必须从数据中学回来：注意力对输入是置换等变的——打乱 token 顺序，输出只会跟着打乱，模型本身没有"上下左右"的概念。CNN 免费获得的空间结构，Transformer 只能通过位置编码显式注入，其余部分要靠数据拟合。

1.3 主线：四条并行的技术路线

ViT 给出的答案很干脆：把图像切成 $16\times16$ 的块（patch），每块拉平成"一个词"，序列长度立刻从 5 万降到 $196$。归纳偏置则不注入，改用大规模数据让模型自行学习。由此展开四条路线，本模块按此顺序推进：

2ViT：把图像变成序列

2.1 动机：一次"用数据换先验"的赌注

ViT 的核心判断是：CNN 的归纳偏置不是必需的，只是数据不足时的替代品。作者的原话大意是——当数据规模足够大时，模型不需要人工注入局部性与平移等变，它完全可以从数据中学会这些规律，甚至学得更好、更一般。这个判断把研究问题从"如何设计更好的视觉专用结构"改成了"能否用通用架构 + 更多数据达到同等效果"。

因此 ViT 的论文最重要的不是架构本身（它几乎是 Transformer 编码器的原样搬用），而是那个对照结论：在 ImageNet-1k 上单独训练，ViT 不如同规模的 ResNet；但在 JFT-300M 上预训练后，ViT 反超，且数据越多优势越大。这解释了为什么 ViT 明确把自己的适用场景限定为"大规模预训练 + 下游微调"。

2.2 图像即序列：Patch Embedding

把图像 $\mathbf{x} \in \mathbb{R}^{H \times W \times C}$ 划分为 $N$ 个大小为 $P \times P$ 的不重叠块，$N = HW/P^2$。每块展平为长度 $P^2C$ 的向量，再经可学习的线性映射压缩到模型维度 $D$：

$$\mathbf{x}_p^i \in \mathbb{R}^{P^{2}C}, \qquad N = \frac{HW}{P^{2}}, \qquad \mathbf{x}_p^i E \in \mathbb{R}^{D}, \quad E \in \mathbb{R}^{P^{2}C \times D}$$

以 $224\times224\times3$、$P=16$ 为例：$N = 196$，序列长度 196，比逐像素建模缩短了 256 倍。这一步在实现上等价于一个 kernel_size=16, stride=16 的卷积——ViT 的第一层其实就是卷积，只是之后再无卷积。这是理解 ViT 的一个实用要点：它并非"完全没有卷积"，而是把卷积压缩成一次性的分块嵌入。

2.3 CLS Token 与位置编码

在序列开头拼接一个可学习的向量 $\mathbf{x}_{\text{class}}$，它的作用类似 BERT 的 [CLS]：不与任何图像块对应，只负责在多层注意力中汇聚全局信息，最终用它的输出做分类。同时为 197 个位置各加一个可学习的位置编码，恢复空间顺序：

$$\mathbf{z}_0 = \big[\,\mathbf{x}_{\text{class}};\; \mathbf{x}_p^1 E;\; \mathbf{x}_p^2 E;\; \dots;\; \mathbf{x}_p^{N} E\,\big] + E_{\text{pos}}, \qquad E_{\text{pos}} \in \mathbb{R}^{(N+1)\times D}$$

ViT 的实验表明位置编码取可学习的一维编码与人工设计的正弦余弦编码效果接近，因此选择了实现更简单的前者。注意这里的编码是 1D 的——模型并不知道 patch 的二维排布，只是被告知"你在序列里的第几位"。2D 感知完全依赖于 $P \times P$ 图像块内部的像素结构。

2.4 Transformer Encoder：Pre-LN 结构

ViT 堆叠 $L$ 个结构相同的编码器层。每个含两个子层——多头自注意力（MSA）与前馈网络（MLP），均采用前置层归一化（Pre-LN）与残差连接：

$$\mathbf{z}'_\ell = \text{MSA}\big(\text{LN}(\mathbf{z}_{\ell-1})\big) + \mathbf{z}_{\ell-1}, \qquad \mathbf{z}_\ell = \text{MLP}\big(\text{LN}(\mathbf{z}'_\ell)\big) + \mathbf{z}'_\ell$$

其中多头注意力是 $h$ 个单头注意力的拼接后线性变换：

$$\text{MSA}(\mathbf{z}) = \big[\,\text{head}_1; \dots; \text{head}_h\,\big]W^{O}, \qquad \text{head}_i = \text{Attn}\big(\mathbf{z}W_i^{Q},\, \mathbf{z}W_i^{K},\, \mathbf{z}W_i^{V}\big)$$
$$\text{Attn}(Q,K,V) = \text{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V$$

前馈网络对每个 token 独立作用，先升维到 $4D$、再降回 $D$：

$$\text{MLP}(\mathbf{u}) = \text{GELU}(\mathbf{u}W_1 + b_1)\,W_2 + b_2, \qquad W_1 \in \mathbb{R}^{D \times 4D},\; W_2 \in \mathbb{R}^{4D \times D}$$
为什么用 Pre-LN 而不是原始 Transformer 的 Post-LN

原始 Transformer 用 Post-LN：$\mathbf{z}_\ell = \text{LN}(\text{MSA}(\mathbf{z}_{\ell-1}) + \mathbf{z}_{\ell-1})$。Post-LN 把归一化放在残差相加之后，梯度要穿过归一化层才能回传到主干，深层时容易不稳定，通常需要学习率预热。ViT 采用 Pre-LN 后无需预热即可训练到 32 层以上，这是它"能往深了堆"的前提之一。代价是最终特征需要额外做一次 LN，公式 (7) 中的 $\text{LN}$ 正是为此。

2.5 完整前向传播

经过 $L$ 层编码后，只取 [CLS] 位置的输出，经 LN 与线性分类头得到预测：

$$\mathbf{y} = \text{softmax}\Big( \text{LN}\big(\mathbf{z}_L^{0}\big)\,W_{\text{head}} + b_{\text{head}} \Big)$$

分类也可以改用全部 token 的全局平均池化（GAP），两者效果相当。ViT 作者选择 CLS token 既是沿用 BERT 习惯，也是因为它在自监督与多任务中更易复用；而后续不少工作（尤其是密集预测任务）会去掉 CLS、直接对 patch token 做池化或上采样。

2.6 归纳偏置的代价：为什么小数据不如 CNN

这是 ViT 最值得记住的结论。ViT 缺少 CNN 的两条空间先验，于是它必须从数据中把"局部性"和"平移等变"学回来。小数据下这个过程学不充分，模型只能退而记住训练集的表面统计，泛化差；大数据下学到的是更一般的规律，反而超过人工设计的偏置。

2.7 高分辨率微调

预训练用 $224\times224$ 得到 $N=196$ 个位置编码，下游若换成更大分辨率（如 $384$、$512$），patch 数 $N'$ 会变化，位置编码数量不匹配。ViT 的做法是对预训练的位置编码做二维插值，而非从头初始化——因为从头学需要额外大量数据，会浪费预训练成果：

$$E'_{\text{pos}} = \text{Interp}_{2\text{D}}\big(E_{\text{pos}},\, \tfrac{H'}{P} \times \tfrac{W'}{P}\big)$$

实践中把预训练编码按原始的 $14\times14$ 网格还原、双三次插值到 $24\times24$（对应 384）或 $32\times32$（对应 512），再展平。这个细节看似琐碎，却是 ViT 能跨分辨率复用的关键——否则每换一次输入尺寸都要重训。

2.8 参数量与计算量

设模型维度 $D$、层数 $L$、token 数 $N$。主要计算量集中在两处：自注意力 $O(N^2D)$ 来自 $N\times N$ 的注意力矩阵；线性投影 $O(ND^2)$ 来自 $Q,K,V$ 与 MLP。当 $N \gg D$ 时第一项主导——这正是 Swin 要解决的问题：

$$\text{FLOPs} \approx \underbrace{4ND^{2}}_{\text{QKV 与输出投影}} + \underbrace{2N^{2}D}_{\text{注意力矩阵}} + \underbrace{8ND^{2}}_{\text{MLP}}$$

参数量主要落在 MLP 与投影矩阵上，与 $N$ 无关，因此 ViT-Base（$D=768,L=12$）约 86M 参数，与 ResNet-50（25M）相比更重——但有归纳偏置的 ResNet 用更少参数就能达到相近的 ImageNet-1k 精度，这又回到了 2.6 节的"数据换先验"。

2.9 PyTorch 实现

vit.py — Patch Embedding 与编码器块
import torch
import torch.nn as nn

class PatchEmbed(nn.Module):
    """把 (B,3,H,W) 切成 patch 并线性投影到 D 维"""
    def __init__(self, img_size=224, patch_size=16, in_chans=3, embed_dim=768):
        super().__init__()
        self.num_patches = (img_size // patch_size) ** 2
        # 等价于 kernel=stride=patch_size 的卷积，无重叠、无 padding
        self.proj = nn.Conv2d(in_chans, embed_dim, kernel_size=patch_size, stride=patch_size)

    def forward(self, x):
        x = self.proj(x)                       # (B, D, 14, 14)
        x = x.flatten(2).transpose(1, 2)       # (B, 196, D)
        return x

class Block(nn.Module):
    """Pre-LN 编码器块：LN -> MSA -> 残差 -> LN -> MLP -> 残差"""
    def __init__(self, dim, num_heads, mlp_ratio=4., drop_path=0.):
        super().__init__()
        self.norm1 = nn.LayerNorm(dim)
        self.attn  = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        self.norm2 = nn.LayerNorm(dim)
        hidden = int(dim * mlp_ratio)
        self.mlp = nn.Sequential(
            nn.Linear(dim, hidden), nn.GELU(), nn.Linear(hidden, dim)
        )
        self.drop_path = drop_path

    def forward(self, x):
        # Pre-LN：先归一化再进子层，梯度主干不被归一化阻断
        h = self.norm1(x)
        h, _ = self.attn(h, h, h)              # 自注意力，Q=K=V
        x = x + h
        x = x + self.mlp(self.norm2(x))
        return x

class ViT(nn.Module):
    def __init__(self, img_size=224, patch_size=16, num_classes=1000,
                 dim=768, depth=12, heads=12):
        super().__init__()
        self.patch_embed = PatchEmbed(img_size, patch_size, 3, dim)
        n = self.patch_embed.num_patches
        # CLS token 与位置编码都是可学习参数
        self.cls_token = nn.Parameter(torch.zeros(1, 1, dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, n + 1, dim))
        self.blocks = nn.Sequential(*[Block(dim, heads) for _ in range(depth)])
        self.norm = nn.LayerNorm(dim)
        self.head = nn.Linear(dim, num_classes)

    def forward(self, x):
        B = x.shape[0]
        x = self.patch_embed(x)                       # (B, 196, D)
        cls = self.cls_token.expand(B, -1, -1)        # (B, 1, D)
        x = torch.cat([cls, x], dim=1) + self.pos_embed  # (B, 197, D)
        x = self.blocks(x)
        return self.head(self.norm(x)[:, 0])       # 只取 CLS 位置

3Swin：层次化与窗口注意力

3.1 动机：ViT 的两个结构性缺陷

ViT 证明了纯注意力可行，但要当"通用视觉骨干"还有两处硬伤，它们不是调参能解决的：

  • 单一尺度，无法做密集预测。ViT 全程保持 $14\times14$ 的特征图分辨率，只有 $1/16$ 这一种尺度。而目标检测、语义分割、实例分割都需要多尺度特征金字塔（FPN 之所以有效正是基于此）。ViT 缺少高分辨率层级，直接接检测头效果不佳。
  • 全局注意力的二次复杂度。每个 token 都要与其余所有 token 计算注意力，$O(N^2)$ 使其在高分辨率输入（如 $1024\times1024$ 的分割任务）下代价急剧上升。而视觉任务恰恰对分辨率极其敏感。

Swin 的作者把这两点挑明后给出方案：让注意力只在局部窗口内进行，再让窗口"错位"以交换跨窗口信息；同时像 CNN 那样逐级下采样，构建层次化表示。这两条设计分别解决了复杂度与多尺度。

3.2 窗口注意力（W-MSA）

把特征图划分为不重叠的 $M \times M$ 窗口（默认 $M=7$），自注意力只在每个窗口内部计算。窗口内 token 数恒为 $M^2$，与图像大小无关。设特征图有 $h \times w$ 个 token、通道数为 $C$，两种做法的复杂度对比：

$$\Omega(\text{MSA}) = 4hwC^{2} + 2(hw)^{2}C, \qquad \Omega(\text{W-MSA}) = 4hwC^{2} + 2M^{2}hwC$$

两式第一项相同（QKV 投影），差别全在第二项：全局注意力随 token 数平方增长，窗口注意力则线性增长（$M^2$ 为常数）。当 $hw \gg M^2$ 时，后者优势巨大——这是 Swin 能处理高分辨率的根本原因。

3.3 移位窗口（SW-MSA）

窗口划分的代价是窗口之间失去了联系：每个 token 只能看到同窗口内的 $M^2-1$ 个邻居，感受野被锁死在局部。Swin 的解法非常巧妙——在相邻的两层之间，把窗口整体向右下平移 $\lfloor M/2 \rfloor$ 个像素再划分一次：

$$\text{偏移量} = \Big\lfloor \frac{M}{2} \Big\rfloor \quad (\text{默认 } M=7 \Rightarrow \text{偏移 } 3)$$

这样上一层的边界会落到这一层的窗口内部，信息得以跨窗口流动。但偏移会产生尺寸不足 $M\times M$ 的边角窗口。Swin 的处理是循环移位（cyclic shift）：把特征图整体平移，使边角部分补到另一侧，从而保持窗口数不变；同时用注意力掩码阻止原本不相邻的区域互相注意，保证计算等价于真正的分块。

循环移位与掩码：一个容易忽略的实现细节

直接平移会让边缘窗口变小，导致窗口数变化、无法批量并行。Swin 的做法是把特征图循环平移（torch.roll）使窗口数不变，但这会把原本相距很远的区域塞进同一个窗口。为了不让它们互相注意，需要给注意力矩阵加一个掩码：

$$\text{Attn} = \text{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}} + B + \mathbf{M}\right)V, \qquad M_{ij} = \begin{cases} 0, & i,j \text{ 在移位前同属一个窗口} \\ -\infty, & \text{否则} \end{cases}$$

掩码位置填 $-\infty$，经 softmax 后权重为 0，等价于"这些位置互不可见"。这一步保证循环移位后的计算与真实分块完全等价，是 Swin 实现中最容易写错的地方。

3.4 层次化结构与 Patch Merging

Swin 把网络分成 4 个 stage，每个 stage 内保持分辨率不变、堆叠若干 Transformer 块（窗口注意力 + 移位窗口注意力成对出现）；stage 之间通过 Patch Merging 下采样：把 $2\times2$ 邻域内 4 个 token 在通道维拼接（$4C$），再经线性层压回 $2C$。这与 CNN 中"空间减半、通道翻倍"的经典金字塔完全对应。

$$\text{PatchMerging}: \mathbb{R}^{\frac{H}{2^{s}}\times\frac{W}{2^{s}}\times C} \longrightarrow \mathbb{R}^{\frac{H}{2^{s+1}}\times\frac{W}{2^{s+1}}\times 2C}$$

3.5 相对位置偏置

ViT 的绝对位置编码在窗口注意力下不再合适（窗口会移位，绝对坐标失去意义）。Swin 改用相对位置偏置，直接加到注意力得分上：

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d}} + B\right)V, \qquad B \in \mathbb{R}^{M^{2}\times M^{2}}$$

$B$ 中的元素只取决于两个 token 的相对位移，因此取值空间远小于 $M^2 \times M^2$——位移在两个方向上各被裁剪到 $[-M+1, M-1]$，参数表大小为 $(2M-1)^2$。$M=7$ 时仅需 $13\times13=169$ 个偏置参数，比完整的 $49\times49=2401$ 小一个量级。实验显示这一项对精度贡献显著。

3.6 两种注意力的适用边界

维度ViT（全局注意力）Swin（窗口注意力）
注意力范围全图，每个 token 可见所有 token窗口内，$M^2$ 个 token
计算复杂度$O(N^2)$，随分辨率平方增长$O(N)$，随分辨率线性增长
特征尺度单一尺度（$1/16$）四级金字塔（$1/4 \sim 1/32$）
跨区域信息单层即可全局交互需靠窗口移位逐层扩散
作为检测/分割骨干需额外改造（如 ViTDet）开箱即用，直接接 FPN
感受野增长第一层就全局近似卷积式的逐层扩大

两者的取舍本质上是"早全局"还是"晚全局"：ViT 在第一层就让每个 token 看到全图，代价是二次复杂度；Swin 先局部、逐层靠移位扩大感受野，代价是信息扩散需要更多层。对于需要高分辨率的密集预测任务，后者更划算；对于固定低分辨率的分类任务，前者简单有效。

3.7 Swin v2：把模型推到 30 亿参数

Swin v2 的目标是让 Swin 在更大规模下不崩，为此做了三处改动，都是针对"深层大模型训练不稳定"的：

  • 残差后归一化：把 LN 从子层输入侧移到输出侧（即回到 Post-LN 的位置，但配合缩放）。前作 Pre-LN 在大模型上激活值会逐层累积放大，Swin v2 改回后置并配合缩放，使激活幅度稳定。这是 ViT 与 Swin 在归一化位置上的一个直接对立选择，原因是模型规模不同。
  • 余弦注意力：把注意力得分用 $\cos$ 函数缩放替代原来的 $\sqrt{d}$ 缩放，使极值有界，避免大模型下注意力 logits 过大导致训练发散。
  • 对数连续位置偏置：把相对位置偏置从离散参数表改为小型 MLP 对连续相对坐标建模，使模型能在预训练分辨率之外外推到更大窗口与更高分辨率。

Swin v2 用 70 亿张图像（70M 私有数据 + 1.5B 公开数据）预训练出 30 亿参数的模型，在 ImageNet 上达到 84.0% top-1，说明窗口注意力架构确实能随规模扩展。

3.8 PyTorch 实现：移位窗口的掩码

swin_window.py — 窗口划分、循环移位与注意力掩码
import torch

def window_partition(x, M):
    """(B,H,W,C) -> (B*num_win, M, M, C)"""
    B, H, W, C = x.shape
    x = x.view(B, H // M, M, W // M, M, C)
    windows = x.permute(0, 1, 3, 2, 4, 5).contiguous()
    return windows.view(-1, M, M, C)

def window_reverse(windows, M, H, W):
    """窗口还原为特征图，与 window_partition 互逆"""
    B = int(windows.shape[0] / (H * W / M / M))
    x = windows.view(B, H // M, W // M, M, M, -1)
    x = x.permute(0, 1, 3, 2, 4).contiguous()
    return x.view(B, H, W, -1)

def compute_mask(H, W, shift, M):
    """循环移位后，标记哪些 token 原本不属于同一窗口 —— 这些位置将被置 -inf"""
    img_mask = torch.zeros((1, H, W, 1))
    h_slices = (slice(0, -M), slice(-M, -shift), slice(-shift, None))
    w_slices = (slice(0, -M), slice(-M, -shift), slice(-shift, None))
    cnt = 0
    for h in h_slices:
        for w in w_slices:
            img_mask[:, h, w, :] = cnt
            cnt += 1
    mask_windows = window_partition(img_mask, M).view(-1, M * M)
    attn_mask = mask_windows.unsqueeze(1) - mask_windows.unsqueeze(2)
    # 同一原始窗口内 -> 0；否则 -> -100（softmax 后近似 0 权重）
    return attn_mask.masked_fill(attn_mask != 0, float(-100.0))

def shifted_window_attention(x, M=7, shift_size=3, attn=None):
    B, H, W, C = x.shape
    # 1) 循环移位：把特征图整体平移，使边角补到另一侧
    shifted = torch.roll(x, shifts=(-shift_size, -shift_size), dims=(1, 2))
    # 2) 划分窗口 + 带掩码的窗口内注意力
    windows = window_partition(shifted, M).view(-1, M * M, C)
    if attn is not None:
        out = attn(windows, attn_mask=compute_mask(H, W, shift_size, M))
    else:
        out = windows
    # 3) 还原窗口并反向移位，回到原坐标系
    out = window_reverse(out.view(-1, M, M, C), M, H, W)
    return torch.roll(out, shifts=(shift_size, shift_size), dims=(1, 2))

4.2 数据效率线：在 ImageNet-1k 上也能训

DeiT（2020.12）的动机最直接：ViT 需要 JFT-300M，但学术圈拿不到。它证明只用 ImageNet-1k 也能训好 ViT，靠两招——其一是强数据增广（RandAugment、Mixup、CutMix、随机擦除）与正则化（随机深度、标签平滑），其二是蒸馏：引入一个额外的 distillation token，让学生同时模仿教师的输出：

$$\mathcal{L} = (1-\lambda)\,\mathcal{L}_{\text{CE}}\big(\psi(Z_s),\, y\big) + \lambda\,\mathcal{L}_{\text{CE}}\big(\psi(Z_s),\, y_t\big), \qquad y_t = \arg\max_c Z_t(c)$$

关键结论是用 CNN（RegNet）当教师比用同类 Transformer 教师更好——因为学生从教师那里继承的正是它所缺的归纳偏置。DeiT 的另一个副产品是"DeiT 数据量"这个新基准：不再是"要不要 3 亿图"，而是"用对方法，1k 就够"。

CaiT（2021.03）从另一个角度切入：DeiT 证明了能训，但深层 ViT 仍不稳定。CaiT 提出两项改动——LayerScale 给每个残差分支的输出乘一组可学习的小初值缩放系数（初值约 $10^{-4}\sim10^{-6}$），使深层残差接近恒等映射，训练初期更稳；Class-Attention 把网络拆成两段，前段所有 token 一起注意，后段只让 CLS token 注意、patch token 不再更新，减少冗余计算。后者把深层的计算量集中到分类真正需要的部分。

$$\text{LayerScale}: \mathbf{z}_\ell = \mathbf{z}_{\ell-1} + \text{diag}(\lambda_1,\dots,\lambda_D)\cdot \text{MSA}(\text{LN}(\mathbf{z}_{\ell-1})), \quad \lambda_i \sim \mathcal{N}(0, \epsilon)$$

T2T-ViT（2021.01）则质疑 patch 化本身：把图像硬切成 16×16 的块，块内像素结构被展平后可能已经损失。它用一次Tokens-to-Token 模块（递归地把相邻 token 聚合展开）逐步"软"分块，再用更浅的 ViT 处理。

4.3 自监督线：把预训练的成本从"标注"换成"算力"

有监督预训练需要海量标注。自监督的价值在于用无标注图像即可预训练，标注只留给下游微调。

BEiT（2021.06）借鉴 BERT 的掩码语言建模：随机掩掉 40% 的 patch，让模型预测被掩 patch 的离散视觉 token。视觉 token 由一个预先训练好的 dVAE 提供（类似把图像"分词"）。之所以不用像素回归，是因为直接回归像素会让模型关注低级细节、学不到语义——这一点与 MAE 的选择恰好相反，值得对照。

MAE（2021.11）把掩码率提高到 75%，并采用非对称编码器-解码器：编码器只处理可见的 25% patch（大幅省算力），解码器（轻量）负责重建全部 patch。损失只在被掩 patch 上计算：

$$\mathcal{L}_{\text{MAE}} = \frac{1}{|\mathcal{M}|}\sum_{i \in \mathcal{M}} \big\| \hat{\mathbf{y}}_i - \mathbf{x}_i \big\|^{2}, \qquad \mathcal{M} = \text{被掩码 patch 集合}$$

MAE 的关键洞察有两条：其一，高掩码率逼出语义理解——只看到 25% 的图，靠低级插值补不出缺失内容，模型必须理解物体结构；其二，掩码率高反而省算力，因为编码器只见 1/4 token。这里与 BEiT 的分歧（像素回归 vs token 分类）说明：像素重建本身可行，关键是配合足够高的掩码率，避免模型走"复制邻近像素"的捷径。

DINO（2021.04）走第三条路：不重建、不预测 token，而是自蒸馏——同一图像的两个增广视图分别送入学生与教师，让学生匹配教师的输出分布。它用两个技巧防止坍缩：中心化（减去输出的滑动平均中心，避免某一维主导）与锐化（低温 softmax 让分布更尖），配合教师权重的 EMA 更新：

$$P_s(x)^{(i)} = \frac{\exp\!\big(g_s(x)^{(i)}/\tau_s\big)}{\sum_k \exp\!\big(g_s(x)^{(k)}/\tau_s\big)}, \qquad \mathcal{L} = -\sum_i P_t(x')^{(i)} \log P_s(x)^{(i)}$$

DINO 的意外收获是：其注意力图自动呈现清晰的物体分割——完全无监督、无分割标签。这说明自监督 ViT 内部自发形成了物体级表示，也直接启发了后续大量分割工作。

4.4 效率与层次线：把 ViT 变成真正的骨干

这一线已在第 3 章详述 Swin，此处补上同期的其他思路，重点在各自对"稀疏注意力"的不同理解：

  • PVT（2021.02）：最早的 ViT 金字塔方案。用 Spatial Reduction Attention 把 K、V 的空间尺寸缩小 $R$ 倍再算注意力，复杂度降为原来的 $1/R^2$；与 Swin 的区别是它保留了全局注意力的形状，只是降低了分辨率。
  • Twins（2021.04）：交替使用局部窗口注意力与全局下采样注意力（对池化后的全局 token 做注意力），兼顾局部细节与全局建模，同时用位置编码生成器处理可变分辨率。
  • CSWin（2021.07）：把窗口改成十字形——横向与纵向的长条窗口，再拼接。作者观察到"横向/纵向长条"比方形窗口更契合图像的行列结构，且可用更大的窗口而不增加太多计算。
  • Neighborhood Attention（NAT，2022）：用固定稀疏模式（每个 token 只注意邻域）替代窗口，配合专门的 CUDA 核，实现"滑动窗口式"注意力。

4.5 混合结构与多模态

ConViT（2021.03）的动机带有理论色彩：它指出标准自注意力在初始化时等价于一个带特定权重结构的卷积，但训练会把这个结构破坏掉。于是它引入 gated positional self-attention，用一个门控在"卷积分支"与"自注意力分支"之间连续插值，让模型自己决定某层更像卷积还是更像注意力。CvT（2021.03）则更直接：把卷积嵌入注意力内部（用卷积生成 Q、K、V，用深度可分离卷积代替 patch 化），走"卷积与注意力真正融合"的路线。

CLIP（2021.02）把 ViT 带到多模态：用 4 亿图文对做对比学习，让图像编码器（ViT）与文本编码器（Transformer）的输出在共享空间中对齐，从而实现零样本分类——把类别名写成 prompt，与图像算相似度即可分类，不需要任何该类别的训练样本。SigLIP（2023.03）把 CLIP 的 softmax 对比损失换成 sigmoid 形式，解耦了 batch 内全局归一化，使小 batch 训练也稳定，工程上更实用。EVA（2022.11）在掩码重建时以 CLIP 特征为回归目标（而非像素），把"语义级重建"与"无标注数据"结合，是 MAE 路线的自然延伸。ViT-22B（2023.02）把 ViT 推到 220 亿参数，重点解决大规模训练的数值稳定问题（查询-键归一化、并行层），验证了"视觉 Transformer 也遵循某种规模规律"。

5内部机制：registers 与 attention sink

前面几章讨论的都是"架构长什么样"。但 ViT 的实际行为里有一些只靠架构图看不出来、却直接影响训练与部署的现象——它们多在 2023 年前后才被系统研究清楚。本章讨论其中最关键的两个：attention sink 与 registers。

5.1 Attention Sink：softmax 逼出来的"垃圾桶"

先说清一个容易被忽略的约束。自注意力对每个查询 $i$ 都要做一次 softmax 归一化：

$$\alpha_{ij} = \frac{\exp(s_{ij})}{\sum_{j'=1}^{n} \exp(s_{ij'})}, \qquad \sum_{j=1}^{n}\alpha_{ij} = 1 \;\; \text{（强制）}$$

关键在于这个和为 1 是强制的。这意味着：当某个查询位置不需要从任何位置取信息时（比如对应的 patch 是一片无内容的背景），模型无法输出"全零注意力"——它必须把这份概率质量分配到某处。于是模型学会了一个策略：把质量集中投给某个固定且信息量为零的 token，让该 token 的 value 向量在训练中演化成一个近似"空操作"的表示。这个被吸收注意力的位置就称为 attention sink（注意力汇）。

$$\text{sink 条件}: \quad \exists\, s^{*}:\; \sum_{i} \alpha_{i s^{*}} \gg \frac{1}{n}, \qquad \text{且 } s^{*} \text{ 的语义贡献可忽略}$$

最直观的证据来自 [CLS] token 与首个 patch：ViT 中它们经常成为 sink，被几乎所有层大量关注——即便在分类任务里它们并不承载任何具体语义。这个现象并非视觉独有：大语言模型里同样存在 attention sink（首个 token 常被大量关注），并且在长上下文推理中非常关键——如果为了省显存把早期 token 从 KV cache 中删掉，模型输出会崩坏，原因正是丢掉了 sink。

5.2 Registers：给模型一个显式的"垃圾桶"

attention sink 解释了"为什么注意力会跑到无意义的 token 上"，而 registers 是对这一现象的工程化利用。研究者的出发点是另一个观察：ViT 的特征图里存在高范数的离群 token，它们集中在信息量很低的背景区域。这些 token 在推理时承担了 sink 的角色，但它们同时会污染特征——在做分割、深度估计这类需要逐 patch 输出的密集任务时，这些异常值会出现在结果里。

解法出人意料地简单：额外拼接若干个（通常 4 个）可学习的 register token，让它们专门去当 sink，把原本流向背景 patch 的注意力吸收过来。

$$\mathbf{z}_0 = \big[\,\mathbf{x}_{\text{class}};\;\mathbf{r}_1;\dots;\mathbf{r}_K;\;\mathbf{x}_p^1E;\dots;\mathbf{x}_p^{N}E\,\big] + E_{\text{pos}}, \qquad K = 4$$

效果很具体：注意力图变得干净，patch token 之间的注意力恢复正常；在下游密集预测任务上（如 ADE20k 分割、NYUd 深度估计）获得明显提升，且分类精度不受影响。另一个有价值的副产品是，加入 registers 后对模型做 token 剪枝或丢弃更安全——因为信息不再集中存储在少数几个会被误删的 token 里。

5.3 训练稳定性：三件常被低估的小事

ViT 能训到几十层，靠的不只是架构，还有几个实现层面的技巧。它们在论文里往往只占一两行，但去掉就会明显变差。

  • LayerScale（CaiT，见公式 16）：给每个残差分支输出乘一组小初值可学习缩放。深层的残差在初始化时接近恒等映射，梯度可稳定回传。初值越小越稳定，但收敛越慢，实践中常取 $10^{-4}$（浅层）到 $10^{-6}$（深层）。
  • 随机深度（Stochastic Depth / DropPath）：训练时以一定概率整层跳过残差分支，相当于对深度做随机正则。ViT 中常用的丢弃率随层数线性增长（如从 0 到 0.1），浅层保留、深层多丢。
  • 权重衰减与 EMA：ViT 对权重衰减比 CNN 更敏感，通常需要显式设置（约 0.05）；同时用参数的指数滑动平均（EMA）作为最终模型，可显著平滑训练波动。
一个常见误区：Pre-LN 与稳定训练并不等价

ViT 用 Pre-LN 免去了学习率预热，但 Pre-LN 的副作用是残差主干的激活值会随层数累积放大——因为没有在相加之后做归一化，每层的输出量级都在往主干上加。模型小时不明显，规模上去后会出现激活爆炸。这既解释了 Swin v2 为何改回后置归一化（3.7 节），也解释了 ViT-22B 为何要额外做查询-键归一化。"用 Pre-LN 就稳"只在中小规模成立。

5.4 位置编码插值：实现上的两个坑

2.7 节已给出插值的概念形式，实现时有两个细节值得强调。其一是插值必须在二维网格上做：位置编码是按 $14\times14$ 展平存储的，必须先用 reshape 还原成二维，插值后再展平；直接按一维长度插值会破坏空间邻接关系。其二是CLS 的位置编码要单独处理：它不参与二维网格，通常保持原值或单独插值，不能与 patch 编码混在一起。

pos_interp.py — 二维位置编码插值
import torch.nn.functional as F

def interpolate_pos_encoding(pos_embed, num_patches, patch_grid, new_grid):
    """pos_embed: (1, 1+N, D)；patch_grid: 预训练的 (h, w)；new_grid: 目标的 (H, W)"""
    N = pos_embed.shape[1] - 1
    if num_patches == N and patch_grid == new_grid:
        return pos_embed
    # 1) 分离 CLS 与 patch 的位置编码
    cls_pos = pos_embed[:, :1]
    patch_pos = pos_embed[:, 1:]
    D = pos_embed.shape[-1]
    h, w = patch_grid
    H, W = new_grid
    # 2) 还原成二维网格再做双三次插值 —— 不能拉平成一维插值
    patch_pos = patch_pos.reshape(1, h, w, D).permute(0, 3, 1, 2)
    patch_pos = F.interpolate(patch_pos, size=(H, W), mode='bicubic', align_corners=False)
    patch_pos = patch_pos.permute(0, 2, 3, 1).reshape(1, H * W, D)
    # 3) 重新拼回 CLS
    return torch.cat([cls_pos, patch_pos], dim=1)

5.5 注意力距离的层间演化

最后补一个有助于建立直觉的观察：ViT 的注意力平均关注距离随层数显著增长。浅层倾向于关注邻近 patch（行为接近卷积），中层开始跨越中等距离，深层则几乎全局。这与 CNN 通过堆叠扩大感受野的过程相似，但 ViT 是"自发学出来的"，而非结构强制的。

这个演化规律有三点实用含义：其一，它解释了为什么在浅层做局部窗口注意力（Swin、CSWin）代价不大——浅层本来就在看局部；其二，它解释了 DINO 的注意力图为何能自动分割出物体——深层注意力已经具备全局、物体级的组织；其三，它也是"要不要给 ViT 注入卷积先验"这一争论的经验依据：浅层的局部性与卷积先验一致，这也是 ConViT 用门控让浅层偏向卷积的动机。

6DETR：Transformer 作为 decoder 与范式改变

6.1 动机：检测管线里的手工组件

在 DETR 之前，目标检测的主流范式（Faster R-CNN、RetinaNet、YOLO 系列）有一条固定流水线：生成大量候选框 → 逐框分类与回归 → 非极大值抑制（NMS）去重。这条流水线里有两个"不优雅"的地方：

  • 需要人工设计的先验：锚框（anchor）的尺寸、长宽比、数量都要针对数据集调参；正负样本如何分配（哪些框算正样本）也是启发式规则。
  • NMS 是不可微的后处理：它无法参与端到端训练，且需要调 IoU 阈值。阈值稍变，结果就会明显波动。这意味着检测器不能真正"端到端"。

DETR 的动机是把这个管线整体去掉，把检测直接建模成一个集合预测问题：给定图像，输出一个大小固定的预测集合（如 100 个框），其中包含真实物体与"无物体"（∅）两类，然后用一个能处理集合的损失去训练。既然预测集合是"无序"的，NMS 这种"去重"操作在原理上就不再需要——去重由损失函数在训练中完成，而不是由后处理在推理中完成。

6.2 架构：编码器看全局，解码器出集合

DETR 的架构可以清晰地分成三段，其中 Transformer 的角色与第 2 章完全不同——它不再是骨干，而是解码器：

  • CNN 骨干（ResNet）：把图像转成特征图，展平并加位置编码后送入 Transformer。注意这里仍用 CNN 提特征，ViT 尚未接管这一步。
  • Transformer 编码器：全局自注意力。之所以关键，是因为检测需要整图推理——判断"这是一个物体"往往要看它与其他区域的关系（如与旁边物体对比大小）。CNN 的局部感受野需要堆很多层才能建立这种全局依赖，而自注意力一层即可。论文指出编码器的作用类似"把实例从背景中解耦出来"。
  • Transformer 解码器 + object queries：这是 DETR 最核心的设计。解码器有固定的 $N$ 个输入位置，称为 object queries——它们是可学习的向量，不是来自图像。每个 query 通过交叉注意力"查询"编码器输出的特征，最终各自输出一个预测（类别 + 框）。
$$\hat{\mathbf{y}}_i = \big(\hat{p}_i(c),\; \hat{\mathbf{b}}_i\big), \quad i = 1,\dots,N, \qquad N = 100 \text{（远大于图中物体数）}$$

object queries 的直觉可以理解为：模型被分配了 100 个"查询槽位"，每个槽位学习去关注图像的某类位置或模式。因为分配是无序的，所以必须用集合损失来训练——这就是下一节的二分匹配。

6.3 二分图匹配损失：去重的关键

训练时，模型输出 $N=100$ 个预测，而真值只有 $M$ 个物体（$M \ll N$）。由于预测是无序集合，需要先确定"哪个预测对应哪个真值"，这正是一个二分图匹配问题。DETR 用匈牙利算法求使总匹配代价最小的分配 $\hat{\sigma}$：

$$\hat{\sigma} = \arg\min_{\sigma \in \mathfrak{S}_N} \sum_{i=1}^{M} \mathcal{L}_{\text{match}}\big(y_i,\, \hat{y}_{\sigma(i)}\big)$$

匹配代价同时考虑分类与框的位置：

$$\mathcal{L}_{\text{match}}\big(y_i, \hat{y}_{\sigma(i)}\big) = -\mathbb{1}_{\{c_i \neq \varnothing\}}\,\hat{p}_{\sigma(i)}(c_i) + \mathbb{1}_{\{c_i \neq \varnothing\}}\,\mathcal{L}_{\text{box}}\big(b_i, \hat{b}_{\sigma(i)}\big)$$

确定匹配后，计算真正的损失。分类项用交叉熵，框回归项用 L1 与 GIoU 的线性组合——L1 对尺度敏感、GIoU 对尺度不敏感，两者互补，这是 DETR 的一个工程经验：

$$\mathcal{L}_{\text{Hungarian}}(y, \hat{y}) = \sum_{i=1}^{N}\Big[ -\log \hat{p}_{\hat{\sigma}(i)}(c_i) + \mathbb{1}_{\{c_i \neq \varnothing\}}\big(\lambda_{\text{iou}}\mathcal{L}_{\text{GIoU}} + \lambda_{\text{L1}}\|b_i - \hat{b}_{\hat{\sigma}(i)}\|_1\big) \Big]$$
为什么一对一匹配能替代 NMS

NMS 存在的理由是：同一个物体被多个候选框命中，需要去重。而在 DETR 的一对一匹配里，每个真值物体只被分配给一个预测，其余预测被显式监督为"无物体"（∅）。于是模型在训练中学会"一个物体只由一个 query 负责"，冗余预测在源头上就被抑制了。这正是"把去重从后处理搬进损失"的含义——NMS 处理的是结果，匹配损失处理的是动机。

6.5 DETR 的问题与后续改进

DETR 的理念优雅，但原版有两个明显的工程问题，后续工作几乎都是围绕它们展开：

  • 收敛极慢：需要 500 个 epoch 才能收敛，而 Faster R-CNN 只需几十个。原因是交叉注意力在训练初期要"从零学会关注哪里"，且一对一匹配使每个 query 的正样本极其稀疏。Deformable DETR（2021.03）的解法是让注意力只在参考点周围的少量采样点上进行（可变形注意力），把收敛轮数降到约 1/10，同时也降低了高分辨率下的复杂度。
  • 小物体效果差、query 语义不明：object queries 学到的模式不可解释，且多尺度特征利用不足。DAB-DETR（2022.01）把 query 显式定义为 4 维框坐标（$x,y,w,h$），并在解码器逐层细化，让 query 有了明确语义；DN-DETR（2022.03）引入"去噪训练"——给真值框加噪声让解码器重建，缓解一对一匹配的稀疏监督问题；DINO（2022.03，与 4.3 节的自监督 DINO 同名但不同工作）结合对比去噪与混合 query 选择，成为 DETR 系列的强基线。
  • 实时化：RT-DETR（2023.04）通过高效混合编码器与 IoU 感知的 query 选择，把 DETR 推到实时检测的速度区间，证明"无 NMS 的端到端检测"可以实用。
detr_decoder.py — DETR 解码器与 object queries
import torch
import torch.nn as nn
from scipy.optimize import linear_sum_assignment

class DETRDecoder(nn.Module):
    """Transformer 解码器：object queries 通过交叉注意力读取编码器特征"""
    def __init__(self, dim=256, num_queries=100, num_heads=8, num_layers=6):
        super().__init__()
        # object queries：可学习参数，与输入图像无关
        self.query_embed = nn.Parameter(torch.randn(num_queries, dim) * 0.01)
        layer = nn.TransformerDecoderLayer(dim, num_heads, dim * 4,
                                           dropout=0.1, batch_first=True)
        self.decoder = nn.TransformerDecoder(layer, num_layers)

    def forward(self, memory, memory_mask=None):
        # memory: 编码器输出 (B, HW, D)
        B = memory.shape[0]
        queries = self.query_embed.unsqueeze(0).expand(B, -1, -1)
        # 自注意力在 100 个 query 之间，交叉注意力的 K/V 来自编码器
        return self.decoder(queries, memory, memory_key_padding_mask=memory_mask)

def hungarian_match(cost_matrix):
    """二分图匹配：返回 (行索引, 列索引)。要求行数 >= 列数（预测数 >= 真值数）"""
    assert cost_matrix.shape[0] >= cost_matrix.shape[1]
    row, col = linear_sum_assignment(cost_matrix.detach().cpu().numpy())
    return torch.as_tensor(row), torch.as_tensor(col)

7未来方向

前面六章覆盖了视觉 Transformer 的架构、变体、内部机制与一个范式改变的案例。本章讨论仍在演进中的方向，重点说明每个方向要解决的瓶颈是什么，而不是罗列名词。

7.1 效率：把二次复杂度真正降下来

Swin 用窗口注意力把复杂度降到线性，但代价是感受野需要多层才能扩散到全局。真正"既线性又全局"的方案是线性注意力：把 softmax 换成可核化的相似度函数 $\phi(\cdot)$，利用矩阵乘法结合律把 $O(n^2)$ 重排为 $O(n)$：

$$\text{Attn}(Q,K,V)_i = \frac{\phi(q_i)^{\top}\sum_j \phi(k_j)\,v_j^{\top}}{\phi(q_i)^{\top}\sum_j \phi(k_j)}$$

关键变化在于 $\sum_j \phi(k_j)v_j^\top$ 与查询无关，可预先计算一次并被所有 token 复用，于是复杂度从"两两交互"变成"累加统计"。代价是表达能力下降——softmax 的尖锐选择性被削弱，实际精度常不如标准注意力，因此后续工作多采用"局部窗口 + 线性全局"的混合形式（如 FLatten、EfficientViT）。

另一条路线来自序列建模领域：状态空间模型（SSM），以 Mamba 为代表，用线性递推替代注意力：

$$h_t = \bar{A}\,h_{t-1} + \bar{B}\,x_t, \qquad y_t = C\,h_t$$

它的优势是推理时每步代价恒定（与序列长度无关），适合高分辨率密集预测；把 2D 图像按扫描顺序展平为 1D 序列即可套用，视觉 Mamba 系列（Vim、VMamba）即由此而来。目前的开放问题是：扫描顺序破坏了图像的空间邻接，如何在保持线性复杂度的同时恢复二维结构，尚无公认最优解。

7.2 统一骨干：一个模型做多种任务与模态

当前主流的视觉系统仍是"任务专用头 + 共享骨干"。统一化方向有两层含义：任务层面，希望同一骨干（如 ViT 或 Swin）加不同轻量头即可覆盖分类、检测、分割、深度估计（论文标题里的"One Model, Many Tasks"即指此）；模态层面，希望图像与文本、视频、点云共享同一套 Transformer 参数。

这一方向的推进依赖两件事：其一，表示本身足够通用——这也是自监督预训练价值所在，因为它不针对特定标注；其二，输出的统一形式。DETR 的集合预测提供了一个范例：把"检测框、分割掩码、关键点"都表示成"输出槽位 + 属性"，就能共用一个解码头。

7.3 数据效率与自监督：还要不要标注

ViT 的原始结论是"要 3 亿张图"。目前已经用两条路绕开它：更强的正则与蒸馏（DeiT 路线）与自监督预训练（MAE、DINO 路线）。但自监督本身也在遇到新问题：

  • 重建目标的选择。BEiT 用离散 token、MAE 用像素、EVA 用 CLIP 特征。三者的分歧说明"什么才是好的重建目标"仍未定论。当前的经验倾向是：目标越语义化，表示质量越好，但语义目标通常依赖一个已经训练好的教师模型，形成"鸡生蛋"。
  • 掩码策略。MAE 证明高掩码率（75%）优于低掩码率，但这是针对重建目标；若换成对比学习目标，最优掩码率可能完全不同。掩码率与目标的联合设计尚无理论指导。
  • 评估方式。"线性探针"与"微调"给出的排名经常不一致，说明我们还不完全清楚该用哪个指标衡量"表示好坏"。

7.4 内部机制与可解释性

第 5 章的 attention sink 与 registers 提示了一类更一般的研究方向：模型的许多行为由归一化、残差、softmax 这些"非语义约束"决定，而不是由注意力学到的语义模式决定。这类机制往往在规模放大后才显著，且对部署影响直接（token 剪枝、KV cache 压缩、量化）。

可解释性方面，ViT 的注意力图常被当作"解释"，但这一点需要谨慎：注意力权重高不等于因果贡献大（后续层的 value 变换、MLP 与残差都会重新混合信息）。更可靠的解释方法（如基于梯度的归因、消融式探针）在视觉 Transformer 上仍不成熟。DINO 那种"注意力自发形成分割"的现象虽然直观，但它是否等价于模型的"决策依据"，目前没有严格答案。

7.5 与其他范式的融合

  • 与扩散模型结合：扩散模型的去噪网络常直接以 ViT/Swin 为骨干，而"条件于文本或布局生成图像"可控生成，本质上是把结构约束（第 6 章 DETR 的思路）推广到像素生成。
  • 与三维 / 视频结合：三维点云与视频都面临"序列更长"的问题，因此它们对线性注意力与 SSM 的兴趣远高于图像分类任务；视频还引入了时间轴上的因果性，可能需要"时间因果 + 空间双向"的混合注意力。
  • 与高效的推理系统结合：多模态大模型把视觉编码器当作"感知前端"，其输出 token 直接进入语言模型上下文。这使视觉编码器的输出 token 数成为新的瓶颈——一张高分辨率图像动辄产生数千 token，如何压缩视觉 token（如 Q-Former、Perceiver Resampler）成为一个独立研究点。

8.2 核心公式速查

编号公式含义关键点
(1)(2)Patch 嵌入与序列构造$N=HW/P^2$，拼接 CLS 与位置编码
(3)(4)(5)(6)Pre-LN 编码器块与多头注意力先归一化再进子层，梯度不被归一化阻断
(7)分类输出只取 CLS 位置，经 LN 与线性头
(8)位置编码二维插值先 reshape 成二维网格再插值
(9)ViT 复杂度注意力项 $O(N^2D)$ 在 $N$ 大时主导
(10)窗口注意力复杂度由 $(hw)^2 C$ 降为 $M^2hwC$，线性增长
(11)(12)移位窗口与注意力掩码偏移 $\lfloor M/2 \rfloor$，掩码填 $-\infty$
(13)Patch Merging空间减半、通道翻倍，构成金字塔
(14)相对位置偏置参数表 $\propto (2M-1)^2$，远小于 $M^4$
(15)(16)DeiT 蒸馏与 LayerScale教师提供归纳偏置；小初值缩放稳住深层
(17)(18)MAE 与 DINO 损失仅在掩码处重建 vs 自蒸馏匹配分布
(19)(20)Attention sinksoftmax 强制和为 1，质量必须流向某处
(21)Registers额外 4 个可学习 token 专门当 sink
(22)(23)(24)(25)DETR 集合预测与匹配损失匈牙利一对一匹配，替代 NMS
(26)(27)线性注意力与 SSM把 $O(n^2)$ 交互重排为 $O(n)$ 累加

8.4 一页知识图谱

一句话总结

视觉 Transformer 的十年问题可以概括为四次"用什么换什么"：ViT 用数据换掉卷积先验，Swin 用稀疏窗口换掉全局注意力的代价，MAE / DINO 用算力换掉标注依赖，DETR 用匹配损失换掉 NMS 后处理。理解每一次交换的收益与代价，比记住任何一个结构都更有长期价值。
