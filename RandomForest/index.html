一 决策树基础

1.1 什么是决策树

决策树（Decision Tree） 是一种树形结构的监督学习模型，以"分而治之"的策略递归地把特征空间划分为若干互不相交的区域：从根节点出发，每个内部节点对应一个特征上的判定条件（if-then 规则），每个叶子节点给出预测结果。它可解释性极强——任意一条从根到叶的路径都是一条完整的 if-then 规则，人类可以直接阅读并验证。

核心直觉

决策树本质上是一组"层层追问"的规则集：先问最重要的特征（如花瓣长度是否大于 2.45cm），再问次重要的特征，直至可以确定地给出类别。它把复杂的决策过程拆解为一系列简单问题，这正是它直观、易解释的原因。

1.2 信息增益（Information Gain）

决策树划分特征的选择标准是"如何让划分后的数据更纯"。经典度量之一是信息熵（Entropy）：熵越小，数据越纯。数据集 $D$ 的熵定义为：

$$H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k$$

其中 $p_k$ 是第 $k$ 类样本在数据集 $D$ 中占的比例，$K$ 为类别数。若以特征 $A$ 对 $D$ 进行划分（$A$ 有 $V$ 个取值），划分后每个子集 $D_v$ 的熵按样本量加权平均，即条件熵：

$$H(D \mid A) = \sum_{v=1}^{V} \frac{|D_v|}{|D|} H(D_v)$$

信息增益为划分前后熵的减少量，信息增益越大，说明特征 $A$ 带来的"纯度提升"越多：

$$g(D, A) = H(D) - H(D \mid A)$$
ID3 算法

ID3 在每一层直接选择信息增益最大的特征进行划分。其偏好取值较多的特征（如"编号"这种每行一个唯一值的特征会带来最大增益），因此后续 C4.5 引入增益率加以修正。

C4.5 算法：增益率（Gain Ratio）

C4.5（Quinlan, 1993）是 ID3 的后继改进，核心修正用增益率替代信息增益来选择特征。首先定义特征的固有值（Intrinsic Value），衡量特征取值数量的"分裂度"：

$$\text{IV}(A) = -\sum_{v=1}^{V} \frac{|D_v|}{|D|} \log_2 \frac{|D_v|}{|D|}$$

取值越多、各子集越均匀，$\text{IV}(A)$ 越大。增益率定义为信息增益与固有值之比：

$$g_R(D, A) = \frac{g(D, A)}{\text{IV}(A)}$$

C4.5 选择增益率最大的特征。由于 $\text{IV}(A)$ 对取值多的特征施加惩罚，增益率有效抑制了 ID3 对"编号"类高基数特征的偏好。实际中 C4.5 做了两步启发式：先挑出信息增益高于平均的特征，再从中选增益率最大者，避免过度偏向低 IV 的特征。

信息增益计算示例：水果分类

有 6 个水果组成的数据集 $D$：3 个苹果、2 个橙子、1 个香蕉。有两个候选特征——颜色（红/黄）和大小（大/小）。数据如下：

1红大苹果
2红小苹果
3红小苹果
4红大香蕉
5黄小橙子
6黄小橙子

第一步：计算划分前的熵 $H(D)$。三类的比例为 $p_1=3/6$、$p_2=2/6$、$p_3=1/6$：

$$H(D) = -\left(\frac{3}{6}\log_2\frac{3}{6} + \frac{2}{6}\log_2\frac{2}{6} + \frac{1}{6}\log_2\frac{1}{6}\right) \approx 1.459 \text{ bits}$$

第二步：计算颜色的条件熵 $H(D \mid \text{color})$。颜色将 $D$ 分为两个子集：红色 $D_1$（4 个：3 苹果 + 1 香蕉）、黄色 $D_2$（2 个：2 橙子，纯净）。

$$H(D_1) = -\left(\frac{3}{4}\log_2\frac{3}{4} + \frac{1}{4}\log_2\frac{1}{4}\right) \approx 0.811 \text{ bits}$$
$$H(D_2) = -\left(\frac{2}{2}\log_2\frac{2}{2}\right) = 0 \text{ bits} \quad (\text{纯子集})$$
$$H(D \mid \text{color}) = \frac{4}{6} \times 0.811 + \frac{2}{6} \times 0 \approx 0.541 \text{ bits}$$

第三步：计算颜色的信息增益：

$$g(D, \text{color}) = H(D) - H(D \mid \text{color}) = 1.459 - 0.541 = 0.918 \text{ bits}$$

对比：计算大小的信息增益。大小将 $D$ 分为：大 $D_1$（2 个：1 苹果 + 1 香蕉）、小 $D_2$（4 个：2 苹果 + 1 橙子 + 1 香蕉）。

$$H(D_{\text{大}}) = -\left(\frac{1}{2}\log_2\frac{1}{2} + \frac{1}{2}\log_2\frac{1}{2}\right) = 1.000 \text{ bits}$$
$$H(D_{\text{小}}) = -\left(\frac{2}{4}\log_2\frac{2}{4} + \frac{1}{4}\log_2\frac{1}{4} + \frac{1}{4}\log_2\frac{1}{4}\right) = 1.500 \text{ bits}$$
$$H(D \mid \text{size}) = \frac{2}{6} \times 1.000 + \frac{4}{6} \times 1.500 \approx 1.333 \text{ bits}$$
$$g(D, \text{size}) = 1.459 - 1.333 = 0.126 \text{ bits}$$

结论：$g(D, \text{color}) = 0.918 \gg g(D, \text{size}) = 0.126$，ID3 选择颜色作为根节点划分特征。直觉上红色已能区分出大部分苹果、黄色完全区分出橙子，而大小对类别的区分力很弱。

C4.5 增益率验证。两个特征都有 2 个取值，固有值相同：$\text{IV}(\text{color}) = \text{IV}(\text{size}) = 0.918$。增益率：颜色 $g_R = 0.918/0.918 = 1.000$、大小 $g_R = 0.126/0.918 = 0.137$。C4.5 同样选择颜色——当两个特征取值数相同时，增益率排名与信息增益一致。

1.3 基尼指数（Gini Index）

基尼指数是另一种"不纯度"度量：从数据集 $D$ 中随机抽取两个样本，它们类别不同的概率。基尼值越小，数据越纯：

$$\text{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2$$

以特征 $A$ 划分后的加权基尼指数为：

$$\text{Gini}(D, A) = \sum_{v=1}^{V} \frac{|D_v|}{|D|} \, \text{Gini}(D_v)$$

CART 分类树在候选特征中选取基尼指数最小的特征作为最优划分特征，并支持对连续特征做二分。

二 决策树剪枝

2.1 过拟合问题

决策树的归纳偏好是"尽可能拟合训练数据"：如果不加限制地生长，树可以把每个训练样本都单独划进一个叶子，此时训练误差为 0，但泛化能力（对未见数据的预测能力）很差，即过拟合（Overfitting）。随着树深度增加，模型复杂度上升、方差变大，测试误差呈"先降后升"的 U 型曲线。剪枝（Pruning）正是为了在"拟合能力"与"模型复杂度"之间取得平衡。

过拟合信号

训练集准确率接近 100% 而验证集准确率明显偏低；或树深超过特征数时仍持续分裂。出现这些信号就应考虑剪枝、限制深度或改用集成方法。

2.2 预剪枝 vs 后剪枝

策略时机做法优点缺点
预剪枝建树过程中在分裂前评估：若当前划分不能带来验证集性能提升（或节点样本数过少、深度过大），则停止分裂，当前节点直接作为叶子计算开销小、树更矮、抗过拟合强可能"欠拟合"：贪心停止过早，错过后续有增益的分裂
后剪枝树建成后自底向上考察非叶节点：若剪掉该子树（替换为叶子）后验证集性能不下降，则剪掉保留充分生长、效果通常更好计算开销大（需完整建树再评估）

2.3 代价复杂度剪枝（Cost-Complexity Pruning）

CART 采用代价复杂度剪枝（CCP）：把"误差"与"复杂度"放进同一个目标函数，通过一个可调参数 $\alpha$ 权衡。对一棵子树 $T$，定义其代价复杂度：

$$R_{\alpha}(T) = R(T) + \alpha\, |T|$$

其中 $R(T)$ 为子树 $T$ 在训练集（或验证集）上的误分类代价（回归时取平方误差），$|T|$ 为叶子节点个数，$\alpha \geq 0$ 为复杂度惩罚系数。$\alpha$ 越大，树越倾向于"小"（叶子少、结构简单）。CCP 先对完整树生成一组嵌套子树 $T_0 \supset T_1 \supset \dots \supset \{root\}$，再通过交叉验证选择使验证误差最小的 $\alpha$ 及其对应子树。

剪枝的本质

剪枝 = 正则化。深度、叶子最小样本数、$\alpha$ 惩罚项，都是限制模型复杂度的旋钮。集成学习（Bagging / Boosting）则从另一个角度解决同一问题：通过组合多棵树来降低方差或偏差。

三 集成学习概述

3.1 为什么需要集成

集成学习（Ensemble Learning） 的核心思想是"三个臭皮匠，赛过诸葛亮"：训练多个弱学习器（只比随机略好的模型，如浅决策树），再用某种策略把它们组合成一个强学习器。单个弱学习器能力有限、偏差或方差偏大，但多个弱学习器的组合可以互相纠错、互相补充，显著提升整体精度与鲁棒性。

直觉类比

一位医生可能误诊，但多位独立医生会诊后投票，错误会被多数票淹没；类似地，随机森林让成百上千棵"有分歧"的树分别投票，最终答案往往比任何一棵树都可靠。

3.2 Bias-Variance 分解

理解集成学习为什么有效，需要引入偏差-方差分解（Bias-Variance Decomposition）。对回归问题，设真实函数为 $f(x)$，模型预测为 $\hat{f}(x)$，期望误差可分解为三部分：

$$\mathbb{E}\left[\left(y - \hat{f}(x)\right)^2\right] = \text{Bias}^2\big(\hat{f}(x)\big) + \text{Var}\big(\hat{f}(x)\big) + \sigma^2$$
  • 偏差 $\text{Bias}$：模型预测期望与真实值的差距，刻画欠拟合程度（模型太简单）。
  • 方差 $\text{Var}$：模型在不同训练集上的波动幅度——刻画过拟合程度（模型太敏感）。
  • 不可约误差 $\sigma^2$：数据本身的噪声，任何模型都无法消除。

集成学习正是沿着这两条线发力：Bagging 通过平均降低方差，Boosting 通过加权组合降低偏差。

四 Bagging 与随机森林

4.1 Bagging 原理

Bagging（Bootstrap Aggregating，自举汇聚） 由 Breiman 于 1996 年提出，是并行式集成学习的代表。流程分为三步：

  • ① Bootstrap 采样：从原始训练集 $D$（含 $N$ 个样本）有放回地随机抽取 $N$ 个样本，形成子集 $D_1, D_2, \dots, D_M$（约 63.2% 的样本会被抽到，其余构成袋外数据）。
  • ② 并行训练：在每个子集上独立训练一个基学习器（通常为决策树）。
  • ③ 聚合预测：分类采用多数投票，回归采用取平均。

由于 Bootstrap 采样引入了样本扰动，各基学习器之间存在差异，平均/投票后方差被显著降低——这正是"降低方差"这一集成路径的实现机制。

4.2 随机森林的"随机"

随机森林（Random Forest） 是 Bagging + 决策树的组合，由 Breiman 于 2001 年正式提出。它引入了双重随机性：

  • 样本随机：每个基学习器用 Bootstrap 子集训练（与 Bagging 一致）。
  • 特征随机：每次分裂时，只从全部 $d$ 个特征中随机选取 $m$ 个（分类常取 $m = \lfloor \sqrt{d} \rfloor$，回归常取 $m = \lfloor d/3 \rfloor$），在 $m$ 个特征中找最优分裂。这一机制让树与树之间更加"去相关"，进一步压低方差。
为什么特征随机有用

若只做样本扰动，若干棵"最强特征"相同的树会在同一位置分裂，高度相关；投票时它们的错误会"共振"。特征随机让不同的树关注不同的特征子集，错误相互独立，集成效果才真正显现。

4.3 随机森林的预测

  • 分类：每棵树给出类别，最终取多数投票（可叠加样本权重 / 树权重）。
  • 回归：对每棵树的输出取算术平均。

4.4 袋外误差（OOB Error）

由于 Bootstrap 有放回采样，每棵树训练时约有 $1 - 0.632 \approx 36.8\%$ 的样本未被用到，这些样本称为该树的袋外样本（Out-of-Bag, OOB）。对每个样本 $x_i$，用"所有没有在训练时用到它"的那些树做预测，再投票/平均，即可得到 OOB 预测。OOB 误差是免费的交叉验证：无需额外划分验证集，就能在训练过程中估计泛化误差，且随树的数量增加而趋于稳定。

五 随机森林的特征重要性

随机森林不仅能给出高质量预测，还能回答一个关键问题：哪些特征对预测贡献最大？这在实际业务（特征筛选、模型解释、风控审计）中往往与预测本身同等重要。

5.1 基于不纯度下降（Gini Importance）

基于不纯度下降的重要性（也称 MDI，Mean Decrease in Impurity） 统计每个特征在所有树的所有分裂节点上带来的基尼指数下降量，按各节点样本占比加权后累加：

  • 对每棵树的每个分裂节点，计算该节点分裂前后基尼指数的减少量 $\Delta = G_{\text{parent}} - (G_{\text{left}} + G_{\text{right}})$（按样本数加权）。
  • 把 $\Delta$ 归因于该节点使用的特征，在整片森林上累加、再按树数归一化。
  • 最终每个特征得到一个重要性得分，可归一化为百分比，用于排序。

该指标的优点是计算零成本（训练时顺带统计）；缺点是存在偏向连续/高基数特征的偏差，且对特征之间的相关性敏感。

5.2 基于排列重要性（Permutation Importance）

排列重要性（MDA，Mean Decrease in Accuracy） 的思路更直接：

  1. 用训练好的森林计算 OOB 误差 $E_0$。
  2. 对特征 $j$，在 OOB 样本上随机打乱该特征的取值（破坏其与标签的关联），再预测并计算误差 $E_j$。
  3. 重要性 = $E_j - E_0$（误差上升越多，说明该特征越重要）。

相比 Gini 重要性，置换重要性不易被高基数特征带偏，是更"诚实"的度量，但需要额外计算（对每个特征重测一遍）。

两种重要性 ≠ 因果重要性

无论是 Gini 重要性还是置换重要性，度量的都是统计关联而非因果效应。若两个特征强相关，重要性会被"分摊"，排序结果可能误导因果判断。

5.3 SHAP 值简介

SHAP（SHapley Additive exPlanations） 源自合作博弈论的 Shapley 值，为每个样本的每个特征给出一个加性贡献值：预测值 = 基线值 + 各特征 SHAP 值之和。其性质优良：

  • 可加性：$\text{SHAP}(x_1) + \dots + \text{SHAP}(x_d) = f(x) - \mathbb{E}[f]$。
  • 局部解释：单样本层面解释"为什么这个样本被判为 X"。
  • 全局汇总：对全部样本的 |SHAP| 取平均，得到全局特征重要性排序，比 Gini/置换更稳定。

随机森林是 SHAP 最常见的应用场景之一（配合 TreeSHAP 可在线性时间内精确求解），是"模型可解释性"事实标准。

六 Boosting 概述

6.1 Boosting 的核心思想

Boosting（提升） 是串行式集成学习的总称：逐个训练基学习器，每个新学习器都致力于纠正前面所有学习器犯的错误，最终把所有学习器按一定权重组合起来。与 Bagging 降低方差不同，Boosting 走的是降低偏差的路线——即使基学习器很弱（准确率略高于 0.5），经过多轮迭代也能组合出强学习器。

直觉类比

就像"错题本"学习法：第一轮复习后找出仍然做错的题，第二轮重点攻克这些错题；每轮都聚焦上一轮的错误，整体水平逐步提升。

6.2 加法模型与前向分步算法

Boosting 家族（AdaBoost、GBDT、XGBoost）都可以统一到加法模型（Additive Model）框架下：最终模型是一组基学习器 $b_m(x)$ 的加权求和：

$$F_M(x) = \sum_{m=1}^{M} \beta_m \, f_m(x)$$

直接联合优化所有 $(\beta_m, f_m)$ 是困难的，因此采用前向分步算法（Forward Stagewise Algorithm）：从 $m=1$ 到 $M$ 逐轮求解——每轮只优化当前新增的学习器，固定之前已经学到的部分：

$$(\beta_m, f_m) = \arg\min_{\beta, f} \sum_{i=1}^{N} L\left(y_i, \; F_{m-1}(x_i) + \beta f(x_i)\right)$$

6.3 指数损失函数与 AdaBoost 关系

当损失函数取指数损失 $L(y, F(x)) = \exp(-y F(x))$（其中 $y \in \{-1, +1\}$）时，前向分步算法推出的加权更新规则恰与 AdaBoost 完全等价——这是统计学习视角对 AdaBoost 的标准解释：

$$L(y, F(x)) = e^{-y F(x)}$$

指数损失对错分样本施加指数级惩罚，天然地在每轮迭代中"放大"难样本的权重，这正是 AdaBoost 权重更新机制的内在原因。

七 AdaBoost

7.1 AdaBoost 算法流程

AdaBoost（Adaptive Boosting，自适应提升） 由 Freund 与 Schapire 于 1995 年提出，是第一个实用化、理论完备的 Boosting 算法。输入带标签样本集 $D = \{(x_1, y_1), \dots, (x_N, y_N)\}$，$y_i \in \{-1, +1\}$，弱学习器算法 $\mathcal{A}$，迭代轮数 $M$：

  1. 初始化：样本权重 $w_i^{(1)} = 1/N, \; i = 1, \dots, N$。
  2. 迭代 $m = 1, 2, \dots, M$：
    1. 在权重 $w^{(m)}$ 下训练弱分类器 $f_m(x)$，使其加权误差最小。
    2. 计算加权错误率 $\epsilon_m = \frac{\sum_i w_i^{(m)} \mathbb{I}[f_m(x_i) \neq y_i]}{\sum_i w_i^{(m)}}$。
    3. 计算弱分类器权重 $\alpha_m$（见公式 (12)）。
    4. 更新样本权重（见公式 (11)），并归一化。
  3. 输出：加权组合的最终强分类器（见公式 (13)）。

7.2 样本权重更新

每轮迭代后，提高被分错样本的权重、降低被分对样本的权重，使下一轮弱学习器被迫更关注"难样本"：

$$w_i^{(m+1)} = w_i^{(m)} \cdot \exp\left(-\alpha_m \, y_i \, f_m(x_i)\right), \quad \text{再归一化至 } \sum_i w_i = 1$$

7.3 弱分类器权重

每个弱分类器的发言权重由它的错误率决定——错误率越低，权重越大：

$$\alpha_m = \frac{1}{2} \ln \frac{1 - \epsilon_m}{\epsilon_m}$$

当 $\epsilon_m < 0.5$ 时 $\alpha_m > 0$，错误率越低 $\alpha_m$ 越大；若某轮 $\epsilon_m \geq 0.5$（弱于随机猜测），则停止迭代或翻转分类器。

7.4 最终分类器

八 梯度提升树（GBDT）

8.1 梯度提升的核心思想

梯度提升（Gradient Boosting） 由 Friedman 于 1999 年系统化提出，是 AdaBoost 之后 Boosting 家族最重要的一次升级：不再依赖指数损失的特殊形式，而是用损失函数的负梯度（pseudo-residual）来指导每轮新树的拟合。任何可微损失函数都可以套进这个框架——回归用平方误差，分类用对数几率损失，排序用 LambdaRank 等。

从"加权错分"到"拟合残差"

AdaBoost 通过调整样本权重来间接纠正错误；GBDT 则直接计算当前模型对每个样本的负梯度（即"还差多少"），让新树去拟合这个残差——每棵树都在"补课"，逐步逼近最优模型。

8.2 损失函数的负梯度（Pseudo-Residual）

对当前集成模型 $F_{m-1}(x)$，第 $m$ 轮针对每个样本 $x_i$ 计算损失函数 $L$ 关于当前预测值的负梯度，作为该轮的"伪残差"：

$$r_{im} = -\left[ \frac{\partial L\big(y_i, F(x_i)\big)}{\partial F(x_i)} \right]_{F(x) = F_{m-1}(x)}$$

当 $L$ 取平方误差 $L = \frac{1}{2}(y - F)^2$ 时，负梯度恰好是 $y_i - F_{m-1}(x_i)$——即普通残差；取指数损失时退化为 AdaBoost。这一观点把"梯度下降"从参数空间推广到了函数空间。

8.3 GBDT 回归算法流程

  1. 初始化：$F_0(x) = \arg\min_c \sum_i L(y_i, c)$（平方损失下即样本均值）。
  2. 对 $m = 1, \dots, M$：
    1. 计算伪残差 $r_{im}$（公式 (11)）。
    2. 用回归树拟合 $\{(x_i, r_{im})\}$，得到叶子区域 $R_{jm}$。
    3. 对每个叶子求最优输出 $c_{jm} = \arg\min_c \sum_{x_i \in R_{jm}} L\big(y_i, F_{m-1}(x_i) + c\big)$。
    4. 更新模型 $F_m(x) = F_{m-1}(x) + \nu \sum_j c_{jm} \mathbb{I}[x \in R_{jm}]$，其中 $\nu$ 为学习率（shrinkage）。
  3. 输出 $F_M(x)$。

8.4 GBDT 分类（对数几率损失）

二分类场景采用对数几率损失（Logistic Loss） $L(y, F) = \log\big(1 + e^{-2yF}\big)$（$y \in \{-1, +1\}$），其负梯度为：

$$\tilde{r}_{im} = \frac{2 y_i}{1 + e^{2 y_i F_{m-1}(x_i)}}$$

最终的输出经 sigmoid 变换 $p = 1 / (1 + e^{-2F(x)})$ 得到类别概率。多分类则采用 One-vs-Rest 叠加 softmax 变换。

九 XGBoost

9.1 XGBoost 的目标函数

XGBoost（eXtreme Gradient Boosting） 由陈天奇等于 2014 年提出，是 GBDT 的极致工程化版本。与经典 GBDT 相比，它在目标函数中显式加入正则化项（叶子数 + 叶子权重的 L2 惩罚），从源头控制模型复杂度、抑制过拟合：

$$\mathcal{L}^{(t)} = \sum_{i=1}^{N} L\left(y_i, \; \hat{y}_i^{(t-1)} + f_t(x_i)\right) + \Omega(f_t), \qquad \Omega(f) = \gamma T + \frac{1}{2}\lambda \sum_{j=1}^{T} w_j^2$$

其中 $T$ 为叶子数，$w_j$ 为叶子得分，$\gamma$、$\lambda$ 为正则系数。

9.2 二阶泰勒展开近似

经典 GBDT 只利用一阶导数（负梯度），XGBoost 则对损失函数做二阶泰勒展开，同时利用一阶导 $g_i$ 与二阶导 $h_i$，逼近精度更高、收敛更快：

$$\mathcal{L}^{(t)} \approx \sum_{i=1}^{n} \left[ L(y_i, \hat{y}_i^{(t-1)}) + g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i) \right] + \Omega(f_t)$$

其中 $g_i = \partial_{\hat{y}^{(t-1)}} L(y_i, \hat{y}^{(t-1)})$，$h_i = \partial^2_{\hat{y}^{(t-1)}} L(y_i, \hat{y}^{(t-1)})$。由于常数项不影响优化，目标简化为对每个叶子求解最优权重 $w_j^* = -G_j / (H_j + \lambda)$，并按"增益公式" $\text{Gain} = \frac{1}{2}\left[\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right] - \gamma$ 决定是否分裂。

9.3 XGBoost 的工程优化

  • 列采样（Column Subsampling）：类似随机森林的特征随机，进一步降低方差、加速训练。
  • 缺失值处理：自动学习缺失值的最优默认方向（把缺失样本分到增益更大的一侧）。
  • 直方图/近似分位点：对连续特征按分位数候选分裂点，降低寻找最优分裂的计算量。
  • 并行化与缓存感知：按特征块预排序、支持多线程并行计算梯度统计；用缓存感知访问（Cache-Aware Access）优化 IO。
  • early stopping 与原生交叉验证：训练时内置早停与 CV 支持。

十 LightGBM 与 CatBoost

10.1 LightGBM：Leaf-wise 生长策略、直方图算法、GOSS、EFB

LightGBM 由微软于 2017 年提出，主打"更快、更省内存"，四项核心技术：

  • 直方图算法（Histogram-based）：把连续特征离散为固定数量的分箱，以直方图统计代替逐点排序，训练速度与内存占用大幅下降。
  • Leaf-wise 生长策略：每次选择增益最大的叶子进行分裂（而非按层生长），在相同叶子数下精度更高；配合 max_depth 限制防止过拟合。
  • GOSS（Gradient-based One-Side Sampling）：保留梯度大的样本，对梯度小的样本随机采样——只靠"难样本"估算分裂增益，进一步提速。
  • EFB（Exclusive Feature Bundling）：把互斥（几乎不同时为非零）的稀疏特征捆绑成单一特征，减少特征维数。

10.2 CatBoost：类别特征处理、Ordered Boosting

CatBoost 由 Yandex 于 2017 年发布，最擅长处理高基数类别特征：

  • 类别特征原生支持：用"目标编码 + 有序统计"（基于目标均值与先验）把类别特征转为数值，避免独热编码爆炸。
  • Ordered Boosting：在每轮迭代中，当前样本的预测只由"在该样本之前"的样本训练出的模型给出，避免经典 GBDT 中因目标泄漏导致的预测偏移（Prediction Shift），对噪声标签也更鲁棒。
  • 对称树（Oblivious Tree）：同一深度所有节点用相同分裂特征，天然支持 GPU 并行且不易过拟合。

import numpy as np

# 简易 CART 决策树（分类，基尼指数，numpy 实现，递归建树）
def gini(labels):
    n = len(labels)
    if n == 0:
        return 0.0
    _, counts = np.unique(labels, return_counts=True)
    p = counts / n
    return 1.0 - float((p ** 2).sum())

class Node:
    def __init__(self, feat=None, thr=None, left=None, right=None, cls=None):
        self.feat = feat
        self.thr = thr
        self.left = left
        self.right = right
        self.cls = cls  # 叶子节点的类别

class DecisionTree:
    def __init__(self, max_depth=3, min_leaf=1):
        self.max_depth = max_depth
        self.min_leaf = min_leaf

    def fit(self, X, y):
        self.n_classes = int(np.max(y)) + 1
        self.root = self._build(X, y, 0)
        return self

    def _build(self, X, y, depth):
        if depth >= self.max_depth or len(np.unique(y)) == 1 or len(y) <= self.min_leaf:
            return Node(cls=int(np.bincount(y, minlength=self.n_classes).argmax()))
        best = None
        n_feat = X.shape[1]
        for f in range(n_feat):
            vals = np.unique(X[:, f])
            for t in (vals[:-1] + vals[1:]) / 2.0:  # 候选切分点
                mask = X[:, f] <= t
                if mask.sum() < self.min_leaf or (~mask).sum() < self.min_leaf:
                    continue
                gain = G_gain(y, y[mask], y[~mask])
                if best is None or gain > best[0]:
                    best = (gain, f, t)
        if best is None or best[0] <= 0:
            return Node(cls=int(np.bincount(y, minlength=self.n_classes).argmax()))
        _, f, t = best
        mask = X[:, f] <= t
        return Node(feat=f, thr=t,
                    left=self._build(X[mask], y[mask], depth + 1),
                    right=self._build(X[~mask], y[~mask], depth + 1))

    def predict(self, X):
        return np.array([self._predict_one(x, self.root) for x in X])

    def _predict_one(self, x, node):
        while node.cls is None:
            node = node.left if x[node.feat] <= node.thr else node.right
        return node.cls

def G(y):
    n = len(y)
    _, c = np.unique(y, return_counts=True)
    p = c / n
    return 1.0 - float((p ** 2).sum())

def G_gain(y, yl, yr):
    return G(y) - (len(yl) * G(yl) + len(yr) * G(yr)) / len(y)

import numpy as np

# 随机森林: Bootstrap 采样 + 特征随机 + 多数投票
class Node:
    def __init__(self, feat=None, thr=None, left=None, right=None, cls=None):
        self.feat, self.thr = feat, thr
        self.left, self.right = left, right
        self.cls = cls

def gini(y):
    _, c = np.unique(y, return_counts=True)
    p = c / len(y)
    return 1.0 - float((p ** 2).sum())

class Tree:
    def __init__(self, max_depth=4, min_leaf=2, m_feat=None):
        self.max_depth, self.min_leaf, self.m_feat = max_depth, min_leaf, m_feat
        self.n_cls = None

    def fit(self, X, y):
        self.n_cls = int(np.max(y)) + 1
        self.root = self._build(X, y, 0)
        return self

    def _build(self, X, y, d):
        if d >= self.max_depth or len(np.unique(y)) == 1:
            return Node(cls=int(np.bincount(y, minlength=self.n_cls).argmax()))
        n_feat = X.shape[1]
        m = self.m_feat if self.m_feat else int(np.sqrt(n_feat))
        feats = np.random.choice(n_feat, m, replace=False)
        best = None
        for f in feats:
            v = np.unique(X[:, f])
            for t in (v[:-1] + v[1:]) / 2.0:
                msk = X[:, f] <= t
                if msk.sum() < self.min_leaf or (~msk).sum() < self.min_leaf:
                    continue
                g = gini(y) - (len(y[msk]) * gini(y[msk]) + len(y[~msk]) * gini(y[~msk])) / len(y)
                if best is None or g > best[0]:
                    best = (g, f, t)
        if best is None or best[0] <= 1e-6:
            return Node(cls=int(np.bincount(y, minlength=self.n_cls).argmax()))
        _, f, t = best
        msk = X[:, f] <= t
        return Node(feat=f, thr=t,
                    left=self._build(X[msk], y[msk], d + 1),
                    right=self._build(X[~msk], y[~msk], d + 1))

    def predict(self, X):
        return np.array([self._go(x, self.root) for x in X])

    def _go(self, x, node):
        while node.cls is None:
            node = node.left if x[node.feat] <= node.thr else node.right
        return node.cls


class RandomForest:
    def __init__(self, n_trees=20, max_depth=4, m_feat=None):
        self.n_trees, self.max_depth, self.m_feat = n_trees, max_depth, m_feat

    def fit(self, X, y):
        n = len(X)
        self.trees = []
        for _ in range(self.n_trees):
            idx = np.random.choice(n, n, replace=True)  # Bootstrap
            t = Tree(self.max_depth, 1, self.m_feat).fit(X[idx], y[idx])
            self.trees.append(t)
        return self

    def predict(self, X):
        votes = np.array([t.predict(X) for t in self.trees])  # (T, N)
        return np.array([np.bincount(votes[:, i]).argmax() for i in range(len(X))])

    def oob_error(self, X, y):
        n = len(X)
        wrong = 0.0
        total = 0.0
        for i in range(n):
            votes = []
            for t in self.trees:
                # 近似: 用所有树对自身训练样本外评估
                votes.append(t.predict([X[i]])[0])
            if votes:
                total += 1.0
                pred = max(set(votes), key=votes.count)
                if pred != y[i]:
                    wrong += 1.0
        return wrong / max(total, 1.0)

以决策桩（stump）为弱分类器，每轮更新样本权重、计算分类器权重 $\alpha_m$，最终加权投票：

adaboost.py
import numpy as np

# AdaBoost: 样本权重更新 + 弱分类器（决策桩）加权组合
class Stump:
    def __init__(self):
        self.f, self.t, self.polarity, self.alpha = None, None, 1, None

    def fit(self, X, y, w):
        n, d = X.shape
        best = None
        for f in range(d):
            v = np.unique(X[:, f])
            for t in (v[:-1] + v[1:]) / 2.0:
                for pol in (1, -1):
                    pred = np.where(X[:, f] <= t, pol, -pol)
                    err = w[(pred != y)].sum()
                    if best is None or err < best[0]:
                        best = (err, f, t, pol)
        self.feat, self.t, self.polarity = best[1], best[2], best[3]
        return self

    def predict(self, X):
        return np.where(X[:, self.feat] <= self.t, self.polarity, -self.polarity)


class AdaBoost:
    def __init__(self, n_estimators=20):
        self.n_estimators = n_estimators
        self.stumps = []

    def fit(self, X, y):
        n = len(X)
        w = np.full(n, 1.0 / n)
        for _ in range(self.n_estimators):
            stump = Stump().fit(X, y, w)
            pred = stump.predict(X)
            err = w[(pred != y)].sum() + 1e-10
            if err >= 0.5:
                break
            alpha = 0.5 * np.log((1.0 - err) / err)
            stump.alpha = alpha
            w = w * np.exp(-alpha * y * pred)
            w = w / w.sum()
            self.stumps.append(stump)
        return self

    def predict(self, X):
        score = np.zeros(len(X))
        for s in self.stumps:
            score += s.alpha * s.predict(X)
        return np.where(score > 0, 1, -1)

11.4 GBDT 回归（负梯度拟合 + 学习率缩减）

用平方损失下的残差作为负梯度，逐轮用回归树拟合残差，并以学习率（shrinkage）缩减每棵树贡献：

gbdt.py
import numpy as np

# GBDT 回归：负梯度（残差）拟合 + 学习率缩减，numpy 实现
class GBDT:
    def __init__(self, n_estimators=50, lr=0.1, max_depth=2):
        self.n_estimators = n_estimators
        self.lr = lr
        self.max_depth = max_depth
        self.trees = []

    def fit(self, X, y):
        self.base = float(y.mean())
        F = np.full(len(y), self.base)
        for _ in range(self.n_estimators):
            r = y - F  # 平方损失 => 负梯度就是残差
            tree = self._fit_reg_tree(X, r, 0)
            pred = self._pred_tree(X, tree)
            F = F + self.lr * pred
            self.trees.append(tree)
        return self

    def _pred_tree(self, X, node):
        if 'val' in node:
            return np.full(len(X), node['val'])
        m = X[:, node['f']] <= node['t']
        out = np.empty(len(X))
        out[m] = self._pred_tree(X[m], node['l'])
        out[~m] = self._pred_tree(X[~m], node['r'])
        return out

    def _fit_reg_tree(self, X, y, d):
        # 递归回归树（numpy）
        node = {}
        if d >= self.max_depth or len(np.unique(y)) < 2:
            node['val'] = float(y.mean())
            return node
        best = None
        for f in range(X.shape[1]):
            v = np.unique(X[:, f])
            for t in (v[:-1] + v[1:]) / 2.0:
                m = X[:, f] <= t
                if m.sum() < 1 or (~m).sum() < 1:
                    continue
                sse = ((y - y.mean()) ** 2).sum()
                sse_l = ((y[m] - y[m].mean()) ** 2).sum()
                sse_r = ((y[~m] - y[~m].mean()) ** 2).sum()
                gain = sse - sse_l - sse_r
                if best is None or gain > best[0]:
                    best = (gain, f, t)
        if best is None or best[0] <= 1e-6:
            node['val'] = float(y.mean())
            return node
        _, f, t = best
        m = X[:, f] <= t
        node['f'], node['t'] = f, t
        node['l'] = self._fit_reg_tree(X[m], y[m], d + 1)
        node['r'] = self._fit_reg_tree(X[~m], y[~m], d + 1)
        return node

    def _pred_one(self, x, node):
        if 'val' in node:
            return node['val']
        return self._pred_one(x, node['l'] if x[node['f']] <= node['t'] else node['r'])

    def predict(self, X):
        out = np.full(len(X), self.base)
        for i in range(len(X)):
            for tree in self.trees:
                out[i] += self.lr * self._pred_one(X[i], tree)
        return out

11.5 XGBoost 简化版（二阶导数 + 正则化）

演示 XGBoost 的核心机制：利用一阶导 $g_i$ 与二阶导 $h_i$，配合 $\gamma/\lambda$ 正则计算分裂增益与叶子权重闭式解：

xgboost_approx.py
import numpy as np

# XGBoost 简化版：二阶泰勒展开 + 正则化（gamma/lambda），numpy 实现
class XGBTree:
    """叶子权重可求闭式解的单棵回归树"""
    def __init__(self, max_depth=2, gamma=0.0, lam=1.0):
        self.max_depth = max_depth
        self.gamma = gamma
        self.lam = lam

    def _gain(self, G, H, GL, HL, GR, HR):
        left = GL * GL / (HL + self.lam)
        right = GR * GR / (HR + self.lam)
        whole = (GL + GR) ** 2 / (HL + HR + self.lam)
        return 0.5 * (left + right - whole) - self.gamma

    def _build(self, X, g, h, d):
        node = {'w': -(g.sum()) / (h.sum() + self.lam), 'l': None, 'r': None}
        if d >= self.max_depth or len(X) < 2:
            node['leaf'] = node['w']
            return node
        best = None
        for f in range(X.shape[1]):
            v = np.unique(X[:, f])
            for t in (v[:-1] + v[1:]) / 2.0:
                m = X[:, f] <= t
                if m.sum() < 1 or (~m).sum() < 1:
                    continue
                gain = self._gain(g.sum(), h.sum(), g[m].sum(), h[m].sum(), g[~m].sum(), h[~m].sum())
                if best is None or gain > best[0]:
                    best = (gain, f, t)
        if best is None or best[0] <= 0:
            node['leaf'] = node['w']
            return node
        _, f, t = best
        m = X[:, f] <= t
        node['f'], node['t'] = f, t
        node['l'] = self._build(X[m], g[m], h[m], d + 1)
        node['r'] = self._build(X[~m], g[~m], h[~m], d + 1)
        return node

    def fit(self, X, g, h):
        self.root = self._build(X, g, h, 0)
        return self

    def _score(self, x, n):
        while n['l'] is not None:
            n = n['l'] if x[n['f']] <= n['t'] else n['r']
        return n['leaf']

    def predict(self, X):
        return np.array([self._score(x, self.root) for x in X])


class SimpleXGB:
    def __init__(self, n_estimators=30, lr=0.3, max_depth=2, gamma=0.0, lam=1.0):
        self.n_estimators = n_estimators
        self.lr = lr
        self.max_depth = max_depth
        self.gamma = gamma
        self.lam = lam
        self.trees = []

    def fit(self, X, y):
        self.base = float(y.mean())
        F = np.full(len(y), self.base)
        for _ in range(self.n_estimators):
            g = F - y                       # 一阶导 dL/dF（平方损失）
            h = np.ones(len(y))             # 二阶导 = 1
            tree = XGBTree(self.max_depth, self.gamma, self.lam).fit(X, g, h)
            F = F + self.lr * tree.predict(X)
            self.trees.append(tree)
        return self

    def predict(self, X):
        out = np.full(len(X), self.base)
        for t in self.trees:
            out = out + self.lr * t.predict(X)
        return out

11.6 随机森林特征重要性评估（不纯度下降）

统计各特征在所有分裂节点带来的基尼下降量并归一化，区分"区分性特征"与"噪声特征"：

feature_importance.py
import numpy as np

# 特征重要性评估：不纯度下降（Gini importance）
# 复用上文随机森林实现中的 Tree，这里单独演示 Gini importance 统计

def gini_imp(labels):
    n = len(labels)
    if n == 0:
        return 0.0
    _, c = np.unique(labels, return_counts=True)
    p = c / n
    return 1.0 - float((p ** 2).sum())


class ImpTree:
    """记录每次分裂带来的不纯度下降，归属到对应特征"""
    def __init__(self, max_depth=3):
        self.max_depth = max_depth
        self.imp = {}          # feat -> 累积下降量
        self.n_cls = None

    def fit(self, X, y):
        self.n_cls = int(np.max(y)) + 1
        self._build(X, y, 0)
        return self

    def _build(self, X, y, d):
        if d >= self.max_depth or len(np.unique(y)) == 1:
            return
        best = None
        g0 = gini_imp(y)
        for f in range(X.shape[1]):
            v = np.unique(X[:, f])
            for t in (v[:-1] + v[1:]) / 2.0:
                m = X[:, f] <= t
                if m.sum() < 1 or (~m).sum() < 1:
                    continue
                gain = g0 - (len(y[m]) * gini_imp(y[m]) + len(y[~m]) * gini_imp(y[~m])) / len(y)
                if best is None or gain > best[0]:
                    best = (gain, f, t)
        if best is None or best[0] <= 0:
            return
        _, f, t = best
        self.imp[f] = self.imp.get(f, 0.0) + best[0]
        m = X[:, f] <= t
        self._build(X[m], y[m], d + 1)
        self._build(X[~m], y[~m], d + 1)

12.2 工程选型建议

  • 解释性要求高 → 决策树（或单棵 CART + 规则导出）。
  • 通用分类/回归、开箱即用 → 随机森林（几乎无需调参就有不错效果，还能给出特征重要性）。
  • 追求最高精度 → XGBoost / LightGBM（梯度提升家族在结构化数据上通常最优）。
  • 大规模数据 → LightGBM（直方图 + GOSS 在亿级样本下依然可行）。
  • 类别特征多 → CatBoost（原生目标编码处理高基数类别特征）。

十三 演进时间线与总结

13.1 发展时间线

从单棵决策树到梯度提升框架，集成学习走过了 30 余年。下图给出关键里程碑的总览：

分类回归树与代价复杂度剪枝，随机森林的基学习器。
1986

1993

增益率 + 连续特征 + 剪枝，决策树实用化标杆。

2014

13.2 总结：从单棵树到集成学习的演进脉络

回望整条演进路径，可以提炼出三条主线：

  • 从"单模型"到"组合模型"：单棵决策树受限于偏差/方差的固有权衡，集成学习通过"并行平均"（Bagging）与"串行纠错"（Boosting）两条路线突破单模型天花板。
  • 从"启发式"到"优化式"：分裂准则从信息增益/基尼指数等启发式，演进为 XGBoost 的目标函数 + 二阶泰勒展开 + 显式正则——一切分裂决策都被纳入一个可优化的整体目标。
  • 从"算法"到"工程系统"：LightGBM 的直方图与 GOSS、CatBoost 的有序编码、三大框架的 GPU/分布式支持，说明树模型竞争的主战场已经从"算法思想"转向"工程效率与易用性"。
给实践者的核心结论

结构化数据建模的实战顺序清晰可循：随机森林保底 → 梯度提升（XGBoost/LightGBM/CatBoost）冲精度 → SHAP 做解释。理解本文的偏差-方差分解、负梯度拟合与二阶优化三条思想主线，足以应对绝大多数表格数据建模任务。
